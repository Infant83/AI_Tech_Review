## Reliability Notes

1. The YouTube video and companion deck are useful as a discovery map, not as primary evidence.
2. Official product pages and GitHub repositories confirm several platform shifts: Opus 4.7, Agent SDK, plugin marketplaces, MCP, Google Workspace CLI, Cognee, Seedance, Railway, OpenClaw, and Claude Code releases.
3. Anthropic `$30B ARR` and `OpenAI $25B` are widely repeated in media and newsletters, but the strongest accessible sources trace the figure to Bloomberg or secondary reporting. Treat as a high-salience market signal, not audited financial disclosure.
4. Claude Mythos is strong evidence for a cybersecurity capability and governance shift, but claims about internal productivity, regulator emergency meetings, or architectural flywheels are not independently confirmed from official material.
5. Labor-market data remains source-dependent. Layoffs.fyi and TrueUp differ materially by methodology, and job postings do not equal actual hiring.

## Initial Observations

1. The dominant theme is the agent operating layer: model, harness, tools, MCP, memory, workflow UI, permissions, and deployment.
2. Anthropic's week is unusually dense because model release, SDK, plugin distribution, Claude Code updates, and Mythos security framing all point in the same direction.
3. Personal and enterprise AI stacks are converging. The same ingredients appear in Claude Code, OpenClaw, Hermes Agent, Google Workspace CLI, Cognee, Obsidian workflows, and browser or desktop agents.
4. The deck should not over-index on leaderboard rankings. The more durable insight is that the competition is shifting from "best model" to "who owns the agent execution surface."
