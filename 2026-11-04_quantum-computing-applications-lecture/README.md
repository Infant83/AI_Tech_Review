## 공개판 편집

원판 114쪽의 순서·수식·표·그림·공식 출처 링크를 보존하며 개인 대화 링크·출처와 전달·편집 경위만 정제했다. 원본과 변경 사각형 밖 픽셀을 전 페이지 비교한다. 수정본은 `output/pdf/`, 웹 자산은 `dist/`에 있다. 원본·개인 메시지·출처 수집 파일과 QA 이미지는 Git·웹 배포에서 제외한다. `artifacts/prepare_public.py`는 원본 해시를 확인한 뒤 공개판을 만들며 등록·배포를 실행하지 않는다.

원판에 남은 회차별 초안·예정일 표기는 제작 이력이며 실제 학습자 응답이나 미래 실험의 관찰을 뜻하지 않는다. 공개판 등록일은 2026-11-04다. 과학적 내용은 작은 행렬·전수 탐색·합성 입력·상태벡터 계산과 직접 유도의 범위로 읽는다.
