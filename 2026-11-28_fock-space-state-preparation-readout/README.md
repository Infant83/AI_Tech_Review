# 광자 수를 모아 작은 변위를 읽다

2026-11-26 Daily Research Brief의 Fock 공간 상태 준비·센싱 기획을 사용자의 2026-11-28 주제 선택에 따라 발전시킨 독립 리뷰다.

- 한국어: `reports/review_ko.md` → `dist/index.html`, `dist/review_ko.pdf` (7쪽).
- English: `reports/review_en.md` → `dist/en/index.html`, `dist/en/review_en.pdf` (8쪽).
- 내용: 코히런트 상태의 수분포, Kerr 위상과 구동의 집속, 두 번째 렌즈의 근사 복귀, 평균전압에서 추정한 Fisher 정보, 500광자 준비와 400광자 최고 감도의 구분. Davis·Deng·Xu의 선행 결과와 비교한다.
- 그림 1: 자체 제어 순서도. 그림 2: 독립 검산한 이상적 Fock 생존확률 교육 계산. 그림 3: 정식 공개 데이터 20행의 재도표. 세 그림은 한영·데스크톱/모바일 12판을 갖춘다.
- 원 논문의 도안은 복제하지 않았다. Figshare v1 수치는 CC BY 4.0에 따라 출처·변경 범위를 표시했다. 표지는 별도의 AI 생성 개념 일러스트다.
- 정식 Nature 주본문의 구독 접근 제한을 명시하고, 실제 사용한 공개 저자판·정식 보충자료·캡션·원자료를 구별했다. 원 실험과 저자 코드는 재실행하지 않았다.

일반 출판 자산은 명시한 HTML·CSS·표지·SVG·PDF만 `dist/`에 둔다. 원자료 수집물·메일·비공개 조사 기록·QA 화면·모델 설정 증거는 포함하지 않는다. 공개 가능한 고정 모델 기록과 제작·도표 입력은 `artifacts/`에서 관리한다. 등록·후보·실제 공개 확인 상태는 `reports/production-review.md`에 기록한다.
