# Fock 공간의 상태 준비와 판독 — 표지 브리프

- 작성: 2026-11-28, 편집부(AEDAUT), Codex. 상태: 제작 전.
- 기사: 광자 수를 모아 작은 변위를 읽다.
- 사건: 넓은 광자수 분포에 상대위상을 만든 뒤 구동해 집속하고, 신호 뒤 후속 제어로 진공 근처 판독에 연결한다. 단일 초전도 공진기 모드의 실험이며 실제 공간의 광선 집속은 아니다.
- 분야/표현/매체: 보손 양자정보·센싱 / 재배열·집속·회수 / 직물과 종이 부조의 개념 일러스트.

## 후보와 선택

| 안 | 장면과 매체 | 전달 관계와 오독 위험 |
|---|---|---|
| A | 수평의 이산 띠가 넓게 점유된 영역에서 중앙의 좁은 띠로 집중되고, 뒤에서 펼쳐져 낮은 작은 판독 창에 이어지는 직물 부조 | 분포와 복귀를 한 장면으로 연결. 실이 실제 광자의 경로라는 오독은 캡션으로 구별 |
| B | 공진기 단면과 떨어져 배치한 두 장의 반투명 분포 판 | 실제 장치와 상태 공간의 차이를 설명하기 좋지만 실제 배선·치수의 근거 없는 재현 위험 |
| C | 두 번의 인쇄로 중앙에 조밀한 잉크 흔적과 외곽의 상쇄를 보이는 판화 | 위상과 간섭의 비유는 강하지만 독자가 집속·판독 사건을 알아보기 어려움 |

선택 A. 불연속 좌표와 분포의 폭을 직물의 반복으로 보이고, 준비 뒤에도 판독 경로가 이어진다는 관계를 남긴다. 정확한 제어 순서·확률·수치는 별도의 결정론적 그림에 둔다. 표지에 특정 광자수, 정확한 층 수, 장치 회로 또는 수치 곡선을 맡기지 않는다.

## 시각 요소와 의미

| 요소 | 뜻 | 보존할 관계와 생략 |
|---|---|---|
| 층이 구별되는 수평 띠 | 광자수별 진폭 분포의 비유 | 좌표의 이산성과 집중·확산의 차이. 정확한 확률·위상은 생략 |
| 중앙의 좁은 짙은 띠 | 집속 상태 | 여러 이웃한 성분을 남긴다. 단일 정확한 Fock 상태라는 표현을 피함 |
| 두 번째 펼침과 작은 읽기 영역 | 후속 제어와 진공 근처 판독 | 큰 상태의 변화를 작은 판독 영역에 연결. 손실 없는 임의 상태 역변환이라는 뜻은 아님 |
| 짧게 어긋난 구리색 흔적 | 작은 신호가 남기는 차이의 비유 | 비교·설명 관계이며 정량 변위나 실제 궤적은 아님 |

첫 시선은 중앙 집속과 이후 읽기 영역에 머물게 한다. 본문 크기에서는 직물의 이산 반복, 종이 단면, 제한된 색의 교차와 미세한 어긋남을 발견하게 한다. 미색 바탕·짙은 청록·구리색을 사용하고 네온·광선·유리 렌즈·수식 장식을 쓰지 않는다.

## 실제 살펴본 미술 참고

Anni Albers, *Wallhanging* (1925), silk, cotton and acetate, Die Neue Sammlung, Munich 363.26. [Albers Foundation 공식 작품 기록](https://www.albersfoundation.org/art/highlights/wallhanging_die-neue-sammlung)의 이미지와 서지를 직접 확인했다. 반복되는 짧은 가로 띠와 긴 세로 면의 크기 차이, 제한된 색의 대비, 같은 격자 안의 리듬 변주를 관찰했다. 이번 표지는 이 작품의 도안·배색 배열을 재현하지 않으며, 가로로 이어지는 집속·복귀 사건이라는 별개의 구도를 만든다. 원 이미지는 비공개 감상 참고에만 보관하고 생성 입력이나 공개 자산으로 사용하지 않는다.

최근 네 표지(양자 알고리즘, 에너지 해석, 모델 기반 학습, 원자간 포텐셜)의 자산과 비교해 최종 구도·재료·색·썸네일 판독을 기록한다. 해당 작품의 명성이나 특정 작가의 화풍을 생성 지시로 사용하지 않는다.

## 완성본 검토 · 2026-11-28

- 최종 `artifacts/hero.png`: 1672×941px, 명목 16:9. 내장 imagegen 새 생성. 원본은 비공개 제작 보관에도 남기고, 공개 자산 SHA는 figure manifest에 기록했다. 생성 프롬프트는 `artifacts/hero-prompt.txt`이며 참고 작품 이미지는 입력하지 않았다.
- 제목을 가리면 넓게 흩어진 구리색 띠가 중앙의 여러 청록 띠로 모였다가 펼쳐지는 관계와 오른쪽 아래의 별도 작은 띠가 보인다. 직물의 굽음은 상태 공간의 비유이며 실제 경로를 뜻하지 않는다는 범위를 캡션에 적었다. 위상·정확한 제어는 본문 그림 1에서 설명한다.
- 320×180·흑백에서 중앙 집속과 오른쪽 읽기 영역이 남는다. 본문 크기에서는 직조 방향·종이 단면과 수평 띠의 반복을 발견할 수 있다. 모바일은 자르지 않고 전체 비율을 유지한다.
- 최근 네 표지와 실제 비교: 원자간 포텐셜 표지와 따뜻한 종이색은 공유하지만 화학 네트워크 대신 단일 수평 집속 사건을 쓴다. 양자 알고리즘 표지의 연속 파면·수직 판과 달리 이산 직조와 작은 읽기 띠를 남겼다. 에너지 표지의 장치 단면이나 AI 학습 표지의 인물·환경을 반복하지 않았다.
- 중앙 집중·이산 반복·후속 읽기의 과학적 단서를 보존했고, 장식적 입자·장치·곡선은 보충하지 않았다. 수정할 의미 오류는 발견하지 않았다. 한영 본문·메타데이터·PDF에 같은 자산을 사용한다.
