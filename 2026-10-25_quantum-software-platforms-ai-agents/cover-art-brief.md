# 표지 기획: 서로 다른 설계 방식과 공유하는 실행 기반

- 주제: 양자 소프트웨어의 두 경쟁 경로—고수준 회로 합성과 AI 에이전트의 도구 조합.
- 분야: 양자 프로그래밍·컴파일러·소프트웨어 생태계.
- 표현 유형: 같은 목적에 이르는 설계 방식의 차이와, 겹쳐 쓰이는 실행 기반.
- 매체: 직물·염색·목재의 물성을 가진 편집 일러스트.
- 상태: 생성·원본·썸네일·흑백의 독립 의미 검수 완료; 최종 출력·라이브 배포 검수 완료.

## 핵심 사건

프로그램의 의도를 제약 아래 구현하는 합성과, 여러 도구를 조합해 검증·실행하는 오케스트레이션은 구별되지만 함께 쓰일 수 있다. 두 진영이 완전히 분리되거나 어느 쪽이 이미 이겼다는 장면을 만들지 않는다.

| 발상 | 관계와 장면 | 선택·위험 |
|---|---|---|
| A: 하나의 천을 만드는 두 설계 행위 | 전체 무늬 견본과 여러 북·실을 조합하는 행위가 하나의 직조틀과 같은 날실에서 만난다. | 선택. 고수준 의도·조합·공유 제약의 관계를 한 장면으로 묶는다. 실제 양자 장치나 정확한 배선도가 아님을 캡션에 명시한다. |
| B: 교차하는 물류 교량 | 두 설계 경로가 여러 하드웨어 부두를 공유한다. | 플랫폼 호환성은 보이지만 흔한 교통 은유로 컴파일러 역할이 약하다. |
| C: 서로 다른 접힌 지도 | 하나의 목적지로 가는 경로를 전체 설계와 조각 지도로 구성한다. | 최적화와 이식성은 설명되지만 최근 종이 콜라주·접힌 리본 표지와 반복된다. |

## 의미와 오독의 경계

| 요소 | 대응 | 보존할 관계 | 금지할 해석 |
|---|---|---|---|
| 무늬 견본·패턴 카드 | 고수준 프로그램과 명세 | 구현의 앞에 목적과 조건이 있음 | 자연어만으로 문제 정의가 자동으로 정확해짐 |
| 여러 북과 실 묶음 | SDK 함수·합성기·실행 도구의 조합 | 다른 도구가 함께 사용됨 | 도구를 엮기만 하면 물리적 제약이 사라짐 |
| 공유하는 날실과 틀 | 하드웨어·실행·검증의 공통 제약 | 두 방법이 같은 기반과 상호작용함 | 진영이 물리적으로 분리됨 또는 회사별 장치 복제품 |
| 이어지는 무늬 천 | 실행할 프로그램의 구성 | 의미를 유지하는 연결이 중요함 | 이미 검증된 실제 양자 성능 또는 한 방법의 필연적 승리 |

최근 네 표지는 PHP의 도자기 균열, 광양자 잠재분포의 두 줄 인쇄·접힌 리본, 신경망의 고양이·자동차 콜라주, 희소 기준상태의 도자기 원판이다. 이번에는 직물의 연결과 짜임을 주제로 삼고, 균열·복구·두 줄 경주·리본 후보·우주 배경·금속 구체를 피한다. 타 매체의 특정 구도나 작가의 화풍을 입력으로 삼지 않는다.

정확한 양자 상태·회로·수치와 제품 간 연결은 별도의 결정론적 SVG에서 코드와 공식 출처로 표현한다. 표지는 텍스트·수치·로고 없는 독립 개념 일러스트다.

## 제작·검수

내장 image_gen 신규 생성, 참조 이미지 없음. 목표 `artifacts/hero.webp` 1600×900. 최종 프롬프트와 제작 방식은 figure-manifest.json에 보존한다. 원본·320×180·흑백·모바일 및 독립 의미 검토를 수행한 뒤 이 항목에 실제 결과를 추가한다. 사람 독자 이해도 실험은 수행하지 않는다.

## 공개 캡션 초안

무늬를 설계하는 견본과 여러 실을 조합하는 북은 회로 합성과 도구 오케스트레이션을, 공유한 날실은 실행과 검증의 제약을 상징한다. 실제 양자 장치·회로·성능 데이터가 아닌 AI 생성 개념 일러스트.

## 실제 제작과 의미 검수

`artifacts/hero.webp`를 1600×900 RGB로 저장했다. root가 원본을, publish_audit가 원본·320×180·흑백을 독립 검토했다. 실제 그림은 하나의 직조틀 위에 견본·여러 북·미완성 직물이 함께 있는 장면이다. 양쪽 승패·특정 기업 장치·성능 수치를 암시하지 않으며 재생성은 필요하지 않았다. 최종 desktop·390px 한영 HTML에서 표지 전체와 캡션을 확인했으며, 한영 PDF 총 24쪽의 시각 검사도 통과했다. WebP는 RGB이고 EXIF·XMP·개인 경로가 없다. 공개 배포 후 표지·관련 자산이 검수본과 SHA256 단위로 일치함을 확인했다. 실제 Chrome의 한영 1440px·390px 화면에서도 표지와 캡션이 정상 표시됐고, 언어 전환·PDF 링크가 작동하며 이미지 누락·가로 넘침·브라우저 오류가 없었다.
