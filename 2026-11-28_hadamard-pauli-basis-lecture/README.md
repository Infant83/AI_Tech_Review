# 그림의 규칙을 양자회로로 옮기는 법

같은 상태로 준비한 큐비트도 무엇을 측정하느냐에 따라 얻는 정보가 달라진다. 작은 예제로 파울리 행렬과 측정 평균을 연결하고, 네 칸 그림의 부호 규칙을 위상 회로로 옮기는 한국어 학습 노트다. 책임 편집자는 김현중이며 편집부(AEDAUT)가 OpenAI Codex 보조로 작성·감수한다.

2026-11-28 v3 전체 개정은 사용자가 지정한 IBM Quantum의 [Specify observables in the Pauli basis](https://quantum.cloud.ibm.com/docs/en/qiskit/specify-observables-pauli)를 출발점으로, 상태·관측량·행렬 기저·측정 기저를 처음부터 연결한다. 독립적인 행렬 예제, 계수의 유도, 측정 회전과 패리티, 기대값의 조합을 설명하고 기존의 Walsh·위상 오라클·P·CX 회로를 유지했다. 원문의 번역본이 아니며 일곱 원전과 직접 계산을 바탕으로 구성했다. 도해 6개와 풀이를 갖춘 5문제를 포함한다.

최초 등록한 v2는 원판의 5쪽·도해 5개·원전 3개를 보존한 공개 편집이었다. v3는 같은 문서를 개정하며, 다른 주제의 양자회로 기사나 Classiq·광자 내결함성 과정을 교체하지 않는다. 전달 경위와 원판은 비공개 수신 기록으로 분리한다.

- 문서 ID: `2026-11-28-hadamard-pauli-basis-notes-ko`
- 보존 PDF: `archive/files/2026-11-28-hadamard-pauli-basis-notes-ko.pdf`
- 필기: `lectures/reader/?id=2026-11-28-hadamard-pauli-basis-notes-ko`
- 등록 원본: `archive/entries/2026-11-28-hadamard-pauli-basis-notes-ko.json`

목록은 기존 게시기가 한영 요약과 필기·PDF·다운로드 링크를 생성한다. 같은 내용을 반복하는 온라인 수식 본문이나 별도 강의 bundle은 만들지 않는다. 이후 같은 문서가 개정되면 문서 ID·발행일·필기 주소를 유지하고 기존 PDF를 불변 판본으로 보존하는 교체 절차를 따른다.

## v3 원고·검산·제작

출판 입력은 `artifacts/v3/lecture-body.tex`, `disclosure.tex`, `verification-disclosure.tex`, `metadata.json`, `figures.tex`, `atrl-lecture.sty`와 같은 폴더의 `ai-model-provenance.json`이다. `build_pdf.py`는 이 고정 입력과 명시한 로컬 폰트 디렉터리로 별도 PDF 후보를 만든다. XeLaTeX 수식과 임베드한 한글 폰트, 자체 TikZ 벡터 도해를 사용한다. 중간 파일·렌더·원 대화와 검수 화면은 공개하지 않는다. 빌더가 아카이브 PDF를 직접 덮어쓰지 않도록 분리했다.

독립 과학 감수에서 이름을 붙인 27개 고전 검산 항목을 이번에 직접 실행했다. 최대 8×8 행렬로 파울리 직교성·계수와 기대값, 비트 순서, Y 측정의 실행 순서, 상관관계와 가상 패리티 기록, Walsh·위상 생성자·공통 위상을 포함한 게이트 회로, 비가환 지수 분해의 반례, 연습문제와 세 큐비트 이징 모형을 확인했다. 항등식 잔차는 최대 약 8.9×10⁻¹⁶으로 허용 기준 10⁻¹² 이내였다. 검산 항목 수와 실험 횟수를 구별한다. SDK·QPU·실물 실험과 원저자의 별도 프로그램은 실행하지 않았다.

별도 에이전트가 전체 원고의 독자 진입과 설명 흐름을 읽고, 도입의 진폭·주소, 복소 켤레, 계산 기저 측정, 가환의 뜻, 위상 각도와 대각 지수함수 사이의 빠진 연결을 보강한 문장을 다시 확인했다. 이는 실제 사람 독자의 이해도 시험을 뜻하지 않는다. PDF의 모든 쪽·수식·도해·풀이·인용 링크를 검토한 최종 결과는 `reports/v3-qa.json`에 기록한다.

같은 문서 ID·발행일·필기 주소를 유지하고 공식 `inspect`/교체 토큰 절차를 사용한다. v2 PDF는 `archive/editions/`의 불변 사본으로 보존하며 판본별 필기는 섞지 않는다. 실제 HTTPS에서 새 PDF와 이전 판본의 해시, 새 공책과 이전 판본 공책의 필기·책갈피 복원을 확인한다. 출판 후보·이전 배포 스냅샷·연속성 검증·완료 배포는 기존 `PUBLICATION_WORKFLOW.md`를 따른다.

## v2 공개 편집의 기록

원문 대조 담당은 5쪽 전체와 도해·수식·참고문헌을 화면으로 읽고, 공개 편집 영역 밖의 문자·그림·링크를 보존했는지 확인한다. 제작 날짜·도구 메타데이터를 정리하고 마지막 쪽의 기존 여백에 공개판의 역할·모델·검산 범위를 표시한다. 실제 동결 파일의 쪽수·크기·해시와 보존 결과는 `reports/pdf-qa.json`을 따른다.

과학 감수 담당은 5쪽 전체와 원전 3개의 필요한 부분을 대조하고 별도로 작성한 고전 검산 11항목을 수행했다. 최대 4×4 행렬과 두 비트의 네 주소에서 Walsh 계수·정규화, Z 문자열, D의 파울리 전개와 가환 지수 분해, 위상·CX 회로의 정확한 행렬과 공통 위상, 상태·연산자 기저의 구별을 확인했다. 원저자의 별도 검산 기록을 추정하거나 SDK·QPU·실물 실험을 실행한 것으로 표시하지 않는다.

원판의 집필 모델과 추론 설정은 확인할 기록이 없다. 이번 공개 편집·원문 대조·과학 감수·발행 검수의 실제 대화 설정은 `artifacts/ai-model-provenance.json`으로 구분한다. 사람의 문장별 감수가 수행됐다고 주장하지 않는다. 원 대화·개인 메일·인증 정보·수집 자료·검수 화면·내부 경로는 공개하지 않는다.

`artifacts/prepare_public.py`는 명시한 비공개 원판과 검토·모델 기록을 입력으로 받는다. 원판 해시는 공개 코드에 고정하지 않는다. 검수·등록 뒤 `PUBLICATION_WORKFLOW.md`에 따라 실제 이전 배포 스냅샷에서 독립 후보를 생성하고 연속성·페이로드와 화면을 확인한다. 완료된 배포와 실제 HTTPS PDF 해시·필기 연결을 확인한 뒤 발행 성공을 기록한다.
