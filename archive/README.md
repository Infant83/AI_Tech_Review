# PDF 리뷰 아카이브

이 폴더는 Daily Quantum Review, 금요일 주간 리뷰, 사용자가 제공하는 개별 PDF 아티클과 렉처 노트를 리뷰 허브에 등록하는 원본입니다. `manifest.json`에 명시적으로 등록된 PDF만 공개 사이트에 복사됩니다. `files/`에 파일을 넣는 것만으로는 게시되지 않습니다.

사용자가 PDF를 제공하면 먼저 PDF 전체와 공개 제목·요약을 확인합니다. 개인 메일 주소, 수신자, 메일 시각, 비공개 링크, 로컬 경로 등 공개하면 안 되는 내용이 포함되어 있지 않은지 확인한 뒤 등록합니다. `--public-reviewed`는 이 확인을 마쳤다는 표시입니다. 스크립트의 파일 형식 검사는 PDF 내부의 모든 내용을 검토하지 않습니다.

공개 목록에는 메일 식별자, 송수신자, 메일 제목·시각, 첨부 다운로드 주소를 보존하지 않습니다. PDF 본문의 연구 결과와 해석은 발행 당시의 내용입니다. 이후 제공되는 주간·수시 자료도 같은 절차로 등록합니다.

## 렉처 노트 · 2026-10-17 등록

2026-10-16 KAIST Zi-Yang Meng Lecture 4 상세 강의 노트의 27쪽 최종 편집자 주석판을 등록했습니다. 22쪽 초판과 25쪽 수식 조판판 다음에 제공된 개정본이며, 이전 판을 대체한다는 안내와 문서 내용을 대조해 선택했습니다. 이전 두 판은 공개 목록에 별도 등록하지 않았습니다.

강의의 스핀 기저·정확대각화, 벌집 격자 Hubbard 모형과 평균장 임계 현상을 정리한 한국어 학습 자료입니다. 확보된 자막·화면을 재구성한 노트로 강의 초반 13분이 누락됐다는 한계를 목록에도 표시했습니다. 강의 기록과 후속 학술 검토에 따른 편집자 주석은 구분됩니다.

공개용 사본은 부록 24–26쪽의 화면 6개에서 참가자 이름·이니셜과 회의 UI를 PDF 픽셀 삭제 방식으로 제거했습니다. 원래 이미지 객체도 공개 파일에서 제거됐으며, 원본은 개인 보관합니다. 페이지 수 27쪽과 링크 66개를 유지하고, 나머지 24쪽의 본문·수식·주석 및 PDF 내용 스트림이 원본과 동일한 것을 확인했습니다. 부록의 원래 본문도 유지하고 공개용 가림 처리 안내만 하단에 추가했습니다. 별도 점검 역할이 표지·수식 페이지와 부록을 렌더링하여 대조했습니다.

등록 예시:

```sh
python3 scripts/archive_documents.py /absolute/path/review.pdf \
  --date 2026-10-16 \
  --series daily-quantum \
  --title 'Daily Quantum Review · 2026년 10월 16일' \
  --summary '이번 호에서 다루는 양자컴퓨팅 연구를 요약합니다.' \
  --language ko \
  --id 2026-10-16-daily-quantum-review \
  --tag Quantum \
  --source-title 'Daily Quantum Review' \
  --public-reviewed
```

`--series`는 `daily-quantum`(Daily Quantum Review), `weekly-review`(주간 리뷰), `article`(기타 아티클), `lecture-notes`(렉처 노트) 중 하나입니다. `--language`는 `ko` 또는 `en`입니다. 날짜는 실제 발행일을 사용하고, ID는 그 날짜와 영문 소문자·숫자·하이픈으로 만듭니다. 영문 제목·요약이 있으면 `--title-en`, `--summary-en`을 추가할 수 있습니다. 공개 표시 문구에는 이메일 주소·URL·개인 컴퓨터의 경로를 넣지 않습니다.

같은 렉처 노트에 여러 수정본이 있으면 본문과 버전 표시를 대조해 확인한 최신본만 등록합니다. 더 새 수정본이 제공되면 기존 ID를 유지하고 `--replace`로 교체해 이전 판이 별도 문서로 중복 노출되지 않게 합니다. 요약에는 확인된 판본과 기록의 한계를 적습니다.

같은 ID의 자료를 수정할 때만 `--replace`를 추가합니다. 이미 등록된 PDF가 교체되므로 수정할 파일을 확인한 뒤 사용합니다. 등록되지 않은 동명 파일은 `--replace`로도 덮어쓰지 않습니다. 원본 입력 PDF는 그대로 유지됩니다.

등록 후 리뷰 허브를 다시 생성합니다:

```sh
python3 scripts/publish_public_site.py --hub-only
```

파일을 브라우저에 올리는 업로드 기능은 없습니다. PDF 제공 → 내용 확인 → 이 명령으로 등록 → 허브 생성 → 사이트 게시 순서로 진행합니다. 게시 전에는 생성된 허브에서 제목·분류·PDF 링크를 확인합니다.

`manifest.json` 형식:

```json
{
  "version": 1,
  "documents": [
    {
      "id": "2026-10-16-daily-quantum-review",
      "date": "2026-10-16",
      "series": "daily-quantum",
      "title": "Daily Quantum Review · 2026년 10월 16일",
      "summary": "이번 호에서 다루는 양자컴퓨팅 연구를 요약합니다.",
      "language": "ko",
      "file": "files/2026-10-16-daily-quantum-review.pdf",
      "tags": ["Quantum"],
      "source_title": "Daily Quantum Review",
      "public_reviewed": true
    }
  ]
}
```

선택 필드는 `title_en`, `summary_en`, `source_title`뿐입니다. 제목·출처명은 최대 240자, 요약은 최대 1,600자, 태그는 각각 최대 48자로 12개까지 등록합니다. 개인 메일이나 원본 저장 경로 같은 인계용 정보는 이 공개 등록부에 추가하지 않습니다. 등록부가 없거나 비어 있으면 첫 등록 시 생성됩니다.
