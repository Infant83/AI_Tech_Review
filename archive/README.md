# 리뷰·자료 아카이브

이 폴더는 Daily Quantum Review, Daily Research Brief, 금요일 주간 리뷰, 사용자가 제공하는 개별 PDF 아티클과 렉처 노트를 리뷰 허브에 등록하는 원본입니다. `entries/<문서 ID>.json`에 명시적으로 등록된 PDF만 공개 사이트에 복사됩니다. `manifest.json`은 이 문서별 등록 방식을 선택하는 v2 설정이며 글을 추가할 때 편집하지 않습니다. `files/`에 파일을 넣는 것만으로는 게시되지 않습니다. [동시 작성과 배포 후보 안내](../PUBLICATION_WORKFLOW.md)를 함께 따릅니다.

외부 서적은 `external-resources.json`에 공개 서지 정보와 저자·책 공식 페이지 링크로 등록합니다. 아카이브의 ‘외부 서적’ 분류와 검색에 표시되며, PDF 등록부·복사 대상에는 포함되지 않습니다. 링크는 이메일·인증 토큰·직접 PDF 주소를 포함하지 않는 공개 HTTPS 안내 페이지만 허용합니다. 날짜는 책 출간일이 아닌 아카이브 등록일입니다. 공개 JSON에서도 PDF 목록 `documents`와 링크 목록 `external_resources`를 구분합니다.

사용자가 PDF를 제공하면 먼저 PDF 전체와 공개 제목·요약을 확인합니다. 개인 메일 주소, 수신자, 메일 시각, 비공개 링크, 로컬 경로 등 공개하면 안 되는 내용이 포함되어 있지 않은지 확인한 뒤 등록합니다. `--public-reviewed`는 이 확인을 마쳤다는 표시입니다. 스크립트의 파일 형식 검사는 PDF 내부의 모든 내용을 검토하지 않습니다.

브리핑은 `entries/`에 공개 검토를 마쳐 등록한 `daily-quantum`·`weekly-review` 자료만 자동으로 모은다. 달력은 문서의 실제 발행일을 사용하며 메일 수신 시간을 뜻하지 않는다. 월·날짜·검색어로 주제를 찾고 제목이나 읽기 링크에서 해당 PDF를 연다. 빈 날짜는 공개 등록된 브리핑이 없다는 뜻이며, 수신 여부를 추정하지 않는다. 자료 수집 원문·개인 메일·내부 경로를 공개 데이터에 포함하지 않는다. 새 PDF를 등록하고 공개 사이트를 갱신하면 브리핑의 달력과 목록에도 반영된다.

2026-11-13 보완: `daily-research`도 같은 브리핑 달력·목록·검색에 포함한다. 검수한 한영 편집글이 있으면 제목과 읽기 링크는 그 글을 먼저 안내하고, PDF 열기·다운로드를 따로 제공한다. DRB는 `briefings/research/YYYY-MM-DD/`를 사용해 같은 날짜의 DQB 경로를 보존한다. [DRB 조사·공개 기준](../.automation/nature-aps-drb/README.md)에 따라 원문·그림별 공개 권리·전체 PDF와 한영 편집글을 감수하며, 비공개 이메일 전달판과 공개 적합한 파생판의 상태를 구별한다.
