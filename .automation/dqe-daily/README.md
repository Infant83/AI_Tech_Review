# Daily Quantum Exercise의 일일 공개

2026-11-14 사용자 요청으로 DQE(Daily Quantum Exercise)를 DQB·DRB와 함께 보관하고 게시한다. 에이전틱 편집·저술팀(Agentic Editorial and Authoring Team, AEDAUT)이 문제의 과학적 의미·중요성·응용 안내와 감수를 맡고, 운영팀(ADOPT)은 기존 출판 도구·주소·검색 연결을 지원한다. 사용자는 새 메일을 매일 확인하고 검수한 문제와 짧은 안내를 게시하도록 승인했다.

## 메일에서 공개본까지

연결된 Gmail을 먼저 검색한다. 최초 전체 검색과 이후 마지막 성공 조회보다 7일 겹친 검색을 사용하고 모든 결과 페이지를 확인한다. 읽음 여부·받은편지함 라벨로 대상을 제한하지 않는다. 제목의 Daily Quantum Exercise와 실제 본문·첨부를 대조하며, 검색 실패를 새 메일 없음으로 기록하지 않는다. 이전 주제의 언급만으로 확인하지 못한 발행호를 만들지 않는다.

원본·메일 식별자·첨부 해시·수신 이력·검색 cursor와 재개 상태는 저장소 밖 비공개 상태에 원자적으로 보관한다. 원본 메일·주소·추적 링크·원 첨부·QA 화면·내부 절대경로는 공개 Git·사이트에 넣지 않는다. 호 날짜와 원 첨부 SHA-256으로 중복을 찾고, 같은 날짜의 새 해시는 정정 여부를 비교한다. 조회 성공·첨부 확보·전체 감수·공개 등록·웹 게시·실제 URL 확인을 구분한다. 처리 실패는 남겨 다음 실행에서 이어가며 전체 조회 성공 때만 cursor를 진전시킨다.

PDF 전체를 읽고 렌더한다. 문제의 조건·단위·정답·수식·가정·인용을 독립 감수하고 필요한 작은 계산은 재현한다. 원 논문과 공식 문서를 직접 확인하며 실제 QPU·고전 모사·교육용 가정·후속 제안을 구별한다. `archive/README.md`와 PDF 스킬에 따라 개인정보·메타데이터·URI·첨부·자동 실행·재배포 권리도 검사한다. 공개용 삭제·정정이 필요하면 원본을 비공개 보존하고 과학 내용·크레딧·원문 링크·원호 날짜와 수정 이력을 유지한다.

## 문제를 먼저 풀 수 있는 안내

각 호의 짧은 한영 편집글과 별도 목록 요약은 독자가 왜 이 문제를 풀 만한지, 어떤 개념과 판단을 배울지, 연구·업무의 어떤 결정에 응용해 볼 수 있는지 설명한다. 실제 근거가 있을 때 기존 리뷰·렉처·관련 연구를 읽고 연결한다. 문제에 없는 응용 성과를 만들거나 매일 새로운 통찰·고정 목차·분량을 강제하지 않는다. 주장에 영향을 주는 가정과 비교 조건은 그 주장 가까이에 둔다.

문제 PDF의 첫 쪽과 해설이 시작되는 위치를 안내한다. 답을 포함하는 수치·풀이·판정은 웹에서 기본 접힌 `details` 안에 두어 먼저 풀 기회를 보존한다. 해당 호가 다른 구성이면 실제 PDF의 구성을 따른다. 응용 가능성은 배울 수 있는 의사결정·필요한 데이터·비교할 기준을 구체적으로 써서 안내하고, 아직 시험하지 않은 활용은 제안으로 밝힌다. 별도 담당자가 과학 내용·한영 대응과 실제 노출 요약을 함께 감수한다.

## 등록·주소·매일 실행

현행 정책·작성 방법·과학 설명 준칙·APS 인용·문체 감사 기준과 `PUBLICATION_WORKFLOW.md`를 따른다. 검수한 PDF는 `scripts/archive_documents.py`의 `daily-quantum-exercise`로 등록한다. ID는 `YYYY-MM-DD-daily-quantum-exercise`이며 한영 제목·요약과 `source_title: Daily Quantum Exercise`를 기록한다. 원고는 해당 날짜의 `daily_research_review/` 아래 `reports/briefing_ko.md`·`briefing_en.md`, 컴파일 등록은 `scripts/build_briefing_editorial.py`와 `publication/briefings/<ID>.json`을 사용한다.

웹 주소는 `briefings/exercises/YYYY-MM-DD/`와 대응 `/en/`이다. DQB·DRB의 같은 날짜와 기존 주소를 보존한다. 달력·목록·검색·분류와 PDF 열기·다운로드를 확인하고, 독립 후보를 실제 이전 배포와 대조한다. 다른 작업을 섞지 않고 최신 원격을 통합하며, 배포 작업·복구 사본·실제 HTTPS 본문·PDF 해시까지 확인한 뒤 공개 완료로 기록한다.

Codex 앱의 이 대화에 연결된 일일 예약으로 **매일 한국시간 22시**에 확인을 시작한다. 이 시각은 작업 시작이며 공개 완료 마감이 아니다. 첫 확인본이 저녁에 발견되어 여유를 둔 운영 선택이며 메일의 정기 도착 시각을 확정한 것은 아니다. 지연 수신·놓친 실행은 겹친 조회로 회복한다. 로컬 자료를 사용하는 실행에는 호스트·앱과 연결이 이용 가능해야 한다. DQB·DRB나 기존 문제 생성·발송 예약은 변경하지 않고 별도 OS 스케줄러를 만들지 않는다.

일상적인 DQE 문제·공개 적합한 PDF·짧은 안내는 현재 요청 범위에서 게시한다. 새 심층 리뷰나 다른 기존 본문의 실질적 확장은 구체적인 기획과 해당 승인을 따른다. 받은 메일을 이동·삭제·표시 변경하거나 새 이메일·외부 메시지를 보내는 작업은 포함하지 않는다. 실행 보고에는 새로 확인한 호, 공개 상태, 독자가 얻을 의미와 실제 남은 작업만 간결히 남긴다.
