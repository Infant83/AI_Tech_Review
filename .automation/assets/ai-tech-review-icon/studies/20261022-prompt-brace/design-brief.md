# 프롬프트를 연상시키는 중괄호 기둥

- 날짜: 2026-10-22
- 사용자 요청: R의 기둥을 `{`처럼 느껴지게 해 프롬프트를 연상시킨다.
- 범위: 현재 주제 키워드 아이콘의 왼쪽 기둥 형상만 개편. 기사 표지·본문·PDF 변경 없음.
- 보존: 접힌 저널 페이지의 R 오른쪽 윗면·사선 다리, 월넛·베이지·청록, 수채화 안료 번짐, Q / AI / DFT / VQE / LLM / OLED / GPU의 철자·개수·자유로운 배치.
- 의미: R은 리뷰, 왼쪽 여는 중괄호는 프롬프트·구조화된 코드의 시각적 연상, 일곱 약어는 편집 주제다. 중괄호가 특정 모델의 공식 문법이나 프롬프트의 필수 요소라는 뜻은 아니다.

## 기하 후보

| 안 | 형상 | 판단 |
|---|---|---|
| A · 기둥 자체가 여는 중괄호 | 위·아래가 오른쪽으로 감기고 중앙의 꼭짓점이 왼쪽으로 돌출된 `{`형 종이 기둥 | 요청을 직접 반영하면서 하나의 R로 통합. 우선 제작 |
| B · 직선 기둥 옆에 별도 `{` | 기존 R 외부에 기호를 추가 | 별도 장식이 되고 왼쪽 여백과 작은 아이콘이 복잡해져 제외 |
| C · 기둥에 중괄호 음각 | 직선 종이 안쪽에 작은 중괄호 틈을 만듦 | 축소하면 인상이 약하고 기둥 자체를 바꿔 달라는 요청과 거리가 있어 제외 |

## 제작·검토

- 입력: 이전 확정 원본 `../20261022-topic-keywords/selected-A-keywords.png`.
- 제작: built-in image_gen으로 형상을 편집한다. 기존 그림을 코드로 다시 그리거나 문자·형상을 후처리로 덧붙이지 않는다.
- 검사: 실제 결과에서 `{`의 방향과 허리, R 실루엣, 일곱 약어의 유지, 재질·색·여백을 대조한다. 180/64/32/16px와 흑백을 확인한다.
- 한계: 생성 편집이므로 비편집 영역의 픽셀 동일성을 보장하지 않는다. 약어는 64px 이하에서 완독을 보장하지 않는다. 사람 대상 선호도·실제 iOS 설치 시험은 별도로 수행하지 않는다.
- 배포: 최종 내보내기만 사이트에 복사한다. 프롬프트·시안·QA·검토 기록은 사이트 배포물에서 제외한다.

## 상태

발행 가능. 실제 생성한 A를 별도 디자인·판독 검토자들이 채택했다. `{`의 위·아래 끝은 오른쪽으로, 중앙 꼭짓점은 왼쪽으로 향하며 R의 윗면과 사선 다리가 남아 있다. 일곱 약어의 철자·개수·분산 배치와 기존 팔레트·재질을 확인했다.

180px와 흑백에서 중괄호 기둥·R·일곱 약어를 구별할 수 있으나 작은 약어에는 주의가 필요하다. 64px에서 중괄호 인상은 남으며 전체 약어 판독은 보장하지 않는다. 32/16px에서는 실루엣이 중심이다. 실제 iOS 설치·사람 대상 평가를 시행한 것은 아니다.

자산 버전은 `20261022-prompt-brace`, 최종 원본은 `selected-A-brace.png`다. 내보내기·메타데이터·아이콘 복사·사이트 전체 검증과 변경 범위 검사를 통과했다. 프롬프트는 `prompts.json`, 생성 원본은 `assets.json`, 선택은 `selection.json`, 내보내기 해시는 `release-manifest.json`, 검증은 `production-validation.json`에 기록했다.
