# 개정 원고의 독립 문체 재검토

2026-11-06. canonical 한국어 원고 전체와 생성된 dist HTML 본문·부제·캡션·사이드바·작성 정보를 다시 읽었다. 첫 검토의 원고·HTML은 이 폴더의 original.md/.html로 보존했다. 과학적 수치·판본의 원문 검수는 재료·라우터 담당과 알고리즘 담당의 별도 기록을 따른다. 이번 역할이 원 논문 계산·장치 실행·학습을 재현한 것은 아니다.

## 판정

중심 논지는 유지됐으며 문체는 초기 게시본보다 직접적이다. 서로 다른 연구를 하나의 성능 순위로 만들지 않고, 각 결과가 계산의 어느 부분을 바꾸는지 읽을 수 있다. SiC의 광학 경로와 QRAM의 데이터 전달에서 시작한 도입이 독자에게 두 연구의 목적을 먼저 보여준다. 짧아진 부제는 제목·도입·표와 같은 목록을 반복하지 않는다.

초기 검토에서 지적한 소제목의 가상 반박과 표 마지막 열의 미입증 목록은 실제 대상·방법·조건으로 바뀌었다. QRAM의 후선택·RAT 정의, 같은 인코딩의 컴파일 경로, 고정 샷 수에서 PAS의 각도 선택은 개별 주장에 필요한 조건이다. QRC+PIC의 보정 효과와 더 낮은 Ridge-AR 오차의 대비도 실제 비교 결과이므로 유지하는 것이 타당하다. 이 대비들을 부정 표현이나 문장 위치만으로 다시 없앨 이유가 없다.

마무리는 다섯 연구를 한 줄씩 다시 열거하는 대신 재료 선별과 합성 설계의 적용 관점을 남긴다. 기존 업무 지표 목록은 저자의 실무적 관심을 유지한다. 글 전체를 질문·반전·일화·문장 수 양식으로 바꾸지 않았다.

## 수정 요청과 반영 확인

1. **APS 인용 출력의 괄호.** 초기 생성 HTML에서 괄호가 빠지는 문제를 전달했고, 최종 source·dist·공개 출력에는 `[1]`–`[6]`이 보존됐다. 실제 Chrome에서 여섯 링크를 각각 클릭해 해당 참고문헌으로 도달한 것을 확인했다.
2. **QRC의 reservoir.** “저장소 자체의 예측력”은 코드 저장소를 연상하게 한다. “QRC 자체의 예측력”으로 바꾸는 안을 제시했고 canonical에서 반영된 것을 확인했다.
3. **도입의 광학 경로.** “빛을 내고 잃는 경로”는 비방사 과정을 이미 나온 빛의 손실처럼 읽게 할 수 있다. “빛을 내는 경로와 비방사 손실” 같은 표현을 제안했다. 최종 canonical과 Chrome 출력에서 “빛을 내는 경로와 비방사 손실”로 반영됐다.
4. **RAT 문장의 연속 소유격.** “단일 여기 정보의 도착 상태의 점유확률”을 “단일 여기 정보를 보낸 뒤 도착 상태의 점유확률”처럼 다듬으면 뜻을 유지하면서 읽기 쉬워진다. 최종 canonical에 “단일 여기 정보를 보낸 뒤 도착 상태의 점유확률”로 반영됐고, 관측량·추정량의 의미는 유지됐다.

그 밖에 추가 재작성이 필요한 문체 차단 사항은 발견하지 않았다. 수정 이력은 원 발행·근거 기준 2026-08-26과 이번 개정 2026-11-06을 구분하며, 원 작성 세션의 미보존 정보와 실제 이번 감수 역할을 섞지 않는다. 역사적 DQB의 과학 기록과 웹 리뷰의 정정을 구분한 설명도 적절하다.

## 도표와 허브

세 그림의 역할과 배치를 유지했다. 계산 대상 도식의 새 라벨은 RAT·동일 인코딩·고정 샷 수에서의 측정각 선택을 설명한다. QRC 도표의 여섯 RMSE와 원 도표 해시는 보존됐고, 실제 고전 기준선 비교를 가상의 성과 반박으로 바꾸지 않았다. 성숙도 순위가 아니라는 그림 2의 캡션은 도형 배치의 해석을 제한하므로 남겨도 좋다.

2026-10-27 허브 요약은 본문과 어긋나지 않는다. 후속 본문 개편 때문에 요약을 다시 압축하거나 방법 목록을 추가할 필요가 없다.
