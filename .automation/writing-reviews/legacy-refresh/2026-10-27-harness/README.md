## 출판 원본과 검증

정본은 주제 폴더의 `reports/*_final_review.md`다. 기존 `scripts/markdown_to_html.py`와 `scripts/html_to_dist.py`를 사용해 원고·HTML·flat dist를 갱신하고 선택한 공개 페이지를 생성한다. 누락된 Markdown 의존성은 격리 경로에 설치해 기존 빌더를 사용했다. 본문 대신 공개 HTML만 고친 작업이 아니다. 원 패키지의 별도 작성 지침 스냅샷·과거 전달 ZIP·메일용 패키지는 이번 개정본으로 바꾸지 않으며, 이번 기준은 공통 지침과 개정 기록에 남긴다. 등록되지 않은 영어판·PDF·영상·새 표지를 만들지 않는다.

선택 발행 도구가 다른 글의 부가 스크립트·여백을 다시 만들었으므로, 이 실행이 생성한 무관한 변경을 기준 커밋과 대조해 되돌렸다. 다른 48개 manifest 기록과 모든 다른 공개 리뷰 파일을 보존하고, 허브는 기존 manifest에 선택한 한 편의 새 기록만 반영해 생성했다. 선택 글의 기존 공개 집계 설정은 해당 글의 기준 커밋에서 확인해 기존 publisher decorator로 유지했다. 이후 reader enrichment와 전체 공개 검증을 적용한다. 재생성 때에도 선택하지 않은 글의 변경이나 집계 기능 누락이 없는지 확인한다.

`asset-baseline.json`의 원 그림 해시, 최초 인용순·anchor, 원 발행일·수정일·근거 기준일, 문서·외부 원문 링크와 실제 화면을 확인한다. Markdown 렌더러 10건, 허브 언어 처리 17건, 공개 정보 보호 6건의 기존 검사를 통과했다. 브라우저에서는 320·390·1440px에서 가로 넘침 없이 그림 9개와 인용 링크 39개가 표시되고, 원 발행일·새 수정일과 과거 근거 기준일이 구별되는지 확인했다. 휴대폰 실기기·사람 독자 이해도 시험과 논문 벤치마크의 독립 재현을 수행한 것은 아니다.
