## 논지와 설명

교차검증 439개/5겹/4 seed 평균과 독립 시험 110개를 구별했다. QPE의 active volume과 Toffoli 환산 비용은 비교 분모가 다르며, 초기·window 상태와 역 QFT를 제외한 컴파일 비용을 전체 준비·실행 예산과 나누어 설명했다. InSAR의 이상적 학습/22큐비트 QPU 추론을 Miramar의 20큐비트 전 과정 QPU와 구별했다. 기존 수치 도표를 새 계산 결과로 표시하지 않는다.

학술 근거는 네 논문의 v1을 기록된 범위에서 읽고 APS 최초 인용 1–6과 14/10/10/5명의 원저자 크레딧·원제·제출일을 확인했다. D-Wave 현행 행사 메타데이터에서 날짜·장소를 대조했으나 9월 9일 당시 페이지 본문은 확보하지 못했다. 과거 확인 기록과 이번 재검증을 구별하며, 9월 16일 발표된 구체 프로그램은 과거 근거로 편입하지 않는다. [원문·판본·열람 범위](reference-manifest.json)에 SAR v1 내부 수치 불일치와 역사 재검증 한계를 함께 남겼다.

## 기존 PDF 사본의 동기화

5쪽 한국어 PDF는 전체 웹 리뷰의 PDF판이 아닌 당시 DQB의 별도 첨부다. 기존 리뷰의 교정판과 아카이브 구판이 달랐으며, 아카이브 구판에는 최적화 대상 표현·서로 다른 분모를 곱하는 도표·F1 조건·SAR 첫 저자의 오류가 남아 있었다. 이미 발행된 리뷰 교정판을 공식 아카이브 교체 도구로 재사용했다. PDF를 새로 제작하거나 역사적 제호·날짜·문서 ID·URL을 바꾸지 않는다. 이전 사본과 판본 연결도 기존 아카이브 보존 절차로 유지한다.

두 역사판의 10쪽 전체를 렌더로 읽고 개인정보·6개 과학 URI·메타데이터·첨부·실행 동작·페이지 넘침을 확인했다. root도 교정판 5쪽 전체를 렌더로 읽었다. [PDF 감수](pdf-audit.json)와 [최종 사본 대조](final-pdf-copy-review.json)는 이 범위의 기록이다. PDF의 예전 D-Wave 세부는 역사적 원호의 기록으로 보존되며, 이번 과학 감수로 그 9월 9일 열람 상태를 확인한 것으로 표시하지 않는다. 원 메일·첨부 수집본·QA 화면·내부 경로를 공개하지 않는다.

## 실제 역할과 재생성

편집부(AEDAUT) root가 한영 편집·감수 통합·원고 기반 렌더와 패키징·후보 및 공개 확인을 맡는다. `legacy0919_sources`는 네 v1과 공식 자료의 원저자·과학·수치 조건을 독립 대조했다. `legacy0919_prose`는 비작성자로 한영 전체 논지·독자 흐름·조건·캡션·실제 노출 요약을 감수했다. `legacy0919_pdf`는 두 역사판의 전체 렌더와 구조·권리·개인정보·URI 및 최종 사본을 대조했다. [과학 감수](final-source-review.json)와 [문체 감수](final-prose-review.json)의 해시·범위를 따른다.

주제별 어댑터는 기존 Markdown 렌더러·HTML 패키저·집계 보존 함수를 호출하며, 한영 원 생성시각과 기존 8개 절 앵커를 유지한다. 기존 공개 한영 HTML에는 조회 집계 실행 설정이 없었음을 따로 확인했다. 없는 영어 PDF·영상·새 표지는 만들지 않고 원 실험·모델·논리 자원 파이프라인을 재실행하거나 사람 독자 평가를 주장하지 않는다. 운영팀(ADOPT)의 별도 인프라·디자인 변경을 포함하지 않는다.

후보·CI·실제 배포 결과는 검증 뒤 별도로 기록한다.

기존 제호 표시 선언과 이번 본문 개정 선언이 같은 한영 HTML 두 경로를 중복 소유해 연속성 검사가 거절했다. 해당 두 경로의 현재 전이는 이번 개정 선언으로 인계하고 나머지 66개 경로와 과거 Git 기록을 보존했다. 본문·후보 바이트를 바꾸거나 검사 규칙을 완화하지 않았다.
