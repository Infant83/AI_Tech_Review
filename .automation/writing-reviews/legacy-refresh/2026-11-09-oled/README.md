## 편집과 과학 정보

비슷한 ISC 속도를 만드는 서로 다른 전이 경로에서 글을 시작하고, 기작 라벨 감사에서 분자간 상호작용·SCF 비용으로 이어지는 논지를 살렸다. 반복된 결과·한계·제안 표제와 양자 우위 부정은 줄였으며, 실제 계산 모형·비교 조건·미실행 제안은 각 주장 곁에 남겼다. 캡션은 보이는 모티프와 자료 종류를 설명한다. 그림 3의 실제 도식과 맞지 않았던 실선·점선의 증거 범례 설명을 고쳤다.

- WDB-CG의 O(n²)는 일반적인 최소 깊이가 아닌 제시된 구현의 비용으로 명료화했다.
- Mg 8,250원자 SCF 수렴과 독립 기준 해를 비교한 최대 528원자 부분계를 구별하고 추가 학습 조건을 밝혔다.
- DensIP의 S66x8 수치는 상호작용 에너지 RMSE로 적었다. BoMolLLM의 invalid SMILES 제외와 별도 비율 보고를 함께 설명한다.
- PAS의 세 점 복원은 해당 단일 주파수 조건에서 설명한다. 회로 비용식의 갱신 횟수를 모든 파라미터를 도는 sweep 단위로 정의했다.
- 원래의 12–24개 분자 감사에서 4–6개 진동 계산 부분집합은 탐색적 비교로 두었다. Model C의 scaffold-held-out 성능 판정에는 family별 표본 확충이 필요함을 명시했다. 실험을 실행하거나 성능을 얻었다고 표시하지 않았다.

## 출력과 게시 상태

주제별 `scripts/build_review.py`는 기존 공통 Markdown 렌더러와 패키저로 정본 원고에서 한영 HTML·다운로드 Markdown을 만든다. 기존 절 주소를 별칭으로 유지하고 세 그림 확대와 키보드 표 스크롤을 제공한다. 원 발행 호와 새 편집일은 구별한다. 등록의 이관 원본 해시는 보존하고 새 입력은 명시적 출판 요청에 기록한다.

운영팀(ADOPT) 역할 oled_publication은 별도로 로컬 파일·절 링크·중복 ID·원자료 불변을 검사했다. 격리 사본에서 소스 빌더를 실행해 여덟 산출물의 동일성을 확인했다. 후보 릴리스와 실제 HTTPS 확인 전에는 공개 완료로 표시하지 않는다.

후보는 공개 파일 검사·릴리스 연속성·전송량 기준을 통과했다. 다른 54편과 기존 PDF 사본은 변경하지 않는다. Chrome의 한영 각각 320·390·1280px에서 세 그림·여덟 인용·서지·절 링크·그림 확대와 표 스크롤을 확인했다. 영문 수식 40개에 렌더 오류가 없었으며 가로 화면 넘침과 페이지 오류는 없었다. 실제 휴대폰·Safari·사람 독자 평가를 수행한 것으로 확대하지 않는다. 기존 검색 메타데이터의 80KB 증가 경고는 남아 있고 실패 기준은 넘지 않았다.

릴리스 검사에서 이전 제호 표시 개정과 이번 본문 개정의 두 HTML 선언이 겹친 것을 발견했다. 이전 활성 선언에서 이 글의 두 경로만 퇴역시키고 [정확한 전이 기록](display-declaration-handoff.json)을 보존했다. 다른 제호 변경 항목·이력과 릴리스 검사 코드는 바꾸지 않았다. 이번 대상의 실제 배포 기준 해시에서 검수 후보로 이어지는 선언으로 검사를 다시 통과했다.
