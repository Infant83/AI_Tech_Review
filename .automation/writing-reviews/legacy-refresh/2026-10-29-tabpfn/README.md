# TabPFN 글의 순차 편집 개정 · 2026-10-29

대상은 `2026-05-07_tabpfn-oled-manufacturing-foundation-model` 한 편이다. 원 공개 발행일 2026-05-17, 기존 개정·근거 기준일 2026-05-21을 보존하고 이번 편집 개정일을 2026-10-29로 구분했다. 10월의 새 모델·제품 기능으로 확장한 글이 아니다. 제목·ID·URL·허브 요약과 표지를 포함한 그림 3개를 유지한다. 기존 영문판·등록 기사 PDF가 없어 새 번역·PDF·영상·표지는 만들지 않았다.

## 본문과 근거

중복된 도입·활용 목록과 예상 반박을 줄이고, 모델 원리에서 데이터 생성 조건·암묵지·행 단위·예측 시점의 검증으로 이어지는 전개를 정리했다. 계산 protocol 가상 표와 maintenance·rate·lot 이력 표, 코드 예제, 소자·공정 적용의 비교 구조를 보존한다. 가상 값과 사용 구조를 실제 OLED 데이터 평가나 모델 실행으로 표시하지 않는다. 메타데이터 추가의 유용성은 검증할 가설이며, 사후 검토·폐기 정보의 누출 조건을 명시했다.

Nature의 기본 분류 2.8초·회귀 4.8초에 CPU 8코어와 TabPFN의 RTX 2080 Ti 조건을 덧붙였다. 최대 4시간 튜닝한 개별 비교 모델과 AutoGluon 1.0 앙상블 비교를 구별한다. AutoGluon 회귀 비교에서의 우세는 PHE 최소 300초 튜닝 조건이다. TabPFN-3의 행·특징 수 조합은 개발진이 성능을 검증한 범위로 설명하고 보편 입력 한계·보편 sub-ms 지연시간으로 확대하지 않는다. 일반 연속값 순위와 분류 지표, per-estimator 특징 처리와 보편적인 500개 선택 임계값도 구별했다.

당시 설명은 TabPFN-3 보고서 `arXiv:2605.13986v1`(5월 13일), 패키지 8.0.3의 `61db021f63641235e5b792e30ffde9b00ae818dc`, 모델 카드 `299726533b098357029ecac7c4fa27f97c7f9238`, 라이선스 `93b922c00b944e8251f5f18f1b0ec8af70ab309c`와 날짜 있는 PyPI 자료에 연결했다. 가중치·출력과 코드의 이용 조건을 구별하며 개별 이용 허가를 추정하지 않는다. 당시 API 클라이언트 0.3.0도 관련 소스를 읽었으나 실행하지 않았다.

APS 참고문헌 24개를 최초 인용순으로 정리했다. 원저자·원제·정식 DOI·논문 판본·코드와 문서의 실제 식별자를 확인했다. TabArena는 NeurIPS 2025 정식 서지로, ChemFM은 정식 권호 연도 2026으로, Faraday 연구는 정식 2025 권호로 인용한다. JACS의 L90는 수명과 다른 효율 roll-off의 휘도 지표이며 보고된 최대 지표를 같은 소자·조건으로 단정하지 않는다. 원고에서 쓰이지 않는 과거 참고 목록과 내부 수집·퇴고 메모 링크는 공개 본문에서 덜어내고 기존 기록 자체는 보존했다. 재확인하지 못한 MaterialHub 개별 속성 나열은 제외했다.

작성일 5월 7일은 원고 이력과 `manuscript created`에 보존하고, 렌더러가 발행일을 따로 읽도록 `published date`·`issue date`를 5월 17일로 명시했다. 기존 공개 파일의 조회 집계 설정을 유지해 선택한 글만 재게시한다. 개정은 원고와 기존 Markdown·배포·게시 빌더를 통해 생성하며 공개 HTML만 임시 교체하지 않는다. 기존 ZIP·원문 수집·시안은 배포물로 다시 만들지 않았다.

## 실제 감수 범위

`root`가 통합·문체 개정·인용 조판·출력·게시 확인을, `legacy_tabpfn_sources`가 모델·역사 판본·평가 조건을, `legacy_tabpfn_materials`가 재료·데이터 문헌·서지를, `legacy_tabpfn_prose`가 문체·논지의 독립 감수를 맡았다. 마지막 감수에서 전달한 비교·문장 연결 권고를 반영했다. 정확한 실행 모델 ID와 원 작성 에이전트 구성은 추정하지 않는다.

모델 감수는 Nature·2.5·TabArena·3 v1 PDF의 관련 본문·방법·표·도판과 일부 렌더 범위다. 네 PDF 전체·모든 보충자료를 읽었다고 주장하지 않는다. 재료 감수는 ChemFM·FAIR·2020 재료 연구의 관련 공개 본문, AiiDA 공개 preview, JST 요약, 출판사·기관 원문 초록·검색에 표시된 관련 원문 구절·정식 서지 등 확인한 범위를 사용했다. JACS·OLED host의 구독 원문·SI 전체를 확보하지 않았다. MACE는 2026-05-03 README를 확인했다. SCM·Schrödinger 문서는 일반 계산 workflow의 보조 자료로 읽었으며 5월의 제품 페이지 사본을 확보한 것으로 표시하지 않는다.

TabPFN 설치·훈련·API·예측 실행, OLED·DFT·성능 벤치마크 재현, 사람의 문장별 심사·독자 평가는 수행하지 않았다. 참고문헌 manifest는 확인한 판본·원제·저자와 정본 해시를, 자산 baseline은 그림의 보존을 기록한다. 실제 배포 커밋·URL·완료 시각은 공개 검증 뒤 `progress.json`에 남긴다.
