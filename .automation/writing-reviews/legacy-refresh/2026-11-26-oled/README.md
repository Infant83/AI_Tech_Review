## 차단 조건을 다시 판단한 범위

운영팀(ADOPT)의 [기존 손상 PDF 일감](../../../../operations/issues/OPS-f6deea28-7843-4409-9b02-84a7f23e198e.json) v16과 최신 공용 기록에서 정상 원판·원 기술 브리프의 작성 소스·실제 재생성 결과는 확인되지 않았다. 같은 손상 PDF의 이력·백업 검색이나 실패한 전체 렌더를 다시 실행하지 않았다. 종전 `original_required`는 원래 5쪽의 전체 내용·레이아웃을 복원하고 대조할 수 없다는 자료 한계다. 기존 기록은 이미 게시 권한이 있고 추가 승인 대기가 아니라고 명시한다.

편집부(AEDAUT)는 사용자가 승인한 같은 글의 개편·기존 PDF 동기화 범위 안에서, 감수된 영문 웹 원고와 동일한 8편의 정확한 1판을 바탕으로 **새 영문 기술 브리프 개정판을 집필한다**고 [범위를 결정했다](pdf-regeneration-scope.json). 이 편집 결정은 정상 원판을 발견하거나 손상 바이트를 기술적으로 복구한 결과와 구별한다. 기존 운영 일감의 소유·우선순위·완료 조건을 임의로 바꾸지 않는다.

종전 PDF 786,445바이트·SHA-256 `ae9b77889c84795c2b630993c097e0d9fc69c81b9e6c837302f9a6ce9e0eaf43`는 원래 Git blob `cc5550ca1eef22843c59c92ae93b003cafa9e5c5`와 정확한 비공개 사본으로 보존했다. 읽을 수 없는 파일을 새 공개 경로로 추가하지 않는다. 원 발행일 2026-09-11·근거 기준일 2026-09-10, 글 ID·제목·기존 한영 첨부 URL을 보존하고 새 PDF 편집일 2026-11-26을 구별한다. 이 첨부는 독립 아카이브 문서로 등록돼 있지 않아 새 문서 ID나 한국어 번역 PDF를 만들지 않는다.

## 내용과 실제 역할

PBTTT의 검출 조건에 따른 선폭에서 출발해, 생성 후보의 목표와 실패 탐지, 상태 교차·유효 퍼텐셜의 전자구조 검증, 양자 에너지의 오차·취득 비용을 연결한다. OLED 소규모 후보군과 고수준 계산안은 계속 제안으로 둔다. 선정 논문·판본이나 근거 기준일을 늘리지 않고, 후속 제품·논문 상태를 9월의 사실로 소급하지 않는다. 한영 허브 요약은 본문과 맞아 그대로 유지한다.

`legacy1126_brief_author`는 11월 22일 감수된 영문 원고 전체와 원출처·문체 감사 기록을 읽고 새 기술 브리프를 집필했다. `legacy1126_pdf_gate`는 8편의 보관 원문 해시·기존 감수 범위를 대조하고 저장 원문의 핵심 조건을 선택 독해한 뒤, 한영 원고·새 브리프 전체의 과학·논지·문체·APS를 비작성자로 감수했다. [원고 감수](final-editorial-source-review.json)는 세 Markdown 해시에 결속하며 실제 새 독해와 이전 감사의 재사용을 나눈다. root도 한영 원고와 새 기술 브리프를 전체 읽고 통합했다.

`dqb1125_pdf`는 기존 `scripts/markdown_to_pdf.py`의 스타일·인라인 구성을 재사용하는 주제별 ReportLab 어댑터를 작성했다. root가 실행·출력 검증을 맡았다. 원 생성 대표 그림과 제안 workflow는 바이트를 보존했다. 근거 지도의 세로축 문구가 그림 위쪽에서 잘려, 문구·연구 노드·축·정성적 분류는 그대로 두고 해당 라벨의 y/회전 중심만 165에서 360으로 옮겼다. 숫자와 단위가 페이지 양쪽으로 나뉘지 않게 처리했다. 새 표지·그림·영상이나 원 논문 그림을 제작·복사하지 않았다.

## 새 PDF의 출력 검수

새 개정판은 **5쪽·2,490,570바이트**, SHA-256 `8d68d1bfae35224e9c6f0b5405707a962d7eb8b5ea9e8c2df0def12e63420409`다. 원판과 페이지 수가 같아도 원래 5쪽의 복원·동일 내용·동일 레이아웃을 뜻하지 않는다. PDF는 새로 쓴 기술 브리프와 세 기존 그림, 8개 전원 저자·원제·정확한 arXiv v1 서지, 새 판본·작성 공개를 담는다. 생성 시각은 실제 UTC 판본 생성 시각을 보존하며 한국시간의 편집 날짜와 나눠 기록한다.

root가 최종 Poppler 110dpi 전 5쪽을 열어 읽고 전쪽 텍스트·엄격 파싱·메타데이터·외부 URI 8개·내부 인용 9개·실행 동작·첨부·개인정보·글꼴·페이지 경계를 확인했다. 비작성자 `legacy1126_pdf_gate`의 전쪽 화면·전체 텍스트·과학·APS·구조 감사는 별도 최종 기록에 남긴다. 원 계산·학습·QPU·증명이나 사람 독자 실험을 수행했다고 주장하지 않는다.

이 원고·출력 검수는 후보·CI·실제 공개 완료를 대신하지 않는다. 검증한 PDF만 기존 원본 위치와 한영 배포 사본에 동기화한 뒤, 최신 공개 기준과 다른 자료 보존·정확한 출판 요청·한영 브라우저·실제 CI 및 HTTPS를 대조한다. 그 전에는 `current`를 비우거나 `completed`를 늘리지 않는다.


## 후보·기존 자료 보존과 웹 화면

고정 Pillow 11.2.1로 후보를 만들고 [전체 후보 독립 감수](candidate-independent-review.json)를 거쳤다. 배포 기준·전송량·봉인·전체 공개 파일 검증은 통과했으며, 봉인 포함 2,783파일·82개 카탈로그 항목을 확인했다. 전송량의 기존 비차단 경고 두 개는 운영팀(ADOPT)의 기존 용량 과제 범위로 남긴다. 실제 페이로드 2,782경로 중 삭제·추가 없이 2,774경로가 이전 공개판과 바이트가 같고, 변경은 승인한 본문·PDF·SVG 한영 6경로와 파생 manifest·reader-updates 두 경로다.

다른 58개 리뷰의 전체 메타데이터·본문·자산, 177개 아카이브 항목, 82개 카탈로그 전체 JSON, 다른 PDF 290경로·날짜별 편집글 68경로·Classiq 강의 23경로와 L016 두 PDF, 최신 DQB·DRB·DQE를 보존했다. [글 원본과 후보의 별도 대조](candidate-own-source-correspondence-review.json)는 한영 각 61문단·8개 참고문헌·최초 인용순·제목·원 날짜·요약·집계 설정 null·명시 출판 요청의 세 해시와 10경로 공개 allowlist를 확인했다.

이전 제호 정리 선언과 이번 본문 개정 선언이 같은 두 HTML을 소유해 처음 배포 기준 검사에서 중복을 거절했다. [선언 이관 기록](declaration-transition.json)에 따라 이 글의 한영 HTML 두 경로만 새 전용 개정 선언으로 옮겼다. 이전 표시 전환의 해시·Git 이력과 나머지 모든 선언 항목을 보존했고, 원인 수정 뒤 재검사했다. 별도로 자동 생성된 다른 글의 무변경 선언은 원래 Git에 없고 두 경로의 전후·실제 후보·이전 봉인 해시가 같음을 확인해 이번 생성물만 제외했다. 다른 게시물의 재개편을 뜻하지 않는다.

[후보 브라우저 검사](candidate-browser-review.json)는 한영 데스크톱·390px 모바일 도입, 그림 세 개의 로드, 인용 이동이 끝난 서지 화면, 허브의 기존 요약·검색·키보드 본문 진입을 확인했다. 후보 언어 링크는 실제 공개 주소를 보존하므로 후보 경로를 각각 읽었고 실제 언어 전환은 배포 후 확인한다. 인앱 브라우저의 기본 PDF 화면은 비어 있어 네이티브 PDF 뷰어 성공으로 기록하지 않았다. 최종 PDF의 전쪽 Poppler·독립 파서 검수와 실제 HTTPS 바이트 확인은 별도 근거다. 새 계정·알림·필기 데이터나 다른 사용자 탭을 변경하지 않았다.

독립 후보의 실제 검사·봉인·전체 검증·바이트 대조는 `dqb1125_qflow_materials`가 순서대로 수행했고, 자체 원본→후보의 별도 대조는 `legacy1126_pdf_gate`가 맡았다. root는 두 결과를 통합하고 한영 브라우저와 게시 검증을 수행한다. 게시 직전 원격 main과 공개 release 전체 바이트가 검증한 기준과 같음을 다시 확인했다.
