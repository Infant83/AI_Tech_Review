# TabPFN 글의 최신 동향 확장 · 2026-10-29

사용자가 앞선 순차 문체 개정 뒤, 첫 공개부터 현재까지 표 데이터 파운데이션 모델의 발전·최신 경쟁·효용·관심·전망을 함께 읽을 수 있도록 이 글의 내용 확장과 공개 반영을 요청했다. 대상 ID·URL과 원 발행일 2026-05-17을 보존하며, 원 평가의 2026-05-21과 새 근거 기준일 2026-10-29를 구분한다. 제목은 「TabPFN과 표 데이터 파운데이션 모델의 진화」로, 부제와 실제 허브 요약도 확장 범위에 맞춘다. 이 후속 작업은 초기 49편 순차 개편의 다음 대상을 바꾸거나 완료 수를 늘리는 작업이 아니다.

## 추가한 논의

5월에 이미 TabPFN-3의 큰 표·text·thinking 방향이 존재했음을 보존했다. 그 뒤 Google TabFM, Kumo Tabular, TabPFN-3.5, LimiX-2, EXAONE Tabular, Mitra-v2의 구체적인 설계·공개 시점·이용 조건을 비교한다. 5월 이전 모델인 TabICLv2와 실제 표 사전학습 계열 TabDPT도 현재 선택지와 학습 방식의 비교 맥락에서 다룬다. 모델 이름이나 당시 1위 주장을 현재의 보편 순위로 바꾸지 않는다.

공식 TabArena와 BeyondArena 보드의 2026-10-28 판본 `68988c6e5b31e2ec9a2d193c555dd41b8cb01fd3`를 사용했다. 그림 3은 개별 모델·전체 IID 과제·누락 실행 대체 허용 pool에서 선택한 default 설정 8개의 보고 Elo와95%구간을 Matplotlib으로 재도표했다. 선택한 8개 설정은 대체율0%이며 모두GPU지만, 전처리·앙상블·미세조정 조건은 같지 않다. Mitra-v2의50-step fine-tuning/8-fold bagging을 명시했다. LimiX-2의 두 과제에 관한 미해결 오염 경고는 보고자의 관찰과 의혹으로 귀속하고 수치·코드를 직접 재현했다고 쓰지 않았다. 신뢰구간 겹침은 독립적인 유의성 검정을 수행한 결과로 표시하지 않는다.

시간·그룹 분할과 예측 분포의 평가, 추가 추론 계산의 효과를 실제 논문 범위에서 연결했다. TabReliBench의 작은 IID 무작위 분할과 TTC의 TabPFN-3·TabICLv2·TabFM 판본을 구별한다. 7월 MFTabPFN의 고정 본체·encoder/보정 학습은 계산 protocol과 비싼 라벨 논의에 연결한 연구 사례다. OLED 실험 성공이나 모든 계산 수준의 결합 성공을 주장하지 않는다. BigQuery preview와 SAP의 인수·투자 계획은 연구·제품 개발의 관심을 보여주는 자료로 읽으며 채택률·시장점유율·ROI·이미 집행한 투자로 확대하지 않는다. BigQuery의 현행50특징/10범주와 서비스/다운로드 가중치 조건도 원문을 확인했다.

발전과 새로운 활용의 출현은 서로 다른 예측 작업의 학습 경험을 다시 쓰고 연구·데이터 시스템에서 호출하는 방식으로 설명했다. 불연속적인 능력의 출현을 통제 실험으로 입증했다고 주장하지 않는다. 기존 글의 계산 조건·암묵지·행 단위·후보 선택 관점을 유지하고 중복되던 과거 벤치마크 목록 표는 새 비교와 연결했다.

## 실제 검토 범위

`root`는 통합·집필·참고문헌 조판·재도표와 출력 검수를, `tabular_frontier_models`는 최신 모델·구조·판본·제공 및 이용 조건을, `tabular_benchmark_emergence`는 보드 데이터·평가 방법·연구 활용 근거와 도표 값을, `tabular_editorial_evolution`은 역사적 연속성·문체·요약과 그림을 독립 검토했다. 현재 모델 ID는 추정하지 않는다. 앞선 10월29일 역사·재료 감수 자료도 재사용했다.

각 담당은 원논문 관련본문·표, 공식 카드·README와 코드 공개 정보·라이선스를 확인했다. root는 TabFM v1 PDF의 원리·방법·평가·확장 부분을 읽고 구조 도판을 렌더했으며, TabPFN-3.5 v2 PDF의 관련 본문·평가 도판도 대조했다. 모든 논문의 PDF·보충자료를 완독·렌더했다고 쓰지 않는다. 일부 재료 문헌의 구독 원문 범위는 앞선 감수 기록과 같다. 모델 훈련·예측·API 호출·벤치마크 재현·OLED/DFT 실험·사람 독자 평가는 수행하지 않았다.

APS 최초 인용순47개 참고문헌·62개 인용을 대조했다.20명 이하의 원저자와 정식 원제·출판본·보고서 판본을 보존했다. TabDPT는 공식 출판PDF의 저자10명을 사용했으며 출판 웹 metadata의 누락을 원저자 누락으로 옮기지 않았다. 코드와 모델 카드의 실제 commit을 인용한다. 참고문헌에 임의 설명·번역 제목을 추가하지 않는다.

원 그림 파일3개와 표지·ID·URL을 유지하며 새 그림1개만 추가했다. 기존 그림3은 첫 등장 순서에 맞춰 그림4로 표기했다. 새 원자료와 생성 코드에는 공개 보드의 선택한 수치·조건·출처만 있다. 원 메일·비공개 자료·원문 사본·QA화면·내부 절대경로는 공개 배포물에 넣지 않았다. 기존 영문판·등록 기사PDF가 없어 새 번역·PDF·영상·표지는 만들지 않았다. 영문UI도 한국어판 표시와 한국어 제목/요약을 유지한다.

## 출력·공개 확인

생성은 canonical Markdown→기존 HTML/dist builder→선택한 글의 publisher→공통 허브의 순서로 수행했다.33개 관련 단위 검사가 통과했고, 공개 검증은1,627개 파일·52개 출판 항목을 통과했다.320·390·1440px에서 가로 넘침 없이 그림4개와47개 참고문헌·62개 인용 링크를 확인했다. 기존3그림의 해시와 다른48개 manifest 항목·다른 기사 갱신/알림 기록·아카이브 등록부를 보존했다. 변경된 갱신 페이지는 이 글과 제목/요약이 달라진 한영 허브뿐이다.

독립 감수는 새 모델의 근거와 평가 조건·문체를 통과했으며 최소 권고를 반영했다. 그림의8개 중심값과CI 양끝을 원자료와 대조했고, 통합 검토에서SVG의 좌표도 역산해 일치했다. 그림의 서체는 브라우저 의존 없이 표시되도록 윤곽선으로 저장했다. 최종 공개 검증과 배포 커밋·확인 시각은 후속 기록에 남긴다.

## 공개 검증 완료

게시 커밋 `3688ba0d62fde2e422c8f01cd421b54c3479a3a0`, Actions 실행 `40804225659`의 build·deploy·notify-readers가 모두 성공했다. 실제 HTTPS 본문은 Cloudflare가 추가한 통계 beacon 한 개를 제외하면 검수본과 바이트가 같고, 새 SVG와 기존 세 그림의 공개 해시도 일치한다. 공개390px 화면에서 그림4개·참고문헌47개·인용62곳의 로드/연결과 원 발행일·새 수정일, 가로 넘침 없음을 재확인했다. 한영 공개 허브의 제목·전체 요약도 검수본과 일치한다.

로컬390px 허브에서 긴 요약의 펼치기·접기 상태를 클릭해 확인했고, 영어UI의한국어판표시·한국어전체요약·표지로드를 확인했다. 차트는 모바일에서 읽기 폭을 유지하는 내부 스크롤과 데스크톱 표시를 확인했다. 최종SVG의행끝공백정리는 모든XML기하·텍스트의동등성을확인했다. 휴대폰 실기기·알림 도착을 확인한 것은 아니다. 기존 조회 집계 서비스의 별도 오류에 관한 앞선 기록도 정상 집계 증거로 바꾸지 않았다.

이번 후속 확장은 초기49편의 순차 완료수3편을 유지한다. 다음 예약 대상은 「AI 과학자, 시작의 끝에서」이며, 같은 글을 다음 회차 대상으로 다시 잡지 않는다.
