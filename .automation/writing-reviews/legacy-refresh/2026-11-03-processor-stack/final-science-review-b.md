# 개편 원고의 독립 과학·서지 재감수 B

2026-11-03 · `legacy1103_sources_b`

총괄이 병합한 원고를 다시 연속해서 읽고 참고문헌 manifest와 대조했다. 이 역할의 원출처 감수 범위는 [8]–[10], [12]–[22]이며, 다른 자료의 본문 사실 검증은 담당 역할의 기록을 따른다. [4] Groq의 구조 설명도 이 역할이 원 출처를 읽었다. 원 발행일·근거 범위 2026-06-17과 이번 개정일이 구별되어 있다.

## 확인 결과

- 최초 인용 순서가 [1]–[22]이고 총 27개 인용 링크가 해당 22개 서지와 대응한다. 누락된 번호·미인용 서지·중복 ID가 없다. URL은 공개 HTTPS이며 사용자명·암호·인증 query가 없다. 원고에 개인 주소나 내부 절대경로가 없다.
- [8] IPU는 인프라 처리 장치로 먼저 정의됐다. [9] AMX의 BF16·INT8와 [10] SME·SME2의 CPU 확장 설명은 확인한 원 자료와 대응한다.
- [12] Copilot+ 요구와 지원 소프트웨어 경로, [13] M4의 제조사 38 TOPS가 구별된다. 정밀도·연산 계수 조건과 실제 실행시간을 따로 설명해 두 숫자의 직접 순위를 만들지 않는다.
- [14]–[16]은 BlueField-3의 400 Gb/s, BlueField-4의 발표 사양 800 Gb/s와 파트너 스토리지 플랫폼의 2026년 하반기 공급 계획으로 대응한다. [15]의 원저자 Itay Ozery에게 크레딧이 있다.
- [17]은 Hartmut Neven의 Willow 글이며 오류정정과 일반 AI 실행 성능을 구별한다. [19]은 WSE-3 최초 발표이고 현재 WSE-3 Turbo/CS-4 사양을 들여오지 않는다. 페이지 날짜 불일치는 manifest에 기록하고 서지에는 연도만 쓴다.
- [20] AI200·AI250은 각각 2026·2027년 상용화 계획이다. [21] Guide는 Passage 광 연결에 빛을 공급하는 광원과 당시 파트너 검증 단계로 설명한다. [22]는 2021년 Loihi 2 기술 요약의 이벤트·비동기·메모리 구조를 근거로 한다.
- 서지에는 원제·저자·기관·날짜·식별 링크가 있으며 감사 해설을 서지 문자열에 붙이지 않았다. Groq의 옛 architecture 주소, 현재 Cerebras 제품 및 Arm SME2 소개 페이지는 해당 시점의 날짜 있는 자료로 정리됐다.

## 정밀화 반영 확인

AMD AI Engine의 타일 배열과 이를 포함하는 Versal SoC 전체의 관계를 구분하도록 전달했다. 최종 `AMD Versal SoC [18]는 AI Engine의 VLIW/SIMD vector processor tile을 programmable logic, Arm core와 network-on-chip에 결합해 DSP와 ML inference를 처리합니다`라는 문장을 다시 확인했다. 플랫폼과 타일 배열의 관계가 정확하며 이 역할의 사실 검수에서 남은 차단 사항은 없다.

그림 2·7의 원 좌표·효율 순위 문제는 총괄에게 이미 전달했다. 수정된 SVG의 텍스트 구조에서 성능 순위를 없앤 병렬 역할·조건 구성을 확인했으며 최종 렌더·모바일 검수는 별도 기록을 따른다. 그림 4의 수정된 캡션은 선의 연결이 직렬 실행 순서나 실제 버스 구성을 뜻하지 않는 작업 배치 개념임을 명시한다. 이번 역할은 원 실험·제품 벤치마크·사람 독자 평가를 수행하지 않았다.

[19]의 Julie Choi 크레딧도 별도 재확인했다. 공식 글 상단의 이름은 `/author/juliec`에 연결되며, 해당 공식 저자 페이지의 글 목록에 이 WSE-3 발표가 포함된다. 본문 말미의 보도 문의 담당자와 구별되는 표시다. 따라서 현재 표시된 원저자와 기관을 보존하는 `J. Choi … (Cerebras Systems, 2024)` 서지를 유지한다. 날짜 불일치는 앞선 감사 기록처럼 연도로 처리한다.
