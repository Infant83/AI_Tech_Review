## 이번 개정

실패 복구·자원 확장·탐색 종료라는 세 과업에서 판단의 속도와 잘못된 결정의 비용을 비교하는 논지를 유지했다. 결과 뒤에 거듭 붙은 부정·유보를 실제 비교 조건에 통합하고, ‘읽다’를 해석·판단의 뜻으로 반복한 문장을 구체화했다. 총비용 논의는 추론·대기·복구·사람 개입의 계상과 후속 종료 규칙 비교로 연결했다. 일률적인 문장 수·반전·결말을 적용하지 않았다.

원문 대조에서 E1의 `p=0.35`는 실패·지연 사건을 주입하는 조건으로 명확히 했다. E2는 actor가 `midway3-login3` 로그인 노드에서 동작하고 수치 worker는 별도의 전용 `caslake` 노드에서 실행됐다는 배치를 보완했다. 단일 프로세스의 actor 메시지 교환과 모든 계산이 같은 노드에서 실행된다는 주장을 구별한다. arXiv의 9월 9일 제출일을 별도의 최초 공개 시각으로 단정하지 않았다.

Avatar v1의 원제와 저자 6명, Academy 0.5.0의 정확한 문서 판본을 APS 서지에 반영했다. 참고문헌 항목에 섞인 읽기 순서·검증 설명을 정리하고, 9월의 자료 확인 기록과 11월 27일 재대조를 구분했다. 원 발행의 단일 에이전트·표지 제작·검토 범위는 과거 이력으로 보존하고 이번 역할을 별도로 공개했다.

## 실제 역할과 보존 범위

- `avatar1127_prose`: 원고의 초기 독립 문체 검토 후 한영 수정 초안 작성. 자기 수정본의 최종 독립 감수자로 기록하지 않는다.
- root: 기존·수정 한영 본문 전체 검토, Avatar v1의 실험 정의·배치·결과 직접 대조, 통합 편집과 출판 작업.
- `avatar1127_science`: v1 HTML 본문·표·캡션·참고문헌 전체, 8쪽 PDF 전체 추출 텍스트와 선택한 1·7쪽, 정확한 Academy 0.5.0 문서·선택 코드, Colmena 공식 문서와 연구자 소개 대조. 최종 한영 과학·APS·역할 공개의 독립 감수.
- `avatar1127_build_audit`: 기존 실제 한영 공개본과 출판 경로 확인, 수정 한영 원고 전체의 비작성자 문체·보존 감수. 후보·출력·실제 게시 검토는 수행한 단계에 따라 추가 기록한다.

낭비 계산 최대 약 55%, N=128에서 평균 backlog 약 21과 99, QM9 후보 5,000개·초기 라벨 100개·회차당 32개, 12→7회차·GPU 활동 시간 약 40% 절감을 원 조건과 함께 보존했다. 5/12≈41.7%는 회차 비율의 산술이며 GPU 시간 측정을 재현한 값과 구별한다. QM9 조회, 신규 DFT, 전체 비용과 전력의 구별을 유지했다.

기존 표지·도식 자산 7개와 리뷰 제안식 원문을 보존한다. 등록된 기사 PDF가 없어 새 PDF를 만들지 않는다. 표지·영상도 새로 제작하지 않는다. 원 연구의 코드·GPU 실험·성능, 모델 학습이나 사람 독자의 이해도 시험은 수행하지 않았다. 원문 PDF 전쪽의 시각 감수를 수행한 것으로 표시하지 않는다.

과거 `build_support.py`는 도식과 당시 전체 사이트의 조사 목록을 다시 쓰는 도구이고, `validate_package.py`는 28편 등 과거 발행 조건에 묶여 있다. 이번에는 기존 본문 렌더러·packager와 현재의 후보·출판 보존 검사를 사용한다. 검사를 완화하거나 과거 검사에 맞춰 현재 공개 자료를 줄이지 않는다.

배포 정책 검사에서는 과거 제호 정리 선언 62행 중 Avatar의 두 HTML 경로와 이번 개정 선언이 중복되는 문제를 확인했다. 과거 변경의 `after`가 실제 배포 기준 및 이번 변경의 `before`와 같고, 새 `after`가 감수한 후보와 같음을 대조한 뒤 이 두 경로만 새 개정 선언으로 인계했다. 다른 60행과 기존 사유·버전은 보존했고, 원 62행은 기준 커밋의 Git 이력에 남아 있다. [정확 전이 대조](declaration-handoff-review.json)는 후보 바이트를 바꾸거나 검사를 완화한 조치와 구별한다.

## 검증 상태

한영 원고의 [과학·서지 감수](science-final-review.json), [비작성자의 문체·보존 감수](manuscript-prose-preservation-final.json), 기존 렌더러의 본문 생성·패키징과 로컬 참조 검사를 마쳤다. [후보 브라우저 확인](browser-candidate-review.json)에서는 한영 데스크톱·모바일의 본문·기존 그림·수식·표를 확인했다. 모바일 표는 내부에서 가로로 넘겨 볼 수 있고 페이지 전체의 가로 넘침은 없었다. 이 확인은 실제 HTTPS 공개 검증과 구별한다.

[후보 독립 감수](candidate-independent-review.json)는 배포 정책·용량 기준·봉인·전체 공개 파일 검사를 통과했다. 기존 2,795개 payload 경로와 봉인 파일을 포함한 2,796개 파일을 확인했다. 본문 변경은 Avatar 한영 두 페이지이며 목록의 해당 수정일과 독자 갱신 기록이 함께 바뀌었다. 다른 58개 리뷰, 181개 아카이브 행, PDF 297경로, 날짜별 편집글 74경로와 Classiq 24경로를 보존했다. 기존 검색·전체 용량의 주의 표시 두 건은 통과 결과와 함께 기록했다.

CI 네 단계와 실제 HTTPS 공개 확인은 수행한 증거에 따라 별도로 기록한다. 아래 완료 기록을 남기기 전에는 공개 완료로 판정하지 않는다.
