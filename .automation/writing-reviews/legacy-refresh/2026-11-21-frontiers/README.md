## 실제 역할과 보존

편집부(AEDAUT) root가 한영 편집·통합과 신경과학·기후 원출처, 교육용 계산을 대조한다. 신경과학은 17번의 관련 서론·방법·결과·논의, 18번의 저자 소속기관이 공개한 초록과 서지를 확인했다. 18번 PDF의 재취득은 제한됐으며 전체 본문을 새로 읽었다고 표시하지 않는다. NOAA 당시 보관본과 MAAP의 결과·방법·부록·권장 인용을 읽고 관측과 전망을 구별한다.

`frontiers1121_physics`는 물리·충돌·QML 자료와 정식 서지 1–8을 독립 대조했다. 의향서·논문의 선택한 본문·표·초록과 일부 PDF 렌더를 구분하며 장치·벤치마크를 재현하지 않았다. `frontiers1121_math`는 NS 원고 166쪽 중 1–6쪽·125쪽, Clay 문제 진술 6쪽·Buckmaster 성명 4쪽, 공식 발표와 고정 커밋의 관련 안내·진입·비교 명제를 읽었다. 전체 증명이나 Lean·Comparator를 실행하지 않았다. `frontiers1121_prose`는 비작성자로 한영 원고 전체·제목·요약·수정 이력을 읽고 문장의 연결과 강약을 감수한다. 실제 읽기·초록·선택 범위와 원래 작성 이력을 구별하고 조직명으로 사람 검토를 보증하지 않는다.

기존 원고와 Node·marked 빌더로 생성하며 공개 HTML만 임시 수정하지 않는다. 이번 새 내용 판본의 제호는 ATRL, author 메타데이터는 책임 편집자로 표시한다. 표지와 래스터·SVG 24사본, 언어별 이미지 경로 11개·식 블록 6개, AUC·집중 모형 CSV와 편광 조작식을 유지했다. 교육용 집중 모형의 기존 4행과 기본 편광 확률은 식으로 대조했다. 없는 PDF·영상·새 표지를 제작하지 않는다. 과거 원문·메일·QA 화면·내부 경로는 공개하지 않으며 운영팀(ADOPT)의 인프라·디자인 작업을 섞지 않는다.
