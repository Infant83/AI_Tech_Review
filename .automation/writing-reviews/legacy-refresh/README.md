# 기존 게시물의 순차 개편

2026년 10월 27일 사용자 요청으로 시작한다. [진행 기록](progress.json)의 초기 49편을 실제 발행일·글 ID 순서로 한 편씩 검토한다. `current`가 있으면 그 글부터 이어가고, 없으면 `completed`에 없는 첫 글을 선택한다. 매회 한 편만 다루며 이미 잘 작동하는 문장과 구성을 보존한다.

공통 문체 하네스와 편집 정책·작성 방법·과학 설명 준칙·APS 인용 기준을 적용한다. 원 발행일과 근거 기준일, 저자 목소리와 과학적 주장 범위를 유지하고 수정 이력을 별도로 남긴다. 원문과 문체·참고문헌을 함께 대조하고, 필요한 기존 한영판·HTML·PDF·아카이브를 동기화한다. 없는 번역·PDF·영상·새 표지의 제작을 일괄 요구하지 않는다. 2026-10-27에 개편한 허브 소개는 본문과 어긋날 때만 조정한다.

검토 뒤 `updated` 또는 `reviewed_no_change`로 완료를 기록한다. 수정한 글은 실제 공개 검증까지 끝난 뒤 배포 커밋·확인 시각·간단한 변경 이유를 기록한다. 수정이 불필요한 경우에는 이유와 확인한 판본을 남긴다. 막힌 작업은 완료로 표시하지 않고 재개할 단계와 필요한 자료를 `current`에 남긴다. 진행 기록에는 글 ID·커밋·검수 결과만 두고 개인 자료·인증정보·내부 절대경로·원문 수집물을 넣지 않는다.

첫 글은 폴더 이름의 날짜와 무관하게 발행일이 2026-05-09인 「AI 에이전트를 일하게 하는 기술: 하네스 엔지니어링」이다. 전체 초기 대상을 처리하면 같은 글을 계속 다시 고치지 않고 완료 상태를 기록한다.
