# 문단의 주장과 대비 대상 감수

2026-11-01 · 양자와 재료 연구의 AI 자동화와 과학적 판단

## 확인한 문제

기존 하네스는 과도한 대비를 문맥으로 판단하도록 안내했다. 이번 원고의 출처·과학 조건·한영 대응 감사에서는 비교 조건의 보존을 확인했으나, 일부 문단이 논의하지 않은 주장을 새로 반박하는 흐름을 놓쳤다. 게시 검사와 렌더러는 링크·메타데이터·자산·공개 범위를 확인하며 문장의 논증 기능을 판정하지 않는다.

현재 적용한 Pages 글쓰기 스킬의 편집 기준도, 맥락에서 이미 드러나는 정보나 주장하지 않은 성과에 면책 문장을 덧붙이지 않도록 안내한다. 실제 적용에서는 원고를 연속해서 읽고 대비 대상과 의미 변화를 확인하는 감수가 더 필요했다.

실제로 관찰한 z/y·초기 분포의 이탈, 행렬 오차와 궤도 간격 오차의 역전, 여러 초기화 모형의 비슷한 SCF 가속, 대조군 차이의 신뢰구간은 논증과 함께 유지한다. 표본 추정의 조건과 개별 결과 검사의 목적도 각각 설명한다.

## 지침·도구와 산출물의 구분

그림 생성기에는 QPU 측정·정리의 반례·사람의 확정 오류율을 부정하는 문구가 정적 텍스트로 들어 있었다. 원고를 고쳐도 그림을 다시 만들면 이 설명이 남는 구조였다. 생성기의 footer·접근성 설명·메타데이터를 CPU 보고값, 고정 기저 예측 행렬, AI 평가자의 표본별 판정처럼 실제 대상과 작성 방법을 설명하는 문구로 수정했다. 그림의 수치와 도형 속성은 이전 출력과 대조한다. HTML 생성기와 해당 리뷰의 게시 메타데이터도 실제 확인한 자료·수행한 계산·제안의 정체를 직접 기록하도록 맞췄다.

공통 문체 하네스에 대비 대상의 근거와 문장을 덜었을 때의 의미 변화를 확인하는 실행 감수를 추가하고, 현재 한영 원고를 적용 범위에 명시했다. 작성 방법과 과학 설명 준칙은 이 절차를 참조한다. 설명 기획 브리프의 항목도 질문·근거·해석의 연결을 읽고 필요한 조건을 배치하도록 다듬었다. 부정어 수·문장 위치·정형 문단 구조를 판정 기준으로 삼는 새 자동 검사는 만들지 않았다.

이 문서는 교정 판단과 실제 지침 변경을 기록한다. 한영 원고·그림 설명의 반영, 독립 문맥 재독해, HTML/PDF·공개 배포 확인 결과는 해당 주제의 README와 figure-manifest에 각각 남긴다. 별도 에이전트의 감수와 사람의 독자 이해도 평가는 구별한다.
