# Nature·APS DRB 조사와 공개

2026-11-13 사용자 지시로 Daily Research Brief(DRB)에도 DQB의 공개 기준과 방법을 적용한다. 이 과제는 Agentic Tech Review Letters(ATRL)의 에이전틱 편집·저술팀(Agentic Editorial and Authoring Team, AEDAUT) 업무다. 이후 보고와 인계에는 편집부(AEDAUT)를 사용하고, 기술 문제는 운영팀(ADOPT)과 연결한다.

DRB는 현재 매주 금요일 한국시간 오전 9시에 작성하는 별도 예약이다. 이름의 Daily를 근거로 일일 예약으로 바꾸지 않는다. Codex 앱의 기존 `nature-aps-drb` 예약을 이어가며 DQB·기존 게시물 개편 예약이나 별도 스케줄러를 추가하지 않는다. 기존에 승인된 본인 이메일 전달과 중복 발송 방지 절차는 유지한다. 사이트 공개를 위해 같은 회차의 메일을 다시 보내지는 않는다.

## 원문에서 편집글로

`AGENTS.md`, 편집 정책·작성 방법·과학 설명 준칙·APS 인용 기준과 공통 문체 감사 하네스를 적용한다. Nature 계열, Artificial Intelligence Review, PRL·PRB·PRX·PRX Quantum의 기존 조사 범위와 관심 주제는 비공개 인계 기록 및 예약의 지시를 따른다. 공식 목록의 확인 범위, 초록과 전문, 저널 출판본과 공개 preprint, 새 조사와 재사용한 감수를 구별한다. 메일·목록 조회 실패를 새 자료 없음이나 전체 조사 완료로 표시하지 않는다.

DRB와 DQB는 연구 탐색의 출발점이다. 원 논문·보충자료·공식 코드 및 관련 연구를 직접 확인하고 연구 질문·물리적 메커니즘·방법·근거·열린 문제로 연결한다. 기존 리뷰·렉처·DQB 기획과 대조하며 후속·병렬 관계와 공통 질문을 누적한다. 이미 다룬 연구를 새 발견이나 새 승인 기획으로 중복 등록하지 않는다.

독자가 읽는 공개 산출물은 짧은 한영 편집글과 별도 목록 요약이다. 구체적인 연구 상황에서 도입해 편집부가 얻은 관점으로 이어가고, 필요하면 주요 원 논문·관련 연구와 기존 글의 실제 논의를 연결한다. 원 제목·초록을 옮기거나 연구 목록만 나열하지 않는다. 제목은 이번 글의 초점을, 요약은 읽을 이유와 핵심 관계를 드러낸다. 보관·검수·수정 작업 보고를 요약의 중심에 놓지 않는다. 매회 새 통찰·고정 문단 수·심층 리뷰 분량을 강제하지 않는다.

보고된 결과, 편집 해석, 독립 산술 대조와 후속 제안을 구별한다. QPU 실행·고전 계산·전자구조 계산·컴파일·논리 자원 추정은 해당 주장에 필요한 위치에서 설명한다. 원저자·원제·판본과 최초 인용 순서에 따른 APS 서지를 유지한다. 독립 담당자는 과학 근거와 함께 도입·관점·한영 대응·실제 노출 요약을 교차 감수하고 실제 읽은 범위를 기록한다.

## PDF와 공개 권리

원호 날짜·원 자료의 출처와 원본을 보존한다. 이메일 전달판과 웹 공개판은 별도 상태이며, 메일 발송 완료가 사이트 공개 적합성의 증거는 아니다. 원 메일·메일 ID·수신자·개인 주소·비공개 링크·원 첨부·QA 화면·내부 절대경로는 공개 Git과 사이트로 복사하지 않는다.

`archive/README.md`와 PDF 스킬에 따라 전체 본문·렌더·메타데이터·URI·첨부·자동 실행·개인정보·재배포 조건을 검사한다. 논문을 읽을 수 있다는 사실과 원 그림의 공개 재사용 권리는 구별한다. 그림별 라이선스와 크레딧을 확인하며, 공개 재사용이 해결되지 않은 원 그림은 그대로 게시하지 않는다. 필요한 경우 검증 가능한 보고 수치나 관계를 직접 도식화하고 ‘리뷰 재구성’, 근거와 바뀐 범위를 표시한다. 곡선·실험 데이터를 임의로 복원하지 않는다.

공개용 삭제·정정·그림 교체가 필요하면 원본과 이메일 전달판은 비공개로 보존하고, 과학 내용·수치·원문 링크·크레딧과 공개 파생판 이력을 유지한다. 권리나 과학 검수가 남으면 해당 PDF의 공개를 보류하고 재개 원인을 남긴다. 새 표지·영상·별도 심층 리뷰 PDF를 자동으로 추가하지 않는다.

## 등록과 검증

검수가 끝난 PDF만 `scripts/archive_documents.py`로 `daily-research` 시리즈에 명시 등록한다. 원고는 해당 회차 `daily_research_review/`의 `reports/briefing_ko.md`·`briefing_en.md`로 관리하고 `scripts/build_briefing_editorial.py`로 HTML 조각과 `publication/briefings/<DRB ID>.json`을 만든다. 웹 작성·수정일과 추가 근거 기준일은 원호 날짜와 구별한다.

DRB 편집글은 `briefings/research/YYYY-MM-DD/`와 대응 영문 경로에 공개한다. 같은 날짜의 DQB `briefings/YYYY-MM-DD/`와 ID·URL을 덮어쓰지 않는다. 날짜별 달력·목록·검색은 짧은 편집글을 먼저 안내하고 PDF 열기·다운로드를 별도로 제공한다. 제목·요약·언어 전환·원문 출처·링크·검색·달력·실제 공개 PDF 해시를 확인한다.

최신 원격 기준의 깨끗한 checkout이나 적절한 managed worktree에서 필요한 원고·검수 자산·최소 공통 배포물만 게시한다. 다른 작업의 미완성 변경을 섞지 않는다. 원문 수집·내용 감수·이메일 전달·PDF 공개 보관·웹 편집글 공개·리뷰 기획을 별도 상태로 기록한다. 배포와 실제 HTTPS 확인 후에만 공개 완료로 표시한다. 진행·승인·실패·재개 단계는 저장소 밖 기존 DRB 비공개 state에 원자적으로 저장한다.

## 승인 경계

2026-11-13의 ‘DQB와 유사하게 DRB 역시 같은 기준과 방법으로 공개’ 지시는 검수한 일상적인 짧은 DRB 편집글과 공개 적합한 PDF 보관·목록 반영의 승인이다. 같은 범위를 회차마다 다시 승인받지 않는다.

새 심층 리뷰·후속 시리즈·병렬 기획과 다른 기존 본문의 실질적 확장은 구체적인 기획안이나 검토 가능한 초안을 제안하고 개별 승인을 받는다. 별도로 승인된 주제·범위에는 같은 승인을 반복 요구하지 않는다. 공개 브리핑을 새 심층 리뷰 승인으로 기록하거나 승인 대기 후보의 상태를 바꾸지 않는다.

보고에는 해당 회차의 웹 편집글·PDF 공개 상태, 새 근거가 바꾼 판단과 다음 기획을 간결하게 남긴다. 설정 변경을 실제 수집·감수·공개 완료로 대신하지 않는다.
