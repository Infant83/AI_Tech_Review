# 04. 데이터 인코딩과 상태 준비의 숨은 비용

> 독립 집필한 80분 학습 단원 · 2026-10-20 기준. 원강좌 Lecture 3·Lab 2의 주제를 확장한다. 아래 예제와 유도는 자체 교육 자료다.

## 시작하기 전에

[2강](02-qubits-gates-and-measurement.md)의 회전·Born 규칙, [3강](03-entanglement-and-circuits.md)의 텐서곱을 사용한다. 내적과 정규화는 [수학 준비 노트](../math-primer.md)에서 복습한다. 이 강의 후에는 세 인코딩의 보존 정보를 비교하고, 작은 상태 준비 회로를 설계하고, 인코딩이 만든 커널을 유도하며, 입력 접근 가정이 계산 비용에 미치는 영향을 설명할 수 있어야 한다.

머신러닝에서 전처리는 단순한 청소 단계가 아니다. 양자 인코딩은 데이터의 어떤 차이를 구별할 수 있는지 결정한다. 먼저 인코딩에서 합쳐진 두 점을 찾아야 한다. 나중의 회로를 아무리 복잡하게 만들어도 완전히 같은 입력 상태에 서로 다른 정답을 주지는 못한다.

## 핵심 용어

| 한국어·영어 | 정의·기호·직관 |
|---|---|
| 특징 맵·feature map | 입력 \(x\)를 새 표현 \(\phi(x)\)나 상태 \(\rho(x)\)로 보내는 함수. |
| 인코딩·encoding | 숫자·비트·물리 신호를 양자 상태 또는 게이트 파라미터로 대응시키는 규칙. |
| 상태 준비·state preparation | 초기 상태에서 목표 \(\rho(x)\)를 실제로 만드는 연산 과정. 표현의 정의와 구현 비용은 다르다. |
| 기저 인코딩·basis encoding | 디지털 비트열 \(b\)를 계산 기저 상태 \(|b\rangle\)로 나타내는 방법. |
| 각도 인코딩·angle encoding | 특징을 회전 게이트의 각도로 쓰는 방법. 주기와 스케일이 모델의 일부다. |
| 진폭 인코딩·amplitude encoding | 정규화한 벡터 성분을 상태 진폭으로 넣는 방법. 전체 크기를 별도로 보존해야 한다. |
| 정규화·normalization | 여기서는 \(x/\|x\|_2\)로 단위 길이를 만드는 연산. 통계적 표준화와 구별한다. |
| 충실도·fidelity | 순수 상태 사이 \(F=|\langle\phi|\psi\rangle|^2\). 본 강의에서는 제곱한 convention을 쓴다. |
| 커널·kernel | 여기서는 \(K(x,z)=\operatorname{Tr}[\rho(x)\rho(z)]\)라는 양의 준정부호 유사도. |
| 앨리어싱·aliasing | 서로 다른 입력이 주기성 때문에 같은 표현으로 겹치는 현상. |
| 양자 RAM·qRAM | 주소를 중첩으로 주어 메모리 내용에 coherent하게 접근하는 구조의 개념. 고전 배열과 다르다. |
| 오라클·oracle | 허용 연산을 하나의 호출로 묶어 추상화한 계산 자원. 호출 내부의 구현 비용은 별도로 적는다. |

[통합 용어집](../glossary.md)의 fidelity 정의와 맞춰 읽는다. 문헌에 따라 제곱근 fidelity를 fidelity라고 부르기도 하므로 식을 확인한다.

## 데이터 분할과 단위를 먼저 고정한다

훈련·검증·테스트를 먼저 나누고, 평균·표준편차·PCA는 훈련셋에서만 추정한다. 그 변환을 다른 집합에도 고정 적용한다. 전체 데이터의 평균을 미리 사용하면 테스트 분포의 정보가 모델 선택으로 들어온다. 양자 회로에 들어가기 전의 고전 전처리도 학습 파이프라인에 포함된다.

단위도 중요하다. 온도 300K를 그대로 300라디안 회전으로 쓰면 가까운 온도가 주기 때문에 예상과 다른 상태 거리를 가질 수 있다. \(z_j=(x_j-m_j)/s_j\)로 무차원화한 뒤 \(\alpha z_j\)를 각도로 쓰는 등의 규칙을 명시한다. \(\alpha\)를 검증셋으로 선택하면 하이퍼파라미터 튜닝이며, 테스트 최고 점수로 선택하면 독립 평가가 깨진다.

## 세 가지 인코딩을 같은 기준으로 비교한다

기저 인코딩은 정밀도까지 디지털 레지스터로 보존한다. 32개 실수를 각각 16비트로 쓰면 단순한 병렬 입력 레지스터는 512큐비트가 필요하다. 부호·고정소수점 규약, 가역 산술과 보조 큐비트는 추가 비용이다. 비트값이 알려져 있으면 1인 위치에 X를 적용해 상태를 만들 수 있다. 그러나 기저 상태의 단순 겹침은 서로 다른 비트열에서 0이므로 숫자 7과 8이 가깝다는 정보를 자동 제공하지 않는다.

각도 인코딩의 한 예는

$$
|\phi(x)\rangle=\bigotimes_{j=1}^{d}R_y(\alpha x_j)|0\rangle
$$

다. 이 설계는 \(d\)큐비트와 \(d\)개 회전을 사용한다. 병렬 회전은 깊이를 줄일 수 있지만 특징을 읽고 파라미터를 설정하는 비용은 남는다. 큐비트가 부족하면 데이터를 순차 재업로드할 수 있으며 이 경우 깊이가 증가한다. 6강은 이 선택이 함수 표현에 미치는 영향을 다룬다.

진폭 인코딩은 영벡터를 제외하고

$$
|x\rangle=\frac1{\|x\|_2}\sum_{j=0}^{d-1}x_j|j\rangle,
\qquad n=\lceil\log_2d\rceil
$$

로 정의한다. \(d<2^n\)이면 나머지 진폭을 0으로 padding한다. 복소수 입력도 가능하지만 실수 데이터와의 의미 대응을 명시해야 한다. 이 식은 \(n\)큐비트로 표현할 수 있다는 선언이며 일반 상태를 \(n\)개 게이트로 만들 수 있다는 선언이 아니다.

| 방식 | 보존되는 정보·손실 | 비용 장부 |
|---|---|---|
| 기저 | 정한 비트 precision과 부호 보존 | 비트 수·산술·보조 레지스터 |
| 각도 | 주기적 특징 geometry | 특징 수·스케일·재업로드 깊이 |
| 진폭 | 방향, norm과 전역 위상은 별도 | 정규화·분해·상태 재준비 |

## 유도 1과 완전 예제 1: 진폭 상태를 실제로 만들기

\(x=(3,4)\)의 norm은 5다. \(R_y(\theta)|0\rangle=\cos(\theta/2)|0\rangle+\sin(\theta/2)|1\rangle\)이므로

$$
\cos(\theta/2)=3/5,\quad \sin(\theta/2)=4/5,
\qquad \theta=2\operatorname{atan2}(4,3)
$$

로 준비할 수 있다. \(\operatorname{atan2}\)는 사분면을 보존하므로 음의 성분까지 다룰 때 단순 \(\arctan(x_1/x_0)\)보다 안전하다. 준비 상태의 계산 기저 확률은 0.36과 0.64다. 진폭 0.6·0.8을 한 번 측정해서 그대로 읽는 것은 아니다.

이제 \(y=(6,8)\)도 같은 상태를 만든다. 원래 제곱거리는 \((6-3)^2+(8-4)^2=25\)인데 상태 fidelity는 1이다. \(z=(-3,-4)\)도 전체 부호만 달라 같은 물리 상태다. \(x,z\)의 원래 제곱거리는 100이지만 fidelity는 다시 1이다. 따라서 norm이나 방향 부호가 정답과 관련되면 이 인코딩만으로는 충분하지 않다.

가령 \((1,0)\)에 label 0, \((-1,0)\)에 label 1이 붙어 있다고 하자. 두 점을 동등한 빈도로 단순 진폭 상태로 넣으면 어떤 고정 측정·학습 회로도 두 label을 구별할 수 없다. 최선의 분류 오류는 1/2다. shots를 늘리거나 더 깊은 후속 회로를 붙여도 동일 입력 상태라는 사실을 바꾸지 못한다. norm 보조 특징은 크기 손실을 해결할 수 있지만 \(x\)와 \(-x\)의 부호 손실까지 자동 해결하지는 않는다.

## 유도 2와 완전 예제 2: 인코딩이 만드는 geometry

각도 인코딩에서 한 큐비트의 겹침은 삼각함수 덧셈 공식으로

$$
\langle0|R_y(\alpha x_j)^\dagger R_y(\alpha z_j)|0\rangle
=\cos\left(\frac{\alpha(x_j-z_j)}2\right)
$$

다. 텐서곱의 내적은 부분 내적의 곱이므로

$$
K(x,z)=|\langle\phi(x)|\phi(z)\rangle|^2
=\prod_{j=1}^{d}\cos^2\left(\frac{\alpha(x_j-z_j)}2\right).
$$

이 커널은 고전적으로 \(O(d)\)에 계산된다. “양자 상태로 정의했다”는 것만으로 고전 계산 난도가 생기지 않는다. 순수 상태 projector를 특징으로 보면 \(K(x,z)=\operatorname{Tr}[\rho(x)\rho(z)]\)이고

$$
\|\rho(x)-\rho(z)\|_{\rm HS}^2
=\operatorname{Tr}(\rho(x)^2)+\operatorname{Tr}(\rho(z)^2)
-2\operatorname{Tr}[\rho(x)\rho(z)]=2(1-K).
$$

Hilbert–Schmidt norm은 행렬 성분의 유클리드 길이다. 이 식은 상태공간 거리와 원 데이터 유클리드 거리가 다른 이유를 명확히 보여준다.

\(d=2,\alpha=1\)에서 \(x=(0,0),z=(\pi,0)\)이면 K=0이다. 그러나 \(w=(2\pi,0)\)이면 K=1이다. 원래 x–w 거리는 x–z보다 크지만 상태에서는 w가 x와 겹친다. 또 각 특징 차이가 모두 \(\pi/2\)면 \(K=2^{-d}\)다. 이는 이 특정 product map과 입력 차이에 대한 정확한 계산이다. 모든 인코딩이 지수 집중한다는 일반 정리로 확대하지 않는다. 그래도 많은 특징을 곱할 때 신호가 얼마나 작아지는지 먼저 점검하는 좋은 예다.

## 유도 3: 로그 큐비트 수가 로그 적재 시간이 아닌 이유

일반 정규화 실수 d차원 벡터에는 \(d-1\)개의 연속 자유도가 있다. 각 고정 크기 게이트가 상수 개의 연속 파라미터에 매끄럽게 의존하는 회로 모형에서는 임의 벡터를 모두 표현하려면 파라미터 수 자체가 d에 비례해야 한다. 이 차원 계산은 구조 없는 일반 상태 준비가 공짜가 될 수 없는 이유다. 가변 큰 다중 큐비트 게이트나 데이터 oracle을 한 번의 연산으로 허용하면 그 내부 비용을 숨긴 것이므로 가정이 바뀐다.

반대로 모든 상태가 어렵다는 결론은 틀린다. \(2^n\)개 성분이 같은 정규화 벡터는 \(H^{\otimes n}|0^n\rangle\)로 준비한다. n개 H면 충분하다. 희소성, 곱 구조, 알려진 생성 회로 같은 정보는 준비 비용을 낮출 수 있다. 따라서 “일반 벡터”와 “특수한 효율적 준비 회로가 주어진 벡터”를 구별한다.

시뮬레이터의 상태 배열에 숫자를 바로 쓰는 기능은 CPU 메모리에 벡터를 넣는 일이다. 실제 QPU에서는 초기화에서 그 상태를 만드는 연산이 필요하다. 편리한 `AmplitudeEmbedding` 템플릿도 이 물리적 의무를 제거하지 않는다. 분해·정규화·padding·미분 제약을 설치 버전 문서로 확인한다.

## qRAM과 oracle의 정확한 역할

디지털 데이터 oracle은 예를 들어 \(O_x|j\rangle|0\rangle=|j\rangle|b_j\rangle\)로 쓸 수 있다. \(b_j\)는 값의 비트 표현이다. 주소를 중첩으로 주면 선형성으로 여러 값에 coherent하게 접근한다. 그러나 이 연산만 썼다고 \(\sum_jx_j|j\rangle/\|x\|\)가 즉시 만들어지지는 않는다. 진폭을 조절하는 절차·추가 데이터 구조·성공 확률·정규화 정보가 필요할 수 있다.

qRAM은 이런 접근을 구현하려는 메모리 구조다. [Giovannetti–Lloyd–Maccone의 원 제안](https://arxiv.org/abs/0708.1879)은 중첩 주소 접근의 개념과 구조를 다룬다. 고전 배열을 생성한 것만으로 같은 자원이 제공되지는 않는다. 데이터 초기 적재·업데이트·오류율·제어 비용, 반복 재사용 횟수를 기록한다. 고전 비교에도 원소 질의나 norm 기반 샘플 접근을 줄 것인지 정한다. 이 조건이 14강의 탈양자화 논의를 결정한다.

## 연습문제와 풀이

### 문제 1. 큐비트와 입력 크기

1,000차원 벡터를 진폭 인코딩할 최소 큐비트 수와 padding 원소 수를 구하라. 구조가 없다면 상태 준비가 10단계라고 말할 수 있는가? **힌트:** \(2^9<1000\le2^{10}\)을 사용한다.

**풀이:** 최소 10큐비트이며 1,024개 진폭 중 24개를 0으로 채운다. 표현에 필요한 공간과 준비 연산 수는 다르다. 정규화 계산과 일반 회로 분해에는 벡터 성분 정보가 필요하므로 10큐비트라는 이유만으로 10단계 준비를 결론 내릴 수 없다. 효율적 준비 oracle을 가정했다면 그 가정을 명시해야 한다.

### 문제 2. 사라지는 norm과 부호

\(x=(1,0),y=(-1,0),z=(2,0)\)의 모든 쌍에 대한 fidelity와 원래 제곱거리를 구하라. **힌트:** 세 상태는 전역 위상까지 같다.

**풀이:** 모든 fidelity는 1이다. 원래 제곱거리는 x–y가 4, x–z가 1, y–z가 9다. norm을 별도 저장하면 z의 크기 2와 x·y의 크기 1을 구별할 수 있지만 x와 y의 부호는 여전히 잃는다. 원 데이터의 정보 보존 요구를 먼저 쓰고 인코딩을 선택해야 한다.

### 문제 3. 곱 커널 계산

\(d=3,\alpha=1\)에서 모든 특징 차이가 \(\pi/2\)다. K와 projector 사이 제곱 Hilbert–Schmidt 거리는? **힌트:** 한 특징의 인자는 1/2다.

**풀이:** \(K=(1/2)^3=1/8\)이고 제곱거리는 \(2(1-1/8)=7/4\)다. 원래 데이터 제곱거리는 \(3\pi^2/4\)라서 수치와 단위가 다르다. 커널 값과 유클리드 거리를 같은 종류의 거리라고 보고 직접 교환하면 안 된다.

### 문제 4. 스케일 선택과 누수

회전 스케일 후보 50개를 최종 테스트셋 정확도로 골라 최고 결과를 보고했다. 어떤 수정이 필요한가? **힌트:** 양자 회로 밖의 선택도 모델 선택이다.

**풀이:** 훈련셋에서 전처리 통계와 파라미터를 맞추고, 별도 검증셋 또는 내부 교차검증으로 스케일을 선택한다. 고정된 선택을 독립 테스트셋에서 한 번 평가한다. 이미 50개 선택에 사용한 집합을 새 독립 테스트라고 부를 수 없으므로 가능하면 새 평가 자료를 확보한다. 선택 횟수·고전 기준선의 동일한 튜닝 예산도 보고한다.

## 학습 완료 점검

- 기저·각도·진폭 인코딩에서 데이터의 어떤 정보가 유지되는지 각 한 문장으로 쓰면 통과다. 실패하면 비교표와 예제 1을 다시 본다.
- product 각도 커널을 한 큐비트 내적에서 시작해 곱으로 유도하면 통과다. 마지막 공식을 외우기만 했다면 유도 2를 반복한다.
- qRAM 값 질의와 진폭 상태 준비가 같은 연산이 아님을 식으로 구별하면 통과다.
- 인코딩에서 합쳐진 서로 다른 label의 두 점을 후속 회로가 왜 구별하지 못하는지 설명하면 통과다. shots 증가로 해결한다고 답하면 정보 손실 반례로 돌아간다.

## 원문 읽기

- [Schuld, Sweke and Meyer, Effect of data encoding… (2021)](https://arxiv.org/html/2008.08605v2): Section I의 모델 정의와 Section IV.1의 classical pre-processing을 읽는다. Fourier 주파수의 엄밀한 전개는 6강에서 직접 유도한다. 본문의 product 커널과 반례는 자체 계산이다.
- [Giovannetti, Lloyd and Maccone, Quantum Random Access Memory (2008)](https://arxiv.org/abs/0708.1879): 초록과 메모리 접근 구조를 읽고 주소 레지스터·저장 용량·한 질의 비용을 구별한다. 현대 대규모 장치의 실증 성능으로 읽지 않는다.
- [PennyLane AmplitudeEmbedding](https://docs.pennylane.ai/en/stable/code/api/pennylane.AmplitudeEmbedding.html): normalization, padding, feature differentiation 설명을 확인한다. SDK 실행 버전은 [실습 안내](../labs/README.md)를 따른다. 실습 2는 geometry 비교이며 qRAM 구현이 아니다.
