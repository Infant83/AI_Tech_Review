# 01. 머신러닝 문제를 양자 계산의 언어로 바꾸기

> 독립 집필한 80분 학습 단원 · 근거 기준일 2026-10-20. CMU 공식 강의록이 아니다. 원강좌의 7강·5실습과 별개로 구성한 자체 시리즈의 첫 강의다.

## 시작하기 전에

이 강의의 질문은 “양자컴퓨터를 넣으면 정확도가 오르는가?”보다 먼저 “무엇을 학습하며 무엇을 비용으로 셀 것인가?”다. 벡터의 내적, 평균, 분산을 알고 있으면 시작할 수 있다. 식의 합 기호와 기댓값이 낯설면 [수학 준비 노트](../math-primer.md)를 먼저 읽는다. 양자 상태를 아직 몰라도 괜찮다. 여기서 **양자 상태**는 장치가 준비하는 입력, 관측량은 장치에서 읽을 수 있는 수량으로 이해하고, 2–3강에서 정확한 정의를 배운다.

학습 후에는 데이터와 출력의 종류를 명시하고, 경험 위험과 모집단 위험을 계산하며, 학습 오차의 원인을 세 가지로 분리하고, shot을 포함한 훈련 비용을 직접 산출할 수 있어야 한다. 외부 논문의 속도 향상 주장에는 입력 접근·출력·오차·자원이라는 네 조건을 붙일 수 있어야 한다.

## 80분 학습 순서

| 시간 | 수행할 활동 | 남길 결과 |
|---|---|---|
| 0–10분 | 용어를 읽고 자신이 관심 있는 학습 문제를 한 문장으로 정의 | 입력·정답·출력 명세 |
| 10–25분 | 위험과 오차 분해를 종이에 유도 | 세 항이 생기는 이유 |
| 25–45분 | 평균 예측기 예제와 shot 비용 예제 계산 | 수치와 단위가 있는 장부 |
| 45–60분 | 동일하지 않은 비교를 찾아 비교 조건을 수정 | 공정한 비교표 |
| 60–75분 | 문제 1·3을 먼저 풀고 선택한 문제의 해설만 대조 | 틀린 이유 두 문장 |
| 75–80분 | 본문을 덮고 완료 점검에 답함 | 다음 강의 진행 여부 |

80분은 읽는 데 걸리는 시간을 보증하는 수치가 아니다. 계산과 회상을 포함한 첫 학습 세션이다. 네 문제를 모두 독립적으로 풀고 원문까지 읽는 일에는 별도의 복습 시간이 필요하다.

강의 후 **60–90분**에는 남은 문제를 해설 없이 풀고, 유도 하나를 재작성하고, 오답을 수정한다. 원문 전문 독해와 코딩 실습은 별도 시간이다.

## 핵심 용어

| 한국어·영어 | 정의·기호·구별할 것 |
|---|---|
| 표본·sample | 분포에서 관측한 한 사례 \((x_i,y_i)\). 샷 한 번과 훈련 사례 하나는 다른 단위다. |
| 가설 집합·hypothesis class | 선택 가능한 예측 함수들의 집합 \(\mathcal F\). 회로 구조와 고전 후처리까지 포함한다. |
| 손실·loss | 한 예측을 평가하는 수 \(\ell(f(x),y)\). 분류 정확도와 미분 가능한 훈련 손실은 다를 수 있다. |
| 경험 위험·empirical risk | 관측 데이터의 평균 손실 \(\widehat R_D(f)\). 훈련 데이터에만 대한 성적이다. |
| 모집단 위험·population risk | 새 사례 분포의 평균 손실 \(R(f)\). 실전 목표이며 보통 정확히 알 수 없다. |
| 경험 위험 최소화·ERM | \(\widehat R_D\)를 줄여 모델을 선택하는 원리. 일반화나 최적화 성공을 자동 보장하지 않는다. |
| 근사 오차·approximation error | 허용한 모델 집합으로 최선의 목표 함수에 얼마나 가까이 갈 수 있는가의 한계. |
| 추정 오차·estimation error | 유한한 훈련 표본으로 모델을 선택하면서 생기는 차이. 측정 shot 오차와 구분한다. |
| 최적화 오차·optimization error | 정한 훈련 목적함수의 최솟값에 실제 알고리즘이 도달하지 못한 정도. |
| 샷·shot | 상태 준비부터 측정까지 한 번 실행하여 결과 하나를 얻는 반복 단위. |
| 접근 모형·access model | 데이터에 어떤 연산을 얼마의 비용으로 허용하는지 정한 계산 규칙. |
| 종단간 비용·end-to-end cost | 입력 준비부터 최종 산출물까지 포함한 비용. 회로 실행 시간만으로 대체하지 않는다. |

용어의 영문 표기와 다른 강의의 사용례는 [통합 용어집](../glossary.md)을 따른다. “위험”은 안전상의 위험이라는 뜻이 아니라 통계학의 평균 손실이다.

## 무엇을 예측하는지부터 적는다

지도학습의 데이터셋을 \(D=\{(x_i,y_i)\}_{i=1}^{N}\)라 쓰자. \(N\)은 사례 수이고, \(x_i\in\mathbb R^d\)는 \(d\)개 특징, \(y_i\)는 정답이다. 회귀는 실수 정답을, 분류는 범주 정답을 예측한다. 비지도학습은 정답 없이 밀도나 군집 같은 구조를 찾는다. 같은 데이터라도 분류, 군집, 생성은 서로 다른 과제이며 출력의 크기도 다르다.

검사표에서 질병을 예측하는 문제의 입력은 이미 고전 메모리에 저장된 숫자다. 이를 QPU에 올리는 비용이 든다. 반면 양자 센서가 생성한 미지의 상태를 분류하는 문제는 측정하기 전의 상태를 입력으로 허용할 수 있다. 상태를 먼저 개별 측정한 고전 기록과, 여러 상태를 함께 처리하는 양자 접근은 같은 정보를 제공하지 않는다. 어떤 접근이 허용되는지가 연구 질문의 일부다.

| 입력·접근 | 학습 절차 | 먼저 비교할 대상 |
|---|---|---|
| 고전 표 데이터 | CPU/GPU 학습 | 강한 고전 기준선과 튜닝 예산 |
| 같은 표 데이터 | 데이터 준비 후 양자 회로 | 준비·측정·고전 처리를 합한 비용 |
| 양자 상태를 개별 측정한 기록 | 고전 통계 학습 | 어떤 측정과 몇 개 상태를 사용했는가 |
| 미지의 양자 상태에 직접 접근 | 양자 메모리·집단 처리 | 메모리·게이트와 상태 사본 수 |

양자 장치를 고전 머신러닝으로 제어하는 연구도 중요하지만, 그것이 곧 머신러닝을 양자 계산으로 가속했다는 뜻은 아니다. 논문 제목의 QML이라는 이름만으로 입력과 계산 방향을 추정하지 않는다.

## 유도 1: 훈련 성적과 실전 성적의 차이

제곱 손실 \(\ell(\hat y,y)=(\hat y-y)^2\)라면 경험 위험과 모집단 위험은 각각

$$
\widehat R_D(f)=\frac1N\sum_{i=1}^{N}(f(x_i)-y_i)^2,
\qquad
R(f)=\mathbb E_{(x,y)\sim\mathcal D}(f(x)-y)^2
$$

다. 여기서 \(\mathcal D\)는 새 사례를 만드는 미지의 분포다. 첫 식은 실제로 계산할 수 있지만 두 번째 식은 대체로 독립 테스트 표본으로 추정해야 한다. 두 분포가 같다는 가정도 필요하다. 훈련 때와 배포 때 장치나 데이터 생성 조건이 달라지면 이 가정부터 확인한다.

모집단에서 가장 좋은 모델을 \(f_{\mathcal F}^*\in\arg\min_{f\in\mathcal F}R(f)\), 훈련 데이터를 가장 잘 맞춘 모델을 \(\hat f\in\arg\min_{f\in\mathcal F}\widehat R_D(f)\)라 쓰자. 실제 학습 결과 \(\tilde f\)가 정확한 최솟값에 도달하지 못하고

$$
\widehat R_D(\tilde f)-\widehat R_D(\hat f)\le\epsilon_{\rm opt}
$$

를 만족한다고 하자. 또한 모든 허용 모델에서 훈련·실전 차이가 \(|R(f)-\widehat R_D(f)|\le\delta\)라고 가정하자. 그러면 항을 더하고 빼서

$$
\begin{aligned}
R(\tilde f)-R(f_{\mathcal F}^*)
={}&[R(\tilde f)-\widehat R_D(\tilde f)]
+[\widehat R_D(\tilde f)-\widehat R_D(\hat f)]\\
&+[\widehat R_D(\hat f)-\widehat R_D(f_{\mathcal F}^*)]
+[\widehat R_D(f_{\mathcal F}^*)-R(f_{\mathcal F}^*)]\\
\le{}&2\delta+\epsilon_{\rm opt}.
\end{aligned}
$$

세 번째 대괄호가 0 이하인 이유는 \(\hat f\)가 경험 위험의 최소화자이기 때문이다. 모든 가능한 예측 함수의 최적 위험을 \(R^*\)라 하면 최종 초과 위험에는

$$
R(\tilde f)-R^*\le
\underbrace{R(f_{\mathcal F}^*)-R^*}_{A}
+\underbrace{2\delta}_{B}
+\underbrace{\epsilon_{\rm opt}}_{C}
$$

가 성립한다. A는 근사 오차, B는 유한 표본으로 생기는 차이의 상계, C는 최적화 오차다. 이는 조건을 가정한 교육용 부등식이며, 모든 QML 회로에 작은 \(\delta\)를 보장한 정리는 아니다. 데이터가 적어서 생긴 문제와 회로가 목표 함수를 표현하지 못해서 생긴 문제를 구별하는 용도로 쓴다. 실제 finite-shot 목적함수는 추가 확률오차를 가지며, 장치 잡음은 평균 자체를 바꿀 수 있다.

## 완전 예제 1: 단순한 상수 예측기도 배울 것이 있다

입력과 관계없이 \(f_a(x)=a\)를 출력하고 정답이 1, 2, 3이라고 하자. 훈련 위험은

$$
\widehat R(a)=\frac{(a-1)^2+(a-2)^2+(a-3)^2}{3}
=(a-2)^2+\frac23.
$$

따라서 최적 상수는 2이고 최소 훈련 위험은 \(2/3\)이다. 전개 없이 미분해도 \(\partial_a\widehat R=2a-4=0\)을 얻는다. 모델이 단순해서 정답 세 개를 모두 맞출 수 없다는 것이 근사 능력의 제한이다.

이제 실제 정답이 0과 4를 같은 확률로 만든다고 가정하면 모집단 위험은 \(R(a)=[a^2+(a-4)^2]/2=(a-2)^2+4\)다. 최적 상수는 여전히 2지만 위험은 4다. 훈련 위험 \(2/3\)을 실전 위험으로 보고하면 틀린다. 이 예제의 훈련 정답과 모집단은 의도적으로 다르게 정했다. 데이터 분포가 바뀌면 작은 훈련 오차만으로 평가할 수 없다는 반례다.

## 유도 2와 완전 예제 2: 양자 예측은 측정 예산을 가진다

대표적인 양자 예측기를

$$
f_\theta(x)=\operatorname{Tr}[O\,U_\theta\rho(x)U_\theta^\dagger]
$$

라 쓰자. \(\rho(x)\)는 입력 상태, \(U_\theta\)는 학습 회로, \(O\)는 관측량이다. Tr는 행렬의 대각 원소 합인 trace다. 관측값이 ±1이면 한 번의 결과 \(Z_s\)의 평균은 \(f\)이고 제곱은 언제나 1이다. 따라서 \(\operatorname{Var}(Z_s)=1-f^2\)이며, 독립 \(S\)회 평균의 분산은 \((1-f^2)/S\)다. 정확한 기댓값을 즉시 반환하는 시뮬레이터는 이 통계 비용을 지불하지 않는다.

20개 파라미터를 각각 두 shifted 회로로 미분하고, minibatch 32개, 회로당 1,000 shots를 쓴다고 하자. 한 단계에는 \(2\times20\times32=1{,}280\)개 입력·회로 조합, \(1{,}280{,}000\)개 shots가 필요하다. 100단계면 \(128{,}000{,}000\)회다. 가상의 실행 장치가 한 shot에 10마이크로초를 쓴다면 직렬 순수 측정 시간만 1,280초다. 이 수는 장치 성능 보고가 아니라 단위 계산 예제다. 순방향 손실, 검증, 다중 관측량, 보정과 대기는 아직 빠져 있다.

전체 시간은 교육용으로

$$
T_{\rm end}=T_{\rm prep}+T_{\rm compile}+T_{\rm queue}
+N_{\rm circuits}S\,t_{\rm shot}+T_{\rm classical}+T_{\rm output}
$$

처럼 기록할 수 있다. 실제 배치·병렬 실행에서는 항들이 겹칠 수 있으므로 이 식을 하드웨어의 정밀 모형으로 쓰지 않는다. 표본 수, 회로 수, 벽시계 시간과 메모리는 서로 다른 자원이다.

## 활동: 우위 주장에 비교 조건을 붙인다

“100만 차원 벡터를 20큐비트에 저장하므로 입력이 20단계다”는 문장을 고쳐 보자. 20큐비트는 진폭을 표현하는 공간의 크기를 말한다. 일반 벡터를 준비하는 게이트 수와 데이터 파일을 읽는 시간은 별개다. “20큐비트로 상태를 표현한다. 준비 oracle을 가정한 회로 질의 수를 비교했으며 일반 데이터 적재 시간은 포함하지 않았다”라고 쓰면 검증 가능한 주장이 된다.

또 다른 반례는 전체 해 벡터를 반환하는 고전 알고리즘과, 해 상태의 단일 기댓값만 반환하는 양자 알고리즘을 비교하는 것이다. 출력을 하나의 기댓값으로 맞추거나 양자 쪽에도 전체 읽기 비용을 넣어야 한다. 정확도와 성공 확률도 같아야 한다. 이 네 조건을 못 쓰면 “빠르다”라는 결론을 보류하고 무엇을 줄였는지만 기록한다.

## 연습문제와 풀이

### 문제 1. 경험 위험을 직접 최소화하기

정답 0, 0, 3을 상수 모델 \(a\)로 예측한다. 제곱 손실의 최솟값과 최적 \(a\)를 구하라. **힌트:** 제곱을 전개하고 완전제곱식으로 묶는다.

**풀이:** \(\widehat R(a)=[a^2+a^2+(a-3)^2]/3=a^2-2a+3=(a-1)^2+2\)다. 따라서 \(a=1\), 최솟값 2다. 평균을 쓰는 이유는 외운 규칙 때문이 아니라 제곱 손실의 대수적 성질 때문이다. 절댓값 손실이면 중앙값이 최적이며 여기서는 0이 된다. 손실을 바꾸면 학습 목표도 달라진다.

### 문제 2. 작은 훈련 손실의 의미

모델 A는 훈련 위험 0, 테스트 위험 0.25이고 모델 B는 각각 0.1, 0.12다. 어느 모델을 배포할지 판단하고 더 필요한 정보를 적어라. **힌트:** 테스트 점수의 불확실성과 선택에 사용한 데이터 여부를 생각한다.

**풀이:** 현재 수치만 보면 B가 새 사례에서 낫지만 즉시 확정할 수 없다. 동일한 독립 테스트셋에서 평가했는지, 표본 수와 신뢰구간, 반복 seed, 비용을 확인한다. A의 훈련 성적만으로 근사 능력이 유용했다고 결론 내릴 수 없다. 테스트셋을 여러 번 보고 B를 선택했다면 그 집합은 사실상 검증셋이 되었으므로 새 최종 평가가 필요하다.

### 문제 3. 측정 예산 계산

파라미터 12개, batch 8개, 두 회로 미분, 500 shots, 200단계라면 총 shots는? 표준오차를 절반으로 줄이면 얼마가 되는가? **힌트:** 단계당 비용을 구한 뒤 반복 수를 곱한다.

**풀이:** 단계당 \(2\times12\times8\times500=96{,}000\)회, 총 19,200,000회다. 독립 반복의 표준오차는 \(S^{-1/2}\)에 비례하므로 절반으로 줄이려면 회로당 2,000 shots가 필요하다. 새 총량은 76,800,000회다. 장치의 systematic bias는 이 증가로 사라지지 않는다. 정확도 개선과 측정 예산을 별도로 보고해야 한다.

### 문제 4. 입력과 출력을 맞추기

양자 알고리즘은 공짜 상태 준비 후 평균 하나를 오차 0.1로 출력하고, 고전 알고리즘은 파일을 읽어 모든 예측을 오차 0.001로 출력한다. 실행 시간만 비교해 우위를 주장할 수 있는가? **힌트:** 비교 계약을 네 문장으로 고쳐라.

**풀이:** 현재는 같은 과제가 아니다. 두 방법에 같은 데이터 접근을 주고, 목표 출력을 같은 평균으로 정하며, 허용 오차와 성공 확률을 동일하게 맞춘다. 상태 준비·파일 적재·반복 측정·고전 후처리를 포함한 자원을 다시 센다. 그 뒤에도 차이가 남으면 그 구체적 자원의 우위를 주장할 수 있다. 이 수정은 양자 결과를 무효화하는 것이 아니라 어떤 접근 모형에서 성립하는지 분명하게 만든다.

## 학습 완료 점검

- 경험 위험과 모집단 위험의 식을 보고 각각의 평균이 무엇에 대해 계산되는지 설명한다. \(N\)개 관측 표본과 미지의 분포를 명시하면 통과다. 실패하면 “유도 1”로 돌아간다.
- 근사·추정·최적화 오차마다 서로 다른 개선책을 하나씩 든다. 모델 집합 변경·새 데이터·최적화 개선을 연결하면 통과다. shots 증가를 세 항의 공통 해법으로 답하면 다시 읽는다.
- 두 shifted 회로 비용에서 파라미터·batch·shots·step의 네 인자를 빠짐없이 곱한다. 단위를 shots로 쓰면 통과다.
- 양자 우위 주장의 조건 네 가지를 입력 접근·출력·오차/성공률·자원으로 적는다. 하나라도 빠지면 활동을 반복한다.
