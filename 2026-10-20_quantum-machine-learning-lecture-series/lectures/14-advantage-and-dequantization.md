## 선수 지식과 학습 목표

[4강](04-data-encoding-and-loading.md)의 데이터 부호화, [8강](08-kernels-and-svm.md)의 내적과 커널, [10강](10-generalization-and-benchmarking.md)의 평가 조건을 복습한다. 복소 내적·조건수·확률 표기가 낯설면 [수학 보충](../math-primer.md)을 함께 읽는다. 목표는 ‘양자 우위’를 한 단어로 판정하는 것이 아니라, 비교 명제를 정확하게 쓰는 것이다. 수강 뒤에는 접근 모델을 명시하고, 길이제곱 샘플링으로 내적의 불편 추정량을 유도하며, 부분 알고리즘의 개선이 전체 비용 개선으로 이어지는 조건을 계산해야 한다.

성능 비교의 기본 단위는 \((\mathcal P,\mathcal A,\epsilon,\delta,\mathcal R)\)라는 묶음으로 생각할 수 있다. \(\mathcal P\)는 문제군, \(\mathcal A\)는 입력 접근 방식, \(\epsilon\)은 허용 오차, \(\delta\)는 실패 확률, \(\mathcal R\)은 비교할 시간·메모리·표본 같은 자원이다. 이는 교육용 표기다. 이 다섯 항목 중 하나라도 다르면 같은 알고리즘 문제에 대한 우위인지 다시 확인해야 한다.

## 핵심 용어

| 한국어·영어 | 정의와 직관 |
|---|---|
| 계산 우위, computational advantage | 같은 과제를 더 적은 계산 자원으로 푸는 조건부 비교다. 단순 정확도 차이와 다르다 |
| 표본 복잡도, sample complexity | 목표 오차와 성공 확률에 필요한 독립 자료 수다. 자료 하나의 생성 시간은 별도다 |
| 쿼리 복잡도, query complexity | 정해진 oracle을 호출한 횟수다. 한 호출의 실제 구현 비용을 무료로 볼 수 있는 추상 모델이다 |
| 오라클, oracle | 지정된 입출력 기능을 제공하는 접근 장치다. ‘데이터가 있다’보다 강하고 구체적인 가정이다 |
| 진폭 접근, amplitude access | 벡터 \(x\)를 정규화한 상태 \(\lvert x\rangle\)를 준비하는 접근이다. 원소 목록 전체를 반환하지 않는다 |
| 길이제곱 샘플링, length-squared sampling | \(i\)를 \(\lvert x_i\rvert^2/\lVert x\rVert_2^2\)에 비례해 고르는 고전 접근이다 |
| 샘플 및 조회 접근, sample-and-query access | 길이제곱 샘플, 원소 조회, 노름 정보를 제공하는 기능 묶음이다. 구체적인 정밀도·구축 비용도 필요하다 |
| 탈양자화, dequantization | 양자 알고리즘의 일부 효과를 유사한 자료 접근을 가진 고전 알고리즘으로 재현하는 연구다 |
| 통계적 쿼리, statistical query | 분포에 대한 함수의 기대값을 허용 오차로 받는 학습 모델이다. Sample-and-query와 약자 SQ만 같다 |
| 고전 대리모델, classical surrogate | 원 양자 모델의 출력·학습을 고전 계산으로 근사하는 모델이다. 양자 사전 측정을 사용했는지 표시해야 한다 |
| 점근 복잡도, asymptotic complexity | 문제 크기가 커질 때의 자원 증가율이다. 유한 크기의 상수·통신 지연까지 자동 설명하지 않는다 |

용어는 [용어집](../glossary.md)과 대조한다. 논문에 SQ라고만 쓰여 있으면 풀어 쓴 명칭부터 찾는다. 서로 다른 SQ 접근을 동일시하면 하한과 알고리즘의 가정이 바뀐다.

## 입력 접근은 어떻게 달라지는가

\(x\in\mathbb C^d\), \(x\ne0\)라 하자. 원소 조회는 인덱스 \(i\)를 주면 \(x_i\)를 정해진 정밀도로 반환한다. 진폭 준비는 \(|0\rangle\mapsto |x\rangle=\sum_i x_i|i\rangle/\|x\|_2\)를 구현한다. 상태 복사본만 받는 경우, 준비 유니터리와 역연산까지 호출할 수 있는 경우도 서로 다르다. 고전 샘플링은 \(p_i=|x_i|^2/\|x\|_2^2\)에서 인덱스를 하나 뽑는다.

목록으로 주어진 조밀한 벡터를 읽어 자료구조를 구축하는 데에는 전체 입력 크기에 따른 비용이 든다. 이후 업데이트와 샘플링이 빠를 수 있지만 구축을 공짜라고 두면 최초 실행의 비용을 누락한다. 같은 벡터로 많은 질의를 반복한다면 구축 비용을 분담할 수 있으므로 반대로 모든 호출에서 새로 구축한다고 세는 것도 부정확하다. 입력의 재사용 횟수를 비교의 일부로 적어야 한다.

고전 알고리즘에게 원소 조회와 정확한 노름까지 제공하면서 양자 쪽에는 미지 상태 복사본만 준다면 고전 접근이 더 많은 정보를 가질 수 있다. 양자 알고리즘에게 coherent 준비와 역연산을 주면서 고전 쪽에는 임의 순서 원소 조회만 주면 반대 비대칭이 생길 수 있다. 접근 모델의 공정성은 기능을 나란히 쓰고 과제와 연결해서 평가한다.

## 첫 번째 유도: 샘플링으로 내적을 추정한다

두 벡터 \(x,y\in\mathbb C^d\)의 내적 \(s=x^\dagger y=\sum_i\overline{x_i}y_i\)를 추정하자. \(x\)의 길이제곱 샘플링, \(x_i,y_i\) 조회, \(\|x\|_2\)를 사용할 수 있다고 가정한다. \(x_i=0\)인 위치는 샘플되지 않으며 내적 기여도 0이다. 뽑힌 \(I\sim p\)에 대해

$$
Z=\frac{\overline{x_I}y_I}{p_I}
=\|x\|_2^2\frac{y_I}{x_I}
$$

를 계산한다. 첫 단계로 평균을 취하면 \(\mathbb EZ=\sum_{i:x_i\ne0}p_i\overline{x_i}y_i/p_i=s\)이므로 불편 추정량이다. 두 번째 단계로 제곱 크기를 계산하면

$$
\mathbb E|Z|^2
=\sum_{i:x_i\ne0}\frac{|x_i|^2|y_i|^2}{p_i}
=\|x\|_2^2\sum_{i:x_i\ne0}|y_i|^2
\le\|x\|_2^2\|y\|_2^2.
$$

독립 \(N\)회 평균 \(\bar Z\)의 평균제곱 오차는 \(\mathbb E|\bar Z-s|^2\le\|x\|_2^2\|y\|_2^2/N\)이다. 두 노름이 1이라면 차원 \(d\)가 이 표본 상한에 직접 나타나지 않는다. 다만 접근 기능을 구현하는 비용, 유한 정밀도 나눗셈, 실패 확률 감소를 위한 반복은 별도다. \(s\)가 매우 작을 때 상대오차까지 요구하면 가산오차 보장만으로는 충분하지 않다.

이 유도는 탈양자화가 왜 가능한지 보여주는 작은 예제이며 Tang 추천 알고리즘 전체의 증명이 아니다. Tang의 원 결과는 저랭크 근사와 자료구조·추천 출력의 문제 조건을 더 포함한다. ‘양자 내적 서브루틴이 있으므로 지수 우위’라는 설명을 읽었을 때 고전 확률 추정과 접근 비용을 함께 검토하게 만드는 것이 학습 목적이다.

## 완전 예제 1: 확률만으로 상대 부호를 잃는다

\(x=(3,4)\), \(z=(3,-4)\)는 모두 노름 5이고 계산 기저 측정 확률은 \((9/25,16/25)\)다. 따라서 이 비트열 분포만 반복 관측해서 둘을 구별할 수 없다. 그러나 상태에 Hadamard를 적용하고 측정하면 \(|x\rangle\)의 0 확률은 \((3+4)^2/50=49/50\), \(|z\rangle\)에서는 \((3-4)^2/50=1/50\)이다. 간섭이 상대 부호를 읽는 추가 기능을 제공한다.

이 예제로 고전 원소 조회까지 불가능하다고 결론낼 수는 없다. 조회는 두 번째 성분을 읽으면 바로 부호를 안다. ‘고전 샘플 분포’, ‘Sample-and-query’, ‘양자 상태’가 같은 입력이 아니라는 사실을 보여준다. 동일 확률 분포를 가진 상태도 모든 양자 측정에서 같지는 않다.

## 두 번째 유도: 작은 관측량 공간에서 고전 모사가 가능하다

변분 손실을 \(f_\theta=\operatorname{Tr}[\rho U_\theta^\dagger O U_\theta]\)로 쓰자. \(\rho\)는 초기 상태, \(O\)는 측정 관측량이다. Hermitian 기저 \(B_1,\ldots,B_D\)의 선형공간이 회로의 각 게이트에 의한 conjugation 아래 닫혀 있다고 가정한다. 또한 \(O\)가 그 공간 안에 있고, 각 변환의 계수 갱신과 초기 기대값을 효율적으로 계산하거나 사전 측정할 수 있다고 가정한다.

그러면 \(U_\theta^\dagger O U_\theta=\sum_{a=1}^D c_a(\theta)B_a\)로 나타난다. 기저별 초기 기대값 \(m_a=\operatorname{Tr}(\rho B_a)\)를 한 번 얻으면 \(f_\theta=\sum_a c_a(\theta)m_a\)다. 게이트를 차례로 적용하면서 \(D\)개 계수를 갱신하면 전체 \(2^n\)차원 상태벡터를 저장할 필요가 없다. 다만 \(D\)가 다항식이라는 사실만으로 충분하지 않고 기저 표현·계수 갱신·기대값 획득의 비용도 작아야 한다.

예를 들어 한 큐비트 \(R_y(\theta)\)와 \(O=Z\)에서는 \(R_y^\dagger ZR_y=\cos\theta Z-\sin\theta X\)다. 따라서 \(f_\theta=m_Z\cos\theta-m_X\sin\theta\)를 고전적으로 계산한다. 초기 상태가 복잡한 양자 자료라면 \(m_X,m_Z\)의 측정은 여전히 필요할 수 있다. 이 경우 ‘고전 훈련’과 ‘양자 자료를 사용하지 않는 알고리즘’을 구별해야 한다. 더 큰 회로의 관측량 공간이 지수적으로 커지면 이 방식의 효율성은 사라진다.

## 완전 예제 2: 서브루틴 개선과 전체 시간

교육용 파이프라인에서 고전 핵심 계산이 질의당 \(10^6\)시간 단위, 양자 핵심 계산이 \(10^3\)단위라고 하자. 양자 자료구조 구축은 \(10^8\)단위이고, 고전 방식은 원래 저장된 입력을 그대로 사용한다고 가정한다. 같은 입력으로 \(K\)번 질의하면 \(T_C=10^6K\), \(T_Q=10^8+10^3K\)다. 양자 쪽이 작으려면 \(999000K>10^8\), 즉 정수 \(K\ge101\)이 필요하다.

첫 질의는 양자 쪽이 훨씬 느리지만 입력을 충분히 재사용하면 비교가 달라진다. 매 질의 입력이 완전히 바뀌어 구축을 다시 해야 하면 \(T_Q=K(10^8+10^3)\)이 되어 이 예제의 개선은 사라진다. 숫자는 실제 장치 예측이 아니며, 구축·반복·캐싱을 명시하면 논쟁적인 우위 문장이 계산 가능한 질문으로 바뀐다는 예다.

## 하한과 벤치마크를 읽을 때의 논리

고전 알고리즘의 한 종류가 느리다는 증거는 모든 고전 알고리즘이 느리다는 하한보다 약하다. 특정 gradient 방식 또는 statistical-query 모델에 대한 하한에는 그 모델 이름을 붙여야 한다. 반대로 탈양자화가 알려진 한 문제를 해결했다고 모든 양자 학습이 고전적으로 모사된다는 결론도 나오지 않는다. 과제의 구조·입력·정밀도 의존성을 함께 추적한다.

출력을 모두 쓰는 비용도 간단한 하한을 준다. \(d\)개의 계수를 고전 메모리에 명시적으로 반환하라는 과제는 적어도 \(d\)개 항목을 기록해야 한다. 해 상태 한 개나 확률 표본 하나를 반환하는 알고리즘과 같은 출력이 아니다. 원소 조회만 가능한 길이 \(d\) 비트열이 전부 0인지 정확히 판정하는 결정론적 최악의 경우도 모든 위치를 읽어야 한다. 읽지 않은 한 위치를 1로 바꾸면 관측 이력이 같아져 정확성을 보장하지 못하기 때문이다. 이 단순 논증을 모든 근사·무작위 학습 문제의 하한으로 확대하면 안 된다.

벤치마크에서는 선형 모델·RBF 커널·문제에 적합한 강한 고전 모델을 비교하고 튜닝 예산을 기록한다. 양자 특징 없이 같은 차원의 삼각함수 특징을 쓰거나 얽힘 게이트를 제거한 ablation도 원인을 구분하는 데 유용하다. 작은 데이터의 정확도 차이는 반복·신뢰구간·분할 민감도를 필요로 하며 점근 우위를 대신하지 않는다. Cerezo 등의 2025년 Perspective는 알려진 학습 가능한 구조와 고전 모사성의 관계를 논의하지만, barren plateau가 없으면 항상 고전 모사가 된다는 보편 정리는 아니다.

## 연습문제와 풀이

1. **추정량 계산.** \(x=(3,4)\), \(y=(1,0)\)에서 위 내적 추정량의 가능한 값·평균·분산을 구하라. **힌트:** \(p=(9/25,16/25)\)다. **풀이:** \(I=1\)이면 \(Z=25/3\), \(I=2\)이면 0이다. 평균은 \((9/25)(25/3)=3\), 두 번째 모멘트는 25이므로 분산은 16이다. 참 내적 3과 일치하지만 한 표본은 크게 흔들린다. \(N\)개 평균의 분산은 \(16/N\)이다.

2. **상대오차 비용.** 정규화된 두 벡터의 내적이 \(10^{-4}\)이고 상대오차 10%를 원한다. 분산 상한 1만 쓴다면 평균제곱 오차 기준 샘플 상한의 규모는? **힌트:** 필요한 가산오차를 먼저 구한다. **풀이:** 가산오차는 \(10^{-5}\), 그 제곱은 \(10^{-10}\)이다. \(1/N\le10^{-10}\)을 만족하려면 \(N\ge10^{10}\)이다. 이는 보수적인 충분조건이며 최적 하한이 아니다. 차원에 독립적인 식도 정밀도에서는 비쌀 수 있다.

3. **Surrogate의 범위.** 모든 \(\theta\)에 대해 \(U_\theta^\dagger OU_\theta=c_1B_1+c_2B_2\)이며 \(m_1,m_2\)를 양자 실험으로 얻었다. 이후 훈련을 ‘완전히 고전 자료만 사용’이라고 써도 되는가? **힌트:** 자료 획득과 최적화를 나눈다. **풀이:** 훈련 갱신은 고전 계산이지만 입력 특징은 양자 측정으로 획득했다. ‘양자 사전 측정과 고전 최적화’라고 적는다. 두 기대값의 추정 오차가 \(e_1,e_2\)이면 예측 오차는 \(|c_1|e_1+|c_2|e_2\) 이하이므로 재사용 시 계수 크기도 확인한다.

4. **우위 문장 수정.** ‘60개 논리 큐비트가 수백만 고전 비트보다 작으므로 모든 데이터 처리에서 빠르다’를 정확한 주장으로 바꾸라. **힌트:** 메모리, 시간, 문제군과 출력은 다른 항목이다. **풀이:** ‘지정된 스트리밍 과제와 입력 분포·오차 조건에서, 논리 메모리 규모가 비교 고전 모델보다 작다는 이론적 결과’처럼 범위를 정한다. 시간 우위는 총 호출 수·회로 구현·입출력·고전 기준선에 대한 별도 분석이 필요하다. 논리 큐비트의 물리적 구현 비용도 60이라는 숫자에 포함되지 않는다.

## 학습 완료 점검

- 내적 추정량의 평균과 두 번째 모멘트를 식 없이 설명한 뒤 다시 유도한다. 평균만 맞추고 분산을 생략하면 문제 1을 반복한다.
- 우위 주장에 입력 접근·오차·실패 확률·자원·출력을 모두 적는다. 빈칸은 임의로 채우지 말고 ‘원문 확인 필요’로 남긴다.
- 다항 시간 고전 모사 가능성, 유한 크기의 실용 속도, 양자 자료 획득 필요성을 각각 다른 문장으로 설명한다.

## 원문 읽기

- Tang, [A quantum-inspired classical algorithm for recommendation systems](https://arxiv.org/html/1807.04271), STOC (2019). 공개 본문 **2.2 Sampling**, **3 Data Structure**, **4.1 Vector Sampling**의 제목과 설정을 확인했다. 우리의 단순 내적 추정과 추천용 저랭크 알고리즘이 어디서 달라지는지 적는다.

- Bowles, Ahmed, Schuld, [Better than classical? The subtle art of benchmarking quantum machine learning models](https://arxiv.org/abs/2403.07059), 2024. 작은 분류 비교의 통제 조건을 점검한다. 논문의 대규모 benchmark를 이번 노트에서 재실행하지 않았다.
