# 혼자 따라가는 학습 안내: 학습 시간, 선수 관계와 이해도 점검

> 독립 학습 시리즈 2.0 · 근거 기준일 2026-10-20. 원 수업에 참석하거나 비공개 강의 자료를 확인한 결과가 아니다. 아래 시간과 진도 판정은 이 자료를 공부하기 위한 제안이며, 실제 수강 기록이나 검증된 교육 효과 측정값이 아니다.

이 시리즈의 목표는 실라버스의 제목을 아는 데서 그치지 않고, 핵심 식을 유도하고, 숫자를 바꾸어 계산하고, 주장의 가정을 찾아내는 것이다. 각 강의는 정의·유도·완전 예제·반례·문제와 풀이를 포함한다. 외부 교재는 심화 학습용이다. 본문의 기본 계산을 따라가기 위해 별도의 유료 교재나 원강좌 수강을 요구하지 않는다. 다만 연구 논문의 모든 정리와 부록 증명을 이 노트가 대체하지는 않는다.

처음에는 [수학 보충편](math-primer.md), 용어를 찾을 때는 [한영 용어집](glossary.md), 실제 공부 기록에는 [자율학습 워크북](self-study-workbook.md)을 사용한다. 본문 길이나 PDF 쪽수보다 직접 남긴 계산과 설명으로 이해도를 판단한다.

## 원강좌 시간과 독립 학습 시간을 구별한다

공개 실라버스의 CMU 원강좌는 7개 lecture와 5개 lab을 각각 80분으로 안내한다. 총 12세션, 960분, 16시간이다. [실라버스 정리](syllabus.md)는 그 공개 범위를 기록한다. 이 시리즈는 범위를 확장한 **이론 18강 × 80분 = 24시간**의 자체 구성이다. 원강좌의 7강이 실제로 18강으로 진행되었다는 뜻이 아니다.

80분은 용어 확인, 식 전개, 예제 재계산, 선택 문제와 회상을 포함한 한 세션이다. 장마다 문제 네 개를 수록했지만, 첫 세션에는 핵심 1–2개를 먼저 풀고 나머지와 오답 수정은 복습에 배정한다. 자세한 시간표는 각 강의의 “80분 학습 순서”를 따른다. 처음 보는 수학 때문에 더 오래 걸리면 시간을 늘리고, 이해가 부족한 채 시계에 맞춰 다음 강의로 넘어가지 않는다.

| 학습 활동 | 제안 배정 | 합계의 의미 |
|---|---:|---|
| 수학 보충편 P1–P8 | 4–8시간 | 예제·준비도 문제 재계산 |
| 강의 전 준비 | 18 × 20분 = 6시간 | 선수 개념과 용어 미리 확인 |
| 이론 첫 세션 | 18 × 80분 = 24시간 | 강의별 활동 시간표 |
| 강의별 복습 | 18 × 60–90분 = 18–27시간 | 네 문제 완전 풀이·유도 회상·오답 수정 |
| 필수 실습 5개 | 합계 10–15시간 | 실행·조건 변경·결과 해석 포함 |
| 최종 프로젝트 1개 | 12–20시간 | 세 제안 중 하나를 선택 |
| **전체** | **74–100시간** | 원문 전문 독해를 무제한 포함한 시간이 아님 |

합계는 하한 4+6+24+18+10+12=74시간, 상한 8+6+24+27+15+20=100시간이다. 실험 실패, 기초 보충, 논문 증명 독해, 실제 QPU 이용에는 추가 시간이 들 수 있다. 연구 경험이 있는 독자는 준비 부분을 진단으로 대체할 수 있지만, 생략한 내용을 이해한 것으로 자동 처리하지 않는다.

## 출발 준비도와 학습 환경

수학 보충편의 준비 문제 8개를 풀이를 가리고 시도한다. **6개 이상 독립적으로 해결하고, 틀린 문제를 해당 절로 돌아가 다시 푸는 것**을 시작의 권장 기준으로 삼는다. 이 기준은 표준화된 시험이나 교육적으로 검증된 합격선이 아니다. 총점보다 켤레 내적·부분 trace·평균의 분산·chain rule 중 무엇이 막히는지 찾는 데 쓴다. 한 문제라도 계산 과정을 설명할 수 없으면 그 절을 표시한다.

| 막히는 계산 | 먼저 돌아갈 준비 절 | 바로 연결할 강의 |
|---|---|---|
| 복소수·전역 위상·켤레 | [P1](math-primer.md#primer-complex), [P2](math-primer.md#primer-linear-algebra) | 02 |
| 고유값·PSD·역행렬 | [P3](math-primer.md#primer-spectral) | 02, 05, 08, 17 |
| 여러 큐비트·부분계 | [P4](math-primer.md#primer-tensor), [P5](math-primer.md#primer-states-measurements) | 03, 13 |
| shots·bias·신뢰구간 | [P6](math-primer.md#primer-statistics) | 02, 07, 10, 12 |
| 손실 미분·경사하강 | [P7](math-primer.md#primer-optimization) | 06–07 |
| 데이터 분할·복잡도 표기 | [P8](math-primer.md#primer-learning-complexity) | 01, 10–11, 14, 17 |

실습은 [실습 안내](labs/README.md)의 고정 환경을 따른다. CPU에서 실행하는 NumPy 경로가 기본이며 PennyLane은 별도의 교차검증 경로다. QPU 계정이나 유료 API 없이 핵심 계산과 다섯 실습을 진행할 수 있다. 실제 장치에 제출하지 않은 결과를 QPU 측정으로 기록하지 않는다. 설치·실행 로그와 관측값은 워크북에 버전·seed·실행 수준과 함께 남긴다.

## 한 강의를 혼자 공부하는 절차

사전 20분에는 제목과 학습 목표를 읽고 선수 강의의 식 하나를 빈 종이에 다시 쓴다. 처음 보는 영어 용어는 최대 다섯 개를 골라 한영 이름, 정의, 기호를 미리 적는다. 모든 정의를 외우고 시작하려고 하지 않는다. 80분 세션에는 각 식의 왼쪽과 오른쪽이 같은 종류의 대상인지 확인하고, 완전 예제의 숫자를 직접 재계산한다. 답을 읽기 전에 다음 줄을 예측해 본다.

복습 60–90분에는 본문을 덮고 유도 하나를 다시 만든다. 이어 네 문제를 모두 시도하고, 어떤 문제에서 정의·기술·가정이 부족했는지 표시한다. 힌트나 풀이를 본 문제는 해결했다고 끝내지 않고, 나중에 숫자나 조건을 바꾸어 다시 푼다. 유도에서 생략했던 중간 행렬곱, 분산의 독립성, 최적화 상계의 부등호 방향을 채운다.

원문 읽기는 본문의 모든 계산을 처음부터 외부 논문으로 대체하는 활동이 아니다. 강의 끝에서 지정한 공개 절을 읽고 “노트의 식과 같은 규약인가”, “정리 조건은 무엇인가”, “여기서 직접 확인한 범위는 어디까지인가”를 기록한다. 읽지 않은 증명을 읽었다고 표시하거나 초록의 주장을 전체 증명 검증으로 옮기지 않는다.

## 모르는 영어 용어가 세 개 이상 겹칠 때

한 문장에 낯선 용어가 세 개 이상 있으면 문장 전체를 번역해 암기하기보다 동작을 나눈다. 우선 무엇이 입력이고 무엇이 출력인지 적고, 명사에는 대상, 동사에는 연산, 부사·형용사에는 조건이라는 표시를 붙인다. 용어집에서 가장 핵심인 하나를 찾아 식으로 연결한 뒤 원문으로 돌아간다. 여전히 설명할 수 없는 두 단어를 다음으로 확인한다.

예를 들어 *efficient coherent state preparation with sample-and-query access*를 만나면 efficient의 입력 크기·오차 변수를, coherent의 중첩 보존 의미를, state preparation의 실제 출력 상태를 따로 적는다. sample-and-query가 고전 접근 가정인지 문맥을 확인한다. 같은 SQ가 statistical query도 뜻할 수 있으므로 약자만 보고 같은 모형이라고 결론 내리지 않는다.

용어 카드에는 한국어·영어 이름, 한 문장 정의, 식 하나, 닮았지만 다른 말 하나를 적는다. “fidelity = 충실도”만 쓰는 것은 정의를 아는 증거가 아니다. 순수 상태에서 절댓값 제곱이라는 식과 내적 부호를 잃는 반례까지 쓰면 다음 읽기에 사용할 수 있다. 다음날에는 영어 이름을 보고 식을, 그 다음에는 식을 보고 의미를 회상한다.

## 다음 강의로 넘어갈 때의 자기평가

다음 네 가지를 강의마다 워크북에 남긴다. 권장 기준이며 객관식 시험의 검증된 합격선이 아니다.

- 핵심 용어 다섯 개를 한국어·영어 이름과 함께 정의하고, 닮은 용어와 차이를 설명한다.
- 핵심 유도 하나를 중간 단계를 생략하지 않고 다시 쓴다. 기호의 뜻과 독립성·정규화 등 가정을 표시한다.
- 예제의 숫자나 조건을 바꾸어 새 계산을 하나 하고, 주장이 깨지는 반례를 하나 든다.
- 네 문제 중 세 개 이상을 답·힌트를 보지 않고 풀고, 남은 문제는 해설 확인 뒤 스스로 다시 풀어 오답을 수정한다.

용어만 막히면 용어집과 해당 강의 “핵심 용어”로 돌아간다. 행렬곱·미분이 막히면 수학 준비 절로, 왜 그 식을 쓰는지 설명이 막히면 위 선수 관계 표의 앞 강의로 돌아간다. 숫자는 맞지만 가정을 말하지 못하면 그 문제를 완료로 표시하지 않는다. 예를 들어 fidelity를 유클리드 거리로 바꾼 오류는 계산기를 더 사용하는 대신 04–05강의 정보 손실과 거리 정의를 다시 공부한다.

## 실습과 프로젝트에서 학습을 확인한다

실습마다 변경 전의 예상값, 실제 출력, 차이의 원인, 실행 수준을 적는다. seed 변경으로 달라지는 값과 닫힌 식으로 고정되는 값을 구별한다. 표준편차·신뢰구간·평균 bias를 혼용하지 않고, 상태벡터의 정확 기대값과 finite-shot 추정을 따로 기록한다. 오류가 없다는 로그 하나보다 조건을 바꾸어 예측한 현상이 나타났는지가 이해의 증거다.

[최종 프로젝트](projects/capstone.md)는 세 제안 중 하나를 택한다. 질문 하나, 강한 비교 기준 하나, 실패할 수 있는 조건 하나를 정한 뒤 실험 범위를 고정한다. 전체 데이터와 모든 최신 논문을 한 프로젝트에 담으려고 하지 않는다. 최종 보고서에는 재현한 것, 저자가 보고한 것을 인용한 것, 자신의 해석과 후속 제안을 분리한다. 근거 기준일 이후 논문을 추가하면 새 자료의 날짜·판본과 변경 범위를 따로 기록한다.

최종 점검에서는 다음을 각각 반례나 식과 함께 답한다. 같은 계산 기저 분포인데 다른 상태가 가능한가? 로그 큐비트 표현은 왜 공짜 적재가 아닌가? 큰 상태공간은 왜 좋은 커널을 보장하지 않는가? shots를 늘려도 남는 오류는 무엇인가? 양자 데이터의 표본 우위와 고전 표 데이터의 실용 우위는 어떻게 다른가? 답이 막히면 각각 02–03, 04, 08–09, 12, 13–14강으로 돌아간다.
