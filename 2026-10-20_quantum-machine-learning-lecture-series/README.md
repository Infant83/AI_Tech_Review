## 시간에 맞춘 학습 설계

원 강좌는 강의 7회와 실습 5회, 각 80분으로 총 16시간이다. 우리의 독립 강의는 **18×80분=24시간**이며, 원 수업의 분량으로 표시하지 않는다. 각 강의에는 선수 지식, 확인 가능한 목표, 한영 핵심 용어, 시간별 순서, 단계별 유도, 계산 예제와 반례, **문제 4개와 힌트·완전 풀이**, 출구 점검, 원문에서 확인할 위치와 조건을 넣었다. 강의 문제는 총 **72개**이며 수학 준비도 8문제와 프로젝트는 별도다.

80분에는 핵심 유도와 선택 문제 1–2개를 다룬다. 나머지 문제·유도 재작성·오답 수정에는 각 강의 후 60–90분을 따로 쓴다. 사전 읽기, 수학 보충, 실습, 프로젝트 하나까지 포함한 전체 제안은 **74–100시간**이다. 이 시간은 학습 계획용 추정이며 독자 실험으로 측정한 값이 아니다. 세부 합계와 수준별 경로는 [학습 안내](study-guide.md)에 있다.

내용을 읽었다는 이유만으로 다음 강으로 넘어가지 않는다. 핵심 용어 5개를 한영으로 설명하고, 유도 하나를 빈 종이에 재작성하고, 수치를 바꾼 예제와 반례를 설명하고, 문제 4개 중 3개를 해설 없이 푼 뒤 나머지 오류를 수정하는 기준을 제안한다. 이 기준은 학습을 돕는 자체 점검이며 공식 자격 평가가 아니다.

## 실습과 최신 연구의 확인 범위

실습은 Bell 상태·미분, 인코딩·군집, 커널/VQC와 고전 기준선, 자원·샷 장부, 잡음·완화의 다섯 주제다. NumPy 참조 코드는 작은 상태벡터와 확률 모형을 계산한다. PennyLane 교차검증은 별도 설치 경로로 제공한다. 정확한 명령·의존성·실행 수치는 [실습 안내](labs/README.md)를 기준으로 한다.

직접 실행한 것은 **CPU 기반 교육용 고전 시뮬레이션**이다. 실제 QPU 실행·대규모 논문 재현·실용적 양자 우위 입증을 수행하지 않았다. 작은 실습의 점수는 해당 데이터·분할·모델·seed의 결과이며 일반 성능 순위가 아니다.

2025–2026년의 광학 양자 학습, 학습 가능성과 고전 모사성, 잡음이 있는 학습, 양자 메모리를 쓰는 대규모 고전 데이터 처리, 생성 학습, quantum uploading을 다룬다. 출판·최초 공개·수정일을 구별하고 사전공개 연구는 상태를 표시한다. 작은 예의 자체 증명, 출처의 조건부 정리, 저자가 보고한 장치 실험, 향후 프로젝트를 구별했다. 기준일의 모든 논문을 망라한 체계적 문헌조사는 아니다.

## 보존·재생성

`lectures/`와 루트의 학습 문서는 편집 가능한 정본, `labs/`는 재현 코드·환경·결과, `dist/`는 최종 공개 HTML·수식·승인 코드, `output/pdf/`는 통합 PDF다. `research/`의 작업 메모와 `tmp/`의 QA 화면은 배포하지 않는다. 수집 원문·접속 정보·개인 메일·내부 경로도 배포물에서 제외한다.

HTML은 `artifacts/build_notes.mjs`, PDF와 반응형 QA는 `artifacts/print_notes.mjs`로 생성한다. `artifacts/README.md`에 도구 버전과 순서를 기록한다. 완성본에는 개인 환경 경로를 기록하지 않는다. 표지는 판본과 범위를 식별하는 텍스트 조판이며 기존 리뷰 표지를 교체하지 않았다.

## 판본과 작성·검증 공개

1.0판은 18강·54문제·실습 5개의 초기 아카이브다. 2.0판은 사용자의 “강의 시간에 맞는 학술적 깊이, 수강 없이 가능한 자율학습, 명확한 terminology” 요청에 따라 18강을 전면 확장하고, 수학 준비편·용어 144항목·문제 72개·학습 기록지를 추가했다. 동일 아카이브 ID에서 최신 판을 제공하며 첫 판 PDF는 내부 판본 기록으로 보존한다.

입력은 공개 게시물·공식 실라버스·원 논문·공식 교육 및 SDK 문서다. OpenAI Codex의 **root**가 통합 편집·수학 준비편·용어집·HTML/PDF·아카이브를, **revise_foundations**가 01–06강·학습 안내·기록지를, **revise_learning**이 07–12강을, **revise_research**가 13–18강과 관련 문헌 확인을 맡았다. 초기 실습·프로젝트는 **qml_labs**가 작성·실행했다. 정확한 실행 모델 식별자는 별도로 보존되지 않아 추정하지 않는다. 적용 하네스는 [AI Tech Review Editorial Harness 2026.08](https://infant83.github.io/AI_Tech_Review/methods/)이다.

수학 검토는 작성 역할을 바꿔 수행했다. root가 01–06강을, revise_research가 07–12강을, revise_learning이 13–18강을 검토했고, revise_foundations가 수학 준비편·용어집을 검토했다. 정의의 복소 내적 관례, 재업로드와 주파수의 구별, 군의 공리를 이 과정에서 수정했다. 작은 계산을 독립 재계산하고 문헌의 가정을 대조했지만 원 논문 전체 증명·대규모 데이터·실제 장치 결과를 독립 검증하지는 않았다. 사람은 주제와 개정 방향을 요청했으며 문장·문제별 사람 심사를 마쳤다고 주장하지 않는다. 오류나 후속 결과가 확인되면 판본과 근거 시점을 함께 갱신한다.
