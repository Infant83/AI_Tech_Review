# 뉴로모픽 Edge AI 심층리서치 프롬프트

## 목적

사이언스타임즈가 소개한 2026년 Nature Communications 논문을 출발점으로, 뉴로모픽 컴퓨팅이 physical AI, agentic AI, edge AI, 대안적 AI 하드웨어 논의에서 어떤 위치를 차지하는지 검토한다. 결과물은 AI Tech Review Letters 형식의 한국어 기술동향 리포트로 정리한다.

## 핵심 질문

1. Wang et al. 2026 Nature Communications 논문은 실제로 무엇을 구현했는가?
2. 논문의 91.7% color recognition, 93.5% object detection 수치는 어떤 수준의 검증인가?
3. in-sensor neuromorphic vision은 physical AI 로봇/자율주행/드론/웨어러블에서 어떤 병목을 줄이는가?
4. 2025-2026년 최신 리뷰 논문들은 뉴로모픽 컴퓨팅의 상용화 가능성을 어떻게 평가하는가?
5. 뉴로모픽은 LLM의 한계, 에이전트 AI의 비용/지연 문제, edge AI 시장에서 어떤 역할을 할 수 있는가?
6. 양자 AI와 비교했을 때, 가까운 시점의 산업 적용성은 어디에 있는가?
7. 과장해서는 안 되는 지점은 무엇인가?

## 출처 우선순위

1. Nature, Nature Communications, Nature Electronics, npj Unconventional Computing 등 peer-reviewed paper/review
2. IEEE/Science/PNAS급 핵심 논문과 공개 benchmark framework
3. Intel, IBM, Innatera, SynSense, BrainChip 등 공식 발표는 commercial signal로 분리
4. NVIDIA/Qualcomm 등 physical AI 발표는 배경 맥락으로만 사용
5. Reddit, 일반 블로그, 투자 홍보성 자료는 본문 결론 근거로 사용하지 않는다.

## 산출물

- 원 논문 확인 source note
- evidence-heavy deepresearch report
- 빠른 공유용 memo
- AI Tech Review Letters 형식 final review
- HTML companion
- figure manifest와 3-5개 설명형 figure

## 작성 톤

- 한국어 `-습니다 / -합니다` 문체
- 독자가 physical AI/agentic AI/LLM/edge AI를 어느 정도 알고 있다는 전제
- "뉴로모픽이 모든 LLM을 대체한다" 같은 큰 문장은 피하고, workload fit을 중심으로 설명
- 과학 기사처럼 흥미를 살리되, 실험실 규모와 상용화 병목을 분명히 쓴다.
