## 출판 원본

- `output/pdf/`: 정제한 회차별 PDF 정본.
- `dist/`: 명시적으로 등록할 공개 자산만 포함한다. 한국어 학습 입구와 영어 안내, 여섯 PDF, 최신 L006의 `notes.pdf` 사본, 회차 등록부와 별도 재계산 코드·결과다.
- `unit-registry.json`: 안정적 회차 ID·발행일·주제·공개 PDF 해시·문제/해설/용어 위치를 담는다. L007은 `planned-not-published`로만 표시하고 발행하지 않은 링크는 만들지 않는다.
- `reports/pdf-production-qa.json`: 원본/공개판 SHA-256, 쪽수, 수정 영역, 회차 간 링크, 수정 영역 밖 픽셀 동일성 기록.
- `reports/source-checks.json`: 웹 입구에서 인용한 공식 자료와 실제 확인 범위.
- `reports/archive-entries.json`: 회차별 공개 등록 항목의 제작 기록.

회차별 아카이브 ID는 `unit-registry.json`에 기록한다. L003의 기존 ID를 `LECTURE_BUNDLES`와 안정적 웹 주소 `lectures/classiq-qae-onboarding/`의 앵커로 유지한다. 한국어 입구는 여섯 회차를 순서대로 보여주고 각 PDF·문제·해설·용어색인·필기 reader로 연결한다. 유도와 복습 본문은 PDF에서 읽는다. 영어 입구는 한국어 자료에 대한 안내이며 전체 번역본이 아니다.

## 2026-11-06 회차 선택 화면 개편

렉처 목록의 시리즈는 기본으로 접고 제목 영역에서 세 회차를 펼치도록 했다. 전체 시리즈 요약은 접힌 상태에서도 보이며, 펼친 목록과 별도 회차 선택 페이지에는 각 회차의 짧은 주제 설명을 둔다. 한영 회차 소개는 root가 작성하고 series_summary_review가 기존 교육 내용과의 일치와 주장 범위를 검토했다. 회차별 필기·PDF·다운로드는 작은 텍스트 링크로 표시하며 터치 영역은 44px 이상 유지한다. 별도 회차 선택 페이지의 링크도 같은 밀도로 줄였다.

L003이 시리즈 전체를 대표하는 것처럼 보이던 웹 제목을 `Classiq QAE 온보딩 시리즈`로 바꿨다. `unit-registry.json`의 시리즈 제목·한영 소개와 회차 ID를 이용해 한 묶음으로 표시할 수 있게 했다. L003의 아카이브 제목은 해당 회차의 실제 주제로 바로잡았다.

PDF와 중복되던 유도 요약·웹 복습·일반 문자열 수식을 덜어내고, L001→L003의 필기·PDF 열기·다운로드와 문제·해설·용어색인 쪽 바로가기를 남겼다. 기존 시리즈 주소와 단원 앵커를 유지한다. 별도 보충 코드·결과와 출처·작성 범위는 계속 제공하며, 공개판 PDF 25·20·19쪽의 바이트·해시는 바꾸지 않았다. 이 개편에서 원판 전체 계산이나 자료 대조를 새로 수행한 것으로 표시하지 않는다.

## 검산과 한계

원판 PDF의 32·41개 검사, 특정 NumPy 판본과 그림 생성 기록은 원판 제작자의 수행 기록이다. 원판의 소스 ZIP은 연결 도구에서 지원하지 않아 수집하지 못했으므로 이번 공개 묶음에 포함하지 않았고 그 검증 전체도 독립 재실행하지 않았다. 세 PDF를 읽을 수 있고, 각 회차의 본문에 짧은 코드와 유도·해설이 남아 있다.

`labs/reference_checks.py`는 PDF에 공개된 식에 대해 이번에 별도로 작성한 Python 표준 라이브러리 재계산이다. 20개 조건은 작은 행렬의 Hermitian 성질과 제곱, 변분 에너지, 복소 내적, Bell 계수 행렬, 정확 시간발전·세 회전 분해, Euler 노름과 Trotter 근사를 확인한다. Trotter 차이에 쓴 Frobenius 노름은 원판 표의 spectral/operator norm과 다르다. 유한한 예제의 검산은 일반 알고리즘 성능이나 원판 전체의 정확성을 보증하지 않는다.

실제 Classiq 합성·SDK 호출·QPU 실행, 실제 분자·DFT·고객 데이터 계산은 이 공개 작업에서 수행하지 않았다. 원 작성 세션의 정확한 실행 모델·에이전트 식별자는 미보존이다. 이번 `public_pdf_qa/auth_audit`는 자료 확인·정제·부분검산·웹 입구를, `root`는 최종 통합·게시를 담당한다. 사람의 문장별 전체 감수나 Classiq의 승인을 받았다고 주장하지 않는다. 원판의 자세한 서지·읽은 위치는 원판 제작 기록으로 보존하고 이번 웹 입구의 APS 참고문헌·자료 확인 기록과 구별했다.

## 제작과 후속 회차 추가

개인 원본·수신 기록·QA 렌더링은 Git에서 제외되는 private intake에 보존한다. 그 경로를 공개 배포 자산에 넣지 않는다. 정제 스크립트는 명시적 입력 폴더와 한국어 글꼴 파일을 인수로 받으며 원본 해시를 먼저 대조한다.

1. 새 회차의 번호·발행일·판본·자료 성격을 확인하고 private intake에 원본을 보존한다.
2. 본문·권리·개인정보·메타데이터·링크·실행 동작과 전체 페이지를 검토한다. 회차의 과학적 실행 수준과 실제 검산 범위를 원판 제작 기록과 구별한다.
3. 회차별 정제 스크립트에 원본 해시를 고정하고 `output/pdf/`에 공개판을 만든다. L004의 예는 `artifacts/prepare_l004_public.py`다. 초기 세 회차용 `prepare_public.py`를 다시 실행해 기존 PDF를 재생성하지 않는다. 전체 페이지와 수정 영역 밖의 보존을 검수한 개별 QA 기록을 주 등록부에 추가한다.
4. `artifacts/build_study.py`의 회차 정의·문제/해설 위치와 새 회차 주제를 추가해 `unit-registry.json` 및 한영 입구를 다시 만든다. 이 단계 전에는 계획 회차를 공개 강의처럼 표시하지 않는다.
5. 신규 PDF는 `archive/entries/<문서 ID>.json`에 등록하고 bundle의 명시적 파일 allowlist를 갱신한다. v2 `archive/manifest.json` 설정은 편집하지 않는다. L003의 기존 bundle ID와 `study_href`는 시리즈의 고정 앵커로 유지하며 `notes.pdf`는 등록부의 최신 회차 PDF와 바이트가 같아야 한다.
6. 등록 검사·출판 검사·실제 한영 화면·모바일·각 회차 PDF와 필기 링크를 확인한 뒤 최종 게시한다.

2026-11-09 사용자 요청으로 이 대화에 연결된 수신 강의 확인·웹 발행 예약을 활성화했다. 6시간마다 새 메일과 실제 공개 회차를 대조하며 검수된 새 회차만 누적한다. 기존 집필·본인 메일 발송 예약은 변경하지 않는다. 시리즈 종료가 확인되고 도착분이 모두 발행되면 확인 예약을 종료한다. 메일 식별자·원본·수집 기록은 Git에서 제외되는 private intake에만 남긴다. 적용 편집 원칙은 원판에 기록한 AI Tech Review Editorial Harness 2026.08, 현행 편집 정책·과학 설명 준칙과 APS 인용 기준이다.

## 2026-11-09 L004와 후속 발행

L004 「같은 확률표인데 왜 다른 양자상태인가」는 원 교육16쪽에 공개판 안내1쪽을 더한17쪽이다. 한 기저의 확률표, 밀도행렬의 유효 조건·순도, 부분추적, Bell/분리 혼합의 상관과 얽힘 증인을 다룬다. 원판50개 검사는 이번에 재실행하지 않았고 기존20조건 보충 코드는 L001–L003에만 해당한다. qae_l004_public이 정제·보존·링크·전체 조판 검수를, root가 등록·한영 소개·발행 통합을 맡았다. L005는 원문이 예고한 확률·추정·샷·신뢰구간이며 미발행이다.

공개 시리즈 주소와 publication ID는 L003 앵커에 유지하고 새 회차별 아카이브·필기 ID를 추가한다. `notes.pdf`는 등록부의 `latest_unit`이 가리키는 PDF와 같아야 하며 모든 묶음 내 회차 사본도 등록된 해시로 대조한다. 목록 날짜와 정렬은 최신 회차의 발행일을 사용한다. L001–L003 공개 PDF 바이트는 바꾸지 않는다.

후속 작업에서는 `PUBLICATION_WORKFLOW.md`를 먼저 확인한다. 새 PDF는 `scripts.archive_documents.import_document` 또는 공식 CLI로 등록한다. 별도 후보를 만들어 실제 배포 스냅샷과 비교하고 검수한 시리즈 HTML·등록부·최신 PDF 별칭의 정확한 이전/이후 해시를 출판 변경 기록으로 남긴다. 후보의 한영·모바일·회차별 필기와 연속성·페이로드 검사를 통과한 뒤 기존 승인된 GitHub 발행 경로로 진행한다. 오래된 로컬 `site/` 전체를 최신 원격 위에 덮어쓰지 않는다.

## 2026-11-09 L005 수신분

L005 「샷을 몇 번 쏴야 결과를 믿을 수 있는가」의 공개판은 원 교육17쪽과 공개판 안내1쪽으로 구성한18쪽이다. Bernoulli·이항분포, 표준오차·편향, 고정 샷의 Hoeffding·Clopper–Pearson 구간과 Wald 경계 실패, 에너지 측정의 샷 배분과 얽힘 검출의 동시 신뢰 상한을 다룬다. 기존 L001–L004 PDF와 필기 ID는 보존하고 최신 별칭만 L005로 연결한다. 후속 L006의 변분 원리·수치 최적화·오차는 미발행 계획이다.

qae_l005_public이 정제·17쪽 보존·선수 링크5개 전환·전체18쪽 조판을 검수했다. qae_l005_science는 핵심 통계 유도를 검토하고 표준 라이브러리로 CP 구간·CP/Wald 포함률·Hoeffding738샷·에너지 배분·증인345/1379샷을 별도 계산했다. 원판의57개 검사와 seeded Monte Carlo 전체는 이번에 재실행하지 않았다. 원고·재현 ZIP·개인 수신 및 QA 기록은 공개 자산에 포함하지 않으며 root가 등록·출판 통합을 맡는다. 공개판 보존 검사는 `reports/pdf-L005-qa.json`을 따른다.

## 2026-11-11 L006 수신분

L006 「계산한 에너지가 정확한 바닥보다 낮아져도 되는가」의 공개판은 원 교육16쪽과 공개판 안내1쪽으로 구성한17쪽이다. 같은 Hermitian Hamiltonian의 Rayleigh 몫·변분 상한에서 출발해 상태족 제한과 최적화 오차를 나누고, 두 준위 모형의 정확해·경사하강법·정지 최댓값 반례를 비교한다. 유한 샷 에너지 추정과 동일 상태20배치 최솟값 선택의 하향 편향, 선택 뒤 새 표본의 조건부 신뢰구간을 다룬다. 비직교 기저의 계량과 근사 DFT functional·SCF 수렴의 비교 조건도 구별한다. 문제12쪽·해설13쪽·용어색인14쪽·참고문헌15–16쪽은 원래 쪽번호를 유지한다.
