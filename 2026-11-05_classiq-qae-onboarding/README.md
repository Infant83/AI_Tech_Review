책임 편집자 김현중 · AI 보조 OpenAI Codex · 공개판 기준일 2026-11-05

공개 1차 교재·논문과 공식 Classiq 문서를 바탕으로 자체 집필된 한국어 독립 학습 과정의 세 회차를 공개 학습 자료로 정리했다. QAE는 Quantum Application Engineer다. Classiq 공식 교육·자격 인증 과정이나 실제 웨비나 문답의 기록이 아니다. 기존 `2026-10-22_classiq-talk-series`는 Office Hours와 NVIDIA 공동 금융 웨비나를 다루는 별도 시리즈이며 수정하지 않았다.

## 출판 원본

- `output/pdf/`: 정제한 회차별 PDF 정본.
- `dist/`: 명시적으로 등록할 공개 자산만 포함한다. 한국어 학습 입구와 영어 안내, 세 PDF, 최신 L003의 `notes.pdf` 사본, 회차 등록부와 별도 재계산 코드·결과다.
- `unit-registry.json`: 안정적 회차 ID·발행일·주제·공개 PDF 해시·문제/해설/용어 위치를 담는다. L004는 `planned-not-published`로만 표시하고 발행하지 않은 링크는 만들지 않는다.
- `reports/pdf-production-qa.json`: 원본/공개판 SHA-256, 쪽수, 수정 영역, 회차 간 링크, 수정 영역 밖 픽셀 동일성 기록.
- `reports/source-checks.json`: 웹 입구에서 인용한 공식 자료와 실제 확인 범위.
- `reports/archive-entries.json`: 회차별 공개 등록 항목의 제작 기록.

회차별 아카이브 ID는 `2026-11-01-classiq-qae-l001-notes-ko`, `2026-11-03-classiq-qae-l002-notes-ko`, `2026-11-05-classiq-qae-l003-notes-ko`다. 최신 L003을 `LECTURE_BUNDLES`의 안정적 웹 주소 `lectures/classiq-qae-onboarding/`에 연결한다. 한국어 입구는 세 회차를 순서대로 보여주고 각 PDF·문제·해설·용어색인·필기 reader로 연결한다. 유도와 복습 본문은 PDF에서 읽는다. 영어 입구는 한국어 자료에 대한 안내이며 전체 번역본이 아니다.

## 2026-11-06 회차 선택 화면 개편

렉처 목록의 시리즈는 기본으로 접고 제목 영역에서 세 회차를 펼치도록 했다. 전체 시리즈 요약은 접힌 상태에서도 보이며, 펼친 목록과 별도 회차 선택 페이지에는 각 회차의 짧은 주제 설명을 둔다. 한영 회차 소개는 root가 작성하고 series_summary_review가 기존 교육 내용과의 일치와 주장 범위를 검토했다. 회차별 필기·PDF·다운로드는 작은 텍스트 링크로 표시하며 터치 영역은 44px 이상 유지한다. 별도 회차 선택 페이지의 링크도 같은 밀도로 줄였다.

L003이 시리즈 전체를 대표하는 것처럼 보이던 웹 제목을 `Classiq QAE 온보딩 시리즈`로 바꿨다. `unit-registry.json`의 시리즈 제목·한영 소개와 회차 ID를 이용해 한 묶음으로 표시할 수 있게 했다. L003의 아카이브 제목은 해당 회차의 실제 주제로 바로잡았다.

PDF와 중복되던 유도 요약·웹 복습·일반 문자열 수식을 덜어내고, L001→L003의 필기·PDF 열기·다운로드와 문제·해설·용어색인 쪽 바로가기를 남겼다. 기존 시리즈 주소와 단원 앵커를 유지한다. 별도 보충 코드·결과와 출처·작성 범위는 계속 제공하며, 공개판 PDF 25·20·19쪽의 바이트·해시는 바꾸지 않았다. 이 개편에서 원판 전체 계산이나 자료 대조를 새로 수행한 것으로 표시하지 않는다.

## 검산과 한계

원판 PDF의 32·41개 검사, 특정 NumPy 판본과 그림 생성 기록은 원판 제작자의 수행 기록이다. 원판의 소스 ZIP은 연결 도구에서 지원하지 않아 수집하지 못했으므로 이번 공개 묶음에 포함하지 않았고 그 검증 전체도 독립 재실행하지 않았다. 세 PDF를 읽을 수 있고, 각 회차의 본문에 짧은 코드와 유도·해설이 남아 있다.

`labs/reference_checks.py`는 PDF에 공개된 식에 대해 이번에 별도로 작성한 Python 표준 라이브러리 재계산이다. 20개 조건은 작은 행렬의 Hermitian 성질과 제곱, 변분 에너지, 복소 내적, Bell 계수 행렬, 정확 시간발전·세 회전 분해, Euler 노름과 Trotter 근사를 확인한다. Trotter 차이에 쓴 Frobenius 노름은 원판 표의 spectral/operator norm과 다르다. 유한한 예제의 검산은 일반 알고리즘 성능이나 원판 전체의 정확성을 보증하지 않는다.

실제 Classiq 합성·SDK 호출·QPU 실행, 실제 분자·DFT·고객 데이터 계산은 이 공개 작업에서 수행하지 않았다. 원 작성 세션의 정확한 실행 모델·에이전트 식별자는 미보존이다. 이번 `public_pdf_qa/auth_audit`는 자료 확인·정제·부분검산·웹 입구를, `root`는 최종 통합·게시를 담당한다. 사람의 문장별 전체 감수나 Classiq의 승인을 받았다고 주장하지 않는다. 원판의 자세한 서지·읽은 위치는 원판 제작 기록으로 보존하고 이번 웹 입구의 APS 참고문헌·자료 확인 기록과 구별했다.

## 제작과 후속 회차 추가

개인 원본·수신 기록·QA 렌더링은 Git에서 제외되는 private intake에 보존한다. 그 경로를 공개 배포 자산에 넣지 않는다. 정제 스크립트는 명시적 입력 폴더와 한국어 글꼴 파일을 인수로 받으며 원본 해시를 먼저 대조한다.

1. 새 회차의 번호·발행일·판본·자료 성격을 확인하고 private intake에 원본을 보존한다.
2. 본문·권리·개인정보·메타데이터·링크·실행 동작과 전체 페이지를 검토한다. 회차의 과학적 실행 수준과 실제 검산 범위를 원판 제작 기록과 구별한다.
3. 공개판 정제 규칙과 원본 해시를 `artifacts/prepare_public.py`에 추가하고 결과를 `output/pdf/`에 만든다. 전체 페이지와 수정 영역 밖의 보존을 검수한다.
4. `artifacts/build_study.py`의 회차 정의·문제/해설 위치와 새 회차 주제를 추가해 `unit-registry.json` 및 한영 입구를 다시 만든다. 이 단계 전에는 계획 회차를 공개 강의처럼 표시하지 않는다.
5. 회차별 PDF를 `archive/manifest.json`에 추가하고 최신 회차의 bundle ID·파일 allowlist를 갱신한다. 웹 시리즈 주소와 이전 회차 ID를 유지하며 `notes.pdf`는 최신 등록 PDF와 바이트가 같아야 한다.
6. 등록 검사·출판 검사·실제 한영 화면·모바일·각 회차 PDF와 필기 링크를 확인한 뒤 최종 게시한다.

메일을 자동 감시하거나 새 예약을 만들지는 않았다. 후속 회차 추가는 위 등록부와 명시적 검수 절차를 따른다. 적용 편집 원칙은 AI Tech Review Editorial Harness 2026.08, 문체 감사 하네스·과학 설명 준칙1.0과 APS 인용 기준이다.
