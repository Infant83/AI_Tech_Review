# 한영 출판 출력 검토

2026-11-25 · 편집부(AEDAUT) 집필·번역 및 운영팀(ADOPT) 출판 기술 검토 · 에이전트 `bilingual_production`

## 판본과 범위

원고·근거 기준일은 2026-11-24, 출력 검수일은 2026-11-25다. 국문 원고에 대응하는 영문 원고와 한영 `dist/` HTML·PDF를 제작했다. 이 기록은 로컬 출판 후보에 대한 것으로, 사이트 등록·배포·실제 HTTPS 확인을 수행했다는 뜻으로 쓰지 않는다. 사람의 기획·집필 진행 승인을 기록했으며, 별도의 문장 단위 사람 감수나 이번 리뷰의 게시 승인은 기록하지 않았다.

영문판은 원고의 설명 순서·조건·27개 참고문헌을 보존해 작성했다. 기준 상태의 뜻, 측정 비트의 평균이 에너지가 되는 과정, Pauli 회전 각도 2θ, QPE 기준 이동 3I와 64칸 격자, QAOA·Grover의 서로 다른 연산, QSVT 역함수 예시, 논리·물리 큐비트와 mHa 설명을 국문 수정에 맞추었다. 모든 참고문헌의 항목과 URL은 한영 원고에서 동일하다.

## 배치와 서체

그림 2는 VQE의 결합 회전 설명 뒤, QPE의 시간 진화 설명 앞에 놓았다. 그림 3은 QAOA 설명 뒤, Grover 설명 앞에 놓았다. 앞에서 소개한 두 방법을 비교하는 그림을 설명 도중에 배치해, 그림을 줄이지 않고도 종전의 큰 빈칸을 줄였다. 한영 원고와 출력의 배치를 함께 바꾸었다. 국문 12→11쪽, 영문 13→12쪽이 되었다.

표는 인쇄에서 머리행을 반복하고 행 내부가 분리되지 않도록 했다. 모바일에서는 글자를 11px로 압축하는 대신 13px를 유지하며 표 영역 안에서 가로로 읽도록 했다. 본문·표·그림의 색은 밝은 라벤더 바탕과 남색·절제된 보라색으로 맞췄다. 작성 정보는 페이지 사이에 갈라지지 않도록 했다.

Noto 계열의 한국어·기호·수학 서체를 최종 원고·SVG·출판 문구에 맞춰 다시 부분집합화하고 라이선스를 보존했다. CSS와 SVG에 서체를 포함해 외부 서체 요청 없이 읽을 수 있다. 필요한 문자의 서체 누락은 0개다. 포함한 서체로 다시 렌더링한 한영 데스크톱·모바일 SVG 12개에서 바깥 경계와 그림 1의 연산·출력 열 경계를 검사했다. 긴 영문 라벨을 뜻을 보존해 줄였으며, 글자의 경계 초과는 0개다. 결과는 `artifacts/figure-font-bounds.json`에 남겼다.

## 확인한 출력

Chrome 1440px·390px에서 한영 본문을 실행했다. 각 판본의 표지·세 그림 로딩, 모바일 전용 세 SVG 선택, 문서 가로 넘침 없음, 27개 참고문헌 ID와 본문 인용의 대상 연결, 작성 정보 1개, 표 영역 3개, 언어·canonical·현재 언어 표시를 확인했다. 공개 본문·PDF 링크에 로컬 절대경로나 `file:` URI가 없고 실행 스크립트가 없는 것도 검사했다. 메타데이터의 canonical은 예정된 게시 주소이며, 실제 게시 여부는 별도 발행 작업에서 확인한다.

최종 PDF의 전 페이지를 PNG로 렌더링해 연락판에서 배치·구분선·표·그림의 일관성과 쪽수를 검토했다. 대표 본문·표·표지와 모바일·데스크톱 진입 화면은 확대해서 보았다. 통합 담당자의 최종 전 페이지 독립 시각 검토는 별도로 수행한다.

Chrome이 일부 서체 변형에 출력한 U+0000 문자 매핑은 포함한 서체의 GSUB·글리프 윤곽·폭 대조로 증명한 경우에만 증분 수정했다. 수정 전후 전 페이지의 MuPDF 1.5배 및 Poppler 72dpi 픽셀이 각각 완전히 같았다. 텍스트 추출의 NUL·대체 문자는 0개다. 자세한 해시·쪽수·검사는 `artifacts/production-pdf-manifest.json`, `artifacts/production-html-manifest.json`, `artifacts/publication-text-layer-report.json`에 남겼다.

원 논문의 하드웨어 실행이나 큰 자원 추정 자체를 이 출판 작업에서 재실행하지 않았다. 교육 계산과 최신 연구의 구분은 본문·캡션·작성 정보에서 유지했다.
