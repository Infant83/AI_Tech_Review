## 본문과 그림을 조정한 이유

네 계열의 지도 뒤에 두 스핀을 먼저 놓아 독자가 같은 물리량을 두 방법으로 읽게 했다. 이어 Shor의 주기와 MaxCut의 후보로 계산 대상을 바꾸고, 행렬 변환에서 다시 시간 진화·상태 준비로 돌아온다. 최신 연구와 실용화는 이 연결에 필요한 자원을 중심으로 읽는다.

기획의 세 번째 그림에 예정했던 전망·자원 도식은 본문의 세 시계 설명과 표로 통합했다. 그림 3에는 같은 후보 집합의 QAOA·Grover·QAE를 독립적으로 배치해 실제 위상·회전·관측의 연결을 충분히 보여 준다. 서로 다른 실행 모델과 기업 일정을 하나의 숫자 축에 묶지 않으며, 전망은 명시한 장치 목표와 응용 조건에서 읽는다.

그림 2의 A는 초기 상태의 고유성분, B는 VQE 에너지 곡선, C는 QPE 유한 위상 격자다. 그림 3의 A는 입력 그래프와 후보 상태공간, B는 비용별 확률 분포, C는 진폭 증폭의 회전이다. 본문과 캡션의 패널 지시를 실제 그림에 맞춰 감수했다.

## 문체·설명 감수에서 반영한 것

독립 에이전트가 원고를 추가 해설 없이 읽고 중심 질문·수치·그림 관계를 대조했다. 별도 사람의 문장 단위 이해도 평가는 수행하지 않았다. 사용자의 기획 승인과 실제 사람 감수의 범위를 구별한다.

- 계산 기저 |0⟩·|1⟩을 소개하고, ZZ의 같은 비트·다른 비트에 +1·−1을 매겨 평균하는 과정과 X 측정축 회전, 에너지 합을 본문에 넣었다. 도입의 ‘비트에서 에너지를 읽는 법’을 직접 답한다.
- QSVT를 앞의 2×2 행렬의 고유값 1·3과 역수 가중치에 연결했다. 정규화·다항식의 조건을 같은 설명에 유지했다.
- 자원 추정 전에 물리·논리 큐비트의 관계와 mHa의 뜻을 설명했다. 임의 회전 합성과 T 게이트의 상대위상도 실제 실험의 결과와 연결했다.
- QFT의 역할과 QPE의 총 실행기간·최장 회로를 해당 대상과 조건으로 설명했다. 본문이 제기하지 않은 주장을 문단 말미에서 부정하는 문장은 덜고 과학 정보는 보존했다.
- 상용화 연도는 기업의 목표와 조건부 관찰 구간으로 서술했다. 알고리즘마다 확정된 경제적 채택 연도를 만들지 않았다.

표지와 세 본문 그림은 개별 제작물이다. 표지는 AI 생성 개념 일러스트이며, 본문 그림은 검산한 교육 값과 개념의 코드·SVG 표현이다. 수치 결과는 장치 실험이나 원 논문 재현으로 표시하지 않는다.
