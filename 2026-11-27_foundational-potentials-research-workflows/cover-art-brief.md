# 공유한 상호작용을 새 결정에서 읽는 표지

2026-11-27 · 편집부(AEDAUT) · 신규 제작

## 과학적 관계와 세 발상

원자 이웃에서 학습한 에너지 함수를 다른 결정의 배치에 적용하고, 필요한 국소 수정을 거쳐 집단 진동을 계산하는 관계를 연다. 분야는 계산 재료·물리·AI, 표현 유형은 재사용·적응과 국소–집단 대응, 매체는 과슈·석판 인쇄·드로잉을 결합한 편집 일러스트다.

| 발상 | 눈에 보일 사건 | 선택 판단 |
|---|---|---|
| A 원자 환경의 아틀라스와 겹쳐 읽는 종이 | 여러 작은 원자 이웃의 인쇄 기록 위에서 반투명 종이가 새 결정의 반복 무늬에 겹쳐지고, 한 접점에 수정 흔적과 진동의 이중 윤곽이 이어진다. | 선택. 재사용되는 국소 구조와 새 계에서 검증·적응하는 작업을 한 화면에 보인다. |
| B 탄성 있는 격자의 조율 | 공통 결합 모듈을 새 격자에 끼우고 집단 파형을 만드는 입체 설치. | 의미는 분명하지만 직전 양자 리뷰의 공간 조각·가는 선을 반복하고 실제 결합을 조립식 부품으로 단정할 위험이 있다. |
| C 깊이가 같고 곡률이 다른 그릇 | 두 에너지 곡면의 곡률과 원자 진동의 차이를 미술적 정물로 표현한다. | 교육 예제와 가깝지만 기존 MLIP 지형 표지와 반복되고, 원자가 실공간의 에너지 언덕을 구르는 것으로 읽힐 수 있다. |

## 실제로 확인한 미술 참고와 새 장면

Paul Klee의 *Alter Klang* (1925, 236 (X 6)), Kunstmuseum Basel G 1960.25를 확인했다. [박물관 기록](https://sammlungonline.kunstmuseumbasel.ch/eMP/eMuseumPlus?service=ExternalInterface&module=collection&objectId=1211), [Zentrum Paul Klee의 전시 해설](https://guide.zpk.org/de/fokus-cover-star-klee), 박물관에서 출처를 밝힌 [작품 사진](https://commons.wikimedia.org/wiki/File:Alter_Klang,_1925_-_Paul_Klee.jpg)을 대조하고 실제 이미지를 보았다. 어긋난 사각형의 작은 명도·색 차이가 이웃을 따라 넓은 리듬을 만드는 점, 표면의 붓질과 손으로 그은 경계가 규칙과 변주를 함께 드러내는 점을 참고했다.

원작의 정사각 화면·검은 외곽·색 블록 배치와 중심을 복제하지 않는다. 사진을 생성 입력으로 쓰지 않는다. 새 그림은 밝은 가로 종이 화면, 비대칭으로 겹친 두 인쇄 면, 알아볼 원자 이웃 모티프와 새 결정의 연결, 국소 수정과 집단 진동의 이중 윤곽을 갖는다. 원작에서 관찰한 이웃 사이의 리듬을 기사 고유의 국소 구조·물성 대응으로 발전시킨다.

직전 양자 표지의 회보라 공간 조각, 정보·에너지의 계측 캐비닛, ATRL의 미니어처 공방, 기존 MLIP의 지형 은유와 대비해 종이·인쇄·평면의 겹침을 선택한다. 실제 최근 표지의 이미지와 축소 화면을 함께 비교한다.

## 시각 요소의 의미와 오독 검토

| 요소 | 의미와 보존할 관계 |
|---|---|
| 왼쪽의 서로 다른 작은 이웃 모티프 | 다양한 원자 환경을 학습한 기반의 비유. 각 모티프의 특정 화학종·결합수·실제 학습 자료를 주장하지 않는다. |
| 같은 국소 모티프가 다시 나타나는 투명 종이 | 이미 학습한 관계를 새 문제에 적용하는 사건. 서로 다른 MLIP의 가중치를 임의 교환한다는 의미로 쓰지 않는다. |
| 오른쪽에 연속된 반복 구조 | 새로 계산할 결정의 원자 연결을 알아보게 하는 개념 모티프. 실제 결정학적 원자 위치는 코드 그림에서 담당한다. |
| 접점의 산호색 수정 흔적과 겹친 윤곽 | 새 계에서 추가 계산·조정·검증이 필요한 부분과 진동을 읽는 비유. 수정이 항상 정확성을 보장하거나 색이 실제 오차값이라는 뜻은 아니다. |

실제 구조·개수·변위·힘·곡률·진동수는 검산한 본문 SVG가 담당한다. 표지에 수식·문자·수치·로고·가짜 그래프를 넣지 않는다. 거대한 추상 지형이나 원자가 언덕을 구르는 그림, 로봇·두뇌·회로판을 사용하지 않는다. 제목을 가렸을 때 원자 구조와 재사용·국소 조정의 접점이 보이는지 실제 완성본에서 판단한다.

예정 캡션: 다양한 원자 이웃의 기록을 새 결정의 반복 구조에 겹쳐 읽고 조정하는 장면. 학습한 상호작용의 재사용과 물성 계산을 연결한 AI 생성 개념 일러스트.

### 실제 제작·축소 검수 결과

- 내장 ImageGen으로 신규 제작했다. 실제 프롬프트는 `artifacts/hero-prompt.txt`, 최종 파일은 `artifacts/hero.png`다. 참고 작품의 사진이나 기존 표지를 생성 입력으로 넣지 않았다.
- 1672×941px, SHA-256 `4ad50f09739ed7bfb39b9846fc2321f2c363c7a0f80dd71cef78d9b125504112`.
- 다양한 작은 이웃 모티프와 오른쪽 연속 구조, 중앙 투명 종이의 겹침과 산호색 수정 접점이 실제 그림에 보인다. 연구 대상은 알아볼 수 있고, 특정 화학종이나 실측 오차로 라벨링하지 않았다. 원자 노드의 겹친 윤곽은 움직임의 개념 단서다.
- 320×180 컬러·흑백을 실제로 보았다. 작은 화면에서도 왼쪽의 개별 기록과 오른쪽의 연결 구조가 구별된다. 흑백에서도 종이 경계와 중앙 겹침은 남지만, 세밀한 국소 수정은 본문 크기와 캡션에서 더 잘 읽힌다.
- 양자·정보/에너지·ATRL·현재 MLIP 표지 네 장의 실제 이미지를 나란히 확인했다. 기존 MLIP의 물 분자·에너지 지형과 달리, 새 표지는 다양한 이웃 모티프를 겹쳐 읽는 평면 인쇄 장면이다. 종이·따뜻한 색은 공통이지만 구도·매체와 전달하는 사건은 구별된다.
- 최종 한영 웹·모바일·PDF 배치는 제작 검수에서 추가 확인한다.

최종 한영 데스크톱·390px 모바일 진입 화면과 PDF의 표지를 확인했다. 종이의 겹침과 원자 이웃 모티프를 자르지 않고 가로 비례를 유지한다. 상아색 본문과 청록·산호색 도표 안에서 표지가 같은 색 관계를 유지하고, 긴 텍스트나 피규어와 충돌하지 않는다.
