# 같은 에너지 최솟값에서 달라지는 진동

2026-11-27 · 편집부(AEDAUT) 교육 계산·수치 검산 · foundation_calculations

## 어떤 계를 계산했는가

이 리뷰가 직접 구성한 네 원자의 1차원 주기 조화 사슬이다. 모든 원자의 질량은 28 amu이며, 네 이웃 결합 (0,1)·(1,2)·(2,3)·(3,0)에 같은 스프링 상수 K를 둔다. 에너지는 U=U₀+(K/2)Σ₍ᵢⱼ₎(uⱼ−uᵢ)², 공통 최솟값은 U₀=−10eV다. 실제 MLIP의 학습·실행, 특정 물질의 DFT 계산이나 논문 결과 재현을 수행한 것으로 쓰지 않는다.

선택한 교대 정상모드는 e=(1,−1,1,−1)/2, uᵢ=q eᵢ다. e의 제곱합이 1이므로 유효질량 μ=Σmᵢeᵢ²=28amu다. q는 길이 차원의 모드 진폭이며, 각 원자는 ±q/2만큼 움직인다. 단원자 사슬의 이 모드는 파수 π/a에 대응한다. 그림의 두 색은 반대 변위 방향을 표시하며 원자종이나 질량의 차이를 나타내지 않는다. 빈 원은 평형 위치다.

모드에 따른 에너지는 U(q)=U₀+½kq², 곡률은 k=4K다. 모드의 일반화 복원력은 Q=−dU/dq=ΣeᵢFᵢ=−kq다. 그림 2의 Q는 이 모드 좌표에 작용하는 힘이다. 각 원자의 Fᵢ와 Q의 관계를 코드에서 직접 대조했다.

## 독자가 비교하는 값

| 값 | 기준 사슬 | 연화한 사슬 |
|---|---:|---:|
| K (eV/Å²) | 1 | 0.81 |
| k=4K (eV/Å²) | 4 | 3.24 |
| μ (amu) | 28 | 28 |
| f=√(k/μ)/(2π) (THz) | 5.9088335943 | 5.3179502349 |
| q=0.10Å에서 ΔU (eV) | 0.0200 | 0.0162 |
| q=0.10Å에서 Q (eV/Å) | −0.400 | −0.324 |

스프링 상수와 곡률의 비율 0.81이 진동수의 비율 0.9로 이어진다. 두 에너지 함수의 최솟값은 같아도, 최솟값 주변의 힘과 휘어짐을 읽는 진동수는 달라진다. 그림 2는 이 관계를 독립적인 교육 모형으로 보여 준다. 본문이 소개하는 실제 보편 포텐셜의 연화 결과와 이 예제의 10%를 같은 측정값으로 쓰지 않는다.

모든 모드를 읽으면 기준 사슬의 진동수는 0, 4.1781763034, 4.1781763034, 5.9088335943THz다. 첫 값은 병진 모드이며 중간 두 값은 축퇴한다. 그림 3의 작은 4×4 힘상수 행렬과 네 모드의 막대는 같은 사슬의 구조를 사용해 입력→힘→힘상수→진동이라는 절차를 구체화했다.

## 검산과 재계산

주제 폴더에서 NumPy가 있는 Python으로 `python3 artifacts/verify_examples.py`를 실행한다. 검산 후 `artifacts/examples.json`을 저장한다.

- 직접 원자 좌표 에너지와 모드의 이차식을 여러 q에서 대조했다.
- 원자별 힘의 모드 투영, −kq, 에너지의 중앙 유한차분을 대조했다.
- 원자별 힘의 차분으로 얻는 4×4 Hessian을 세 변위 간격 0.01·0.005·0.002Å에서 해석 행렬과 대조했다.
- 동역학 행렬의 고유값으로 얻은 가장 높은 ω와 √(k/μ)를 대조했다. 진동수 f는 ω/(2π)로 읽는다.
- 주기 Laplacian의 고유값 0·2·2·4, 교대 모드와 그 정규화, 두 사슬의 f 비율을 확인했다. 검증 허용오차와 실제 식은 스크립트의 assertion에 남겼다.

SI 환산에는 1eV=1.602176634×10⁻¹⁹J, 1Å=10⁻¹⁰m, 1amu=1.66053906892×10⁻²⁷kg을 썼다. eV와 질량 단위는 [NIST의 2022 CODATA 공식 표](https://physics.nist.gov/cuu/pdf/RevModPhys.97.025002.pdf)에서 확인했다.

그림은 `/Users` 등 로컬 경로와 외부 서체 요청 없이 SVG 원본을 만든다. `uv run --with matplotlib --with numpy python artifacts/build_figures.py`로 다시 생성할 수 있다. 제작 환경은 Matplotlib 3.11.2·NumPy 2.5.5다. 정량 곡선은 Matplotlib SVG이고, 원자·입출력·실행 경로는 코드로 제작한 개념도다. 최종 출판 서체를 포함한 검수는 통합 제작 단계에 연결한다.
