## 이번 판본과 출력

국·영문 원고의 그림 3·4를 원논문 PNG 전체로 추가하고, 기존 계산 절차 개념도를 그림 5로 옮겼다. 그림 1·2의 관계·수치와 세 자체 피규어의 반응형 구성을 유지했다. 원고의 파수·질량 가중 변위·일반화힘, 원시 단위격자와 선 종류를 반영한 최종 입력으로 서체·웹·PDF를 다시 만들었다. 최초 제작 단계의 8·10쪽 출력은 이전 감수 기록이며, 이번 최종 제작본은 **국문 10쪽·영문 11쪽**이다.

## 원그림의 보존과 화면 배치

Deng 등의 원 Fig. 4와 Grandel 등의 원 Fig. 4는 `artifacts/source-figures/manifest.json`의 검토한 SHA를 빌더가 확인한 뒤 국·영문 배포 폴더로 복사한다. 두 언어의 공개 PNG는 확보한 원본과 바이트가 같다. 크롭·패널 재배열·재채색·라벨 번역·수치 변경을 하지 않았다. 캡션의 원 Fig. 번호·원저자·참고문헌·저작권자·CC BY 4.0과 전체 원본 재수록 표시는 한영으로 대응한다. 과학·권리 대조는 `reports/source-figure-audit.md`에 연결한다.

흰 원그림 바탕을 보존하고 기사 색의 가는 테두리와 캡션으로 자체 개념도와 구별했다. 데스크톱에서는 본문 너비로 전체를 보인다. 모바일에서는 342px 영역 안에 860px 너비의 원그림을 유지하고 가로 스크롤·키보드 초점·지역 이름·짧은 읽기 안내와 원본 크게 보기 링크를 제공한다. 인쇄에서는 스크롤과 안내를 제거하고 전체 원그림과 캡션을 한 덩어리로 배치한다. 그림 3·4는 양쪽 PDF의 5·6쪽에 각각 포함됐으며 원 PNG 해상도 1451×527, 1450×1261이 PDF 안에도 유지된다.

영문 비교표의 마지막 비용 행만 다음 쪽으로 넘어간 초기 출력을 수정했다. 본문 글자나 그림 크기는 유지하고 인쇄 표의 수직 패딩을 6pt에서 3.5pt로 조정했다. 최종 영문 9쪽에 머리행과 다섯 데이터 행이 모두 들어가고 10쪽은 이어지는 비용 해석으로 시작한다. 실제 확대 화면에서 글자·행 간격·구분선과 바닥글 간격을 확인했다.

그림 5의 새 번호와 파일 이름을 생성기·원고·웹에 함께 반영했다. 미게재 그림의 이전 `fig3_*` 파일만 그림 5로 이관했고 관련 생성 코드와 Git 이력은 보존했다. 배포 폴더는 언어별 HTML·CSS·PDF와 명시한 이미지 아홉 개뿐이다. 원문 HTML·논문 전문·권리 검수 원문·QA 스크린숏·비공개 증거는 포함하지 않는다.

## 실제 서체와 출처

기존과 같은 SHA의 Noto Sans KR 원본 두 굵기를 재사용했다. 보조 일반·수학 서체는 Noto 공식 저장소의 실제 원본과 동봉 SIL OFL을 확보해 다시 부분집합화했다. 그 URL·해시는 `artifacts/font-source-manifest.json`, 실제 서체·원고·제작기 입력 해시는 `artifacts/font-coverage.json`에 남겼다. 이전 보조 서체의 출처를 새 원본인 것처럼 표시하지 않았다. 원본의 완전한 라이선스를 동봉하고 부분집합 이름을 바꿨으며 외부 서체 요청은 없다. 최종 입력에 대한 누락 글자는 0개다.

## 최종 화면·PDF 검수

- Chrome 1440px·390px 한영 화면에서 이미지 여섯 개, 참고문헌 11개, 인용 대상, 작성 정보, 표 영역, 언어·canonical을 확인했다. 문서 가로 넘침·깨진 이미지·개인 경로·실행 스크립트는 없다.
- 자체 피규어 12개를 실제 포함 서체로 렌더링했다. 바깥 문자 경계와 그림 5의 단계 열 넘침은 모두 0개다. 모바일에서는 자체 피규어 세 개가 각각 모바일 SVG를 선택한다.
- 최종 21쪽을 전부 PNG로 렌더링하고 한영 연락판에서 읽는 순서·구분선·그림과 본문·바닥글을 검토했다. 국문 6쪽 원그림과 캡션, 영문 5쪽 원그림과 연구 설명, 영문 9쪽 전체 표, 국문 10쪽·영문 11쪽 작성 정보를 확대 확인했다. 웹의 국문 그림 4 데스크톱과 영문 그림 3 모바일도 실제 화면으로 읽었다. 이는 에이전트 시각 검수이며 사람의 이해도 평가로 표시하지 않는다.
- 한국어 변형 글리프·합자의 NUL 매핑은 포함 서체의 GSUB·윤곽·폭이 일치하는 경우에만 증분 수정했다. 수정 전후 MuPDF 1.5배와 Poppler 72dpi의 전 페이지 픽셀이 각각 동일하다. 최종 NUL·대체 문자·개인 URI는 0개다. 해당 기록은 `artifacts/publication-text-layer-report.json`이다.
- 원고와 서체 입력 해시, 최종 HTML 해시, 언어별 공개 파일 허용 목록, 원 PNG의 국·영문 복사본 해시를 다시 대조했다. 최종 기호와 그림 1–5 순서도 확인했다.

## 이번 편집·제작의 모델 기록

원고 전체의 최초 저술 모델을 현재 설정으로 소급하지 않았다. `artifacts/ai-model-provenance-figures-integration.json`은 이번 원그림 보완 편집의 `gpt-6.1-sol`, 추론 강도 `ultra`를 대화 설정 기록(`turn_context`)으로 확인한다. 제작 담당자는 자신의 기본 식별로 별도 수집했으며 `artifacts/ai-model-provenance-figures-production.json`의 근거는 현재 기본설정 스냅숏(`settings_snapshot`)이다. 이를 실제 제작 대화의 모델 확정으로 쓰지 않았다. 초기 집필 담당별 설정은 이번 보완에서 확인하지 않았다고 한영 작성 정보에 적었다.

빌더는 이 고정 공개 JSON을 읽어 표시 문구를 만들고 세션·현재 설정·비공개 증거를 조회하지 않는다. 비공개 증거는 저장소 밖에 보관했다. 원그림·원 논문의 수치 계산을 이번 제작에서 독립 재실행하거나 원 연구의 물리적 정확성을 새로 입증했다고 표시하지 않았다.

통합 담당자는 최종 한영 21쪽 연락판 전체와 영문 9쪽 표·국문 10쪽 작성 정보를 따로 확대 확인했다. 원 PNG 두 개와 각 PDF에 포함된 해당 이미지의 모든 RGB 픽셀이 같음을 독립 대조했고, 원본·국문 웹·영문 웹의 여섯 PNG SHA도 확인했다. 최종 PDF 해시·NUL/대체 문자 0개, 한영 참고문헌 11항목의 동일성, 그림 1–5 순서와 두 캡션의 CC 크레딧도 별도로 확인했다.
