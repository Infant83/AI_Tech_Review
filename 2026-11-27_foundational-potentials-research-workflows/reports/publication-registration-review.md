## 승인과 작업 범위

사용자가 완성한 리뷰의 게재를 명시한 범위에서 신규 리뷰 등록, 한영 허브 소개와 두 PDF의 아카이브 가져오기를 수행했다. 원고·PDF를 새로 제작하거나 과거 모델 설정을 소급 변경하지 않았다. 출판 요청 생성·실제 배포 기준 확보·후보·봉인·Git·공개 확인은 통합 담당자가 이어 간다.

`PUBLICATION_WORKFLOW.md`, 편집 정책·작성 방법의 작성·모델 공개 기준과 허브 요약 감수, 기존 등록·아카이브 형식을 확인했다. 원고와 1차 자료 대조, 원그림 선별·권리 대조, 원그림 통합 후 최종 제작 감수를 읽어 수행 범위를 등록정보에 옮겼다.

## 날짜와 신규 기록

- 리뷰 ID는 기존 주제 폴더 `2026-11-27_foundational-potentials-research-workflows`를 유지한다. 신규 등록은 `publication/reviews/2026-11-27_foundational-potentials-research-workflows.json`이다.
- 원고·근거·최종 출력 검수 기준일은 **2026-11-27**, 최초 게재일과 허브 정렬 날짜는 **2026-11-28**로 구분했다.
- 아카이브 ID는 `2026-11-28-foundational-potentials-research-workflows-ko`와 `2026-11-28-foundational-potentials-research-workflows-en`이다. 새 공유 일련번호나 과거 `legacy_position`을 부여하지 않았다.
- 한영 소개는 `scripts/hub_summaries_en.json`에 한 항목으로 추가했다. 기존 55항목의 값은 HEAD와 비교해 모두 보존했으며, 국문 `source`는 등록의 `review.summary`와 정확히 같다.

통합 담당자는 원시 HTML의 `article:published_time`만 실제 최초 게재일로 맞추는 작업을 별도로 맡았다. 원고의 날짜·근거 기준일·PDF는 11월 27일을 유지하는 범위이며, 이 등록 담당자는 승인된 `dist/`나 빌더를 수정하지 않았다.

## 독자가 진입하는 소개

국문 소개는 새 결정의 진동을 계산하는 상황에서 시작한다. 에너지 최솟값과 진동수의 관계를 설명하는 교육 모형, 같은 불안정 진동 뒤에도 다른 상으로 간 실제 연구를 구별해 제시했다. 마지막은 새 물질의 검증과 기록 보존이 모델·계산 절차의 재사용으로 이어지는 논지를 전한다. 첫 문장에 MLIP·DFT·모델 이름을 밀집시키지 않았다.

영문은 같은 작은 모형·실제 연구와 재사용의 범위를 보존했다. 문장과 단위·시제에서 교육 계산을 실험·MLIP 재현으로 높이거나 실제 연구를 이 리뷰의 새 결과로 표시하지 않았다. 실제 카드의 표시·줄바꿈·이미지·검색 노출은 통합 담당자가 만드는 후보 화면에서 확인한다. 이 메모는 그 화면을 이미 검수했다는 기록으로 쓰지 않는다.

## 과학·그림·사람 검토 범위

등록은 참고문헌 11항목과 읽은 판본의 범위를 보존한다. 출발 Perspective는 공개 소개·공식 서지까지 확인했고 전문은 미확보다. Rensmeyer의 세부는 실제 읽은 arXiv v1을 정식 출판 항목과 구별한다. 실제 MLIP·DFT·MD·에이전트 시스템 연구는 원저자 보고이며, 리뷰의 네 원자 조화 모형 검산과 구별했다.

그림 1·2·5는 자체 제작 개념·교육 계산 그림이고, 그림 3·4는 Deng 등과 Grandel 등의 원 Fig. 4 전체다. 원저자·정식 출처·저작권자·CC BY 4.0 링크·내용 무변경 표시와 원본 해시·PDF RGB 픽셀 보존 검수를 등록의 설명에 연결했다. 전체 논문·권리 대조 원문·QA 화면·비공개 증거를 공개 배포물에 추가하지 않았다.

사람의 연구 관점·기획·진행 승인과 원논문 결과 그림 보완 요청, 11월 28일 게재 요청을 기록했다. 별도의 문장 단위 사람 재독이나 독자 이해도 실험은 수행 기록이 없어 주장하지 않았다.

## 역할별 모델 근거

모델 ID와 추론 강도를 각각 기록했다. 초기 집필 담당별 설정을 이번 값으로 소급하지 않았으며, 등록의 `ai_model`·`ai_model_ko`도 이 차이를 설명한다.

| 수행 단계 | 모델 ID | 추론 강도 | 확인 근거와 범위 |
|---|---|---|---|
| 초기 집필 담당별 설정 | 이번 게시에서 미확인 | 미확인 | 현 설정을 과거 집필 모델로 대입하지 않음 |
| 원그림 보완 편집 | `gpt-6.1-sol` | `ultra` | `ai-model-provenance-figures-integration.json`의 `turn_context` |
| 원그림 통합 PDF 제작 | 기본 설정 스냅숏에 `gpt-6.1-sol` | 스냅숏에 `ultra` | `ai-model-provenance-figures-production.json`의 `settings_snapshot`; 실제 제작 대화 모델은 미확정 |
| 통합 담당자의 게시 검수 | `gpt-6.1-sol` | `ultra` | `ai-model-provenance-publication-20261128.json`의 `turn_context` |
| 등록 담당자의 이번 게시 작업 | `gpt-6.1-sol` | `ultra` | `ai-model-provenance-registration-20261128.json`의 `turn_context` |

등록 담당자는 현재 수집 도구를 `publication-audit` 역할로 직접 실행했다. 공개 JSON은 허용한 모델·추론 강도·역할·근거 유형·확인일만 담고, 비공개 증거는 저장소 밖에 별도로 보관했다. 공개 기록의 `checked_on: 2026-11-27`은 UTC 확인일이며, KST 11월 28일 게시 작업과 구분된다. `turn_context`는 클라이언트 선택 설정의 증거이며 서버 가중치 판본의 독립 검증으로 표현하지 않았다. 이미 고정한 PDF의 원그림 보완 모델 기록과 이번 게시·등록의 추가 기록은 서로 다른 작업 단계다.
