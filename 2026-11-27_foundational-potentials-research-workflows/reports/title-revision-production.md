# 제목·부제 개정과 출력 재검수 · 2026-11-28

편집부(AEDAUT)는 편집자의 제목 명료화 요청에 따라 한영 제목·부제를 개정했다. 운영팀(ADOPT)의 기존 출판 도구로 동일 글·아카이브의 개정 후보를 만든다.

## 편집 판단

기존 「원자의 에너지 함수를 함께 쓰는 시대」는 공유하는 대상과 재료 연구의 변화가 즉시 드러나지 않았다. 새 제목은 「원자의 힘을 배운 AI, 재료 연구의 출발점을 바꾸다」, 부제는 「사전학습 포텐셜을 검증하고, 계산 절차까지 재사용하는 연구」다. 여러 원자 환경을 미리 학습한 모델로 새 물질 계산을 시작하고, 필요한 물성을 검증하며 계산 조건과 성공·실패 기록도 이어 쓴다는 중심 논지를 전한다. 정확도 보장이나 범용 연구 자동화를 약속하지 않는다.

영문 제목은 “AI That Learns Atomic Forces Is Changing Materials Research”, 부제는 “From pretrained interatomic potentials to validated, reusable computational workflows”다. 한영 과학 본문은 H1·부제 뒤의 원문과 같으며, 참고문헌·수치·캡션·원그림·개념도·표지·스타일을 유지한다. 별도 에이전트의 독립 판단은 `title-revision-review.md`에 남긴다.

## 제작 확인

한영 HTML의 H1·title·Open Graph 제목, 부제와 PDF 첫 페이지를 대조했다. 원고·근거 기준일 11월 27일과 제목·부제 개정·출력 재검수일 11월 28일을 구별한다. 새 제작의 모델·추론 설정은 대화 설정 기록으로 확인하고, 이전 원그림 PDF 제작의 미확인 범위를 소급 변경하지 않는다.

현재 PDF는 국문 10쪽·영문 11쪽이다. 전 페이지 연락판과 첫 페이지 확대 화면에서 제목·부제·그림·참고문헌·작성 정보의 배치 및 글자 판독을 확인했다. 새 제목의 모든 글자가 기존 정규·굵은 서체에 포함되어 서체와 그림 자산은 재생성하지 않았다. 두 원논문 결과 그림의 RGB 픽셀은 원본과 같고, 두 PDF의 NUL·대체 문자·개인 경로·file URI는 0개다. Chrome 글자 매핑 보정 전후의 전 페이지 픽셀도 PyMuPDF·Poppler에서 같다.

## 후보·실제 공개

최종 후보의 배포 보존 검사와 페이로드 검사를 통과했다(`ok=true`, 차단 없음). 실제 11월 28일 공개 스냅샷을 기준으로 리뷰 61편·아카이브 197항목·정규 게시물 95개의 기존 ID·주소·발행일을 보존한다. 허브 카드와 검색에는 새 한영 제목이 있고, 1440px·390px Chrome에서 기사의 제목과 카드·그림·인용·연결을 확인했다. 검색 자료와 전체 공개 크기의 기존 소프트 경고는 유지된다. 실제 공개 검증까지 완료했다. 아래의 개정 게재 확인과 `title-revision-live.json`을 따른다.

### 개정 게재 확인

[배포 run 46070706067](https://github.com/Infant83/AI_Tech_Review/actions/runs/46070706067)의 build·deploy·recovery-copy·notify-readers가 모두 성공했다. 실제 배포 소스는 `4018023ed5dab348ab75db1568c20faa4f3c53e6`이다. 31개 HTTPS 주소가 모두 200이며 한영 기사 자산 24개와 아카이브 PDF 2개는 최종 후보와 바이트가 같다. 두 HTML에서 edge 변경은 관찰되지 않았다. 릴리스 자체를 제외한 30개 다운로드를 봉인 목록의 SHA와 대조했고 모두 일치한다. 카탈로그의 SHA도 릴리스와 같다. 후보와의 메타데이터 차이는 카탈로그의 소스 revision과 개정 기사의 최초 생성 updatedAt(로컬 21:27:13Z, CI 21:33:52Z)뿐이다.

실제 Chrome의 한영 1440px·390px 화면에서 새 제목·부제·카드, 그림 6개·참고문헌 11개, 원 발행일·canonical과 모바일 가로 넘침 없음을 확인했다. 복구 작업은 실제 배포의 2,884파일·941,436,976bytes를 검증했고 복구 tar.gz SHA는 `8ade6d2375b9955af2216ff579f74be68d24962a5dc2e40849262e5370f201c0`이다. 업로드 artifact와 보존 검증은 CI 로그·API로 확인했으며 대용량 파일을 로컬에서 다시 내려받지는 않았다. 독자 동기화는 95개·ok이며 새 글 0·알림 이벤트 0이다. 개인별 전달을 검증한 것으로 기록하지 않는다. 최초 게재와 이번 제목 개정의 원고·PDF 해시를 각각 보존했다.
