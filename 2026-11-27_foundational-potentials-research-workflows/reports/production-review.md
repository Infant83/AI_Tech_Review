아래는 원논문 결과 그림을 추가하기 전의 최초 제작 검수 기록이다. 같은 날 진행한 그림3·4 추가와 기존 도식의 그림5 이동, 새 한영 출력의 검수·쪽수·해시는 [원그림 통합 출력 감수](source-figure-production-review.md)와 최신 `artifacts/production-pdf-manifest.json`을 따른다. 최초 제작 단계와 이후 개정의 수행 범위를 구별해 보존한다.

## 판본과 수행 범위

동결된 국문에 대응하는 영문 원고, 한영 `dist/` 웹 제작본과 PDF를 만들었다. 원고·근거·출력 검수 기준일은 2026-11-27이다. 이 작업에서는 다음 리뷰의 공개 등록·아카이브 가져오기·배포·실제 HTTPS 확인을 수행하지 않았다. 웹 메타데이터의 canonical은 예정된 게시 주소다.

영문은 국문 본문 전체와 11개 참고문헌에 대응한다. 에너지에서 힘을 구하는 음의 기울기는 해당 모델로 범위를 정했고, 기준 계산의 총에너지, 모드 진폭 q와 일반화힘 Q, 개별 원자 힘, Φ와 질량 가중 D의 고유값 ω²를 구별했다. 단위·수치·검증 대상을 원문 대조와 함께 확인했다. 53재료의 진동수 MAE 중앙값과 상 복원 F1, K₃Sb의 R−3 표기, LaMnO₃의 에너지 불확실성 판정과 구조 변화, Potente의 같은 모델·설정 500구조×5회 비교를 보존했다.

국문 독립 감수에서 보완된 DFT 교환상관 근사, 후방분포, 장거리 전기장 보정의 의미와 구체적인 마지막 문단을 영문에서도 대조했다. 사람의 기획·진행 승인과 에이전트의 원문·독자·출력 감수를 기록했으며, 별도 사람의 문장 단위 감수나 이해도 시험으로 표시하지 않았다. 출발 Perspective의 전문 미확보와 공개 소개·서지 확인 범위는 작성 정보에서 명시했다.

## 그림·배치와 실제 서체

그림 1은 MLIP의 첫 정의 뒤에, 그림 3은 진동 계산 요청을 실제 단계로 설명한 첫 문단 뒤에 배치했다. 한영 원고의 위치를 함께 바꾸었으며, 본문의 주장을 바꾸거나 그림을 줄이지 않고 큰 빈칸을 줄였다. 국문은 첫 출력 9쪽에서 8쪽이 됐고 영문은 10쪽을 유지했다. 그림 2는 좌표·단위·사슬의 계산 수치를 먼저 읽을 수 있도록 기존 설명 뒤에 유지했다. 정의 직후로 옮긴 별도 시험은 국문 빈칸을 더 크게 만들어 채택하지 않았다.

실제 Noto 한국어·기호·수학 원본에서 이번 원고·그림·출판 문구에 필요한 서체를 부분집합화하고 라이선스를 보존했다. 서체 누락은 0개이며 CSS와 SVG에 포함했다. 서체 포함 후 데스크톱·모바일 한영 SVG 12개를 실제 Chrome으로 렌더링했다. 중첩 Matplotlib 좌표의 변환까지 적용되는 전역 문자 경계를 사용했고, 그림 3의 네 단계 열 경계도 검사했다. 모든 바깥 경계·단계 열 넘침은 0개다. 긴 영문 라벨과 인접 화살표에 닿던 문구는 의미를 보존해 짧게 정리했다.

표는 모바일에서 13px를 유지한 가로 스크롤 영역이며 페이지 전체를 넘치게 하지 않는다. 인쇄에서는 표 머리행을 반복하고 행 내부의 분리를 막았다. 화면과 그림은 밝은 상아색 바탕·짙은 청록색 본문·절제된 산호색 계열로 맞췄다.

## 화면·PDF 검증

Chrome 1440px·390px에서 한영 화면의 표지와 세 그림, 11개 참고문헌 ID와 본문 인용 연결, 작성 정보 1개, 표 영역 1개, 언어·canonical·현재 언어 표시를 확인했다. 모바일에서는 세 전용 SVG를 선택했고 이미지 4개가 모두 로딩됐다. 전체 페이지의 가로 넘침, 실행 스크립트, 공개 본문·링크에 개인 절대경로 또는 `file:` URI는 없었다. 한영의 참고문헌 항목과 URL은 동일하고 본문 인용 그룹도 대응한다.

최종 국문 8쪽·영문 10쪽의 전 페이지를 PNG로 렌더링해 연락판에서 배치·머리행·표·구분선·본문/그림 흐름을 검토했다. 국문 수식·힘상수 설명·그림 3, 영문 실제 연구 비교와 작성 정보를 확대해서 보았고, 한영 데스크톱·모바일 진입 화면도 확인했다. 통합 담당자의 최종 독립 시각 확인은 별도로 기록한다.

Chrome이 포함한 한국어 서체의 일부 변형에 부여한 NUL 문자 매핑은 원본 GSUB·글리프 윤곽·폭으로 증명한 경우에만 증분 수정했다. 수정 전후 **MuPDF 1.5배와 Poppler 72dpi의 전 페이지 픽셀이 각각 동일**했다. 수정 후 NUL·대체 문자와 개인 URI는 모두 0개다. 페이지·해시·서체·범위 검사는 다음 상대 경로의 기록에 결속한다.

- `artifacts/production-html-manifest.json`
- `artifacts/production-pdf-manifest.json`
- `artifacts/font-coverage.json`
- `artifacts/figure-font-bounds.json`
- `artifacts/publication-text-layer-report.json`

원 연구의 MLIP·DFT·MD·에이전트 시스템을 이 제작 작업에서 재실행하지 않았다. 리뷰의 작은 조화 모형 계산과 원 논문 보고 결과를 본문·캡션·작성 정보에서 구별했다. 원문 라이선스의 공백은 보존했다.

통합 후 소스 문단 말미의 공백 한 글자를 정리하고 HTML을 다시 생성했다. 국문 HTML 차이는 그 공백 한 글자의 삭제뿐이고 영문·자산·본문의 의미와 PDF는 그대로다. HTML manifest의 국문 해시만 다시 결속했으며 승인한 PDF의 해시를 재확인했다. Matplotlib이 생성한 SVG 경로와 원문 OFL 라이선스의 공백은 생성 결과 그대로 보존했다.
