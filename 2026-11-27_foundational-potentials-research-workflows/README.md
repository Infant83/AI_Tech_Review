## 직접 계산한 것과 문헌 대조

동일 질량 28amu인 네 원자의 주기 사슬과 교대 모드 e=(1,−1,1,−1)/2를 교육 모형으로 계산했다. q=0.1Å에서 각 변위는 ±0.05Å다. K=1eV/Å²에서 모드 힘상수 k=4K, f≈5.908834THz이며 K를0.81배로 바꾸면 f≈5.317950THz, 정확히0.9배다. 원자 좌표의 에너지·힘과 모드 투영, 유한차분 힘상수, 질량을 반영한 동역학 행렬을 독립식과 대조했다.

q는 모드 진폭이고 Q는 그 좌표의 일반화힘이다. 역공간의 파수점과 구별했다. 그림3의 Φ/K는 무차원 힘상수 행렬이며, 네 진동수에는 함께 병진하는 영진동수 모드가 포함된다. 실제 MLIP·DFT·원 연구의 MD·에이전트 시스템을 실행한 것으로 표시하지 않는다.

원 연구는 공개 전문을 읽은 범위에서 해석했다. 출발 Perspective는 공식 서지·공개 소개를 확인했으나 정상 공개 HTML·PDF가403이라 전문을 읽은 것으로 기록하지 않는다. Rensmeyer의 세부 계산은 실제 읽은 arXiv v1을 정식 출판 항목과 구분해 인용했다. Potente 본문·SI의 비용 요약 불일치는 조사 기록에 보존했고 본문에서 절감 배율이나 전력으로 확대하지 않았다.

## 설명과 문체에서 반영한 감수

별도 에이전트가 국문·세 그림·수치와 연구 조건을 검토하고 실제로 읽은 중심 질문과 통찰을 기록했다. 그 의견에서 일반화힘 Q, 힘상수 Φ·동역학 행렬 D, 후방분포의 대상과 DFT 교환상관 근사를 본문에 보완했다. 힘은 에너지의 음의 기울기로 정확히 적고, 기준 전자계산은 원자 배치의 총에너지를 제공한다고 썼다.

전문가 역할의 구체적인 선택 뒤에 추상적으로 반복한 문장과, 기존 과학 소프트웨어의 축적을 지우는 결말 대조를 덜었다. 마지막은 다음 결정의 허수 모드를 발견했을 때 어떤 배치를 더 계산하고 같은 절차를 다시 쓸 수 있는지로 이어진다. 그림1의 불필요한 부품 교환 반박도 빼고 보이는 적용·조정·검증을 직접 설명했다.

## 제작과 발행 상태

자체 피규어는 국·영문 데스크톱·모바일12종으로 제작했다. 그림1은 공통 함수와 새 물질의 자료·검증, 그림2는 검산한 곡률·힘·진동수, 그림5는 같은 사슬 계산으로 구체화한 일반화 워크플로다. 실제 연구의 결과를 보여 주는 원논문 그림 두 개를 그림3·4로 추가했다. 표지는 새로 생성한 개념 일러스트이며 정확한 구조·수치는 코드 그림과 원논문 결과가 담당한다. 최종 출력의 해시·쪽수·글자·화면 검수는 `artifacts/production-pdf-manifest.json`과 제작 감수에 기록한다.

이번 작업에서 이 다음 리뷰의 공개 등록·아카이브 가져오기·배포는 수행하지 않는다. 한영 원고와 제작본을 완성해 사용자가 검토할 수 있도록 보관한다. 양자 알고리즘 리뷰의 게시 작업과 상태를 분리한다.

### 원논문 결과 그림 보완 · 2026-11-27

사용자 요청에 따라 직접 검산한 교육 모형과 원 연구의 증거를 함께 읽을 수 있도록 편집했다. Deng 등의 원 Fig. 4를 그림3으로 실어 CsF의 진동 분산과 229재료의 최대 진동수 비를 설명한다. Grandel 등의 원 Fig. 4를 그림4로 실어 K₃Sb의 불안정 진동·이중 우물·이완한 최종 상을 연결한다. 기존 계산 절차 도식은 그림5로 옮겼다.

두 원그림은 CC BY 4.0과 제삼자 제외 표시의 유무를 확인하고 전체 PNG를 변경 없이 사용했다. 본문에서 패널·축·읽을 차이를 안내하고, 캡션에 원저자·참고문헌 번호·원 Figure 링크·저작권 고지·라이선스와 변경 여부를 표시한다. 내부 manifest에는 원본 URL·판본·확인일·파일 해시를 보관하며 조사 HTML과 전체 논문은 공개 제작본에 포함하지 않는다.

별도 원문 감수자가 새 한영 본문·캡션·대체 설명을 대조했다. 백분율은 과소 예측한 재료의 비율로, 원그림의 Q는 질량 가중 변위 좌표로 설명했다. L²-TSP도 에너지 우물의 깊이에는 오차가 있음을 실제 결과와 함께 읽는다. 이 보완은 웹 제작본·PDF와 작성·검증 정보에 함께 적용하며, 공개 등록·게시 작업은 아직 수행하지 않았다.

현재 개정본은 국문10쪽·영문11쪽이다. 원본 그림 두 개와 한영 웹 복사본의 파일 해시, PDF에 포함된 두 그림의 RGB 픽셀을 대조해 모두 동일함을 확인했다. 통합 담당자는 최신21쪽 전체 연락판과 원그림·표·작성 정보의 확대 출력을 검토했다. 영문 비교표는 같은 쪽에서 다섯 행을 읽도록 인쇄 여백을 조정했다. 최초 제작의 8쪽·10쪽 기록은 위의 이전 단계로 보존한다.

이번 그림 보완의 편집 모델은 대화 설정 기록으로, PDF 제작 담당의 값은 기본 설정 스냅숏으로 구별해 고정 JSON과 작성 정보에 반영했다. 이전 집필 담당별 설정을 이번 확인값으로 소급하지 않는다. 새 외부 그림 편집 기준은 저장소의 과학 설명 준칙·편집 정책·작성 방법·인용 기준과 작업 안내에 연결했다.
