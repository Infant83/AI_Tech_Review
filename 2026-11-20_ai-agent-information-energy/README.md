# AI의 정보와 에너지 리뷰 편집 구성

조사·국문 초안 2026-11-20 · 한영 출판 제1판 2026-11-22 · 편집부(AEDAUT) · 게시용 산출물 검증 완료

**AI가 답을 만드는 동안 에너지는 어디로 가는가**를 제목으로, 프롬프트에서 검증된 결과까지 정보 처리와 물리적 에너지 흐름을 함께 따라가는 교양과학 리뷰를 준비했다. 토큰이 쓰인 곳을 진단하는 과학적 관찰에서 시작해, 현재 시스템의 효율을 측정하고 환경 부담과 설계 책임을 판단하는 이야기로 전개한다.

## 독자에게 남길 질문과 인사이트

프롬프트가 길어진 결과로 바뀌는 동안 입력 이외에 어떤 지식과 증거가 이용되는지, 그 계산을 수행하는 물리적 장치가 무엇을 교환하는지 함께 본다. 정보의 유용성·목표 진행·물리적 발열을 구체적인 대상과 지표로 설명한다.

유용한 계산도 열을 방출한다. 정보를 담은 출력과 낭비열을 전기에너지의 두 분기로 그리는 대신, 같은 작업의 정보 흐름과 에너지 흐름을 두 층으로 배치했다. 단일 환경의 단순 모형에서 에너지 보존과 장치·환경의 엔트로피 수지를 소개하고, 실제 냉각과 시설 계측으로 이어간다.

기여하는 탐색과 반복 낭비를 구별하려면 실패·재시도·검증까지 기록해야 한다. 효율은 독립적으로 적합성을 확인한 결과와 전체 비용을 연결해 평가한다. 앞선 조건과 검증을 재사용하는 기록도 초기 생성·저장·검색·갱신 비용을 포함해 비교한다.

거버넌스는 목적·품질·위험·지연·작업 예산을 정하고 실제 실행과 소비를 살펴 다음 선택을 바꾸는 구조로 제안한다. 작업당 효율과 기간별 총량, 탄소와 물의 지역적 조건을 함께 보고, 어떤 용도를 우선할지 판단할 책임을 남긴다.

## 근거와 해석의 범위

출발점은 Aspuru-Guzik와 Bernales의 2026-11-17 프리프린트 v1이다. 논문의 token work/heat 분류와 물리적 일·열을 구별하고, 자유에너지 추정의 유추적 성격과 두 과제의 다른 검정 결과를 보충 설명에 남겼다. 성공한 실행의 활동과 전체 실패 비용은 각각의 분모로 표시했다.

Landauer·Sagawa·유한시간 초기화·예측의 열역학을 관련 물리 연구로 연결한다. Wolpert의 2025년 개정 공개본 v3를 읽고, 정식 출판 서지는 출판사 DOI와 Crossref 기록의 2019년 논문으로 확인했다. 실제 소비는 Yang–Armour의 가속기 계측과 Google의 서비스 계측을 각각의 경계에서 설명한다.

IEA 2026 보고서의 2025년 추정과 2030년 전망을 구별한다. SCI 현행 명세, ISO 공식 표준 정보, OECD 원칙, MLPerf Agent 작업반의 개발 목표를 근거로 사용한다. 이들 기준을 에이전트에 적용한 그림 5는 리뷰의 제안이다. EU 법규 해설은 조사했으나 이번 원고의 논지에는 포함하지 않았다.

원 논문의 비공개 하네스·실행 원문을 독립 재실행하지 않았고 ATRL 전력을 측정하지 않았다. 11월22일 원 논문·실측 논문의 판본, SCI·MLPerf 자료 상태를 재확인했다. 조사일20일과 출판 확인일22일은 구분해 기록한다. 표지와 피규어는 이번 원고용이며 기존 게시물을 변경하지 않았다.

## 수행한 감수와 출판 출력

- entropy_flow_review가 실제 원고를 읽고 물리 경계와 Landauer의 대칭 조건을 보완했다.
- sustainable_agent_governance가 실제 원고와 공식 자료를 대조해 SCI 단위·전력 조달 표현·미완료 인계 장면을 보완했다.
- 기획 설명을 별도로 받지 않은 energy_reader_review가 원고만 읽고 중심 질문을 요약했다. 선택의 엔트로피에서 물리 상태로 넘어가는 연결, q의 구체적 예제, 선택형 통계물리 설명, 내부 명칭의 갑작스러운 등장을 다듬었다.
- energy_figures가 10개 SVG를 Chrome에서 렌더하고 직접 읽었다. 총괄이 별도로 본문에 삽입한 데스크톱·모바일 화면과 그림·표지의 관계를 검토했다. 기술 검사와 실제 시각 검토의 범위는 artifacts/editorial-review.json에 기록한다.

11월22일 energy_publication_production이 영어 전문과 영어 도표 10종을 완성했다. energy_reader_review의 한영 대조 감수에 따라 에너지 비율의 분자·분모, token 단위 자유에너지, 물리적 평형·열저장고 조건과 Crooks 검정의 의미를 다듬었다. 에너지 총량과 일을 할 수 있는 상태를 잇는 한영 문단을 보완했다. 그림 2의 메모리·환경 해설과 그림 3의 비용 분포 해설을 해당 그림 앞으로 옮겨 읽는 순서와 조판을 개선했다.

한국어 9쪽·영어 10쪽 전부를 렌더해 직접 읽었고, 총괄(root)이 같은 19쪽을 별도로 읽었다. 제목·한글·수식·도표·캡션·참고문헌·페이지 번호와 큰 공백·꼬리 페이지를 확인했다. 작은 화면390px와 데스크톱1440px에서 이미지 로딩·가로 넘침·언어별 도표 선택을 검사했다. 참고문헌 13개와 보충 설명의 Crooks/Jarzynski, Unicode 기호와 폰트 범위를 대조했다. 폰트·이미지는 로컬 자산이며 외부 폰트 요청이 없다.

Chrome의 일부 SVG 공백·문장부호·fl 합자 문자층에 남은 U+0000 대응은 동일 번들 폰트의 GSUB 원본과 윤곽선으로 증명한 문자만 복구했다. 글자 윤곽선·본문 스트림을 바꾸지 않는 incremental 갱신을 사용했고, 전19쪽을 MuPDF와 Poppler로 전후 렌더해 픽셀 차이0을 확인했다. 최종 PDF는 대체문자·null 문자·첨부파일·내부 파일 URI가 각각0이다. 생성·보정·검증 범위와 SHA256은 위 manifest와 검증 JSON에 남겼다.

사람은 주제·관점·기획을 제시하고 게시를 승인했다. 별도의 문장 단위 사람 감수는 기록되지 않았다. 정확한 저술 모델 식별자는 보존되지 않아 추정하지 않는다. 작성 방법서 기본판2026.08, 적용한 보완 지침의 날짜, 이번 원고 판본2026-11-22는 공개 작성정보에서 구별한다.

정식 출력의 자산은 언어별 HTML·CSS·PDF·표지·도표로 한정한 28개 파일이다. 초기 `dist/assets/`의 중복 미리보기 11개는 `preview/assets/`로 옮겨 보존했다. `tmp/`와 `preview/`, 원문 수집 자료와 QA 화면은 공개 배포 대상에서 제외한다. 등록·아카이브·독립 후보·CI·실제 HTTPS 배포 검증은 총괄(root)이 이어서 기록한다. 기존 글과 다른 작업의 진행 파일은 보존했다.

## 재생성

폰트 subset은 [build_fonts.py](artifacts/build_fonts.py)에 정식 라이선스를 가진 전체 글꼴 네 파일을 인자로 전달해 만든다. 원본 글꼴의 개인 저장 경로는 스크립트와 공개 출력에 넣지 않는다. 완성된 subset과 OFL 라이선스는 `artifacts/`에 보존한다.

```sh
python3 artifacts/localize_figures.py
uv run --with markdown python artifacts/build_review.py
REVIEW_NODE_MODULES="$PLAYWRIGHT_MODULES" node artifacts/render_publication.mjs
```

위 명령은 이 주제 폴더에서 실행한다. `PLAYWRIGHT_MODULES`는 설치된 Playwright 의존성 디렉터리다. 출력 코드는 Chrome에서 양쪽 PDF를 인쇄한 후 `fix_pdf_text.py`를 자동 실행한다. Python에는 PyMuPDF와 FontTools가 필요하다. 출력 재생성은 판본의 PDF 해시를 바꾸므로 생성 뒤 시각·기술 검증과 최종 manifest를 함께 갱신한다. `build_preview.py`는 초기 시안 검토에만 사용한다.

총괄은 최종 후보 검사에서 현재 언어 표시 누락을 확인해 양쪽 HTML 상단에 `lang`·`aria-current="page"`를 갖는 현재 언어 표지를 보완했다. 헤더는 인쇄에서 숨겨지며 검수된 PDF·본문·그림·CSS는 그대로 유지했다. 출판 manifest는 변경된 두 HTML 해시를 반영한다.

영문 작성정보의 두 항목명 안에 있던 줄바꿈 마크업은 게시기의 항목 인식에 공백을 만들었다. 이 마크업을 제거해 방법서 기본판·적용 보완·운영 근거·이번 원고 판본 네 항목이 한영 공개본에 모두 보존되도록 했다. 항목의 문구와 검수된 PDF는 바뀌지 않았다.
