## 본문과 근거

도구가 수행 범위를 넓힌 역사, 도구 활용 숙련의 인정, 성취를 비교하는 평가, 올림픽의 사례, AI 시대의 새 기준을 순서대로 연결한다. 올림픽에서 기술사 전체를 증명하거나 독자가 그 역사를 저절로 연상한다고 전제하지 않는다. 고대의 도구 종목과 장비 규정은 참고 설명으로 보존하고 비유와 교육 효과의 실증 근거를 구별한다.

고객지원과 제품 제안의 기회 확대, 과업에 따른 도움의 차이, 연습 성과와 독립 학습의 차이를 원 연구에 연결했다. 현재 수행·학습·전이·자격을 구별하고, 검증되지 않은 평가안을 보편 척도로 제시하지 않는다. 수능 규정과 수업 연계 수행평가 지침도 목적이 다른 제도 자료로 구분했다.

19개 인용 문헌 그룹은 일부 항목에 여러 공식 자료를 묶는다. 저널 논문, 프리프린트, 메타분석, 역사 해설, 규정과 정책 지침의 역할을 밝혔다. 원 실험이나 개인별 통계 분석을 독립 재현하지 않았다. Shen·Tamkin 연구의 백분율·평균차 표기는 원자료로 확정하지 못해 해당 정량값을 본문에서 생략했다.

수학 사례는 기존 페르마의 마지막 정리 증명의 형식화로 좁혔다. Quanta의 공개 연재 원문, Anthropic 공식 발표·고정 코드, Kevin Buzzard의 직접 재검사 보고와 Lean 공식 검증 문서를 대조했다. AI의 생성·형식화와 검사기의 역할을 나누고, 검사 통과가 원래 질문의 정확한 표현·개인 학습·현실 모형의 적합성을 모두 보증하지 않음을 설명했다. 해당 구분을 평가표·작은 수학 수업 과제·재사용 가능한 공동 지식·결론까지 연결했다. 대규모 형식 증명을 독립 재실행한 것은 아니다.

## 제작과 재생성

표지는 기존 수영·카누 이미지를 built-in ImageGen으로 편집했다. 카누 이용자가 활용하는 스마트 안경·디지털 선택지 지도와, 주변부에서 여러 형태로 열리는 틀을 더했다. 중심은 ‘변화한 역량과 환경에 걸맞은 평가’다. 최종 자산은 [artifacts/hero-v3.webp](artifacts/hero-v3.webp)와 활성 사본 [artifacts/hero.webp](artifacts/hero.webp), 실제 편집 프롬프트는 [artifacts/hero-v3-prompt.txt](artifacts/hero-v3-prompt.txt)에 있다. 입력·3개 발상 비교·오독 범위·독립 검토는 [표지 브리프](cover-art-brief.md)에 기록했다. 제작용 원본 PNG·이전 버전은 배포 자산에 포함하지 않는다.

`artifacts/build_figures.py`는 Matplotlib으로 Table 1의 네 계수와 ±1 SE를 재도식화하고, 별도의 교육 제안 SVG를 작성한다. `--font-regular`와 `--font-bold`로 공개 라이선스 Noto Sans KR 원본 글꼴을 지정한다. 계수·분모·표준오차는 `artifacts/study-figure-data.json`에 보존했다.

`artifacts/build_fonts.py --regular FONT_REGULAR --bold FONT_BOLD`는 최종 원고·UI·SVG의 글꼴 subset을 만든다. SIL OFL 전문과 원본 크레딧을 보존하고 파생 글꼴을 별도 이름으로 지정한다. Matplotlib, NumPy, Pillow, fontTools, Brotli가 필요하다.

`REVIEW_NODE_MODULES`를 `marked`와 `playwright`가 있는 패키지 디렉터리로 지정한 뒤 Node로 `artifacts/build_review.mjs --publish`를 실행하면 공개판을 만든다. 기본 실행은 검토용 `noindex,nofollow` 표시를 유지한다. `artifacts/build_pdf.py --node NODE --modules MODULES`는 Chrome을 통해 한영 PDF와 PC·390px 모바일 QA 화면을 만든다. `artifacts/verify_review.py --public`은 실제 자산·참고문헌 anchor·PDF 링크/첨부·메타데이터와 경로를 검사한다. 검수에는 pypdf, Pillow와 PDF 전 페이지 렌더링용 PyMuPDF를 사용했다.

## 검토 결과와 배포 상태

v5의 한국어 9쪽·영어 13쪽 최종 22쪽을 모두 렌더링해 확인했다. 새 표지·한영 캡션·대체 텍스트·중심 문장이 반영됐고, root의 한국어 실제 출력 검토와 assessment_research의 영어 전 페이지·모바일 별도 검토를 마쳤다. 공개판에서 최초 인용순과 정식 서지를 정리했다. 연구 결과·수치·한계와 표지 v3는 유지했다. 최종 배포 허용목록은 14파일이며 표지의 EXIF·XMP, 공개 자산의 내부 경로가 없다.

한국어 9쪽·영어 13쪽의 최종 22쪽을 렌더링했다. 제목·본문·도식·표·참고문헌·작성 공개를 시각 검토하고, 페이지 밖 텍스트·대체문자·내부 파일 경로·PDF 첨부·file URI가 없음을 확인했다. 두 언어의 제목·Open Graph·언어·의도한 canonical이 일치하며, 390px 모바일 가로 넘침·깨진 이미지·페이지 실행 오류는 0이다. 원고·도식·표지의 PC/모바일과 표지의 320×180·흑백을 확인했다. 인용 anchor와 언어 전환도 로컬 HTTP에서 확인했다.

`augmentation_evidence`가 실제 한영 도식의 수치·오차막대와 v2 표지·썸네일·흑백, v4 수학 형식화의 공식 코드·검증 범위를 독립 대조했고, `conceptual_review`가 실제 원고를 읽고 중심 논지·비유와 수학 사례의 연결을 검토했다. `assessment_research`가 영어판과 개정 도입을 작성하고 수치·한계·출처 순서를 대조했다. v4에서 영어 최종 13쪽의 전 페이지와 새 절·표·결론·참고문헌·작성 공개의 개별 페이지 및 모바일 화면을 별도 시각 검토했고 필수 수정은 없었다. 한국어 최종 9쪽은 통합·개별 렌더에서 본문·표·출처·공개를 확인했다. 정확한 모델 식별자는 미보존이다. 주제·비유·문체에 관한 사람의 편집 방향을 실제 문장과 표지에 반영했지만 전체 문장의 사람 감수·독자 이해도 평가는 수행하지 않았다.

책임 편집자의 게시 승인에 따라 공개판을 준비했다. 검토본 표시를 제거하고 최초 발행일은 2026-11-15로 정했으며, 근거 기준일 2026-11-12와 실제 사람·에이전트 검토 범위는 보존했다. 글별 등록·아카이브·실제 HTTPS 배포 검증은 후속 발행 기록에 남긴다.

`dist/`에는 언어별 HTML·CSS·표지·최종 SVG·PDF만 허용한다. 원문 수집 자료·조사 메모·QA PNG·가상환경은 `notes/`와 `tmp/`에 분리하고 Git 및 배포 허용목록에서 제외한다. 검사 결과와 해시는 해당 내부 QA 기록에 있다.

## 공개판 준비 · 2026-11-15

책임 편집자의 게시 승인에 따라 검토본 표시를 제거하고 최초 발행일을 2026-11-15로 정했다. 근거 기준일은 2026-11-12다. 공개판의 19개 문헌 그룹을 최초 인용순으로 정리하고 원저자·원제·DOI·출판 판본을 재확인했다. 미인용 배경자료 두 항목과 개별 서지의 검증 메모를 목록에서 제외했다. Barba·Stegner의 정식 출판 정보를 반영하되, 설계 설명은 실제 읽은 공개 v1에 근거함을 작성 공개에 밝혔다. 공개판 한영 PDF 22쪽과 모바일을 다시 검토했다.

게시 후보 검증: 실제 이전 HTTPS 릴리스와 대조한 연속성 검사가 통과했다. 리뷰 58개·공개 PDF 141개이며 이번 리뷰와 한영 PDF 두 항목만 새로 추가했다. 기존 과학 본문·PDF·ID·주소는 보존된다. Python 검사 404개(1개 skip)와 검색·탐색 검사 12개, 초기 전송량 기준을 통과했고 한영 허브·검색·본문과 모바일을 브라우저에서 확인했다. 로컬 API 요청의 CORS 제한은 실제 공개 origin에서 별도 확인한다. 실제 배포·복구 아티팩트와 HTTPS 해시는 후속 발행 기록에 남긴다.
