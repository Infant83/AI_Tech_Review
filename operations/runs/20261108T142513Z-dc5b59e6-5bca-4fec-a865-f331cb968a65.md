# ADOPT 운영팀과 AEDAUT 편집부의 약칭과 호칭 정리

## 이름과 의미

사용자의 최신 설명에 따라 운영팀의 약칭은 ADOPT(애돕트), 편집부는 AEDAUT(에이돗)으로 정리한다. 정식명은 에이전틱 개발운영팀(Agentic DevOps Team)과 에이전틱 편집·저술팀(Agentic Editorial and Authoring Team)이다. ADOPT는 A(gentic) + D(ev) + OP(s) + T(eam), AEDAUT은 A + EDitorial + AUthoring + T의 조합형 약칭이다. 에도잇트도 편집부의 대안 호칭으로 인식한다.

adopt에서 떠올리는 받아들임은 유용한 기술·피드백을 검토해 운영에 적용하는 역할로, edit의 연상은 저술과 편집으로 내용을 다듬는 역할로 설명한다. 호칭과 의미 부여를 사전 발음·어원으로 기록하지 않는다. ADT는 운영팀의 이전 약칭으로 연결하고 과거 실행·관찰·증거는 보존한다.

## 적용 범위

현재 지침·조직도·팀 기준·브랜드 기획·운영 템플릿과 열린 일감의 담당 명칭을 갱신했다. 사람의 관리·기획·프롬프팅·Human Audit과 두 팀의 역할 및 조직도의 연결은 유지했다. 기존 제호 정리와 손상 PDF 복구는 계속 계획 상태다.

기존 운영·편집 예약은 같은 식별자를 사용하고 이름과 조직명 안내만 갱신했다. 주기·상태·연결된 대화·권한·작업 경로·알림 선호를 유지했고 추가 예약을 만들지 않았다. 실제 설정을 다시 읽어 반영과 보존을 확인했다.

## 검증

영문명·조합형 약칭·호칭의 독립 검토, 기본 호칭에 맞춘 국문 조사 교정과 문서 링크·JSON 형식·현재 담당·과거 기록 보존을 확인했다. 웹 생성 코드·공개 글·PDF는 수정하지 않으며 이름 정리를 기술 결함의 구현·복구 완료로 기록하지 않는다. 이후 보고·인계에는 운영팀(ADOPT)과 편집부(AEDAUT)를 사용한다.
