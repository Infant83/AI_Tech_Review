# ADOPT · ATRL 공개 도메인과 현재 제호의 연결 교정

운영팀(ADOPT)이 사용자의 점검 후 교정·재배포 요청에 따라 현재 공개 주소와 표시를 정리했다. 편집부(AEDAUT)의 기존 제호·과학본문·발행 이력 보존 기준을 적용했다. 기존 [제호 일감](../issues/OPS-79b80bf3-b847-485a-9f60-3cd663e5b433.json)의 후속 기술 교정이며 콘텐츠 기획·집필·새 예약은 포함하지 않는다.

## 변경과 보존

- 기본 공개 URL과 canonical·hreflang·OG·내비게이션을 `https://infant83.io/AI_Tech_Review/`로 통일했다. 이전 호스트는 검증용 alias로 계속 인식하고 기존 경로는 유지한다.
- HTML의 과학 article·lecture document·코드·인용과 기존 PDF는 보존한다. 역사적 제호·서지·하네스명·아이콘·앱 ID·scope·구독 식별자는 바꾸지 않는다.
- 정규화 뒤 파생 lecture HTML 체크섬을 검색 검증 전에 갱신한다. 기존 dist의 hub 링크도 alias로 인식해 버튼 중복을 막는다.
- 실제 이전 배포 `4e80668d08e5374246d98010f3d37c9c8d87c3c2`와 동일한 원래 소스 대조 후보를 만들었다. 보호 과학 영역 1,066블록 변경0을 확인했다. 최종 후보의 기존 PDF321경로·ID/경로/발행일은 유지한다.
- 표시가 바뀐104개 글은 정확한 새 전체 자산 해시에 기존 논리개정·읽음·갱신일을 상속한다. 전체192개 recency record가 이전 배포와 같다. 페이지·배포 해시는 실제 새 바이트를 계속 사용한다.

## 검증과 배포 상태

- Python 전체665개 통과(1개 기존 skip), 브랜드 보호4개·내비게이션/출처7개·recency12개 및 검색/렉처 Node 검사가 통과했다. Pages CI에서 최종 소스를 다시 검사한다.
- backend73개 통과. Worker는 실제 활성 source `1f2227cd3bab2d947d86878c9e4bf58a10e9f2a3`와 비교해 테스트 알림 제목 한 문자열만 `ATRL 알림 테스트`로 교정했다.
- 기존 인증·keep-vars·strict 배포로 Worker `5d03d9df-1f1d-44d9-9e88-88465d4135b0`100%를 확인했다. 전후7개 binding·runtime·fetch/queue/scheduled·named handlers가 같고 코드 etag만 바뀌었다. 공개 config와 익명 study/me는 정상이다.
- 테스트 푸시·이전 알림 재발송·DB migration·키/권한/과금 변경은 수행하지 않았다. 기기 수신 검증을 주장하지 않는다.
- Pages는 최종 후보의 정확한 변경 선언·연속성·payload 검증 뒤 기존 main workflow로 배포한다. 실제 완료 run과 HTTPS 확인은 후속 결과에 연결한다.
