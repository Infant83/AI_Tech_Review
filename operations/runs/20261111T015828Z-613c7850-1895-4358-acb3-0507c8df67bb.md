## 선정과 변경

후보 생성기에서 실제 내용 변화가 없고 기존 선언의 `after` 해시가 현재 검수 출력과 일치할 때에만 선언 쓰기를 생략한다. 사유·이전/이후 해시·파일 전체와 선언 원본 bytes를 보존한다. 선언 없음·낡은 결속은 기존 출력 결속 생성 경로를 유지하고, 실제 개정은 정확한 baseline `before`와 후보 `after`를 계속 기록한다. 파일 존재만으로 검사를 생략하지 않는다.

개발 담당은 소스·회귀 검사만 수정했고, 통합 담당은 관련 검증과 최신 원격 확인 후 Git main에 반영했다. 출판 요청 형식·잠금·배포 경로·과학 원고·기존 선언·공개 파일은 바꾸지 않았다. 최신 독자 친화적 편집 기준은 편집부(AEDAUT)의 기존 지침 개정을 재사용하며 운영팀이 글을 새로 쓰거나 콘텐츠 예약을 인수하지 않았다.
