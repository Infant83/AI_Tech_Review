# ADOPT 자산 기록

[보안파트 프로시커(Proseeker)](../../SECURITY_OPERATIONS.md)가 운영팀(ADOPT)의 공개·비공개 자산 경계를 확인하는 최소 기록이다. 새 서비스·도메인·임시 앱·저장소·실행 경로를 추가하거나 정리할 때 연결한다. 기존 게시물마다 자산 파일을 만들지 않는다.

자산 하나에 `ASSET-<UUID>.json` 하나를 사용한다. 날짜·공용 일련번호 대신 UUID를 새로 만들고 `asset_key`와 실제 목적을 대조해 중복을 피한다. 담당·목적·공개 범위·원본 설정 참조·검증 시각·확인/미확인 사항·퇴역/복구 조건을 남긴다. 같은 자산의 동시 수정은 최신 Git 변경과 버전을 대조해 통합한다. 이 기록은 분산 잠금이나 자동 자산 탐지 시스템이 아니다.

`active`는 실제 서비스 또는 기존 실행 근거를 확인한 자산, `configured`는 설정·실행 기반을 확인했으나 공급자 설정 전체를 감사하지 않은 자산, `prepared`는 준비·예시 단계다. 상태와 개별 미확인 항목을 함께 읽는다. 자산 목록이 있다고 운영 DB·권한·복구의 전수 검증이 끝난 것은 아니다.

공급자 계정·DB·버킷의 실제 식별자, 비밀정보, 개인 계정 주소, 내부 호스트명·절대경로·비공개 링크는 기록하지 않는다. 필요한 공급자 설정은 권한 있는 비공개 경로에서 확인하고 공개 가능한 결론만 연결한다. 담당은 역할로 기록하고 실제 계정의 소유권과 위임 여부는 별도 확인한다. 서비스 종료 때 관련 도메인·연결·데이터·복구 사본·비밀정보의 정리 결과를 갱신한다.
