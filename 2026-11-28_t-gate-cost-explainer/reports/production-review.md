## 출력과 편집 범위

「양자컴퓨터는 왜 T 게이트를 아끼려 할까」를 A4 3쪽으로 조판했다. 부제는 「45도의 위상 변화에서 양자화학의 계산 비용까지」다. 보존한 `review_ko.md`는 검토한 원고와 바이트가 같다. 과학 본문·수치·예제·원전 5항목을 유지하고 소제목, 번호 인용, 그림·캡션, 관련 학습 링크와 짧은 작성 정보를 추가했다. 참고문헌은 본문에서 인용된 순서의 번호를 갖고, PDF 내부 이동과 각 원전의 외부 URL을 연결한다.

첫 4쪽 proof에서 참고문헌이 마지막 두 쪽에 나뉘고 짧은 마지막 쪽이 생겼다. 그림과 인접 문단의 배치, 참고문헌의 들여쓰기, 문단 간격을 조정하고 본문 10pt·줄간격 1.68로 정리했다. 최종 3쪽은 첫 쪽의 위상·간섭과 Clifford+T, 두 번째 쪽의 간섭 그림·오류정정·화학 회전, 세 번째 쪽의 ELOTE와 참고문헌·관련 글·작성 정보를 연결한다. 참고문헌은 8pt, 작성 정보는 7.4pt다. 그림은 두 번째 쪽의 본문 폭으로 배치했고 원본 PNG의 RGB 픽셀을 보존했다.

## 수식·자산·공개 확인

T 적용의 정규화된 상태와 45도 위상 인자, H-T-H 회로의 확률, T₉₅의 아래첨자와 본문의 단위가 PDF에서 판독된다. 교육 예제의 0·45·90·180·270·360도 여섯 경우를 복소수 진폭 계산과 해석식으로 대조했고 저장한 그림 데이터와 10⁻¹² 이내로 같다. 원 연구의 ELOTE 벤치마크를 재실행하지 않았으며, 보고된 성과는 원저자의 고전 검증·논리 자원 추정으로 구분한다.

한국어 정규·굵은 글꼴과 기호·수학 보조 글꼴의 전체 필요한 글자 범위를 확인해 부분집합을 만들었다. 폰트의 원본 파일명·해시와 적용 범위를 기록하고 해당 OFL 원문을 보존했다. 제작 코드는 외부 입력으로 라이선스가 확인된 폰트를 받으며 특정 내부 경로를 저장하지 않는다. 본문·PDF에 개인 경로·file URI, 첨부 파일, JavaScript 객체, NUL·대체 문자는 각각 0개다. 화면용 HTML도 1440px·390px에서 문서 가로 넘침 없이 수식·그림·인용 5개를 표시했다.

## 역할·모델과 후속 게시

기존 저술 담당과 원문 대조·과학 감수 담당의 공개 설정 기록을 각각 보존했다. 이번 PDF 조판·검수 담당의 실제 대화 설정은 시작·종료 시각 범위의 별도 기록으로 수집했다. 세 역할 모두 모델 `gpt-6.1-sol`, 추론 강도 `ultra`, 근거 유형 `turn_context`로 확인되며 역할별 JSON을 PDF의 작성 정보와 대조했다. 대화 식별자·원문·설정 전체는 공개 자료에 포함하지 않는다.

이 기록은 PDF 제작 검수다. 새 문서 등록·리뷰허브 배포·실제 HTTPS 확인과 메일 발송은 통합 담당자가 별도로 수행하고 기록한다. 제작 결과만으로 게시나 메일 전달을 완료했다고 표시하지 않는다.
