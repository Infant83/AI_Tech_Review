# T 게이트 해설의 독립 과학 감수 · 2026-11-28

편집부(AEDAUT) · 원문 대조와 독립 과학 감수. 운영팀(ADOPT)의 게시·아카이브 등록·실제 HTTPS 검증은 이 감수의 범위와 구별한다.

## 현재 판정과 확인한 원본

**확정 원고와 동결 3쪽 PDF의 과학 설명·인용·그림 대조 통과. 이 판본에서 과학 감수의 차단 사항은 없다.**

공유용 최종 원고 「양자컴퓨터는 왜 T 게이트를 아끼려 할까」를 대상으로 했다. 감수한 입력 SHA-256은 `584efcc3c99ffc57adf69dcc9bc5d322bac9f514a658cac3a1763edc93f1bb34`다. 통합 담당자는 이 원고를 이번 PDF의 출판 원본으로 확정했다. 실제 채팅 응답 전문의 바이트 대조는 수행하지 않았고 이 감수의 완료 조건으로 삼지 않는다.

## 설명과 수치

- T의 동작을 0 성분은 유지하고 1 성분에 45도의 위상을 주는 연산으로 설명한다. 같은 크기의 중첩에 T만 적용한 직후 0/1 확률은 각각 50%이며, 뒤따르는 H에서 상대위상이 간섭 결과로 나타난다.
- H–T–H의 상태벡터를 독립식으로 계산해 P(0)=0.8535533905932735, P(1)=0.14644660940672616을 확인했다. 그림의 여섯 위상 표본도 P(0)=[1+cosφ]/2와 10⁻¹² 이내로 같다. 기하학적 화살표를 복소수평면의 위상 차이로 설명하며 실제 장치 측정으로 표시하지 않는다.
- Clifford 회로의 효율적인 고전 모사는 0으로 준비한 큐비트, Clifford 게이트와 0/1 측정이라는 범위를 둔다. T가 Clifford 집합 바깥에 있다는 설명과 Clifford+T의 근사적 범용성을 구분한다. T를 여덟 번 적용하면 I가 되는 설명도 정확하다.
- 논리 큐비트에서 T를 구현하기 위한 마법 상태의 준비·증류·소모를 설명한다. 이 공급 부담과 실제 시간·병렬성·목표 논리 오류율을 연결하고, 논리 T 개수 하나를 전체 실행시간으로 등치하지 않는다.
- QPE는 보조 큐비트의 1 성분에만 시간진화를 제어 적용해 에너지 정보를 상대위상으로 옮긴다고 설명한다. 고유상태의 전체위상을 직접 측정하는 듯했던 앞선 원고의 오독 위험이 해소됐다.

## ELOTE 결과의 범위

[원논문 arXiv:2611.33509v1](https://arxiv.org/html/2611.33509v1)의 초록·방법·결과·부록과 [공식 HSOpt의 보존 결과·정책](https://github.com/bestquark/hsopt/tree/main/results/elote)을 앞선 원문 대조에서 확인했으며, 이번에는 그 확인 범위 안에서 최종 문장을 재대조했다.

최종 원고는 정확한 바닥상태 입력을 고정한 고전 검증을 먼저 밝힌다. T₉₅는 정확도 기준을 만족하는 에너지 추정값을 한 번 이상 얻을 확률 95%를 위한 QPE 호출·반복을 포함한 논리 T 비용이다. 초기 상태 준비와 오류정정 장치 전체의 비용을 별도 평가 대상으로 둔다. 4–16큐비트의 115개 훈련 해밀토니안에서 보정한 2차 곱공식·균일 정밀도 기준 대비 감소율 중앙값 85.35%, 약1kcal/mol≈1.6mHa의 정확도 조건을 기록한다. 18–22큐비트 76개 모형의 정확도 통과는 평가 사례의 결과로 설명한다. 같은 항 합산·곱공식 변경·회전별 정밀도 조정을 함께 다뤄 절약을 단일 변경의 효과로 분리하지 않는다. 원 연구의 에이전트 탐색·CUDA-Q 합성·GPU 검증을 독립 재실행한 것은 아니다.

## 서지와 독자 흐름

원고의 참고문헌은 1–5의 다섯 항목이다. T의 정의, 안정자 회로, 마법 상태, Clifford+T 회전 합성, ELOTE가 각각 본문의 관련 설명과 연결된다. Ross–Selinger의 정식 출판 항목을 사용한다. 상대위상→간섭→비Clifford와 범용성→마법 상태 공급→양자화학 회전 합성→ELOTE라는 흐름에서 대상과 비용의 연결이 유지된다. 이번 퇴고는 필요한 과학적 조건을 주장과 함께 설명하고, 문단 말미에 반복적인 일반 경고를 덧붙이지 않는다.

## PDF 이후 대조

통합·제작 담당자가 동결한 `dist/t-gate-explainer-ko.pdf`를 마지막으로 대조했다. **3쪽·196,082bytes**, SHA-256은 `1f015dbf63121fea3852356b1df6d88d869ad265e5edae904566d2baa64d8552`이며 전달받은 동결값과 같다. 원고 사본은 위 입력과 바이트가 같다.

PDF 제목과 메타데이터 제목이 「양자컴퓨터는 왜 T 게이트를 아끼려 할까」로 일치한다. QPE의 제어 시간진화·상대위상, T₉₅의 한 번 이상 성공 확률 95%, 고정한 바닥상태와 고전 검증, 115개 훈련 해밀토니안·76개 평가 모형, 85.35% 중앙값과 약1kcal/mol≈1.6mHa 조건을 추출 텍스트에서 대조했다. 문자의 범위 표시는 출력에서 ASCII 하이픈으로 정규화됐으며 수치 의미는 같다. 참고문헌 절의 순서는 정확히 [1]–[5]다.

그림 한 개는 2쪽에 있으며 2015×1080 RGB 픽셀이 원본 PNG와 전부 같다. 원 PNG SHA는 `069f7adbfdff1f45b767860bd1f5b3d664098447d6e5d34d2d39f9f54c703d1d`다. PDF의 링크 주석은 19개(외부 URI 주석 14개·문서 내부 인용 연결 5개), 고유 외부 목적지는 공식 원자료 5개와 기존 리뷰 2개의 HTTPS 주소 일곱 개다. 내부 이름 기반 인용 연결 다섯 개는 모두 참고문헌이 있는 3쪽의 유효한 좌표로 해석된다. 파일 URI·개인 절대경로·NUL·대체 문자와 민감한 메타데이터 경로를 발견하지 않았다. 이 검사는 URI와 목적지를 대조했으며 모든 원격 페이지를 새로 요청하는 검사는 아니다.

제작한 proof-v2의 전 페이지 연락판과 3쪽 확대 화면을 읽었다. 제목·수식·그림·문단·참고문헌·작성 정보가 3쪽 안에 배치되며 이전 4쪽 proof의 큰 마지막 여백이 해소됐다. 별도 원 연구 실험의 재현이나 독자 이해도 실험, 실제 웹 공개·메일 전달을 확인했다고 표시하지 않는다. 게시와 공유 결과는 통합 담당자의 후속 기록을 따른다.
