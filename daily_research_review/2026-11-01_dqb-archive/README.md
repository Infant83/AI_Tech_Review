## 공개 범위와 정정

기존에 승인된 DQB 공개 보관 흐름에서 이번 호의 과학 브리핑을 보관한다. 수집 경위, 개인 메일에서 유래한 보조 정보, 소셜 신호와 내부 검수 메모는 실제 PDF 텍스트에서 삭제했다. 원본은 비공개 보존하며 공개 저장소에는 넣지 않는다. 이번 파일은 원 논문 PDF·도판·연구 코드를 복제하거나 재배포하지 않는다. 공개 과학 본문에 인용되지 않은 수집용 문헌은 참고문헌에 추가하지 않았다.

본문의 손상된 상관 기호 `⟨ZᵢZⱼ⟩`를 복원했다. 원문 대조로 다음 조건을 정정·보완했고 6쪽에 수정 기록을 남겼다.

- **AI 연구 평가 [1]**: 88%는 전체 228편 중 200편에 대한 AI referee의 지적률이다. 실제 사용뿐 아니라 제안된 LLM 역할을 포함하는 검색 표본이다. 같은 분야 AI 130편과 대조 50편을 구분했다. 모델 나이 96일의 분모는 228편 중 해당 간격을 산출한 189편이며, 각 논문이 실행한 최신 범용 모델의 출시일부터 첫 arXiv 제출일까지의 간격이다.
- **SP-HQAOA [2]**: N=500·1000의 0.956±0.003·0.870±0.003은 최종 전역 local search 전 결과이며 10 instances의 평균±SEM이다. N=40의 고전 정련 후 수치, 별도 N=16 finite-sampling 모사, 큰 문제의 statevector 평가를 구별했다. 큰 문제 실험에서는 유한 repair-risk budget을 적용하지 않았다. 일반 solver의 20-restart 분기를 이 실험의 실행 경로처럼 설명한 문구를 제거했다.
- **FermiScope [3]**: 69.0%는 QH9-stable 4,000분자의 오류 방향 개수 비율의 중앙값이며 오류 norm 비율이 아니다. density-blind 조건과 per-spin 누적 LDOS를 구분했다. SCF 평가가 전혀 없다는 표현을 바로잡았다. Appendix G.5, Table 12의 50 stable-id에서 minao 대비 반복 수 비 0.6713, 추론 포함 시간 비 0.8505가 보고되며 기존 pretrained 모형의 0.6732·0.8619와 비슷하다. 이 수치를 실제 OLED screening의 가속으로 확대하지 않았다. gap 오차 감소의 비교 기준은 pretrained 모형이다.
- **원자 준비 [4]**: 58.2(2)%는 최종 단일 원자 filling이다. 제거 펄스 구간과 냉각·준비를 포함한 전체 시간은 구별했다.
- **GKP [5]**: 이상적 QEC에서 약 두 orders의 decoder 개선과 근사 teleportation QEC에서 약 한 order를 구별했다. 원 본문의 GKP 약칭 설명 제목은 유지하고 APS 서지는 정식 Gottesman-Kitaev-Preskill 원제를 사용했다.
- **광격자 재배열 [6]**: N=L² 모드와 최대 L−1 보조열을 쓰는 HVH의 O(√N)은 회로 깊이다. 총 gate 수·전체 비용이나 실제 장치의 성능과 구분했다.

참고문헌은 본문의 최초 인용순 [1]–[6]으로 수록했다. 원어 제목, 저자 순서, 정식 출판 정보 또는 확인한 arXiv 판본을 유지하고 DOI·해당 판본으로 연결했다. 해설은 참고문헌 문자열에 덧붙이지 않고 별도의 편집 기록으로 구분했다.

## 재빌드와 검사

`artifacts/build_public_archive.py`에 원본 PDF, 일반·굵은·서지용 폰트, 비공개 QA 디렉터리를 각각 인자로 전달한다. 이 다섯 인자는 호출자가 제공하며 원본·폰트·QA는 저장소에 복사하지 않는다. 원본 해시와 5쪽 조건이 일치하지 않으면 중단한다.

필요 라이브러리는 PyMuPDF, Pillow, ReportLab이다. 별도 추출 검사는 pypdf를 사용했다. 빌더는 다음을 확인한다.

- 삭제·정정 영역 밖 원 5쪽이 144dpi에서 픽셀 단위로 동일한지 확인한다. 허용 영역은 QA의 페이지별 좌표로 남긴다.
- 지정한 과학 문장이 정확히 한 번 발견되는지, 글리프와 줄폭이 유지되는지 확인한다.
- 부록 줄 넘침, 6쪽 구성, 정확한 6개 서지 URI의 최초 순서를 확인한다.
- 본문·PDF object의 개인 주소·내부 경로·수집 정보·손상 기호와 XML·첨부·폼·실행 동작을 검사한다. 최종 링크 동작은 공개 HTTPS URI뿐이다.
- 재빌드 시 등록용 `public_reviewed`와 검수 상태를 먼저 미완료로 바꾸며, 원본에 선언되지 않은 변화나 검사 실패가 있으면 중단한다. 새 렌더를 직접 확인한 뒤 독립 검수를 거쳐야 공개 검수를 완료할 수 있다.

최종 파일은 제작 담당의 6쪽 시각 검사와 PyMuPDF 구조 검사, pypdf 6.10.0 strict 경고 0 검사를 통과했다. 이 폴더의 제작 완료와 아카이브 등록·실제 공개 배포 완료는 별도 단계다. 등록·배포 및 공개 URL 검증은 호출자의 작업 흐름에서 수행한다.
