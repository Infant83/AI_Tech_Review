# DQE · 분자 예측의 정확도와 커널 측정 비용

원호·공개판 편집·웹 갱신·근거 기준일은 2026-11-24다. 편집부(AEDAUT)가 사용자 승인 범위의 짧은 한영 안내와 독립 과학 감수를 맡고, 운영팀(ADOPT)이 기존 등록·후보·배포 도구를 지원한다. 같은 날짜 DQB·DRB, 기존 DQE와 요청형 NTCA 호의 ID·날짜·주소·본문·PDF, 기존 문제 생성·메일 발송 예약을 보존한다.

## 문제와 독립 감수

OLED 수송재의 DFT 정공 재배열 에너지를 예측하는 가상 KRR 문제다. 커널 유사도가 예측에 주는 영향, PSD의 전역 조건, 측정 쌍·shots·전체 시간과 검증 라벨 비용을 함께 판단한다. 문제 PDF는 1쪽, 해설은 2쪽부터 안내하고 수치 정답·풀이·판정은 웹에서 기본 접힌 영역에 둔다. 한영 목록 제목·요약도 본문과 별도로 감수했다.

`root`가 집필·통합하고 `dqe_science_1118`이 원 PDF 4쪽·계산·원출처·한영 안내를 독립 감수했다. 두 점의 중심화 라벨 KRR, 별도 감사 행렬의 행렬식·고유값, ridge와 PSD 보정의 차이, 측정 수·시간·처리율·정수 shots 문턱을 재계산했다. 훈련 행렬과 예측 벡터의 일관성은 명시적인 순수 상태 구성으로도 확인했다. PSD만으로 임의의 행렬이 fidelity 커널이 된다고 주장하지 않는다. [검산 코드](artifacts/science/verify_exercise.py)·[계산 결과](artifacts/science/calculations.json)·[과학·출처·한영 감사](artifacts/science/scientific-reference-audit.json)에 실제 범위를 기록한다.

Gómez-Bombarelli 등의 Princeton 공개 저자본 1–2·5쪽에서 산업 참여 연구 흐름과 실험 검증을 읽었다. scikit-learn 1.9.1의 KRR·규제·사전 계산 훈련/예측 행렬 형식, IBM 연구 소개와 Havlíček 등의 arXiv v2 1·5·18·22쪽을 직접 대조했다. Nature 직접 열람은 접근 확인 경로로 제한되었고 서지는 출판사 등록 Crossref 기록과 대조했다. 첫 논문은 저자 21명으로 첫 저자와 et al., 양자 커널 논문은 저자 7명 전원을 표기한다. 논문·보충자료 전체 감사나 원 실험·수치 재현, 실제 분자·DFT·QPU 실행은 수행하지 않았다. 실제 읽은 기존 QuanONet 리뷰 절과 QML 08 강의의 PSD·표본 비용·시험 누출 설명을 연결한다. 사람의 문장별 검토나 독자 평가는 수행한 것으로 표시하지 않는다.

## PDF 공개판

`dqe_pdf_1118`이 4쪽 전체를 읽고 공개 파생판을 만들었다. 과학 본문·문제 조건·수식·해설·원호 날짜와 기존 과학 URI 4개를 보존한다. 4쪽의 최근 주제·메일 확인·내부 수집 이력을 삭제하고 참고문헌의 원제·저자·정식 출판 정보와 문서 판본을 보완했다. 누락된 참고문헌 제목의 글자와 저자 이름의 발음 구별 기호도 복구했다. DOI 2개를 추가해 HTTPS URI는 총 6개다.

전 페이지를 PyMuPDF 144dpi와 별도 Poppler 110dpi로 렌더해 읽고, `root`도 원본·최종 공개판 총 8개 렌더를 독립 확인했다. 1–3쪽의 본문·픽셀은 동일하며 4쪽의 선언한 편집 영역 밖 픽셀 변경은 없다. 개인정보·메타데이터·URI·첨부·자동 실행·폰트 임베딩과 원본/파생판 권리 범위는 [PDF QA](artifacts/public-pdf-qa.json)에 기록한다. 공개 PDF는 82,268바이트, SHA-256 `f0e845d922343c4537e48564a24572fb1f5002b6f02b9356b98760c16f2c430d`다. 제3자 논문 본문·그림을 복제하지 않으며 폰트는 허용된 문서 임베딩으로만 포함한다. 원본·메일 식별정보·QA 화면·내부 경로는 비공개로 보존한다.
