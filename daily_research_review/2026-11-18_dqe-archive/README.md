## 내용과 실제 열람

가상의 두 자산 최소분산 문제를 풀어 해 벡터의 합 정규화, 양자 상태의 노름 정규화와 측정 확률을 대조한다. A+I가 조건수와 목적함수를 함께 바꾸는 이유, 전체 주문 비중 판독과 준비·검증을 포함한 실행시간을 설명한다. 정답·수치 풀이·도입 판정은 기본 접힌 영역에 둔다. 별도 목록 요약도 한영으로 작성했다. 실제 내용을 읽은 기존 QML 17강의 역수 필터·ridge·입력과 판독 비용 설명을 연결했다. 강의는 한국어이며 영문 안내에 그 언어를 표시한다.

`root`의 집필·통합과 별도로 `dqe_science_1118`이 원 PDF 전체, 정확한 분수 산술·단위·조건수·시간·부호 정보의 불충분성, 한영 원고와 목록 요약을 감수했다. [독립 검산 코드](artifacts/science/verify_portfolio.py)와 [계산 결과](artifacts/science/independent-calculations.json), [출처와 편집 감수](artifacts/science/scientific-reference-audit.json)에 실제 범위를 기록한다.

CVX Short Course의 위험·제약·요인 공분산 절을 읽고, HHL 공개 저자판 v3의 1–3쪽 및 4–5쪽의 전처리·출력 논의와 Cai 공개 저자판 v2의 1쪽 실험 소개·2쪽 회로와 사후선택 설명을 확인했다. 출판사 서지·초록도 대조했다. 두 논문 전체의 복잡도 증명·보충자료나 실험 데이터를 재현하지 않았다. 원고는 고전 손계산, 저자들이 보고한 2013년 광자 실증, 교육용 미래 오류정정 장치 견적과 후속 시험 제안을 구분한다. 사람의 문장별 감수나 독자 평가를 수행한 것으로 표시하지 않는다.
