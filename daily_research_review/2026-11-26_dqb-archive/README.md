## 별도 편집글과 실제 역할

한영 편집글 「작은 기저가 바꾸는 양자화학 계산의 비용」은 리튬 원자의 궤도함수 모양을 다시 맞추는 상황에서 출발한다. 기저 선택이 바꾸는 유한 기저 해밀토니안·분자 물성의 오차와 준비 회로의 비용을 이어 읽고, 기존 「양자 계산의 전체 비용을 설계하다」의 입력·정확도 질문을 발전시킨다. 별도 목록 요약도 감수했다. 기존 글의 본문·제목·URL을 바꾸거나 승인 대기 기획을 게시한 작업은 아니다.
