# Daily Quantum Brief 공개 보관본 · 2026-11-11

원 DQB 4쪽에 정정·조건과 APS 참고문헌을 각 1쪽씩 보탠 한국어 6쪽 자료다. 원본은 비공개로 보존한다. 수집·소셜 경위와 내부 메모를 실제 삭제하고 과학 원출처 URI 아홉 개를 유지했다. 새 페이지에는 현재 제호 Agentic Tech Review Letters(ATRL)를 사용하고 원 Daily Quantum Brief 발행 라벨은 보존한다.

## 원문 대조와 정정

- PDE 예측의 실제 IBM NRMSE 감소 21.2–41.1%와 모사까지 합친 범위를 구별했다. 26-qubit 장치 시간과 H100 병렬 trajectory 작업시간의 합은 PDE solver 전체 경과시간 비교와 다르다. Autoencoder·readout의 종류, 시험 오차를 이용한 설정 선택과 장치·모사 조건 차이도 보완했다.
- Transferred-angle QAOA의 평균 gap 개선 보존율과 최적해 확률 개선 보존율은 서로 다른 지표다. 62%의 표본 block·instance 분모와 bootstrap 단위를 밝혔다. ADMM 부분문제의 angle 최적화와 고정 전이 실험을 나누고, 97.3%의 공통 궤도·통계 단위, 무잡음 성공확률과 실제 QPU shot 시간을 결합한 별도 TTS 비교를 설명했다.
- VQE 전이는 H₂ 회귀와 작은 기준 분자의 보정을 두 π 계에 재사용한 것이다. 전이오차의 기준은 같은 ansatz를 목표 분자에 직접 최적화한 에너지이며 FCI 오차와 다르다. 비국소 구조를 추가했을 때의 7.40 mHa와 공개 코드의 확인 범위도 적었다. DCSR의 보정 대상은 파일럿 분산으로 구한 샷 배분 계수의 편향이며, 18,000은 에너지 평가 한 번의 예산이다. FCI 1.6 mHa 도달과 500회 내 미수렴 비교군의 비용을 구별했다.
- 얕은 회로 학습 분리의 제한은 출력 생성가설에 걸리며 학습 절차 전체가 얕다는 뜻이 아니다. 2024년 사전공개 연구의 새 동료평가 게재와 실제 QPU 성능 측정도 나눈다. D-Wave의 조건부 자금·향후 장치 목표, 기존 PoT와 예정 PoC, 설치용 인도를 구별했다.

## 실제 수행 범위

편집부(AEDAUT)의 root는 원 DQB 4쪽 전체와 공개본 6쪽의 렌더·텍스트를 읽고 통합·공개 사본 제작을 맡았다. 이론 논문의 공식 출판사 색인 초록·서지·accepted-article 상태와 2024년 arXiv v2의 정의·정리·논의를 대조했다. 출판사 최종 VOR 본문과 부록 증명 전체를 검증한 것으로 표시하지 않는다. D-Wave는 공식 발표의 색인 본문·수치·조건을 읽었으며 독립 장치 benchmark를 확보한 것은 아니다.

dqb1111_pde는 27쪽 v1의 본문·보충자료와 공식 연결 코드의 고정 커밋을 대조했다. 연결 저장소에서 PDE 전체 재현 패키지를 확인하지 못했다. 같은 역할이 최종 PDF의 6쪽 전체, 엄격 파싱·메타데이터·URI·첨부·실행 동작·개인정보와 원 4쪽의 선언 편집 영역 밖 144dpi 픽셀 동일성을 독립 검사했다.

dqb1111_optimization은 13쪽·18쪽 v1의 본문·방법·표·통합 부록을 읽고 공식 코드의 README·확장 결과 및 선택한 캐시의 산술을 대조했다. 코드 저장소 전체의 provenance나 solver·QPU 결과를 재현한 것으로 표시하지 않는다. dqb1111_chemistry는 두 화학 논문의 본문·통합 부록과 전이 연구의 공식 코드 여섯 파일을 대조했다. DCSR의 제시 코드 경로는 확인한 경로에서 404여서 코드·라이선스·실행 결과를 확인하지 못했다. 세 담당자가 관련 공개 문장을 재검토했고, 최종 한 문구의 시간 차원 교정은 최적화 담당이 다시 확인했다.

[서지·판본·실제 열람 범위](reports/reference-manifest.json)는 최초 인용순 [1]–[7]을 따른다. 확인한 소프트웨어 세 저장소의 소유자 크레딧과 고정 커밋을 관련 문헌에 연결했다. 원 논문 실험·QPU·solver·학습을 재실행하거나 사람 독자 평가를 수행하지 않았다.
