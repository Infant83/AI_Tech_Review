# Daily Research Brief · 2026-11-19

이번 호는 마요라나 큐비트의 보호 조건과 패리티 판별을 중심으로, 공진기 매개 게이트, 2차원 상대론적 장의 아날로그 실험, 재료 물성 학습점 선택을 소개한다. 직전 11월 17일 조사 이후의 미처리 기간을 통합한 11월 19일 호다.

`reports_data.json`은 10쪽 한국어 PDF의 검토한 문장·비교·기획·출처 입력이다. `reports/briefing_ko.md`와 `briefing_en.md`는 별도 목록 요약에서 연결되는 짧은 편집글의 원고다. 신규 심층 리뷰 세 기획은 제안 상태다.

원논문 보고, 공개 저자판의 결과, 편집 해석과 산술 재집계를 구별했다. Roy 등의 최종 전문과 Nature Computational Science 출판본 전문은 구독 제한으로 읽지 못했으며 공개 저자판을 사용했다. 실제 읽은 판본과 보충자료·코드 접근 범위는 PDF의 서지 부분에 명시했다.

## 그림과 재생성

- tetron의 최종 Fig. 2는 출판본 CC BY 4.0에 따라 발췌했다.
- 나노선 간섭계는 공개 v1의 응답 연산자와 계산 조건을 새로 도식화했다.
- 공진기 게이트는 469 ns·4준위 조건의 보고값과 저자 이완식에 대입한 항을 재도표했다.
- 원자장 실험은 최종 Nature Fig. 4c·5d를 CC BY 4.0에 따라 발췌·재배치하고 제목을 추가했다. 서로 다른 측정 조건을 보존했다.
- 재료 연구는 출판 원자료의 명시된 정규화 절차를 재집계했다. 원곡선이나 새 학습 결과를 만들지 않았다.

그림별 출처·판본·편집 범위·해시는 `artifacts/figure-manifest.json`, 정제 수치와 산술은 대응 JSON에 있다. 원자료의 개인 메타데이터나 원문 메일은 포함하지 않는다.

`scripts/build_brief.py`는 `--source`, `--output`, `--font`, `--font-heading`, `--font-fallback`을 받는다. 한글 본문·제목 글꼴과 수학 기호를 포함한 fallback 글꼴을 지정한다. 그림 제작 스크립트는 글꼴·입력 그림·출력 폴더를 인자로 받으며, 원자료를 별도로 준비한다. 필요한 Python 패키지는 ReportLab과 Pillow다.

`artifacts/public-pdf-qa.json`은 공개 PDF의 구조·링크·글꼴·개인정보 검사를 기록한다. 모든 페이지 렌더와 독립 과학·한영·판독성 감수를 수행했다. 원 실험·소자 모형·회귀 학습의 독립 재현은 수행하지 않았다. 출판은 기존 `daily-research` 등록과 독립 배포 후보 절차를 따른다.
