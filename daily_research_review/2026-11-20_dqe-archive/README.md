# DQE · 정비 일정의 최적성과 성공까지의 시간

원호 날짜·공개판 편집·웹 갱신·근거 기준일은 2026-11-20이다. 사용자 승인에 따라 편집부(AEDAUT)가 과학 감수·짧은 한영 안내를 작성하고 운영팀(ADOPT)의 기존 도구로 등록한다. 같은 날짜 DQB를 비롯한 기존 ID·본문·PDF·주소와 11월 17일 요청형 NTCA DQE를 보존한다. 문제 생성·발송 예약은 변경하지 않는다.

## 문제와 실제 감수

작은 정비 문제의 최적 일정과 하한, 시간 인덱스 QUBO의 제약, 별도 운영 규모의 95% 성공까지 필요한 표본·전체 시간 계산을 다룬다. 일정 품질과 솔버의 반환 신뢰도를 구분하고 실제 검증 시험에 사용할 데이터·비교 조건을 안내한다. 수치 해설·판정은 웹에서 기본 접힌 영역에 두며 PDF 문제는 1쪽, 해설은 2쪽부터 안내한다. 한영 목록 요약도 별도로 감수했다.

`root`가 집필·통합하고 `dqe_science_1118`이 원 PDF 4쪽·수치·가정·원출처·한영 원고·목록 요약을 독립 감수했다. 고전 전수 검산은 D=5의 이진 배치 16,384개와 별도 시작 시각 조합 144개, D=4의 이진 배치 1,024개와 시작 조합 36개를 대조한다. QUBO 식의 직접 평가·전개된 이차식·별도 일정 제약 판정을 비교했고 성공확률·최소 반복 횟수·단위·시간도 계산했다. [검산 코드](artifacts/science/verify_exercise.py), [결과](artifacts/science/calculations.json), [원출처·편집 감수](artifacts/science/scientific-reference-audit.json)에 실제 범위를 기록한다. OR-Tools 예제 실행이나 실제 QPU·표본 캠페인은 수행하지 않았다.

공식 OR-Tools 문제 정의와 interval·선후관계·NoOverlap·makespan 예제를 읽었다. Venturelli 등의 arXiv v2(2016-10-17)는 문제·QUBO·가지치기·임베딩·실험 설정·고전 비교의 해당 부분을 직접 읽고, 물리 Vesuvius 실험과 가상 성공확률·시간을 구분했다. 메타데이터 제목과 PDF 첫 쪽 제목의 차이를 감사 기록에 남기며 확인하지 않은 학술지·회의록 쪽수·DOI를 만들지 않는다. 기존 D-Wave 분자 역설계 리뷰의 같은 BQM·유효성·임베딩·체인·시간 비교 부분을 읽고 구체적으로 연결했다. 전체 논문의 증명·부록이나 하드웨어 데이터를 재현한 것으로 표시하지 않으며, 사람의 문장별 검토와 독자 평가도 수행하지 않았다.

## PDF 공개판

공개 파생판은 4쪽이며 과학 문제·해설·수식·원호 날짜를 유지한다. 4쪽의 최근 주제·수신 및 수집 이력을 실제 삭제하고 참고문헌의 전체 저자·정식 제목·확인한 판본을 보완했다. 원래 두 과학 URI를 유지하고 arXiv v2 연결을 추가했다. 제3자 논문 그림·본문은 복제하지 않았다. 사용자 승인 자체 교육용 문제의 공개 범위이며 제3자 자료 전체의 재배포 권리를 주장하지 않는다.

`dqe_pdf_1118`이 원본과 공개판 전 페이지를 PyMuPDF 144dpi와 별도 Poppler 110dpi로 렌더해 읽고 메타데이터·개인정보·URI·첨부·실행 동작·폰트 임베딩을 검사했다. `root`도 원본 4쪽과 최종 공개판 4쪽의 총 8개 렌더를 독립 확인했다. 1–3쪽의 추출 본문·픽셀은 동일하고 4쪽의 선언 편집 영역 밖 픽셀 변경은 없다. [PDF QA](artifacts/public-pdf-qa.json)에 실제 범위와 한계를 기록한다. 공개 PDF는 74,884바이트, SHA-256 `6e7de6ebb3afd5cbe0827e24e68e90811ff7f816ac529dfb478010f9e80913be`다. 원본·메일 정보·QA 화면은 비공개 보존한다.
