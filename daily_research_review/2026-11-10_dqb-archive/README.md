# Daily Quantum Brief 공개 보관본 · 2026-11-10

원 DQB 4쪽에 정정·조건과 APS 참고문헌을 각 1쪽씩 보탠 한국어 6쪽 자료다. 원본은 비공개로 보존한다. 공개본에서 수집·소셜 경위와 내부 메모를 실제 삭제했으며, 연구 내용과 원 출처 URI 여덟 개를 유지한다. 새 페이지에는 현재 제호 Agentic Tech Review Letters(ATRL)를 사용하고 원 Daily Quantum Brief 발행 라벨은 보존한다.

## 실제 대조와 정정

- Grover의 최대 1.41배는 모든 표적을 찾는 find-all의 기대 질의 라운드다. Find-one의 최대 1.22배와 공유 레지스터·병렬 질의·큰 N 조건을 구별했다. 고전 수치검증의 어려움을 큐비트 수만으로 일반화하던 문장을 좁혔다.
- Arcsin의 kickmix 탐색·Lean 확장, 기준선 정밀도와 후속 역제곱근 개선 가능성, fusion의 평균 단일 회로와 전체 500회 비용을 보완했다. 고정 명세 대조와 명세 자체의 모델링 검수도 나눈다.
- Fe–S 결과는 5월 선행 프리프린트이며 Willow 논문도 인용했다. 이번 새 출판 소식은 11월 9일 JCTC 온라인 게재다. 직접 fidelity를 다룬 dimer와 cubane 부분공간·FeMo 1-RDM proxy, guiding·measurement trial의 재가중과 남은 오차를 구별했다. 두 역할 자체를 모든 비단조 경향의 충분 원인으로 단정하지 않았다.
- GPU 최적화의 sampling/access time 비교, DCM·DPA-a 정확 알고리즘과의 end-to-end 비교, 별도 진화 휴리스틱 실험을 나눴다. QAOA 결과의 nondominated 해가 열 개 부족하다는 조건도 명료화했다.
- QASC/QuEST 실제 모사 시간과 QACC-perf 추정 시간을 구별한다. Virtual offload는 추정 시간만큼 기다린 뒤 고전 계산 에너지를 반환하는 모드다. 코드의 실제 판본과 권장 companion 논문을 확인하고 placeholder DOI를 인용에서 제외했다.

## 실제 수행 범위

편집부(AEDAUT)의 root는 통합·공개 사본 제작과 전체 PDF 출력을 검토했다. dqb10_formal은 45쪽 v1의 본문·관련 부록과 실제 공개 리뷰 세 편을 대조했다. 공식 Lean 라이브러리·명세·검증 해의 배포본은 확인한 경로에서 찾지 못했으며 재실행하지 않았다.

dqb10_afqmc는 출판사 등록 초록·서지와 저자 원고 v1의 47쪽 본문·S1–S5를 대조했다. 출판사 VOR 본문·보충자료에는 접근하지 못했으므로 두 판본 전체의 동일성을 보증하지 않는다. 전일 Willow 원문 대조 기록과 인용 [41]을 함께 확인했다.

dqb10_costs는 17쪽 QAIA v4와 15쪽 HPC v1의 관련 방법·표·수치·그림을 대조하고 공식 코드의 README·인용 파일·커밋을 확인했다. 전체 코드 실행·QPU·AFQMC·최적화·형식증명의 독립 재현은 수행하지 않았다. 같은 역할이 공개 PDF 6쪽 전체의 렌더·텍스트·메타데이터·URI·첨부·실행 동작과 개인정보를 독립 점검했다. 세 원문 담당자가 수정된 공개본을 다시 읽었다.

[서지·판본·실제 열람 범위](reports/reference-manifest.json)는 최초 인용순 [1]–[6]을 따른다. 25명 공저자는 manifest에 순서를 보존하고 APS 기준에 따라 PDF에서는 첫 저자와 et al.을 사용한다. 그룹 [2]·[4]의 관련 논문·코드 크레딧도 각각 기록한다. 교육용 notebook과 공식 행사 안내는 연구 성과 네 항목과 구별한다.

## 제작·공개 경계

`artifacts/build_public_archive.py`는 호출자가 제공한 원본·글꼴로 공개본을 만든다. 재생성 시 출력 검토 상태를 다시 미완료로 바꾼다. 원 4쪽은 선언한 삭제·정정 영역 밖 144dpi 픽셀이 같으며 최종 6쪽을 모두 렌더링해 읽었다. Strict PDF 파싱·문서 메타데이터·URI·첨부·실행 동작·개인정보 검사를 통과했다. 태그 PDF·스크린리더 검증이나 사람 독자 평가를 수행한 것으로 표시하지 않는다.

기존에 승인된 DQB 공개 보관 흐름에 따라 검수한 편집본과 직접 작성한 조건·서지만 배포한다. 제3자 논문·코드·원 첨부·메일·조사 자료·QA 화면은 배포하지 않는다. 원 논문·코드는 공개 원출처 링크로 안내하며 일괄 재사용 권리를 부여하지 않는다. 신규 심층 리뷰나 기존 글의 실질적 확장은 이 등록과 별도의 승인 상태를 유지한다.
