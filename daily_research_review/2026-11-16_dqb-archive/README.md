# Daily Quantum Brief · 2026-11-16

짧은 한영 편집글 「큰 언어모델 안에서 시험한 작은 양자 회로」는 2,048차원 내부 표현을 32개 작은 head로 나눈 설계에서 시작한다. 시뮬레이터의 학습·perplexity와 실제 QPU의 제한된 head 실행을 각각 설명하고, 구성요소 제거·고정 회로·고전 MLP의 실제 비교로 어떤 기능이 회복됐는지 논의를 전개한다. 별도의 목록 요약을 한영으로 감수했다.

기존 「양자 계산의 전체 비용을 설계하다」의 입력 보존과 반복 측정 논의를 이어받아, 넓은 입력을 나누는 역할과 토큰 간 문맥을 통합하는 역할이 고전·양자 부분에 어떻게 배분되는지 살폈다. 기존 본문을 확장하거나 새 심층 리뷰를 발행하지 않았다. 분자 물성 비교는 마지막 문단의 편집 제안이다.

## 원문과 공개 보관본

원 DQB 4쪽을 비공개 보존한 뒤 필요한 삭제·정정을 적용하고 조건·정식 APS 서지 2쪽을 더했다. 원호 날짜와 과학 주제, 공개 출처 진입점 6개를 유지했다. 수집·메일·소셜 검색 경위와 내부 출판 작업 메모, 깨진 문자와 약식 서지는 공개판에서 실제 삭제·복구했다. 공개판은 6쪽이다.

LLM 원문 v1의 정식 제목·전원 5저자, 깨진 10^6 지수, head bank 제출의 QPU 점유시간과 실제 두 prompt의 3회 생성·135회로, 회로 통제의 seed 수를 확인했다. 16.33%는 저장 매개변수 기준이며 고전 판독부가 전체 학습 매개변수의 대부분이라는 조건을 부록에 남겼다. no-circuit 통제는 head와 판독부를 함께 제거한다. 판독부만 제거한 비교의 유의성은 원문 본문과 부록의 서술이 달라 새 판정을 내리지 않았다.

Cat-QAOA 정식 PDF는 11월 13일에 읽은 파일과 바이트가 같아 당시 전체 본문·보충자료 감수를 재사용하고 현재 판본·metadata를 확인했다. 정확한 cat 기저와 큰 진폭 근사, 코드 제작자의 별도 이름 표기를 유지했다. QRL은 추정량·수렴의 가정과 저자 수락 표기의 확인 범위를 구분했다. Burst 보호의 거리 13 결과는 차이 해소가 아닌 불확실한 비교로 바로잡았고, 38%의 조건부 excess-risk 분모와 49개 보호 ancilla의 보간 추정, 5-round cap의 decoder 조건을 명시했다. 연결된 코드·데이터의 제작자 표기와 README가 알린 일부 추가 분석 차이를 원 논문과 구별했다.
