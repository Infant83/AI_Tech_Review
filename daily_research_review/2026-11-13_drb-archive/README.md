# DRB의 첫 공개 편집글과 보관본 · 2026-11-13

사용자가 DRB에도 DQB와 같은 기준과 방법을 적용해 공개하도록 승인했다. [DRB 운영 기준](../../.automation/nature-aps-drb/README.md)을 따른다. 기존 주간 예약과 이메일 전달 절차는 유지하며 같은 회차를 사이트에 공개하기 위해 메일을 다시 보내지 않는다. 새 심층 리뷰나 승인 대기 기획을 게시하는 작업은 아니다.

## 짧은 한영 편집글

「자화를 맞춘 뒤, 모형을 다시 시험하다」는 자화 곡선의 적합도에서 α-RuCl₃ 상호작용의 식별 문제로 들어간다. 모아레 신경망 VMC와 transferable DeepQMC를 연결해 모형을 고르는 일, 그 모형의 상태를 계산하는 일, 다른 관측량으로 시험하는 일을 설명한다. 관련 LUSH·희소 기준상태 글에서 이어받는 질문과 새로 더하는 내용을 구별한다. 제목과 별도 목록 요약은 원 제목·초록 복사나 보관 작업 보고로 채우지 않았다.

한영 원고는 `reports/briefing_ko.md`·`briefing_en.md`이며 기존 `scripts/build_briefing_editorial.py`로 정적 HTML 조각과 명시적 등록을 생성했다. 편집부(AEDAUT)의 root가 집필·통합하고 drb_workflow_audit가 원문 조건·APS 서지·도입·관점·제목·요약·한영 대응을 독립 감수했다. S_z=0이 총스핀 0을 뜻하지 않도록 표현을 명료하게 했다. 짧은 글은 주요 연구 세 편과 기존 글 두 편을 인용하며 PDF의 여섯 문헌과 목적·범위를 구별한다.

## PDF 판본과 그림

이메일로 전달한 11쪽 피규어 보강판은 비공개 원본으로 보존했다. 그 판본의 SHA-256은 `ca91490c3c7ad92371420e0529da6e3100686e32b8a4ca58d3337c90f5c26816`이다. 공개 재사용 권리가 해결되지 않은 PRB·Nature 원 그림을 그 파일에서 그대로 복사하지 않았다.

공개 파생판은 한국어 8쪽, 167,423바이트이며 SHA-256은 `14ffe05db6c58e5003355c81ec6cabdb62c5acc12383e54972f8471c61d15ab8`이다. 핵심 주장·보고 수치·실행 조건·해석을 여섯 자체 도식과 함께 다시 조판했다. PRB 두 연구의 방법·관측 관계, DeepQMC의 두 상대에너지 오차, vDBF의 서로 다른 계·관측량, 중성원자의 시간창과 계 크기, AIR 표·본문 수치를 각각 재구성했다. 원 논문 이미지·곡선·표의 배치를 복제하거나 실험 곡선을 임의로 복원하지 않았다. 도식마다 근거·단위·조건·리뷰 재구성을 명시하고 원저자·원제·DOI·읽은 판본을 기록했다.

공개 원고는 `reports_data.json`, 빌더는 `scripts/build_public_brief.py`다. 글꼴 경로를 인자로 받아 재생성하며 두 번 생성한 PDF의 바이트가 같았다. 원호·근거 기준일과 공개 파생판 작성일은 2026-11-13이고 원본·파생판 이력을 별도로 적었다. 공개 PDF에 내부 기획·메일·원문 수집물·QA 화면을 넣지 않았다.

drb_public_pdf가 제작과 전체 8쪽 렌더·엄격 파싱·URI·개인정보·메타데이터·첨부·실행 동작을 검사했다. drb_workflow_audit는 최종 PDF를 독립 재렌더해 전체 본문·그림·캡션·서지를 대조했고 root도 8쪽 모두 시각 확인했다. 검수 결과는 [PDF 제작·권리 검사](artifacts/publication-qa.json)와 [원고·독립 감수](artifacts/editorial-qa.json)에 남긴다. 원 논문 계산·학습·QPU 실행이나 사람 독자 평가를 수행한 것으로 표시하지 않는다.

## 원문 대조 범위

첫 DRB의 선별·전문 감수 기록을 재사용했다. 이번 짧은 글의 두 PRB는 공개 arXiv v2 해당 절과 공식 초록·출판사 서지를 다시 확인했으며 정식 출판 전문을 새로 읽었다고 세지 않는다. DeepQMC는 공개 출판 본문·Fig. 1 설명과 정식 서지를 대조했다. PDF의 vDBF·prethermal·AIR는 이전에 확인한 선택 절·그림·표의 감수와 새 서지 확인을 구별한다. Nature 구독 본문·전체 SI 접근을 추정하지 않으며 원래 저널 조사에는 일부 목록 누락과 선택 독해가 남아 있다.

## 공개 경로와 보존

등록 ID는 `2026-11-13-daily-research-brief`, 시리즈는 `daily-research`다. 한영 편집글은 `briefings/research/2026-11-13/`와 `en/`, PDF는 `archive/files/2026-11-13-daily-research-brief.pdf`로 제공한다. 같은 날짜 DQB의 ID·기존 URL·본문·PDF를 보존한다. 달력·목록·검색은 짧은 글을 먼저 안내하고 원 PDF 열기·다운로드를 별도로 제공한다.

drb_publication_support가 기존 경로를 유지하는 시리즈·경로 정본과 목록·검색·보존 검증을 보완했다. Python 전체 389개와 독립 경로 회귀 검사, JavaScript 문법 검사가 통과했다. 실제 후보의 이전 파일 보존·브라우저·배포·HTTPS 확인은 후속 검증 기록에서 구별한다. 문서 설정과 로컬 등록만으로 공개 완료로 표시하지 않는다.
