# 2026년 11월 22일 DQB · 공개 보관과 편집 브리핑

한영 편집글 「에너지보다 늦게 수렴하는 스핀 상관」은 신경망 양자상태의 에너지가 수렴한 뒤에도 이웃 스핀의 상관 오차가 남는 상황에서 시작한다. 에너지 고유상태 사이 교차항, 실시간 전파의 위상 평균과 관측량 편향을 연결하고 초기 상태의 근접성·에너지 차이·시간폭·전파 정확도와 추가 계산비용을 설명한다. 원 DQB의 제목·초록·연구 목록을 옮기는 대신 이 질문에 집중해 별도 한영 요약을 작성한다.

기존 「관측량과 항의 크기에 맞춘 양자 동역학 계산」의 목표 관측량·근사 오차 논의를 이어받는다. 기존 글의 시간발전 근사와 새 연구의 바닥상태 관측량 보정을 서로 다른 방법으로 읽는다. 해당 글의 ID·URL·제목·본문을 보존하며 다른 기존 글을 실질적으로 확장하지 않는다. SiC·이종 원자 결과는 전날 DRB의 실제 공개 내용·원출처 감수를 재사용하고 중복 심층 리뷰를 새로 발행하지 않는다.

## 원출처와 실제 역할

편집부(AEDAUT) root가 원 DQB 5쪽·관련 기존 글과 NQS의 동기·정리·두 표현·수치 결과를 읽고 한영 집필·통합했다. SiC는 오늘 재취득한 출판 HTML의 관련 결과·자기장 정렬·토모그래피·메모리·자료 공개 절을 대조하고 전날 SI·독립 감수의 읽은 범위를 재사용한다. 이종 원자 논문은 공식 최종 PDF가 전날 취득본과 동일한 바이트임을 확인하고 이미 읽은 본문·그림·선택 부록의 감수를 재사용한다. 이 과정을 새 전체 원문·보충자료 재독이나 실험 재현으로 표시하지 않는다.

`dqb1122_research`는 생성모형·NQS 원문, 판본·코드 공개 상태·수치 조건을 독립 대조했다. 생성모형의 수치는 편향 보정한 MMD²이며 사전학습을 제외한 국소 갱신 수와 전체 비용을 구별한다. NQS의 이차 오차 감소는 초기 근접 상태와 시간 분포의 특성함수 조건을 유지한다. 작은 정확대각화 예시와 큰 계의 학습 말기 추정값을 구별하며 명시적 시간 전파와 두 상태 지배를 가정한 저렴한 보정의 비용·가정을 각각 읽는다. 같은 담당자는 한영 편집글·제목·별도 요약을 비작성자로 감수했다.

`dqb1122_boundary`는 OTOC·최솟값 탐색의 원 정리·질의 모형·수치와 정식 서지를 대조했다. OTOC는 1차·1차원·무한온도와 국소 Pauli 연산자·무작위 회로 앙상블 평균제곱오차 조건을 유지한다. 알고리즘 자체는 결정론적이다. 최솟값 탐색은 수치 추정기를 코히런트하게 제공하는 모형의 질의·오차 결과이며, 상태 준비 질의수·점근 공간비용이 명시된 것과 구체적인 게이트·물리 구현·전체 시간이 미평가된 것을 구별한다. 전체 증명을 검증하거나 코드를 실행하지 않았다.

`dqb1122_pdf`는 원 PDF 5쪽 전체의 텍스트·렌더·메타데이터·URI·첨부·실행 동작·공개 적합성을 확인하고 공개 파생판을 제작했다. 원호는 비공개 보존하며 수집·메일·소셜 검색 경위와 내부 체크리스트를 실제 삭제하고 원 과학 내용·날짜·출처 연결을 유지한다. 정정·조건과 정식 APS 서지는 공개판에 구별해 보탠다. 원호·공개 편집·웹 작성·추가 근거 기준일은 2026년 11월 22일이다. 원 메일·첨부 원본·다운로드 토큰·개인 주소·내부 경로·수집 원문·QA 화면은 공개하지 않는다.

## 발행 범위

운영팀(ADOPT)의 기존 출판·보존 도구를 사용하며 인프라·디자인·예약 변경은 추가하지 않는다. 새로 검수한 한 호의 공개 PDF와 일상적인 짧은 한영 편집글만 다룬다. 기존 관심사의 관측량·정확도 초점을 유지하고 승인 대기 기획 5건은 반복 제안하지 않는다. 신규 심층 리뷰·후속 시리즈·병렬 기획이나 다른 기존 본문의 실질적 확장은 공개하지 않는다. 원 실험·QPU·벤치마크·사람 독자 평가는 수행하지 않았다.

PDF 제작·독립 최종 감수·명시 등록·후보 보존·화면·배포·실제 URL 검증은 각각 확인 뒤 별도로 기록한다. 등록과 감수만으로 실제 공개 완료를 표시하지 않는다.

## 최종 원고·PDF 검수와 등록

한영 원고 전체·제목·별도 요약은 비작성자 감수를 통과했다. 전파 오차와 관측량 개선의 관계, 정확한 기존 영문 제호·서지, 실제 완료된 역할의 시제 변경을 최종 차분에서 다시 확인했다. [원고 감수](artifacts/editorial-independent-review.json)에 초기 전체 독해와 변경분, 최종 파일 해시를 구별한다.

최종 공개 PDF는 7쪽·188,264바이트, SHA-256 `e1308f09c35040793ef3540a9517d6cac94f5c664a6dfcd6f54fd8490b06d3db`다. 제작자·root·비제작 담당자가 전체 또는 배정된 원출처와의 대응을 감수했다. 초판 전 7쪽 렌더를 확인한 뒤 충분조건 표현만 고친 최종 6쪽을 다시 열었고 나머지 6쪽 PNG가 동일함을 대조했다. 원 과학 URI 8개를 유지하며 최종 12개 고유 HTTPS URI·엄격 파싱·개인정보·메타데이터·첨부·실행 동작·선언 편집 영역 밖 픽셀 보존 검사를 통과했다. [제작 검사](artifacts/public-pdf-qa.json), [root 전쪽 시각 검수](artifacts/root-pdf-visual-review.json), [독립 3–4번 과학 대응](artifacts/pdf-ml-independent-review.json), [독립 5–6번 및 전쪽 렌더 감수](artifacts/pdf-science-independent-review.json)를 구분한다.

## 정적 후보와 화면 확인

최신 원격 소스 `73790f28f1e1f410abc204b7abcea7f4de7ee1ee`와 실제 배포 `b6f0dfd89aa34490d9219b14bd0c478cb227ac59`의 불변 기준을 사용했다. 소스 검사 490건은 489건 통과·1건 제외·실패 0건이었다. 최종 연속성·페이로드 검사와 봉인을 통과했고 후보에는 리뷰 58편·보관 문서 163개·카탈로그 78건이 있다. 기존 검색 메타데이터·배포 용량 경고는 운영팀(ADOPT)의 기존 추적 범위다.

[후보 화면 검수](artifacts/candidate-browser-review.json)는 원격 IAB의 1280px·390px에서 한영 제목·별도 요약·본문·세 날짜·책임 편집자/AI 공개·인용·실제 언어 전환을 확인했다. 22일 달력 선택·날짜 목록·한영 검색은 편집글을 우선 안내하고 PDF 읽기·다운로드를 따로 제공한다. 후보 PDF의 실제 HTTP 바이트도 최종 검수본과 같았다. 페이지 밖 가로 넘침이나 콘솔 오류·경고는 관찰하지 못했다. 실제 공개 서버와 CI 네 작업의 확인은 별도 단계다.

[독립 후보 보존 감수](artifacts/candidate-independent-review.json)는 이전 페이로드 2,710개에 PDF 1개·한영 편집글 2개만 추가되고 삭제가 없음을 확인했다. 기존 리뷰 58편의 1,937파일, PDF 272경로, 날짜별 HTML 50경로와 Classiq 강좌 파일 20개는 원 바이트를 유지한다. 기존 보관 문서 162개·검색 169개·카탈로그 78개 객체와 원제·한영 요약·ID·URL·원 날짜도 보존됐다. 공통 목록·검색 변경은 새 한 호와 갱신 안내에 필요한 범위다. 후보 봉인의 실제 파일 해시와 등록된 한영 본문 조각도 대조했다.
