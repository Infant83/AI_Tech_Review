# 2026년 11월 21일 DQB · 공개 보관과 편집 브리핑

한영 편집글 「분자 주변 전위에서 에너지를 읽는 법」은 이온 용액 속 생체분자의 전위 지도에서 정전기 에너지를 구하는 문제로 시작한다. LPB 알고리즘이 고전 입력·상태 준비·관측량 추정을 연결하는 방법과, 광자 QADC가 검출·후선택·학습 보정으로 위상 정보를 읽는 방법을 병렬로 살핀다. 서로 다른 물리계의 수치를 하나의 우위나 순위로 합치지 않는다. 기존 「양자 계산의 전체 비용을 설계하다」의 준비·반복·출력 비용 논의를 이어받으며 원 발행일과 11월 19일 개정판의 실제 한영 페이지를 확인했다. 다른 기존 글의 본문은 바꾸지 않는다.

## 읽은 근거와 조건

root는 LPB 1판의 초록·판본과 3.1·3.4·3.5·4절, 입력 준비·전처리의 관련 대목을 읽었다. 연속체·선형화된 정전기 모형, 원자 수 고정, 진폭 추정과 Hadamard 측정의 정확도 비용, 전체 격자를 출력하는 고전 다중격자 풀이와의 정규화 증가율 비교를 구별한다. 61쪽 전체·모든 부록 증명을 감수하거나 실제 생체분자 자원을 산정했다고 표시하지 않는다. 페르미온 정리에서는 서론·주 결과·모형 정의를 읽고 전체 Fock 공간의 에너지, 유리수 입력·결합 크기 상한·오차의 비용을 확인했다.

`dqb1121_photon`은 QADC 게재본 본문·Methods와 13쪽 보충자료를 읽고 실시간 feed-forward 대신 설정별 자료의 후선택·후처리, 원시·DAE 보정 확률의 차이, 성공 검출 사건과 손실 모형의 광자 분모를 대조했다. QRU는 동료평가 후 조기 공개 상태와 사전공개 3판의 관련 기술 대목을 구별했다. 같은 담당자는 LPB 관련 절을 독립적으로 읽고 한영 편집글·제목·별도 요약을 비작성자로 감수했다. [원고 감수](artifacts/editorial-independent-review.json)에 정확한 파일 해시와 실제 범위를 남긴다.

`dqb1121_systems`는 Rapids 본문·Methods·공식 정적 코드와 배치·배선/RTL 자료, 처리율·결정 지연·특정 잡음에서의 비교 기준을 확인했다. CIPEC는 전날 확보한 Article in Press와 감수 기록을 재사용해 다시 읽고 새로 확보한 공식 SI의 동일 해시를 확인했다. 현재 본론 PDF의 재취득 제한을 기록하며 새 VoR 바이트를 확인했다고 표시하지 않는다. BMO 공식 발표와 PQG의 확보된 공개 초록·서지를 읽은 범위도 구별한다. [원출처·판본·공저자·실제 읽은 범위](artifacts/reference-manifest.json)를 따른다.

## 원호와 공개판

원호는 한국어 5쪽이며 비공개로 보존한다. `dqb1121_pdf`가 전체를 렌더·독해하고 과학 URI 8개·문서 구조·메타데이터·첨부·실행 동작·개인정보와 재배포 조건을 검사했다. 공개 파생판은 수집·메일·소셜 검색 경위와 내부 체크리스트·축약 서지를 삭제하고, 원 과학 내용·원호 날짜·출처 연결을 유지하며 정정·조건·정식 APS 서지를 보완한다. 원 PDF의 제목과 별도 웹 편집글 제목은 각각의 역할을 유지한다. 원호·공개판 편집일·웹 작성일·추가 근거 기준일은 2026년 11월 21일이다.

제작자와 별도 원출처 담당자, root가 PDF 전체와 최종 판본을 검수하며 실제 범위는 해당 검사 기록에 남긴다. 공개 원문·추가 보완의 관계와 선언 편집 영역 밖의 렌더 보존도 확인한다. 원 메일·첨부 원본·개인 주소·연결 토큰·내부 경로·수집 논문·QA 화면은 Git과 사이트에 넣지 않는다.

## 역할과 발행 범위

편집부(AEDAUT) root가 한영 집필·통합·등록·후보·실제 공개 확인을 맡는다. 원고와 PDF의 최종 정확성을 제작자 자신의 검사만으로 보증하지 않는다. 운영팀(ADOPT)의 기존 출판·보존 도구를 사용하며 인프라·디자인 변경이나 새 예약을 추가하지 않는다. 기존 승인 대기 기획 5건은 보존하고 반복 제안하지 않는다. 새 심층 리뷰·후속 시리즈·다른 기존 본문의 실질적 확장은 이번 작업에 포함하지 않는다. 원 실험·QPU·알고리즘 벤치마크·사람 독자 평가는 수행하지 않았다.

검수 PDF·후보·배포·실제 공개 결과는 확인한 뒤 별도로 기록한다. PDF 공개 보관과 짧은 웹 편집글의 완료 상태를 나누어 관리한다.
