# Daily Quantum Brief · 2026-11-17

## 원문과 공개 보관본

원 DQB 4쪽은 비공개 보존한다. 공개판은 과학 내용·원호 날짜·원 출처 진입점 9개를 유지하면서 수집·메일·소셜 검색 경위와 내부 출판 메모를 실제 삭제하고, 원문 대조에서 확인한 조건·정식 서지와 수정 이력을 보완한다. 제작·구조 검수와 별도 전 페이지 감수는 최종 파일에 대해 기록한다. 원 첨부·메일 식별자·비공개 링크·내부 절대경로·QA 화면은 Git이나 배포물에 넣지 않는다.

Ni의 18%·약 2.0 ms 결과는 최저차 이항 부호이며, √17 부호의 별도 결과와 구별한다. 공개 게재본 그림의 수명 적합값은 2030±20 대 1724±17 μs로 사전공개본과 불확실성이 달라졌다. Sun의 값은 1627±16 대 1565±13 μs다. 두 결과의 지표는 과정 충실도 감쇠의 시간상수다. Ni의 센싱은 다른 probe 상태와 전체 shot-time으로 정규화한 Fisher 정보이며 메모리 실험의 부호와 비교 분모를 섞지 않는다.

고객 세분화의 구성당 단일 seeded 실행과 서로 다른 목적함수, 전체 지연 장부의 부재를 명시한다. QSVQ-Net의 slice-level 분할·겹치는 교차검증 분할과 외부 mask 교체 조건을 구별하며 p=0.59를 동등성 증명으로 쓰지 않는다. 다이아몬드 maser의 부가 잡음은 3.05±0.23 quanta로 반양자 기준보다 약 2.55 높다. −63 dBm 출력 압축점은 최대 이득 조건이 아닌 10 dB 이득에서의 값이다.
