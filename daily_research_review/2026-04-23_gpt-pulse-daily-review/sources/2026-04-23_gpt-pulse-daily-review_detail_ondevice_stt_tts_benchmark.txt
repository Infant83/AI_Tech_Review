준비 (5분)

whisper.cpp 설치

Bash
git clone https://github.com/ggml-org/whisper.cpp
cd whisper.cpp
cmake -B build && cmake --build build -j
# 한국어 멀티링구얼 모델 예: small 또는 base(또는 tiny로 초저지연)
./models/download-ggml-model.sh small    # 필요 시 base/tiny로 변경

(프로젝트 빌드·모델 다운로드 방법은 README의 Quick start와 동일.) 
GitHub

테스트 오디오 준비

10분 마이크 입력을 녹음하거나, 한국어 문장 30개(자음/모음 고르게 포함) 짧게 녹음.

평가 패키지

Bash
python -m pip install jiwer

(jiwer는 WER/MER/WIL 등 지원.) 
PyPI

옵션: 초소형 대안으로 VOSK 설치 pip install vosk 후 한국어 모델(zip) 받기. 소형 모델은 수십 MB, 경량 기기에서 구동 가능. 
alphacephei.com

실행 (3분)
1) 전사
Bash
# WAV/MP3 입력 -> srt/tsv/text 생성
./build/bin/whisper-cli -m ./models/ggml-small.bin -f input.wav -otxt -of out

(웹브라우저 WASM 데모도 존재—tiny/base 권장.) 
GGML

2) 지연 시간 측정 포인트

TTFW(첫 단어까지 시간): 전사 시작 직후 첫 토큰 출력 시각을 로그로 찍거나, whisper-cli 실행~out.txt 최초 생성 시점을 측정.

RTF(Real‑Time Factor): processing_time / audio_duration (1.0 미만이면 실시간 이상).

3) 정확도(WER) 계산 (파이썬)
Python
실행됨
from jiwer import wer
ref = open("reference.txt").read()   # 정답 원문(사람이 들은 대로)
hyp = open("out.txt").read()         # whisper.cpp 출력
print("WER:", wer(ref, hyp))

(jiwer 사용 예시와 동일한 형태.) 
jitsi.github.io
