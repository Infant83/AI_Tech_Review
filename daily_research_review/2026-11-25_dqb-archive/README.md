# 2026년 11월 25일 DQB · 공개 보관과 편집 브리핑

한영 편집글 「스핀 대칭으로 줄이는 양자상태 준비 비용」은 전체 스핀이 0인 철–황 클러스터 안에서도 부분계의 큰 스핀이 결합한다는 상황에서 시작한다. 고전 DMRG의 축약 MPS가 보존하던 스핀 다중항의 관계를 회로 로딩까지 이어 가는 원리를 설명한다. 원 제목·초록이나 여섯 항목 목록을 옮기지 않고 한영 본문·제목·별도 요약을 작성했다.

## 이어받는 논의와 과학적 범위

기존 `2026-10-03_vqe-energy-subspaces-and-digital-validation`, 「VQE의 현재와 다음 단계: 에너지 최소화, 부분공간 계산, 디지털 검증」의 한영 관련 절을 읽었다. 특히 12절이 다루던 초기 상태의 목표 고유상태 겹침·시간 진화·물리적 오류정정 비용에, 이번 연구의 대칭 보존 로더라는 구체적인 사례를 보탠다. 기존 글의 본문·제목·그림·ID·URL과 승인 대기 심층 기획은 변경하지 않는다.

같은 DMRG 상태를 불러오는 135배·4.9배 Toffoli 절감과 기준 MPS에 대한 절단 충실도를 구별한다. 15비트 회전각, 보조 큐비트 상한 없는 QROAM의 Toffoli 최소화와 발표된 기준 구현을 비교한 조건을 유지한다. 실제 바닥상태 겹침이나 QPE 전체의 물리 실행시간을 측정한 결과로 쓰지 않는다. Fe₄S₄ DMRG가 에너지 수렴 조건을 충족하지 않았다는 사실과 후속 실수 텐서 절감을 포함하지 않은 dense 기준선도 명시했다. 독립적인 유사 선행 프리프린트의 존재는 메타데이터 범위에서 확인했으며 최초·유일한 방법이라고 주장하지 않는다.

QFlow의 26–32큐비트 부모 문제와 8큐비트 부분공간은 확장된 저널판의 결과다. 이전 arXiv 1판과 같은 판본으로 취급하지 않는다. SD/SDTQ 사이의 작은 차이, DMRG 기준 에너지 오차와 변분 상한의 상실을 구별했다. 재료 탐색 논문의 전체 원제·원저자를 복원했고, QUBO 선택·고전 DFT/TDDFT·학습된 물성 예측과 실제 합성·측정을 구별했다. 반복 횟수는 선별 후 평가 수가 같은 전체 예산이 아니다.

AKLT의 실제 2–4자리·2자리 주기 경계 실험, 후선택을 거친 Berry 위상과 최대 40자리 잡음 모사를 나눴다. Regional attention의 최대 1,485배는 GH200 GPU·batch 10 추론과 AWS CPU 수치해법의 특정 비교이며, 학습비용과 실제 장치 폐루프를 포함하지 않는다. Cambridge–IonQ의 광포집·반사율·배치 시점은 설계 예상·성공 조건·계획으로 보존한다.

## 원문·제작·독립 감수

원 DQB 5쪽의 전체 텍스트와 렌더를 읽었다. 원호 날짜·과학 내용·과학 URI 9개를 유지하면서 수집·메일·소셜 문맥, 내부 체크리스트와 검색 메모를 실제 삭제했다. 정정·조건 1쪽과 정식 APS 서지 1쪽을 보탠 최종 공개판은 **7쪽·179,759바이트**, SHA-256 `2de43b257d4110df8e6481b232344fa21221c9f38a39aa295c803b5dbcd940b7`이다. 원 논문 그림·원문 PDF·조사 원문·메일·QA 화면은 공개 파일에 복사하지 않는다.

`dqb1125_spin`은 스핀 적응 논문의 정확한 arXiv 1판과 관련 본문·비교 표·부록, 한영 글·제목·별도 요약을 비작성자로 감수했다. `dqb1125_qflow_materials`는 QFlow 저널 전문·이전 arXiv와 재료 탐색의 공개 승인 원고·조건·그림을 대조했다. `dqb1125_pdf`는 원 PDF의 전쪽·구조·개인정보·권리를 검사하고 공개 파생판을 제작했다. 4·5번 문헌은 전일 DRB의 원문·독립 감수 기록을 재사용하되 현재 승인 원고의 동일 해시·판본과 선택한 본문을 새로 확인했다. 6번 기관 발표는 이번에 새로 읽었다. ## 후보·화면·기존 자료 보존

실제 L016 배포 `32041547d0c4c6c8c236ba90c59105e068543adb`의 불변 release·snapshot·catalog·updates와 해시로 대조한 HTTPS 자료를 기준으로 삼았다. [독립 후보 감수](artifacts/candidate-independent-review.json)는 기존 2,776개 페이로드 경로에서 새 PDF와 한영 페이지 3개만 추가되고 삭제는 없음을 확인했다. 기존 59개 리뷰·175개 보관 문서의 전체 메타데이터, 카탈로그 82건, PDF 290경로·날짜별 편집글 64경로·Classiq 강의 23경로와 L016 두 PDF를 보존했다. 기존 2,700경로의 바이트는 같고 변경 76경로는 파생 목록·검색·등록 자료에 한정된다. 원고→HTML 조각→후보 본문·제목·별도 요약·세 날짜·두 참고문헌과 PDF 연결도 대조했다.

현재 고정 Pillow 11.2.1 환경에서 후보를 만들었다. 관련 로컬 브리핑 검사 25건, 연속성·전송량 검사와 봉인된 전체 2,780파일 검증이 통과했다. 검색 메타데이터와 전체 용량의 기존 비차단 경고는 운영팀(ADOPT)의 기존 추적 범위다. [후보 브라우저 검수](artifacts/candidate-browser-review.json)는 국문 데스크톱·한영 390px 모바일, 실제 언어 전환·인용 이동, 날짜별 편집글 우선 안내와 별도 PDF, 한영 검색·본문 진입을 확인한다. 영문 검색은 초기 포인터 시도와 실제 성공한 키보드 활성화를 구별했다. 실제 PDF HTTP 응답도 등록한 바이트·해시와 같았다. 이 후보 검증은 실제 배포·공개 URL 확인과 별도다.

[실제 브라우저 검사](artifacts/live-browser-review.json)는 한영 390px 모바일 화면, 국문에서 영문으로의 언어 연결, 편집글 우선 목록·날짜 안내, 별도 PDF 읽기·다운로드와 영문 검색을 확인했다. 검색 결과 포인터 활성화는 이동하지 않아 통과로 쓰지 않았고, 정확한 대상 확인 뒤 키보드 Enter로 본문 진입을 확인했다. [완료 증거 독립 감수](artifacts/completion-evidence-review.json)는 두 공개 검증 JSON이 실제 보관 응답과 대응하고 승인 원고·PDF가 그대로임을 확인했다. 이 감수자는 실제 브라우저 동작과 최종 CI 감수를 다시 수행하지 않았다.

[실제 CI 독립 감수](artifacts/ci-independent-review.json)에서 시험 1,082건 중 통과 1,073건·생략 9건·실패 0건이었다. 빌드·Pages 배포·독자 카탈로그 동기화는 성공했고, 동기화 82건·새 알림 대상 0건·대기 이벤트 0건이었다. 현재 복구 사본 2,780파일·856,260,325바이트의 생성·검증·업로드와 현재 실행·소스·업로드 해시 결속을 확인했다. 전체 복구 사본 다운로드·독립 전체 재해시·실제 복원은 수행하지 않았다.

**복구 사본 보존 정리는 미완료다.** 실제 retention 단계는 `incomplete_metadata`로 삭제 전에 거절하고 종료 코드 1을 반환해 `recovery-copy`와 전체 실행은 실패로 기록됐다. 이전 CLI 종료상태 수정은 이번 정상 게시에서 실제 관찰됐다. 후속 읽기 전용 조회는 필터 1쪽 4/4건과 전체 2쪽 114/114건을 모두 확인했으며 미만료 복구 사본은 4개였다. 현재 업로드 성공이나 나중의 완전한 목록을 최신 3개 정리 완료로 해석하지 않는다. 삭제 시도·수동 재시도·코드 변경은 없고 원인도 확정하지 않았다. [기존 운영팀(ADOPT) 일감에 추가한 관찰](../../operations/events/EVT-4988b755-ee5c-4fa6-92f0-257451f2b9b9.json)을 다음 기존 일정에서 이어 확인한다. 편집부(AEDAUT)의 이번 공개 완료와 이 운영 후속 상태를 구별한다.
