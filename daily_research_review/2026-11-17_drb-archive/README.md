# Daily Research Brief · 2026-11-17

편집부(AEDAUT)가 Nature·Artificial Intelligence Review·APS의 공식 목록을 재확인해 작성한 한국어 9쪽 DRB와 짧은 한영 편집글이다. 웹 글은 30 m 저온 링크의 시간 모드 선택과 광학 양자점의 방출 간섭에 초점을 둔다. PDF는 실리콘 정공 소자의 점유수 의존성과 고체 조건부 확률 DFT까지 네 편을 다룬다.

네 논문의 온라인 공개일은 11월 16일이다. PRL 시간 모드 논문은 공개 저자판 v1, PRX Quantum은 최종 출판본, 실리콘 정공 논문은 최종 초록과 2024년 공개 v1, CPDFT는 수정 저자판 v2와 저자 SI를 구별해 읽었다. 온라인 게재를 최초 사전공개와 혼동하지 않는다. Nature Physics의 당일 오류정정 두 편은 DQB와 중복되어 다시 선정하지 않았다. AIR는 별도 최신 목록에 새 관련 리뷰가 없었으며 기존 QML PDF의 원시 바이트 해시 재확인에는 접근 제한이 남았다.

피규어는 목적에 맞춰 구성했다. 시간 모드는 공개 식의 확률진폭과 원 그림의 실측 수신 점유율 9개를 자체 도표로 연결했다. 광학 실험은 CC BY 4.0 최종 출판본 Fig.1(a,f)의 장치와 위상별 출력 패널을 발췌·재배치했다. 정공과 CPDFT는 보고된 사실·수치의 자체 도표를 사용했다. 원 곡선을 임의로 복원하거나 원 실험·전자구조 계산을 재현하지 않았다.

모든 PDF 페이지를 렌더링해 글리프·표·축·범례·캡션·줄바꿈·출처와 공개 적합성을 확인했다. 양자·응집물질 담당자와 별도 편집 감수자가 수치·판본·서지·한영 대응을 교차 검토했다. 책임 편집자는 김현중이며 사람의 문장별 감수는 수행하지 않았다. 심층 리뷰 세 기획은 제안 상태다. 출판 기술은 운영팀(ADOPT)의 기존 절차를 사용한다.

- `reports_data.json`: 새 본문·수치·조사 범위·리뷰 기획과 출처.
- `reports/briefing_ko.md`, `briefing_en.md`: 짧은 웹 편집글과 별도 서지.
- `scripts/build_brief.py`: 한글·수학 기호 글꼴을 임베드하는 PDF 생성기.
- `scripts/draw-temporal-modes.py`: 식으로 만든 진폭과 보고 점유율 도표. 선택적으로 허가된 출판본 패널을 발췌한다.
- `scripts/make_condensed_figures.py`: 명시된 보고값과 방법의 자체 도표.
- `artifacts/figure-manifest.json`: 그림별 판본·출처·권리·변경 범위와 최종 해시.
- `artifacts/public-pdf-qa.json`: 공개 PDF의 해시·구조·검수 범위.

그림 생성기의 글꼴은 명령행 인수로 전달하며 결과는 `artifacts/`에 쓴다. 원문 PDF·전체 원 페이지·메일·개인정보·비공개 링크·내부 경로·QA 화면은 공개하지 않는다. 검수한 PDF는 `daily-research` 시리즈의 독립 ID와 주소로 등록해 같은 날짜 DQB를 보존한다.
