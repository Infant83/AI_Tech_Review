## 제작과 검수

`artifacts/build_public_archive.py`는 호출자가 제공하는 원 PDF·폰트·비공개 QA 경로를 사용한다. 원본 해시와 4쪽 구성을 확인하고, 선언한 삭제·정정 영역 밖의 144 dpi 픽셀 동일성을 검사한다. 재빌드는 `public_reviewed`와 시각·독립 감수 상태를 초기화한다. 원본·메일·원 논문·QA 화면은 저장소에 넣지 않는다.

수집·소셜 경위·내부 검증 메모와 축약 참고문헌을 실제 삭제한다. 원문 진입점 여섯 개를 유지하고 정식 APS 목록에서 원저자·원제·판본을 구별한다. 나머지 과학 구성·표·수치는 해당 정정 영역 밖에서 보존한다.

제작·시각 검수 상태와 최종 해시는 `notes/production-qa.json`, 실제 원문 열람 범위와 역할은 `reports/reference-manifest.json`을 따른다. root와 별도 과학 감수자가 원문 근거를 대조하고 dqb1107_pdf는 문서 구조·본문·렌더·공개 검수를 맡는다. 원 연구의 실험·코드·QPU를 독립 재현하거나 사람 독자 평가를 수행한 기록으로 해석하지 않는다. 공개 등록·배포·실제 URL 확인은 총괄 담당이 별도로 남긴다.

## 원문 대조에 따른 정정

- 원자 전이율은 공통 GRASP 궤도·전이에너지·연산자 행렬을 공유한 비교로 설명했다. 표 I의 계산공간8–12 CSF와 본문의 full-Hamiltonian B=11을 구분하고, 표 II의 표시 정밀도 일치와 계수별 정확도·유효숫자를 혼동하지 않았다. full·축소 계수표의 행 대응을 독립 재구성한 것으로 쓰지 않는다. QAE는 Quantum Annealer Eigensolver로 식별했다.
- GFlowQEC의 비동등 코드 수/평가 횟수와 exact-SAT ladder CPU초당 결과를 분리했다. 같은 CPU에서 PT와 ±5%인 top-code 속도와 PT가 앞선 비동등 코드 수/초, 사전oracle·학습·추론 비용의 범위를 함께 기록했다.
- Gibbs 준비의 가환·bounded-degree 조건과 온도 경로의 최소 Lindbladian gap을 보완했다.
- 회로 합성의 실제 Qiskit/Torino 비용 비교를 복원하고 표2의 잔류 global SWAP, 표준 Toffoli·CALA-n 상대위상 조건과 Article in Press 판본을 구별했다. 원 논문과 직접 대조한 소프트웨어의 개발자·판본도 같은 APS 번호 안에서 크레딧했다.
