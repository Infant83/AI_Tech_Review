# 2026-11-06 Daily Quantum Brief 공개 보관본

원 DQB 4쪽을 원출처와 대조해 조건·판본을 정정하고, 편집 기록 1쪽과 APS 참고문헌 1쪽을 더한 한국어 6쪽 보관본이다. DQB 보관 등록과 새 심층 리뷰의 게재는 별도 작업이다.

## 편집한 범위

- 수집·메일·소셜·학회 검색 상태와 내부 메모, 축약 참고문헌을 실제 삭제했다. 적용 의미 표에서는 연구 결과가 아닌 QML 수집 상태 행을 빼고 기존 세 적용 행을 재조판했다. 나머지 과학 구성·표를 보존하며 최초 인용순 [1]-[5]의 APS 서지를 제시했다.
- Knapsack의 병렬 embedding과 생성 문제군, slackless 하위 QUBO의 평균 성공확률·하위 문제 수를 구별했다. 공식 notebook 설정과 논문 설정이 다르고 전체 실험 재현 코드가 확보되지 않았음을 기록했다.
- Nature의 180원자 실험과 16원자 잡음 수치 모사를 분리했다. 52원자 TEBD의 열린 1D·상호작용 절단·시간창과 유한크기 동역학 상전이 대조의 조건을 보완했다. 2025년 프리프린트와 2026년 Nature 출판을 구분했다.
- Fluxonium의 잘린 공간 차원과 MPS 저장량, 전이 에너지 차이의 수렴 기준, 한 bias의 단일 solve·별도 수렴 연구를 구별했다. 6모드의 전체 수렴 연구 비용을 모든 단일 run의 방법 우열로 확대하지 않는다.
- QAOA는 2026년 PRA 수락과 실제 대조한 2023년 arXiv v2를 구분했다. 큰 회전각의 고유위상 감김과 유한 깊이의 회피교차를 설명하고 수락본 전체와 공개 v2의 동일성을 주장하지 않는다.
- Umbra의 소속과 공식 인프라 발표 상태를 정정했다. 70·438은 IBM 발표가 인용한 값으로 귀속하고 연결 프리프린트 v3의 64 data qubits·314 T gates와의 수치 대응이 확인되지 않았음을 밝혔다. 100,000/438의 산술비를 검증된 QEC 성능 격차로 쓰지 않는다. [5] 안에서 발표 기관과 연결 논문 12명의 크레딧을 세미콜론으로 구분했다.

## 제작과 검수

`artifacts/build_public_archive.py`는 호출자가 제공하는 원 PDF·폰트·비공개 QA 경로를 사용한다. 원본 해시와 4쪽 구성을 확인하고, 선언한 삭제·정정 영역 밖의 144 dpi 픽셀 동일성을 검사한다. 재빌드는 `public_reviewed`와 시각·독립 감수 상태를 초기화한다. 원본과 QA 렌더는 저장소에 넣지 않는다.

제작 담당은 원 4쪽과 공개 6쪽 전체 본문·렌더, 메타데이터·원문 URI·첨부·실행 동작·개인정보와 별도 strict PDF reader를 검사했다. 실제 읽은 범위와 역할은 `reports/reference-manifest.json`, 최종 해시와 감수 상태는 `notes/production-qa.json`을 따른다. 아카이브 등록·배포·실제 URL 확인은 총괄 담당이 별도로 기록한다.

총괄은 [5], 최적화 담당은 [1]·[4], 물리 담당은 [2]·[3]을 대조했다. [2]의 구독 본문 전체와 공식 SI 전체는 읽지 않았으며 출판사 공개 부분·원저자 v1 1–13쪽과 선택 SI 구간의 범위를 명시했다. [5]의 연결 프리프린트는 앞부분과 수치 검색을 확인했으며 57쪽 전체 정독으로 표시하지 않는다. PDF 제작 담당은 구조·본문·렌더를 확인했다. 원 연구의 실험·코드·QPU를 독립 재현하거나 사람 독자 평가를 수행하지 않았다. 원 연구 PDF·도판·코드, 원 메일과 QA 화면은 공개 배포하지 않는다.
