## 원문 대조와 정정

제조 QAOA의 4,096표본은 24개 배치 부분문제의 시험이며 전체 15개 합성 일정은 결정당 768표본을 쓴다. 균등표본 선택기는 전체 일정에서 비교하지 않았다. 14큐비트 시험군 6개는 모두 균등표본보다 최적해 확률이 높아 일률적인 ‘샘플링 우위 없음’ 제목을 고쳤다. 배치별 정확해와 전체 일정의 정확해, 평균 최적해 확률로 계산한 N95와 문제별 보장을 구별했다. 실제 공정 검증과 OLED 적용은 별도 제안 범위다.

GHZ의 27·24큐비트는 오차를 더한 비배제 탐색 경계이며 엄격한 얽힘 인증으로 쓰지 않는다. 측정한 크기 중 엄격한 기준을 통과한 네 장치와 이진 탐색이 건너뛴 크기를 구별했다. 실제 실행은 7–9월이며 업체별 컴파일 설정도 포함한다.

QRAM은 냉각을 제외한 모형이 아니다. 구동 펄스·감쇠와 이상적 Carnot 냉각의 동적 비용을 포함하며 정적 소모를 0으로 둔다. 12는 주소 큐비트 수이고 한 비트 출력을 갖는 전체 회로는 12,298큐비트다. 충실도 하한·고정 운영점과 같은 목표에서 최적화한 전력을 구별하고, 낙관적인 수명·대기 오류·냉각 가정을 함께 남겼다.

광자 반사의 정식 원제, 약한 결맞은 연속파 입력과 모드 정합·공간 필터링을 바로잡았다. 광자 통계, 모드 결합, 전체 검출 사슬과 장시간 평균 반사는 다른 지표다. Cat-QAOA의 정식 제목·출판 이력과 모사 수준을 정정했다. PsiQuantum·AMD 발표의 이미 소개된 연구 사례와 향후 공동설계, D-Wave 시장 포지셔닝과 새 성능 측정을 나누었다. 원문 URI 진입점 8개를 보존한다.
