# Daily Quantum Brief · 2026-10-30 공개 보관본

원 DQB 5쪽에 정정 기록·APS 참고문헌 1쪽을 보탠 한국어 6쪽 보관본이다. 한영 목록은 같은 한국어 PDF를 안내한다. 신규 심층 리뷰 게재와 별개의 공개 아카이브용 자료다.

1쪽의 수집 경위와 5쪽의 소셜·내부 작업 메모, 수집 판정만 담은 표의 마지막 행을 실제 삭제했다. 원본·메일·조사 자료·QA 화면은 공개하지 않는다. 과학 본문의 최초 인용순 [1]-[6]을 유지하고, 짧은 서지를 정식 원제·전 저자·판본을 갖춘 APS 목록으로 옮겼다. 원 [7] D-Wave newsroom은 수집 확인용 목록이며 과학 본문에서 인용하지 않아 제외했다.

2쪽의 VQE 행을 무잡음 고전 최적화로 명확히 하고, 3쪽의 미분 규칙 선택·컴파일 비용과 1·5쪽의 cat-qubit 고전 모사 속도에 비교 분모를 보완했다. 4쪽 DeepH-Polar의 SCF 시간 부재 주장을 바로잡고, 1쪽은 DFT 대비 가속·소비에너지 비교가 없다는 조건으로 명확히 했다. JCTC의 날짜는 출판사 목록에 귀속한다. 6쪽에는 고전 statevector 최적화와 QPU 표본 수집, 큰 진동계의 오차 proxy, 무잡음 7-qubit cost plane과 1,000-qubit schedule compiler, 동일 decay-rate 정밀도까지 누적 전파시간의 조건을 정리했다.

출판 원본은 `dist/2026-10-30-daily-quantum-brief.pdf`, 재생성 코드는 `artifacts/build_public_archive.py`, 정식 서지는 `reports/reference-manifest.json`, 등록 메타데이터는 `reports/archive-entry.json`이다. 호출자가 비공개 원본·글꼴·QA 출력 경로를 전달한다. 빌더는 원본 SHA-256과 5쪽 판본을 확인하며 원본·QA가 공개 저장소 안에 있으면 실행을 거부한다. 아카이브 등록이나 게시를 수행하지 않으며, 재생성 시 시각 검수는 다시 대기 상태가 된다.

재생성에는 Python 3.10 이상과 PyMuPDF·ReportLab·Pillow가 필요하다. `--source-pdf`, `--font-regular`, `--font-bold`, `--font-reference`, `--qa-dir`을 모두 전달한다. 한글 본문에는 NanumGothic, 서지에는 DejaVu Sans의 TrueType 판을 사용했다. 원본 PDF·로컬 글꼴은 이 폴더에 포함하지 않는다.

`dqb_20261030_sqd_resources`는 [1] FeO 13쪽 전체(통합 SI 10-13쪽 포함)와 [2] 진동 계산 42쪽 전체(통합 부록 A-F 포함)를 읽고 핵심 11쪽 렌더 및 진동 코드·예제·raw cost 표의 선택한 부분을 정적으로 대조했다. `dqb_20261030_compiler_trajectories`는 [5] DiffSimuQ 32쪽과 [6] DiSLOU 23쪽 전체·통합 부록·참고문헌을 읽고 핵심 8쪽 렌더와 DiSLOU 코드의 선택한 부분을 정적으로 대조했다. 관련 코드의 개발자 크레딧·커밋과 실제 범위는 참고문헌 manifest에 별도로 보존한다. 코드·benchmark는 실행하지 않았다.

`root`는 [4] DeepH-Polar 17쪽 전체 텍스트와 구조·전기장 응답 도판 두 쪽을 확인했다. [3] JCTC는 공식 출판사 목록·출판사가 제공한 초록·서지 정보만 확인했다. 그 논문의 본문·SI에 접근하지 못했으며 별도 SI 파일이나 특허를 확인했다고 표시하지 않는다. `dqb_20261030_pdf`는 원 DQB 전체 5쪽과 최종 6쪽의 렌더를 각각 모두 열고 공개 사본 제작·일차 개인정보 및 출력 검사를 수행했다.

선언한 변경 영역 밖의 원 5쪽은 144 dpi 픽셀이 같다. 최종 본문·메타데이터·XML·URI·첨부·실행 동작·위젯을 점검하고 pypdf로 다시 추출한 텍스트에서도 삭제 항목·개인 메일·내부 경로가 없음을 확인했다. 최종 원문 URI 주석 13개는 여섯 개 과학 출처에 연결하며, arXiv 링크는 검토한 v1으로 식별한다. 일차 최종 렌더에서 잘림·겹침·깨진 글자·서지 넘침을 발견하지 못했다. 실제 실행·자료 대조·시각 검사 범위와 root의 별도 검수 상태는 `notes/production-qa.json`에 기록한다. 정확한 실행 모델 식별자는 미보존이다. 원 논문의 실험·DFT·QPU·학습·전체 benchmark를 독립 재현하거나 사람이 문장별 심사한 것으로 표시하지 않는다. 별도 심층 리뷰와 기존 본문의 실질적 확장은 각 기획의 승인 상태에 따라 관리한다.

권리는 출처 표기와 구분한다. 사용자가 제공한 DQB의 본문·표를 공개 보관 목적으로 편집하며, 원 논문의 PDF·도판·수집 파일을 재배포하지 않는다. 원 논문·코드의 권리는 각 저자·권리자에게 있고 이 보관본에 일괄 자유이용 허가를 부여하지 않는다.

`root`가 최종 6쪽 렌더를 독립적으로 열어 정정·표·서지·글자와 배치를 확인했고, 과학 감수 역할이 최종 PDF 전체 텍스트·관련 서지·코드 크레딧·한영 소개를 다시 대조했다. 아카이브·목록·브리핑·공개 정보 보호 검사 58건과 공개 배포 검사 1,654개 파일을 통과했다. 한영 브리핑·아카이브 네 경로를 320·390·1280px에서 확인했고 새 제목·PDF 링크와 파일 해시가 일치했다. 영문 브리핑의 원문 한국어 제목은 글꼴 로딩 완료 후 화면에서도 확인했다. 실제 휴대폰이나 사람 독자 평가는 수행하지 않았다. 기존 93개 PDF·등록 정보와 50개 리뷰 목록·본문을 유지한다. 공개 완료는 배포 후 실제 HTTPS URL 확인 기록과 구분한다.
