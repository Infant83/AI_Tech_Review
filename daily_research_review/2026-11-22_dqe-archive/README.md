# DQE · 운전 가능한 발전 계획의 비용

원호·공개판 편집·웹 갱신·근거 기준일은 2026-11-22다. 사용자 승인에 따라 편집부(AEDAUT)가 독립 감수·짧은 한영 안내를 작성하고 운영팀(ADOPT)의 기존 도구로 등록한다. 같은 날짜 DQB·DRB와 기존 ID·본문·PDF·주소, 11월 17일 요청형 NTCA DQE를 보존한다. 문제 생성·메일 발송 예약은 변경하지 않는다.

## 문제와 실제 열람

이진 가동 선택과 연속 출력의 연결, 최소 출력과 기동비가 바꾸는 유효 계획, QAOA·고전 최적화의 분업과 전체 비용을 다룬다. 수치 해설·판정은 기본 접힌 영역에 두며 PDF 문제는 1쪽, 해설은 2쪽부터 안내한다. 별도의 한영 목록 요약도 감수했다. 실제 읽은 기존 풀스택 리뷰의 전력 운영·가스망 사례를 연결하며 서로 다른 알고리즘과 실행 수준을 유지한다.

`root`가 집필·통합하고 `dqe_science_1118`이 원 PDF 4쪽과 한영 원고·요약·참고문헌을 독립 감수했다. 가동 조합 16개와 기동 지표 조합 16개를 대조하고 출력은 격자로 이산화하지 않은 해석적 선형계획으로 검산했다. 최소·최대 출력과 수급을 만족하는 조합, 양의 기동비 아래 최적 기동 지표, 변동비·기동비·시간 단위·44초 견적을 확인했다. [검산 코드](artifacts/science/verify_exercise.py)·[계산 결과](artifacts/science/calculations.json)·[과학·출처·편집 감사](artifacts/science/scientific-reference-audit.json)에 실제 범위를 기록한다. 임의의 유한 불가능 비용을 둔 추가 반례는 원래 네 비트의 값 함수가 자동으로 이차식이 되지 않음을 보여주는 자체 계산이며 논문의 구현으로 표시하지 않는다.

PyPSA 공식 문서의 가동 상태·출력 범위·기동 전환·초기 상태·최소 가동시간·램프 설명을 읽었다. Koretsky 등의 공개 저자판 v1 전체 7쪽을 읽고 IEEE가 등록한 Crossref DOI 서지의 정식 제목·학술대회·쪽수·저자 11명을 대조했다. IEEE 페이지 본문은 자바스크립트 확인 절차로 열람하지 못했다. 논문의 바깥 고전 최적화가 출력·슬랙·QAOA 매개변수를 함께 조정하는 방식과 이 교육용 문제의 조합별 출력 검증을 구분한다. 논문은 Qiskit 시뮬레이션이며, 실제 QPU 우위 자료로 사용하지 않는다. 논문의 수치·벌점 정식화 동등성·고전 벤치마크를 독립 재현하거나 PyPSA·Qiskit·실제 QPU를 실행하지 않았다. 사람의 문장별 감수나 독자 평가를 수행한 것으로 표시하지 않는다.

## PDF 공개판

4쪽 공개 파생판은 과학 문제·해설·수식·원호 날짜를 보존한다. 4쪽의 최근 주제·메일 확인 이력·내부 수집 및 편집 메모를 실제 삭제하고 참고문헌의 전체 저자·정식 원제·출판 정보를 보완했다. 원 과학 URI 2개를 유지하고 출판 DOI를 추가했다. 제3자 논문 그림·본문·코드를 복제하지 않았으며 사용자 승인 자체 교육용 문제의 공개 범위로 등록한다. 제3자 자료 전체의 재배포 권리를 주장하지 않는다.

`dqe_pdf_1118`은 원본·공개판 전 페이지를 PyMuPDF 144dpi와 별도 Poppler 110dpi로 렌더해 읽고 구조·메타데이터·개인정보·URI·첨부·실행 동작·폰트 임베딩을 검사했다. `root`도 원본과 최종 공개판 총 8개 렌더를 독립 확인했다. 1–3쪽의 추출 본문·픽셀은 같고, 4쪽의 선언 편집 영역 밖 픽셀 변경은 없다. [PDF QA](artifacts/public-pdf-qa.json)에 실제 검증 범위와 한계를 기록한다. 공개 PDF는 73,480바이트, SHA-256 `605ba96a65488e8a15a7190f533f2993292e4d9472b7cfa0901b3e3bd09d724d`다. 원본·메일 식별정보·QA 화면·내부 경로는 비공개로 보존한다.
