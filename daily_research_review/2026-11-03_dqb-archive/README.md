# 2026-11-03 Daily Quantum Brief 공개 보관본

원 DQB의 과학 구성·표를 유지하면서 원출처 대조로 오류와 조건을 정정한 한국어 6쪽 보관본이다. 새 심층 리뷰 게재와 원 실험의 재현은 이 자료의 제작 범위에 포함하지 않는다.

## 편집한 범위

- 원 5쪽에서 자료 수집·메일·소셜 경위와 내부 메모를 실제 삭제했다. 최초 인용순에 따라 원제·전 저자·판본을 갖춘 APS 참고문헌 [1]-[7]과 정정 기록 1쪽을 더했다.
- QML의 실제 시간순 실행과 outcome-sorted replay를 구별했다. 원 논문에서 확인하지 못한 finite-sampling 상대 배율·fidelity-kernel 회로 수를 보고 결과처럼 쓴 문장은 삭제하고, 실제 측정 feature와 job-purged split의 의미를 보완했다.
- eCAS의 MP2 RDM 전처리와 localized CAS 결합 조건, 분자 QML의 basis·분할 조건을 명시했다. FCI는 Hamiltonian 전체 시간 발전 대신 target state 준비와 current 재구성의 범위로 정정했다.
- FPGA core 지연·통신 지연·합성 맥락의 power 보고와 실제 QPU 제어를 나눴다. 오류율의 논리큐비트·round 분모와 다중 round 모사, 세 core ensemble의 모사 상태를 구별했다.
- 의료 QML의 잘못된 원저자·제목을 바로잡고, 91.90%의 비교 범위를 Fig.9의 고전 기준선으로 한정했다. 서로 다른 solver·QPU 조건을 묶은 시간 범위 표기는 삭제했다. 9월 9일 저널 출판과 11월 2일 공식 발표를 별도 서지로 제시했다.

## 제작과 검수

`artifacts/build_public_archive.py`는 호출자가 제공하는 원 PDF와 폰트, 비공개 QA 출력 경로를 받아 제작한다. 원본 해시와 5쪽 구성을 확인하며 재빌드하면 기존 검수 승인을 초기화한다. 원본·폰트·렌더를 저장소에 복사하지 않는다.

원 5쪽의 선언 영역 밖 144 dpi 픽셀 동일성, 최종 6쪽 전체 렌더, 본문·메타데이터·URI·첨부·실행 동작·개인정보와 별도 strict PDF reader를 확인한다. 정확한 최종 해시·실제 열람 범위·역할·상태는 `notes/production-qa.json`과 `reports/reference-manifest.json`을 따른다. 새 DQB의 아카이브 등록·배포·실제 URL 검증은 총괄 작업의 별도 단계다.

QML 담당은 [1]·[6]·[7], 양자화학 담당은 [2]-[4], 총괄은 [5]의 원문을 대조했다. PDF 제작 담당은 원 5쪽과 공개 6쪽의 구조·본문·렌더를 확인했다. 논문의 데이터·장치 실행·코드를 독립 재현하거나 사람 독자 평가를 수행하지 않았다. 원 논문 PDF·도판·코드, 원 메일과 QA 화면은 공개 배포하지 않는다.
