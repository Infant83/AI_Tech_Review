# 2026-11-05 Daily Quantum Brief 공개 보관본

원 DQB 4쪽의 과학 구성과 표를 유지하며 원출처 대조로 조건과 판본을 정정하고, 편집 기록 1쪽과 APS 참고문헌 1쪽을 더한 한국어 6쪽 보관본이다. DQB 보관 등록과 새 심층 리뷰의 게재는 별도 작업이다.

## 편집한 범위

- 수집·메일·소셜 경위, 내부 검증 메모와 축약 참고문헌을 실제 삭제했다. 원저자·원제·판본을 대조한 최초 인용순 APS 참고문헌 [1]-[5]를 제시했다. [3]의 arXiv v1 논문과 후속 software 2.0은 같은 번호에서 각각 저자·원제·식별자를 밝혀 세미콜론으로 구별했다.
- Stride의 15초·120초 결과와 이전 제품에 대한 최적해 근접도 개선 배수를 유지했다. 이 수치를 고전 solver 대비 속도비로 읽지 않도록 분모와 공개 근거의 범위를 보완했다. 두 프리프린트의 최초 공개일은 11월 3일 UTC로 정정했다.
- VQC의 Fourier rank 조건을 지정한 encoding·basis·readout의 고정 support별 조건으로 한정했다. Rank≤1은 일반적 표현 가능성의 충분조건이 아니다. QFIM 포화와 readout 차원이 정확도 최적점을 결정하지 않는다는 Table2 결과와 Madelon의 분할·특징 선택·seed 조건을 보완했다.
- Born evidence는 입력에서 분모를 고정한 경로의 class probability와 무정보 기준값 간 차이에 합산됨을 명시했다. v1의 hybrid evidence 보정 실패와 software 2.0의 후속 보고를 구별하고 실제 공식 코드 진입점을 정정했다. 4 data qubits+ancilla, 특정 overlap 상관의 표본과 별도 23큐비트 coherent layer의 컴파일 범위를 구별했다. v2 논문 전체를 읽거나 코드의 상관을 재계산한 것으로 표시하지 않는다.
- Pandora의 정식 원제와 동료평가 채택본 상태를 표시하고 Fermi-Hubbard 전체 컴파일, Shor 고수준 회로·부분 연산 분해, 특정 rewrite 비교와 디스크 표현량을 구분했다. 11월 2일에 읽은 동일 판본과 코드의 검토를 재사용하며 재확인한 범위를 남겼다.
- QAOA–QWS의 고정 5,000초 실험과 별도 수렴 실험을 나누고, 관광객당 효용·20 runs 평균과 표준편차·CPU MPS·active block·후보 재가중의 범위를 명시했다. 논문 PDF·도판·코드를 재배포하지 않는다.

## 제작과 검수

`artifacts/build_public_archive.py`는 호출자가 제공하는 원 PDF·폰트·비공개 QA 경로를 사용한다. 원본 해시와 4쪽 구성을 확인하고, 선언한 삭제·정정 영역 밖의 144 dpi 픽셀 동일성을 검사한다. 재빌드는 `public_reviewed`와 시각·독립 감수 상태를 초기화한다. 원본과 QA 렌더는 저장소에 넣지 않는다.

제작 담당은 원 4쪽과 공개 6쪽 전체 본문·렌더, 메타데이터·원문 URI·첨부·실행 동작·개인정보와 별도 strict PDF reader를 검사했다. 실제 읽은 범위와 역할은 `reports/reference-manifest.json`, 최종 해시와 감수 상태는 `notes/production-qa.json`을 따른다. 아카이브 등록·배포·실제 URL 확인은 총괄 담당이 별도로 기록한다.

총괄은 [1], QML 담당은 [2]-[3], tooling 담당은 [4]-[5]의 원문을 대조했다. PDF 제작 담당은 구조·본문·렌더를 확인했다. 원 논문의 실험·코드·데이터를 독립 재현하거나 사람 독자 평가를 수행하지 않았다. 원 연구 PDF·도판·코드, 원 메일과 QA 화면은 공개 배포하지 않는다.
