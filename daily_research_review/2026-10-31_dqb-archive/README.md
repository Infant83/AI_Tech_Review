# Daily Quantum Brief · 2026-10-31 공개 보관본

원 DQB 5쪽에 편집 정정·조건 보완·APS 참고문헌 1쪽을 보탠 한국어 6쪽 보관본이다. 한영 목록은 같은 한국어 PDF를 안내한다. 신규 심층 리뷰 게재와 별개인 승인된 공개 보관 흐름의 자료다.

1쪽의 수집 경위, 3쪽의 메일 점검 블록, 5쪽의 수집 판정 행·소셜 및 내부 메모를 실제 삭제했다. 짧은 서지는 본문 최초 인용순 [1]-[5]의 정식 원제·전 저자·판본을 갖춘 APS 목록으로 옮겼다. Quntur의 잘못된 원저자명을 정정했다. 원본·메일·조사 원문·QA 화면은 이 폴더에 포함하지 않는다.

손상된 분자식·지수·자화 첨자는 원 논문과 대조해 복원했다. VGSQD의 60 spatial orbital과 120 data qubit+4 ancilla를 구분하고, 최적 구조와 고정 구조 에너지의 조건을 보완했다. VULCAN은 VDBF 유도 연산자와 minimal complete pool을 결합하며 후보 선택용 Hamiltonian-gradient 측정을 줄이는 방법으로 명확히 했다. 주요 자원 비교의 GPU 모사와 별도 H₂ 분자 장치 예비실행을 구분했다. Quntur의 기본 32사례 비용과 반복실행 비용, 48% MAE 비교와 state-character 문제를 바로잡았다. 희귀 신호 감지는 평균 논리 위상의 차수와 이론 모형의 조건을 명시했다. 정정 및 보완은 마지막 쪽에 기록했다.

출판용 파일은 `dist/2026-10-31-daily-quantum-brief.pdf`, 재생성 코드는 `artifacts/build_public_archive.py`, 원전 서지는 `reports/reference-manifest.json`, 등록용 소개는 `reports/archive-entry.json`이다. 목록의 한영 소개는 분자 구조를 바꿀 때 표본을 재사용하는 구체적 과학 관계로 작성했다. 원 DQB의 제목과 과학 도표·수치는 검증한 정정 영역을 제외하고 보존했다.

재생성에는 Python 3.10 이상과 PyMuPDF·ReportLab·Pillow가 필요하다. 호출자가 `--source-pdf`, `--font-regular`, `--font-bold`, `--font-reference`, `--qa-dir`을 모두 전달한다. 본문에는 NanumGothic, 손상 기호 복원의 대체 글꼴과 영문 서지에는 DejaVu Sans TrueType 판을 사용했다. 로컬 글꼴과 비공개 원본을 공개 저장소에 포함하지 않는다. 빌더는 원본 SHA-256과 5쪽 판본을 확인하고 원본 또는 QA 경로가 저장소 안이면 거부한다. 아카이브 등록·게시를 수행하지 않으며 재생성하면 시각 검수 상태가 대기로 돌아간다. 임베디드 글꼴 CMap의 비 BMP 문자는 UTF-16BE로 정규화해 보조 PDF 판독기의 경고도 확인했다.

`root`는 [1] VGSQD 전체 19쪽과 핵심 6쪽 렌더를 확인했다. `dqb1031_chemistry`는 [3] VULCAN 전체 20쪽 및 [4] Quntur의 통합 SI를 포함한 전체 51쪽과 핵심 12쪽 렌더를 확인했다. VULCAN 별도 SI는 확보하지 못했다. Quntur의 외부 데이터는 공식 Borealis 메타데이터·파일 목록만 확인했으며 아카이브 payload는 읽지 않았다. `dqb1031_optimization_sensing`은 [2] GMFI 전체 27쪽과 [5] PRL 본문 7쪽·SM 8쪽 및 핵심 8쪽 렌더를 확인했다. 접근이 막힌 코드·데이터의 내용이나 판본을 확인했다고 표시하지 않았다. 원전별 실제 열람 범위와 데이터 크레딧은 참고문헌 manifest에 보존한다.

`dqb1031_pdf`는 원 DQB 5쪽 및 최종 공개 사본 6쪽 렌더를 모두 열고 조판·글리프·정정·서지를 일차 확인했다. 선언한 변경 영역 밖 원 5쪽은 144 dpi 픽셀이 같다. 본문·메타데이터·XML·URI·첨부·실행 동작·위젯을 검사하고 별도 pypdf 추출로 삭제 항목·개인 주소·내부 경로 및 판독 경고를 재검사했다. 실행 범위와 별도 최종 검수 상태는 `notes/production-qa.json`에 기록한다. 정확한 실행 모델 식별자와 원 DQB 작성 세션의 에이전트 구성은 미보존이다. 원 논문의 실험·QPU·ORCA·전체 benchmark를 독립 재현하거나 사람이 문장별 심사한 것으로 표시하지 않는다.

권리는 출처 표기와 구분한다. 사용자가 제공한 DQB의 본문·표를 승인된 공개 보관 목적으로 편집한다. 원 논문의 PDF·도판·수집 파일을 재배포하지 않으며 원 논문·코드·데이터의 권리는 각 저자·권리자에게 있다. 원 자료에 이 보관본의 일괄 자유이용 허가를 부여하지 않는다.

공개 등록과 배포는 최종 독립 검수 이후 담당 흐름에서 수행한다. 제작·검수 완료와 실제 공개 URL 확인은 별개 상태로 관리한다.

최종 해시의 과학 문구·표·APS와 한영 소개를 과학 감수 두 역할이 다시 대조했고, `root`는 여섯 쪽 렌더와 전체 텍스트를 별도로 확인했다. 마지막 쪽 정정 후 재열람과 최종 CMap 정규화 이후 무경고 추출·픽셀 동일성 검사를 함께 사용했다. 관련 검사 58건과 공개 배포 검사 1,643개 파일을 통과했다. 한영 브리핑·아카이브 네 경로를 320·390·1280px에서 확인하고, 글꼴 로딩 완료 후 영문 브리핑의 한국어 원문 제목도 시각 확인했다. 새 링크의 PDF는 출판 원본·아카이브·사이트 사본과 해시가 같다. 기존 94개 PDF·등록 정보, 50개 리뷰 목록·1,470개 리뷰 파일과 기존 독자 업데이트 117개를 유지한다. 실제 휴대폰·사람 독자 평가는 수행하지 않았다.
