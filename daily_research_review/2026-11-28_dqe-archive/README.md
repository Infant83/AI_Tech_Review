## 과학·원출처·한영 검토

AEDAUT의 별도 담당자가 원 PDF 3쪽의 전체 추출문을 읽고 조건·그림 설명·단위·수식·답을 확인했다. `artifacts/science/verify_exercise.py`는 16개 배정의 원래 F·QUBO·Ising 값을 독립 계산하고 조건별 하한·가운데 가중치의 경계·채널 반전·MaxCut·회로 항 수·시간 예산을 확인한다. P5는 원호가 준 합성 시험 입력으로 취급하며, 없는 단말 표본에서 분위수를 계산했다고 표시하지 않는다. 두 배정의 시험값을 다른 배정이나 반전 배정에 옮기지 않는다. 실제 무선망·회로 모사·QPU 실험은 수행하지 않았다.

Cisco RRM Release 8.5의 개요와 DCA, ZIB의 주파수 배정·고정 채널 분류·MI-FAP 본문을 직접 읽었다. ZIB의 원호 표기는 웹페이지의 하위 절 제목이며 정식 참고문헌에는 전체 페이지 제목과 마지막 수정일을 적었다. 이를 발행일로 바꾸지 않았다. Harrigan 등의 공식 Google 소개·다운로드 기술 본문 1–5쪽과 PDF 8쪽 S1/Table S1을 확인했다. 나머지 보충자료 전체를 읽거나 원 실험을 재현하지 않았다. Google 기술 파일의 미완성 출판일 표기를 최종 출판 정보로 쓰지 않고 출판사 등록 Crossref로 저자 86명·정식 서지·온라인 날짜를 대조했다. QML 10강의 국문 자료 분할·대응 비교·공정한 평가 설명을 읽어 새 교대 부하의 시험 설계에 연결했다. 한영 원고·제목·별도 요약의 의미와 근거·처리량 범위·접힌 해설을 독립 감수했다. 고전·양자 경로의 동일 그래프 비교와 기존 컨트롤러의 동일 부하 비교를 분리해, 확인하지 않은 컨트롤러 API를 전제하지 않도록 다듬었다. 상세 계산·출처·최종 원고 결속은 `artifacts/science/scientific-reference-audit.json`을 따른다.

## 그림·PDF·공개 적합성

원본은 공개 저장소 밖에 보존한다. 공개판은 원 1–2쪽의 추출문과 144 dpi 픽셀이 같고, 3쪽의 최근 학습 이력 삭제 사각형 밖 픽셀도 같다. 두 그래프의 꼭짓점·변·가중치·채널 표시·캡션을 그대로 보존했다. 그림은 원호의 합성 교육 도식이며 외부 연구의 결과 그림을 복제하지 않았다. 원호 1/3–3/3 표시는 원래 구성임을 부록에서 설명한다.
