# 2026년 11월 23일 DQB · 공개 보관과 편집 브리핑

한영 편집글 「적게 측정한 분자 에너지의 오차를 읽는 법」은 물속 아미노산 잔기쌍의 작은 활성공간에서 에너지를 읽는 상황으로 시작한다. 중요한 에너지 성분이 적은 시간 신호와, 변분 매개변수별로 다른 기울기 기여도를 이용하는 두 측정 선택의 물리적 원리를 설명한다. 원 제목·초록·연구 목록을 옮기지 않고 별도 한영 제목과 요약을 작성한다.

## 원문 조건과 정정

희소 QPD는 실제 Helios 장치의 자료를 사용했지만, 128개 시간점의 한 취득 자료에서 50개씩 고른 부분집합 200개를 복원한 분석이다. 200회의 독립 QPU 실행이나 처음부터 50개 시간점만 측정한 실증으로 표현하지 않는다. 두 공간 궤도·두 전자를 남긴 내장 활성공간과 생체분자 전체를 구별한다. 1.54 mHa는 균일 선택 복원의 오차 중앙값이고 1.77 mHa는 사분위범위다. 모든 추정값의 화학 정확도나 다른 방식에 대한 정확도 우열을 보장하지 않는다.

VQA 측정 선택의 평균 49.6%는 정확한 기대값을 쓰는 모의 계산의 기울기 샷 계상이다. 5.67 mHa는 Full-QWC와의 평균 절대 차이이며 정확한 분자 에너지에 대한 오차와 구별한다. 학습용 정답 기여도와 선택기 준비 비용을 제외한 절감을 전체 실행시간의 이득으로 바꾸지 않는다.

원 DQB의 다른 네 항목도 원출처·정식 서지·판본과 대조했다. QAN의 정확한 원제와 작은 모형·mean-field의 경계, 위상도 탐색 정리의 올바른 기준 상태·분해능·검출 조건을 유지한다. NestedLoRA의 원 브리핑 K^1.1 대 K^2.5 값은 이전 연구의 비교여서 새 방법의 자체 fit으로 제시하지 않는다. 구현 공개를 예고하는 README와 실제 구현 공개도 구별한다. QVib는 고전 ML 힘장·분자동역학이며 양자 장치 결과가 아니다. 원 DQB의 공개 파생판에 교정과 판본 기록을 명시하고 원호 날짜는 유지한다.
