## 근거와 검토

- Ochoa et al., [arXiv:2610.28528v1](https://arxiv.org/html/2610.28528v1).

`root`가 서문과 한영 설명을 집필·게시하고, `dqb_dmft_insight`가 DMFT 원문과 문장을, `dqb_computational_insights`가 고전 가속·표본추출 주장과 한영 설명을 별도로 감수했다. `dqb_archive_workflow`가 PDF 보관본 제작과 전체 페이지·메타데이터·링크 검수를 맡았다. 정확한 모델 식별자는 미보존이며 원 논문 계산·QPU 실험을 독립 재현한 작업은 아니다. 사람의 문장별 전체 검토는 수행하지 않았다.

## 보관과 재생성

원 PDF의 과학 본문과 직접 링크는 유지하며, 공개본에서는 자료·메일 수집 경위만 제거하고 편집자 서문을 앞에 붙인다. 원본·연구 메모·QA 이미지는 제외 설정된 `research/`·`tmp/`에 보관하며 사이트나 Git에 포함하지 않는다. 공개 사이트에는 명시 등록한 최종 PDF와 검토한 목록 설명만 배포한다.

재생성은 제작 코드의 `--help`를 따른다. PDF 입력·정규/굵은 한글 TTF 글꼴을 지정하면 서문과 정제한 본문을 합친다. 과학 계산 재현 코드가 아니라 문서 조판·보관본 제작 코드다.
