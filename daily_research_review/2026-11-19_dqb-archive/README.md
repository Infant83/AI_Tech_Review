# 2026년 11월 19일 DQB · 공개 보관과 편집 브리핑

한영 편집글 「작은 양자 공간에서 빠진 상관을 되찾다」는 분자를 작은 회로에 담을 때 제외하는 상태와 결합에서 출발한다. SSPT의 안정자 투영·외부 공간·섭동 보정을 설명하고, LiH 결합 길이의 근접준위 실패와 복구를 기존 VQE 리뷰의 누락 상태 문제에 연결했다. 목록 요약은 본문 도입과 별도로 작성했다. 원호·웹 작성·추가 근거 기준일은 2026년 11월 19일이다.

## 근거와 조건

SSPT 사전공개본의 본문·부록을 읽고 종·정렬·레지스터·기준 에너지와 측정 비용을 대조했다. 보정 대상은 같은 궤도 공간에서 안정자 투영으로 버린 결합이다. 정확한 대칭을 이용하는 tapering과 구별하고, 단일 구조의 LiH·BeH+와 별도의 BeH2 시험을 나누었다. 상태벡터 기대값·비변분적 보정·근접준위 처리와 H2CO의 CASSCF 활성공간 기준도 기록했다.

별도 담당자가 QPV의 공격자·위치 부피 조건, fast-feedback의 일반 잡음 보정과 이상적 QEC 시험, Pêlagos의 GPU당 고정 작업량·코드별 처리량 분모, 멀티모드 cat의 유효 모형·실제 수치 모사·disorder 분석 범위를 대조했다. 공개 저널 초록·메타데이터, 접근 가능한 프리프린트·선택 보충 절과 공식 코드를 실제 읽은 범위로 구별한다. [원출처·열람 범위](artifacts/reference-manifest.json)를 따르며 구독 본문 전체·QPU·원 실험·GPU 성능 재현으로 표시하지 않는다.

## 작성과 공개 검수

root가 SSPT 및 기존 글 대조·한영 집필·요약·통합을 맡고, `dqb1119_systems`가 나머지 원출처와 한영 편집글·요약·최종 PDF를 독립 감수한다. `dqb1119_pdf`는 원 4쪽 전체를 읽고 공개용 삭제·정정·PDF 제작·구조·권리·개인정보·렌더를 검사한다. 독립 담당자가 최종 PDF 6쪽 전체와 한영 편집글·요약을 감수했다. M·L·r 정의를 추가한 마지막 판본은 해당 쪽을 다시 보고 나머지 5쪽의 동일성을 확인했다. 실제 공개 결과는 배포 후 별도로 기록한다. 원 메일·첨부 원본·개인정보·원 논문 파일·QA 화면은 공개하지 않는다. 신규 심층 리뷰·다른 기존 본문 확장은 포함하지 않는다.

## 배포 후보

실제 이전 공개 릴리스 `0e15eb2ec0e516ebcc8e5da12a3addbd7f58447b`의 불변 스냅샷과 대조했다. 두 호를 합친 독립 후보는 58개 기존 리뷰의 1,933개 파일과 기존 PDF 255개 경로를 바이트로 보존했다. 152개 보관 PDF·74개 독자 목록·봉인 산출물 2,680개 검증과 연속성 검사를 통과했다. Python 검사 409개 중 408개 통과·1개 제외·실패 0이다. 실제 브라우저에서 한영 본문·날짜·390 px 화면, 날짜 선택·검색의 편집글 우선 안내와 별도 PDF 링크·인용 이동을 확인했다. 기존 검색 메타데이터·전체 아티팩트 용량 경고는 운영팀(ADOPT)의 용량 관리 대상으로 남아 있다. 이는 실제 공개 배포 전 후보 검수 기록이다.

배포 직전 동시 게시된 11월 18일 DQE와 운영 기록을 최신 원격 기준으로 통합했다. 공통 아카이브 안내의 두 작업 기록을 모두 유지했고 DQE의 PDF·한영 본문은 정확히 보존했다. 최종 통합 후보의 새 DQB 한영 본문 네 개·PDF 두 개는 브라우저에서 검수한 후보와 바이트가 같다. 11월 18일 달력 선택에 DQE와 DQB가 함께 표시되고 각각의 글·PDF로 연결됨을 실제 브라우저에서 확인했다.
