# 2026-11-04 Daily Quantum Brief 공개 보관본

원 DQB 4쪽의 과학 구성과 표를 유지하면서 원출처 대조로 오류와 조건을 정정하고, 정정 기록과 APS 참고문헌 1쪽을 더한 한국어 5쪽 보관본이다. DQB 보관 등록과 새 심층 리뷰의 게재는 별도 작업이다.

## 편집한 범위

- 원 자료의 수집·메일·소셜 경위, 내부 메모와 불완전한 참고문헌을 실제 삭제했다. 원제·전 저자·판본과 최초 인용 순서에 맞춘 APS 참고문헌 [1]-[5]을 제시했다. 실제 읽은 arXiv 판본은 정식 저널 인용과 구분해 편집 기록에 연결했다.
- 큐비트의 물리적 주파수 전환을 멈춘다는 제목을 주파수 branch에 맞춰 제어 프레임을 바꾸는 제목으로 정정했다. 강결합 TLS의 추정, single-qubit RB의 평균·시간 변동·최대값 비교 조건을 구별했다.
- Pauli fluctuation 절단과 고정 threshold별 trajectory의 zero-variance 외삽을 명시했다. Heisenberg 100큐비트와 Hubbard의 128 JW 큐비트를 구별하고, 2.5분·53.6시간의 하드웨어·오차 조건, 상계 부재와 에너지·물성 정확도의 차이를 보완했다. HBC의 84큐비트는 고전 active-space 표현으로 다뤘다.
- CE QEC의 동료평가 채택본과 arXiv 판본의 예시 코드를 구별하고, collective Z 잡음·native 게이트·fault 차수에 따른 모사 범위를 명시했다.
- MARQUIS의 Princeton 주도와 최초 발표일을 UCSB 설명 기사 날짜와 구별했다. 확인되지 않은 DFT 결과 표기를 제일원리 결함 계산 계획으로 정정하고, 100배 넘는 footprint 축소를 설계 목표로 표시했다. Toyota 협력의 지향 연구비와 20년의 연구 전망을 구분했다.

## 제작과 검수

`artifacts/build_public_archive.py`는 호출자가 제공하는 원 PDF·폰트·비공개 QA 경로를 사용한다. 원본 해시와 4쪽 구성을 확인하고, 선언한 삭제·정정 영역 밖의 144 dpi 픽셀 동일성을 검사한다. 재빌드는 검수 상태와 `public_reviewed`를 초기화한다. 원본·QA 렌더는 저장소에 넣지 않는다.

제작 검수는 최종 5쪽 전체 렌더, 본문·메타데이터·6개 원문 URI·첨부·실행 동작·개인정보, 별도 strict PDF reader를 대상으로 한다. 실제 읽은 범위와 역할은 `reports/reference-manifest.json`, 최종 해시와 검수 상태는 `notes/production-qa.json`을 따른다. 제작자의 검수와 독립 원문 감수, 아카이브 등록·배포·실제 URL 확인을 별도로 기록한다.

총괄은 [1], Pauli 담당은 [2], QEC·산업 담당은 [3]-[5]의 원문을 대조했다. PDF 제작 담당은 원 4쪽과 공개 5쪽의 구조·본문·렌더를 확인했다. 논문의 실험·코드·데이터를 독립 재현하거나 사람 독자 평가를 수행하지 않았다. 원 연구 PDF·도판·코드, 원 메일과 QA 화면은 공개 배포하지 않는다.
