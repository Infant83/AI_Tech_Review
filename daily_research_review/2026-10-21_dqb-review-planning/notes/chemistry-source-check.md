확인일: 2026-10-21. 대상은 두 논문의 **v1**과 DQB의 화학 부분(2–3쪽)이다. 페이지는 PDF의 인쇄 쪽수이며 HTML 절 번호와 함께 표기했다. 정책·방법을 읽고 원문 HTML, PDF 본문·보충자료를 대조했으며, 주요 표를 렌더링해 열·단위도 확인했다. 아래 수치는 논문 보고값이다. **논문 계산·회로·QPU 실행의 독립 재현은 하지 않았다.** 원문·QA 이미지는 이 노트에 재배포하지 않는다.

## 1. 혼합 추정량: 수백 샷과 실제 장치 결과의 조건

원문: [Lenihan et al., arXiv:2610.26689v1](https://arxiv.org/abs/2610.26689v1), [HTML](https://arxiv.org/html/2610.26689v1), [PDF](https://arxiv.org/pdf/2610.26689v1). 프리프린트.

| 확인 항목 | 원문 위치·판정 |
|---|---|
| 추정량 | §2.1, pp.4–5, 식(1)–(4): \(E_{ME}=\langle\Psi|H|\Phi\rangle/\langle\Psi|\Phi\rangle=E_\Phi+r_\Phi h/s\). \(s\ne0\)가 필요하다. 정확한 고유상태이면 정확한 고유값이다. |
| 크기 측정과 부호 | p.5 식(4), p.11 식(6)–(7): **같은 대칭 부문의 최저 고유상태**이면 보정이 비양수이므로 \(E_{ME}=E_\Phi-r_\Phi\sqrt{p_\Lambda/p_\Phi}\). 임의의 들뜬상태·근사상태까지 부호 보장을 일반화하면 안 된다. |
| 수백 샷 | §2.4, Fig.6(d), p.13: **(6,6), \(R_x\), 기준상태 8 determinants**, 최적 배분의 이상적 분산 추정에서 약 400 CU 샷/1.6 mHa. 약 100배의 분모는 **단일 determinant + classical shadows**(약 40,000샷), 약 1700배는 해당 grouped PA(694,194샷)다. |
| 실제 (10,10) | §2.5, Table 1 p.16, pp.17–18, Table S8 p.75: 구조당 **제출** 10,000샷(기준 2,000+잔차 8,000), 개별 에너지 표준오차 1.66–1.73 mHa. 후선택 전 분모다. |
| 50큐비트 | Table 1; Methods §4.5.2 p.27: 데이터 20+MBPC 보조 30. 활성공간 확대를 뜻하지 않는다. CPC는 총 22큐비트다. |
| PA 비교 | §S4.2/Table S7 p.61: (10,10) \(R_x\) 3,754,694, \(R_0\) 2,522,182샷. CASCI 분산의 이상적 추정이며 장치 오류는 미포함이다. |
| 정밀도와 편향 | p.18/Fig.8: 표준오차와 CASCI 중심값 편차는 별개다. 보고된 개별 편차 0.5–13 mHa, 차이 편차 0.2–9 mHa. parity check는 Helios-1 최종 차이를 일관되게 개선하지 못했다. |
| 화학적 결론 | §2.2 p.6/Table S6 p.50, Discussion p.19: 활성공간·용매·경로·핵동역학 등의 미수렴. 수렴한 반응속도나 양자우위 입증은 아니다. |

DQB 판정: 주요 조건을 이미 올바르게 구분했다. 기사로 확장할 때 ‘약 100배’의 분모에 **classical shadows**를 명시하고 ‘수백 샷’에 **(6,6) 이상적 조건**을 붙이면 더 정확하다. DQB의 ‘중앙값 편향’은 통계적 median으로 오해할 수 있어 **추정 중심값의 편차** 또는 **체계적 편향**으로 다듬는 편이 좋다.

## 2. SVD-THC: 201배의 분모와 큐비트·active-volume 비용

원문: [Cortes et al., arXiv:2610.25968v1](https://arxiv.org/abs/2610.25968v1), [HTML](https://arxiv.org/html/2610.25968v1), [PDF](https://arxiv.org/pdf/2610.25968v1). 프리프린트. 실행 수준은 고전 분해·회로 자원 추정이다.

| 확인 항목 | 원문 위치·판정 |
|---|---|
| 0.6 mHa | §V.B, p.18 식(41): 압축·비트 절단으로 생기는 **CCSD 상관에너지 차이**, 비압축 Hamiltonian의 CCSD와 비교한다. 정확한 물리 에너지의 오차 보장은 아니다. QPE 해상도 1 mHa와 별도다. |
| 모델 범위 | §V.A pp.16–17: BCE·glycine/alanine dipeptide, STO-3G 최소기저의 개념검증이다. |
| 35–201배 | §VI.B, Tables IV–VII pp.27–28: energy-thresholding의 Toffoli-optimal SVD-THC 대 **sliced-THC**. 실제 실행시간이나 물리 큐비트 절감률이 아니다. |
| 큐비트 교환 | Table VII p.28: alanine 5,184구조에서 sliced 1,191큐비트 대 SVD 8,498큐비트로 **200.6배**. qubit-comparable 1,330큐비트에서는 **108.0배**다. |
| 다른 비용 지표 | p.27: Toffoli-optimal에서 active-volume 이득은 glycine **17.6배**, alanine **22.1배**다. Clifford 데이터 로딩이 Toffoli 수에 충분히 드러나지 않는다. |
| 강한 비교 기준 | Appendix C pp.38–40/Table VIII: 독립적인 구조별 QPE 대비 10.1–60.2배. QPE와 역회로의 횟수, Jacobi–Anger 이진 스케줄의 반올림까지 함께 제시해야 한다. |
| 576배 격자 | §VI.B pp.26–28: 구조 수 9→5,184의 세분화에서도 Toffoli-optimal 비용 변화 ≤12%. 분자 크기·화학적 다양성 증가의 보편적 스케일 법칙은 아니다. |
| 상각과 미검증 | Table VII/§VII pp.28–31: 9구조에서 0.39배로 불리하다. 고차원 고전 전처리·불규칙 conformer·반응경로 확장은 남은 과제다. |

DQB 판정: 장치 실험과 논리 추정, sliced 비교와 sequential QPE 비교를 이미 구별했다. 리뷰에는 **201배에서 8,498큐비트, active volume은 22.1배**를 나란히 넣어 ‘최대’의 조건을 드러내면 독자 가치가 커진다.

## 게재 기획 제안

우선안: **「분자 에너지 차이를 계산하는 두 비용: 양자화학의 측정과 데이터 로딩」**. 한 분자·한 구조의 에너지보다 화학적으로 필요한 작은 차이를 얻는 과정에서 어디에 비용이 남는지 묻는다. 현재 장치의 측정 개선을 중심 사례로 두고, 앙상블 압축을 장기적 비교 사례로 붙인다. 두 절감률은 곱하지 않는다.

1. 작은 에너지 차이가 반응속도·구조 순위에 미치는 실제 문제로 시작한다.
2. 기준·잔차 overlap 비율이 Hamiltonian 항 측정을 대신하는 원리를 설명한다. 부호·분모 조건을 그림에 표시한다.
3. ‘400샷 이상적 추정’과 ‘10,000 제출샷 실제 장치’를 같은 성능표의 다른 조건으로 보여준다. 정밀도·편향을 분리한다.
4. 여러 구조의 공통 전자 적분을 공유하는 SVD-THC로 연결하고, 201배/108배/22.1배가 답하는 질문을 비교한다.
5. 기준상태 생성·회로 합성·후선택·고전 전처리까지 포함한 다음 평가를 제안한다.

대안 단독 기사: **「201배 줄어든 게이트 뒤에 남은 비용: 분자 앙상블 압축의 자원 회계」**. 수치 분모를 설명하는 짧은 분석물에 적합하다.

OLED·재료 적용은 **리뷰의 후속 제안**으로만 쓴다. 두 논문에 OLED emitter, 고체·표면 촉매, 재료 합성·소자 성능의 검증은 없다. 비틀림 좌표에서 공유 구조를 얻을지, 강한 상관·들뜬상태에서 기준 overlap과 부호 조건을 유지할지부터 시험해야 한다. 성능 향상을 주장하려면 CASSCF/NEVPT2·selected CI 등 고전 기준과 같은 정확도에서 총시간·메모리·전처리·받아들인 샷 비율을 비교해야 한다.

상태: **게재 가치 있음 / 원고 작성 전 기획**. 표지 제작·웹 게재는 이 노트의 작업 범위에 포함하지 않았다.
