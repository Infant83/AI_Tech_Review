- 이번 패키지에서는 브라우저 기반 GPT 실행 대신, 동일 요구사항을 충족하는 정규화 프롬프트를 직접 작성했다.

  - 공개 기사와 1차 자료를 중심으로 source-bound research를 바로 진행하는 편이 더 안정적이었기 때문이다.

## Prompt

다음 주제에 대해 2026년 4월 기준의 최신 공개 자료와 1차 자료를 바탕으로 심층 리서치를 수행하라.

### 주제

MIT Technology Review Korea가 2026년 4월 공개한 `지금 AI 분야에서 주목해야 할 10대 키워드`를 기반으로, 각 키워드가 실제로 무엇을 의미하는지, 왜 지금 중요해졌는지, 앞으로 기술 조직과 기업, 연구팀, 정책/거버넌스 조직이 무엇을 준비해야 하는지를 재정리한다.

### 분석 대상 키워드

1. 휴머노이드 로봇 데이터
2. LLMs+
3. AI로 더 교묘해진 사기 수법
4. AI 불안/반발
5. 월드 모델
6. 새로운 작전실
7. 무기화된 딥페이크
8. 에이전트 오케스트레이션
9. 중국의 오픈소스 전략
10. AI 과학자

### 대상 독자

- 기술 전략 담당자
- 엔지니어링 리더
- 연구개발 조직
- AI 거버넌스/보안 담당자
- 경영진 보고자료를 준비하는 실무자

### 핵심 질문

1. 이 키워드는 실제로 어떤 기술적 전환 또는 산업적 신호를 가리키는가?
2. 2024년의 논점과 비교할 때 2025~2026년에 무엇이 달라졌는가?
3. 각 키워드에서 `이미 확인된 것`과 `아직 과장/실험/초기 단계인 것`은 무엇인가?
4. 이 흐름이 조직의 데이터, 제품, 보안, 운영, 연구 방식에 어떤 구조적 변화를 요구하는가?
5. 향후 6개월, 12개월, 24개월 단위로 무엇을 먼저 준비해야 하는가?

### 소스 우선순위

반드시 1차 자료 중심으로 검증하라.

1. 공식 연구 블로그
2. 공식 문서 / API 문서
3. 연구 논문 / 모델 카드 / GitHub repo
4. 정부기관 / 규제기관 / 표준기관 문서
5. MIT Technology Review 기사

### 산출물 요구

다음을 포함한 한국어 리서치 결과를 작성하라.

1. 1페이지 요약
2. 키워드별 `confirmed / interpretation / open question`
3. 키워드별 전략적 의미와 준비 포인트
4. 공통 구조 변화 3~5개
5. 30-90일, 3-6개월, 6-12개월 행동 제안
6. 외부 참고 링크 모음

### 작성 원칙

- 상대 표현 대신 정확한 날짜를 쓰라.
- hype를 제거하고 기술적 실재를 분리하라.
- `가능하다`와 `이미 되고 있다`를 구분하라.
- 모델 성능 자체보다 `시스템`, `데이터`, `운영`, `보안`, `정책`, `공급망` 관점까지 확장하라.
- AI 불안/반발과 같은 사회적 신호를 단순 감정이 아니라 실제 배포 리스크로 해석하라.
- 중국 오픈소스 전략은 단순 성능 비교가 아니라 생태계 점유, 개발자 채택, 지정학적 의존성 측면에서 분석하라.
- AI 과학자는 완전 대체가 아닌 `문헌 탐색`, `가설 생성`, `실험 설계`, `분석 자동화` 등 기능 단위로 분해해서 평가하라.
