# 거울상 분자의 작은 불균형을 키우는 화학

2026-11-02 · AI Tech Review Letters · AI for Science

2026년 노벨 화학상의 비선형 효과와 비대칭 자가촉매를 중심으로, 조성의 작은 편향이 반응망에서 커지는 이유를 설명한다. 카강·소아이 연구에서 출발해 촉매 활성종의 후속 연구와 계산·기계학습을 살피고, 말미에 In/Si(111) 전하밀도파의 원편광 전이 선택성과 VASPBERRY를 연결한다.

## 중심 비교와 이력 연결

리간드·활성 복합체·생성물의 ee는 각각의 집단을 분모로 한다. 이상적 짝지음 모형은 리간드 75:25에서 활성 집단 90:10을 설명하며, 실제 DAIB 실험의 15% ee→95% ee와 구별한다. 2003년의 약 0.00005%→99.5% 초과·세 주기는 정량 혼합으로 준비한 초기 편향과 함께 설명한다. Frank형 최소 반응망은 리뷰의 교육 계산이다.

책임 편집자가 공동 교신저자로 참여한 PRL 128, 046401 (2022)과 선행 PRB 102, 121408(R) (2020)을 소개한다. 고체 절의 대상은 전자 운동량별 원편광 전이 선택성이며, 원편광 냉각을 이용한 도메인 선택은 해당 논문의 후속 제안이다. VASPBERRY 1.6.6의 주 개발·유지관리와 원편광 이색성 기능의 기여를 저자 문서에 맞춰 기록한다.

## 실제 역할

- root: 한국어 집필, 계산·기계학습 문헌 검토, 표지 기획·생성, 편집 및 게시 통합.
- dqb_fermiscope: 화학 원전·지표·서지와 한국어·영어의 독립 과학·문맥 감수.
- cuantico_source: 공개 연구 이력, 고체 광학·코드 기여 조사와 고체 원고·정의 감수.
- journal_dataset: 영어 전문 번역 및 한영 논증·조건·서지 대응 검토.
- agent_standards: 교육 도식·수치 검산, 글꼴·HTML/PDF 제작과 출력 검수.

작성 시스템은 OpenAI Codex이고 정확한 작성 모델 식별자는 미보존이다. 주제와 공개 연구 이력의 연결은 편집자가 지정했으며, 전체 원고 감수는 AI 에이전트가 수행한다. 실제 문장 단위 사람 검토와 독자 이해도 평가는 별도 기록이 있을 때 명시한다.

## 제작과 공개 범위

각 도식은 출처와 모형 가정을 해당 캡션에 둔다. 생성형 표지는 개념 일러스트이며 정량·반응식·전이 선택성은 코드 도식이 설명한다. 공개 기사에는 최종 한영 HTML·CSS·표지·명시한 SVG·PDF를 허용 목록으로 복사한다. 수집 원문·메일·상세 감사·QA 화면과 내부 경로는 공개 배포에 넣지 않는다.

다시 만들기는 artifacts의 build_figures.py·build_fonts.py·build_review.mjs·build_pdf.py를 사용한다. PDF 제작 계약에 따른 작업 시작 기록을 먼저 수행하고, 최종 모든 페이지와 1440/390px 출력을 검수한다. 공개 사이트 등록은 scripts/publish_public_site.py와 scripts/hub_summaries_en.json을 사용한다.

## 검증과 발행 기록

한영 PDF 전 19쪽,12개 PC·모바일 SVG와1440/390px 화면을 실제 검수했다.14개 APS 참고문헌과22개 인용 그룹,글꼴·메타데이터·대체텍스트·링크를 대조했다. 관련 87개 회귀검사가 통과했고 공개 사이트 1692개 파일 검사 오류 0이었다.52개 리뷰·103개 아카이브 문서·57개 독자용 기사로 등록했으며, 기존 1489개 리뷰 파일·51개 리뷰 기록·101개 아카이브 기록을 보존했다. 각 언어 PDF의 제작본·원본 아카이브·공개 기사·공개 아카이브 4사본이 같다. 정확한 해시와 제작 범위는 [제작 manifest](figure-manifest.json)에 남겼다. 실서비스 배포 결과는 확인 뒤 추가한다.
