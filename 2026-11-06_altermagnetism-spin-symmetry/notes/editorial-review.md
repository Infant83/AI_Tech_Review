# 작성과 검토 기록

2026-11-06. 요청 범위는 개념·원리·효용·계산·실험·선구적 연구를 연결하는 심층 리뷰와 일러스트 작성이다. 한영 읽기 화면과 PDF를 로컬 검토본으로 마련했다.

## 논지와 기존 글

전체 자화의 보상과 운동량별 스핀 분리가 공존하는 이유를 회전 대칭으로 설명한다. 100 K 스핀 주입의 실제 장면으로 시작해 정의·원리·작은 행렬·3차원 재료·전자와 집단 들뜸의 측정·계산의 난제·소자 조건으로 진행한다. 앞선 플랫폼·양자 알고리즘 기획을 이 주제로 바꾸지 않았으며, 기존 ReAg₂Cl₆의 120도 비공선·SOC 메커니즘과 구별했다.

## 원문과 서지

altermagnet_pioneers는 선행 계산과 2021년 프리프린트/2022년 분류, MnTe·CrSb·RuO₂와 최신 실험을 검토하고 26개 인용 키의 서지를 정리했다. altermagnet_computation은 자기 바닥상태와 대칭 허용성, DFT+U·DMFT·SOC·Wannier와 수송의 관계를 검토했다. altermagnet_repo_evidence는 측정·소자 조건과 기존 글 중복을 확인하고 영어 전문을 작성했다. root가 한국어 집필·논지 통합·표지·수식·참고문헌 출력과 조판을 맡았다.

Science 최종 전문 등 접근이 제한된 자료는 정식 초록·서지와 공개 저자 원고로 대조했다. Jost의 [저자 원고 v2](https://arxiv.org/html/2501.17380v2), Faure의 [저자 원고 v1](https://arxiv.org/html/2509.07087v1), Mencos의 [저자 원고 v2](https://arxiv.org/html/2512.17427v2), Li의 [저자 원고 v1](https://arxiv.org/abs/2607.07299v1)을 확인 범위에 포함한다. 정식 논문의 DOI·서지는 참고문헌에 사용하고, 원고에서 읽은 세부 조건은 본문의 자료 판본 표현으로 구별했다.

## 독립 감수와 반영

- 독립 사실 감수에서 SOC가 고정하는 방향을 순자화축 대신 Néel 질서의 방향으로 고쳤다. CrSb 양자진동의 저온·강자장 조건을 한영에 반영했다.
- 전자 밴드의 관측, 직접 스핀 분석, 도메인 영상과 마그논 편극을 서로 다른 측정으로 썼다. Jost 문장은 분해된 두 에너지 봉우리를 가정하지 않고 들뜸 에너지·손잡이성을 설명하도록 다듬었다.
- RuO₂의 반증을 시료·분석에 한정하고 2.7 nm 변형 초박막 보고와 구별했다. Mn₅Si₃ 박막의 자기구조 해석과 직접 측정한 스핀 주입 신호도 구별했다.
- 영어 번역에서 인용 순서·수식·측정 조건을 별도 대조했다. 부분격자 혼합 가지의 명칭, NxN 격자, 저온·강자장 조건을 맞췄다.
- root의 문맥 감수에서는 그림을 읽는 위치를 화면의 ‘오른쪽’ 대신 패널 C의 X·Y 방향으로 지정했다. 그림 속 유효 모형 문구는 SOC·격자상수·에너지 단위를 설명하도록 다듬었다. 작성·검증 정보는 하단에 유지했다.
- 표지는 실제로 본 최근 네 표지와 비교해 새 구도·매체를 정했다. 두 윤곽의 네 교차 방향과 교대 국소 모티프, 축소·흑백을 대조했다. 생성 이미지의 미세 면들은 개념 표현이며 수치의 세기로 사용하지 않는다.

## 계산과 출력

수치 계산은 128·256·512 주기 격자의 Fermi 점유, 회전·반전·절점, 1,024개 운동량의 부분격자 고유값과 공변성을 확인했다. 별도 검토자가 제작 코드를 가져오지 않고 표준 라이브러리와 해석적인 2×2 근으로 독립 검산했다. 실제 재료의 DFT·DMFT나 실험 재현과 구별한다.

최초 PDF 전체 페이지의 한영 contact sheet를 확인했다. 화면용 가로 도표의 축·범례가 인쇄에서 작아지는 문제를 찾아 인쇄용 배치를 별도로 제작했다. 최종 PDF·웹·모바일·참조 링크·원본 자산·호스트 경로 주석 검사는 `artifacts/output-validation.json` 및 최종 출력 기록에 남긴다. 실제 사람의 문장별 승인·독자 이해도 실험은 수행되지 않았다.

## 최종 출력 확인

최종 국문 12쪽·영문 14쪽의 전체 페이지 contact sheet와 인쇄용 핵심 그림을 확인했다. 인쇄용 도표는 위 두 지도·아래 밴드, 또는 2×2 절차 배치로 확대했고 축·범례·피드백이 겹치지 않는다. 390px 화면의 가로 넘침·누락 이미지·브라우저 오류는 없었다. 한영 수식 49개와 최초 인용순·26개 서지, 국소 링크·PDF 공개 외부 링크·호스트 경로 제외 검사가 통과했다. 최종 파일 해시는 output-validation.json에 있다. 웹은 벡터 확대 링크와 모바일 그림, PDF는 전용 인쇄 그림을 사용한다.

이번 실제 산출물의 과학·설명·문맥·한영·시각·구조 검토를 수행한 기록이며, 사이트 게시나 사람 독자 평가의 기록으로 확대하지 않는다.
