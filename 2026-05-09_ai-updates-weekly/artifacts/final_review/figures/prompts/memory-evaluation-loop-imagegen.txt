Calm magazine-style process infographic for a Korean AI technology review.

Theme: long-running AI agent work needs selected memory and evaluation loops.

Visual concept: a clean workbench with five objects arranged as a loop:
- an agent work engine
- a memory ledger with a few highlighted selected notes
- an evaluation checklist
- a retry loop track for incomplete results
- a human approval stamp at the end

Show selected notes moving into the work engine, output going to the checklist, and only incomplete items returning through a retry path. The key idea is not to show "more memory"; it is to show selected memory, evaluation criteria, retry, and approval as a working structure around the agent.

Composition: 16:9, simple loop with four or five objects, clear separation, few arrows, lots of whitespace for Korean labels. It should be more readable and less slide-like than a standard process diagram.

Style: KIAS Horizon or Quanta-like science illustration, warm off-white paper, muted teal, amber, soft blue, ink-gray linework, refined editorial feel, no corporate presentation style.

Avoid: readable text, fake UI, many tiny icons, brain imagery, neural network cloud, cluttered arrows, decorative blobs.
