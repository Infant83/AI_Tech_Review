# Skywork Visual Prompt v1

## Goal

Create a one-slide editorial infographic that can be exported and used as a candidate figure for a Korean AI technology review.

## Audience

Korean technical and governance readers who understand AI agents but need a clear visual explanation of why harness design is becoming important.

## Slide Message

에이전트는 모델만으로 실무 도구가 되지 않는다. 권한, connector, memory, 검증, 승인, 병합과 되돌리기까지 갖춘 하네스 위에서 실제 업무 흐름으로 들어온다.

## Required Visual Structure

Use one clean slide, 16:9.

Center:
- `AI Agent / Model Core`
- show it as a work engine or core module, not a robot face.

Outer ring or surrounding workbench:
- Permission / 권한
- Connectors / 업무 데이터 연결
- Memory / 작업 기억
- Evaluation / 테스트와 평가
- Approval / 사람 검토와 승인
- Merge & Rollback / 병합과 되돌리기

Bottom:
- Work outcomes: documents, code changes, decisions, audit trail.

Side evidence lane:
- Research: Natural-Language Agent Harnesses, Meta-Harness
- Enterprise: Anthropic finance agents, Claude Managed Agents, xAI Grok connectors
- Open source: DeepSeek-TUI, Hermes Agent, OpenSwarm, InsForge
- Developer workflow: Zed, Jujutsu, Mergiraf, Weave

## Style

- Publication-quality technology infographic, closer to a clean science magazine figure than a sales slide.
- White or warm-paper background, restrained color palette, dark green/teal accent.
- Use simple icons and clean arrows.
- Avoid stock-like AI cloud, generic neural network background, robot faces, fake logos, excessive gradients.
- Korean text is acceptable, but keep labels short and readable.
- If Korean labels become crowded, use short English labels with Korean explanatory caption space.

## Output Need

Make the slide visually usable as a single figure inside a web article. The important thing is not decorative beauty but whether a reader can immediately understand that the competitive layer has moved toward agent harness design.
