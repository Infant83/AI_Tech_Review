# Skywork Image Prompt Pack

## 사용 원칙

Skywork Image는 정보와 개념을 설명하는 editorial infographic 후보를 만들 때 사용합니다. `imagegen`은 분위기와 주제 장면을 여는 그림에 더 적합하고, Skywork는 한 컷 안에 구조와 흐름을 담는 그림에 더 적합합니다.

한국어 장문 라벨은 이미지 안에 넣지 않습니다. 필요한 라벨은 HTML/SVG로 후처리합니다.

## 1. 인포그래픽: Harness Components

Category: `인포그래픽`

Use: `하네스는 모델 바깥에서 성능을 바꿉니다` 섹션 후보

```text
Create a 16:9 editorial infographic for a Korean technology review.

One-sentence message:
An AI agent becomes useful at work only when the model core is surrounded by harness components: context, tools, memory, permissions, evaluation, approval, merge, rollback, and audit trail.

Visual structure:
- Center: a compact model core represented as a calm work engine, not a robot face.
- Around it: separate modules shown as physical workbench objects: access card, connector cables, memory notebook, test checklist, approval stamp, merge rail, rollback lever, audit log.
- Bottom: clean work output: document, code patch, decision memo.

Style:
Quanta Magazine style editorial technology infographic, warm white background, refined line art, restrained teal and amber accents, high resolution, enough whitespace.

Text policy:
No long text, no Korean sentences, no fake UI text. If labels are needed, use only short placeholder-free icons. Korean labels will be added later in HTML/SVG.

Avoid:
generic AI cloud, glowing brain, robot face, fake logos, dense slide layout, stock-photo look.
```

## 2. 포스터: Agent Needs a Workbench

Category: `포스터`

Use: 도입부 이후 또는 섹션 opener 후보

```text
Create a 16:9 poster-style editorial illustration for a technology review.

One-sentence message:
The important shift is not just a smarter AI model, but the workbench that lets the model safely use files, tools, permissions, checks, and approvals.

Scene:
A central AI work engine sits on a clean desk. Around it are a file cabinet, access badge, calendar connector, terminal window, test checklist, approval stamp, and rollback track. The scene should feel like a professional workbench, not a fantasy machine.

Composition:
The eye should first see the central workbench, then the surrounding control objects. Leave calm negative space for article layout.

Style:
Sophisticated science-magazine illustration, soft paper texture, clean lines, subtle depth, editorial but not corporate slide art.

Text policy:
No readable text, no logos, no fake labels. The caption will explain the concept.
```

## 3. 인포그래픽: Enterprise Permission and Approval Loop

Category: `인포그래픽`

Use: `기업용 AI는 권한과 승인 체계를 더 중요하게 다루기 시작했습니다` 섹션 후보

```text
Create a 16:9 editorial infographic explaining enterprise AI governance workflow.

One-sentence message:
Enterprise AI becomes operational when data access, permission scope, draft output, human approval, audit trail, and rollback are designed together.

Visual flow:
Left to right, with calm visual hierarchy:
1. business data vault and document sources
2. permission gate and policy card
3. AI draft workspace
4. human review and approval checkpoint
5. final document and audit log

Style:
Clear editorial infographic, professional but warm, thin line work, small accent colors, high readability.

Use icons rather than text wherever possible. No long labels. No fake company logos.

Avoid:
security fear imagery, padlock overload, cyberpunk style, crowded dashboard.
```
