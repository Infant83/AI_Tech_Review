# Faryad QML 실습 보충

기존 「퀀텀 머신러닝: 데이터, 학습과 양자 우위의 조건」 18강의 독립 보충자료다. 본편은 CMU 17-620 공개 실라버스에서 출발한 학습서이며, 이번 보충은 Muhammad Faryad의 공개 알고리즘 노트북과 QAOA 논문·코드·데이터를 연결한다. 본편의 강사·실라버스나 원래 근거 기준일을 바꾸지 않는다.

책임 편집 김현중 · AI 보조 OpenAI Codex · 이번 확인일 2026-11-10. 원고 전체의 사람 감수는 수행하지 않았다.

## 공개 구성과 연결

- 보충 PDF 8쪽: `dist/supplement.pdf`. 본편 147쪽 PDF와 합치거나 교체하지 않는다.
- 별도 PDF·필기 ID: `2026-11-10-faryad-qml-supplement-ko-v1`.
- 웹 학습 안내: `lectures/quantum-machine-learning/supplements/faryad-qml-v1/`.
- 코스 목차의 `#course-supplements`와 07·10·11·12·17강에서 이어 읽는다. 본편의 기존 과학 섹션과 수식은 그대로 보존한다.
- 노트북 연결표 CSV와 공개 실습 자료 ZIP을 제공한다. ZIP은 원저자 노트북14개·공개 JSON6개와 라이선스를 보존하고, 자체 검산·출처·공개판 PDF·웹 안내·해시 목록을 구별한다.

`scripts/document_archive_site.py`의 명시적 bundle 목록과 부모 시리즈의 `supplement-registry.json`을 사용한다. 새로운 PDF는 `archive/entries/`에 독립 등록하고, 부모의 기존 ID·날짜·PDF·필기 연결은 유지한다. 보충자료는 렉처 목록에서 부모 아래에 표시하며 전체 자료 아카이브에서는 별도 PDF로 찾을 수 있다.

## 확인과 편집 범위

faryad_pdf_review는 공개판에서 전달 경위와 준비 상태 문구·메타데이터를 정리하고, 편집 영역 밖의 문자·픽셀 동일성 및 전체8쪽 조판·목적지·링크를 검수했다. `reports/pdf-publication-qa.json`이 해당 기록이다. 원문과 수집 기록·QA 화면은 공개 자산에서 제외한다.

faryad_science_package는 공개 커밋의 노트북·데이터·라이선스를 대조하고 검토한 오프라인 검산 두 개를 재실행했다. 실제 NumPy는2.0.2였으며 원시 장부도 별도 합산했다. 193작업, 추정 QPU2016.856662초, 측정 제출–결과 wall time8575.527433초다. QPU 계측 fallback과 95% 문턱의 분모, IPE·Trotter·H₂ 정오표를 원문과 대조했다. 원저자 노트북 전체·QPU·교재 본문 전체를 재실행·열람한 기록은 아니다. H₂ sign-trap 설명과 저장 출력의 불일치, 확인 커밋에서 빠진 원저자 재현 스크립트의 제한을 유지한다.

root는 공개 등록·부모 연결·한영 목록·독립 후보와 배포를 통합한다. 편집부(AEDAUT)가 자료의 의미와 공개 범위를 검토하며 운영팀(ADOPT)의 기존 게시·보존 도구를 사용한다. 별도 서비스·유료 계약·장치 실행을 추가하지 않는다.

## 재생성과 게시

`artifacts/prepare_public.py`와 `artifacts/build_supplement.py`는 명시적으로 받은 입력 판본의 해시를 먼저 확인한다. 개인 원본 경로를 소스에 넣지 않는다. 공개판을 다시 만들 때에는 PDF 검수·공개 ZIP과 해시 목록을 함께 갱신하고, 부모의 명시적 사본5개와 등록부를 대조한다. 원래 QML 통합 HTML·PDF를 재생성하는 명령은 이 보충 발행에 사용하지 않는다.

`PUBLICATION_WORKFLOW.md`에 따라 새 독립 후보를 만들고 실제 배포 스냅샷과 비교한다. 보충 연결로 바뀐 코스 목차·관련 강의의 외부 연결·분할 등록부의 정확한 이전/이후 해시를 기록한다. 기존 본문 섹션·원 PDF·개인 필기 ID, 한영 목록·모바일·다운로드·필기 링크를 확인한 뒤 기존 승인된 GitHub 배포 경로를 사용한다.
