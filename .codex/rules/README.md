# AI_Tech_Review Rules Index

이 디렉터리는 AI_Tech_Review 작업공간의 로컬 하네스 규칙을 둔다. `AGENTS.md`가 전체 운영 계약이라면, 이 디렉터리는 반복해서 참조할 세부 규격이다.

## Files

- `writing-harness.md`: 김현중식 한국어 기술 리뷰 문체, 금지 표현, 문장 전개 방식
- `visuals-and-image-generation.md`: figure, illustration, generated image, caption, manifest 규칙
- `skills-and-verification.md`: 리서치, 렌더링, Obsidian/OpenProject/Skywork 검증 절차

## Operating Principle

규칙은 고정 문체 템플릿이 아니라 점진적으로 다듬는 하네스다. 사용자가 문체, 그림 설명, 캡션, 강조 방식, 리포트 구조를 교정하면 그 교정을 다음 작업에서도 재사용할 수 있도록 이 디렉터리에 반영한다.

`final_review`는 파일명과 워크플로 이름일 뿐이다. 독자가 보는 제목과 본문에서는 `기술 리뷰`, `기술동향 리포트`, `도입 검토 리포트`처럼 주제에 맞는 이름을 쓴다.
