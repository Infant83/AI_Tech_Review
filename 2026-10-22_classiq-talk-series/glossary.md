# 한영 용어집

정의는 이 노트에서 사용하는 의미다. 제품 이름, 알고리즘의 개념, 성능 지표를 구분해 읽는다.

| 용어 | 뜻과 구별 |
|---|---|
| 양자 모델 quantum model | 수행할 연산·데이터·제약을 기술한 표현. 특정 장치에서 실행할 게이트 열과 구별한다. |
| Qmod | Classiq의 양자 모델링 언어. Python을 통한 표현과 native 표현이 있다. |
| 합성 synthesis | 모델에서 조건을 만족하는 회로 구현을 만드는 과정. 최종 결과의 업무 적합성을 보증하는 절차는 아니다. |
| 컴파일 compilation | 프로그램을 실행 가능한 표현으로 바꾸는 넓은 과정. 합성·최적화·타깃 변환이 포함될 수 있다. |
| 트랜스파일 transpilation | 회로를 타깃의 게이트 집합과 연결성에 맞춰 변환하는 과정. 산정한 자원이 어느 단계의 값인지 확인한다. |
| 양자 커널 quantum kernel | 호스트 프로그램에서 호출하는 양자 계산 단위. 여기서는 CUDA-Q의 실행 코드 단위를 뜻한다. 머신러닝의 유사도 함수인 kernel과 구별한다. |
| CUDA-Q | 양자 커널과 고전 연산을 함께 다루는 NVIDIA의 프로그래밍 플랫폼. 실행 타깃으로 CPU·GPU 시뮬레이터와 지원되는 QPU 등을 사용한다. |
| JIT just-in-time compilation | 실제 사용 시점에 코드를 컴파일하는 방식. 반복 호출 때 재사용하는지에 따라 총시간이 달라진다. |
| 타깃 target / 백엔드 backend | 프로그램을 실행하거나 변환하는 대상. 이름에 quantum이 있어도 시뮬레이터일 수 있다. |
| QPU quantum processing unit | 물리적 양자 프로세서. CPU나 GPU에서 회로를 계산하는 시뮬레이터와 구별한다. |
| 상태벡터 state vector | 순수 양자 상태의 복소 진폭 표현. 밀집 표현에는 큐비트 수에 지수적으로 증가하는 저장공간이 든다. |
| 샷 shot | 동일한 회로 준비와 측정을 반복하는 통계적 시행 단위. 하나의 샷이 항상 원격 작업 하나와 같은 뜻은 아니다. |
| 샘플링 sampling | 측정 분포에서 결과를 뽑는 과정. 기저별 정확한 확률을 전부 읽는 것과 다르다. |
| 관측량 observable | 측정할 물리량에 대응하는 에르미트 연산자. 기대값은 상태와 관측량을 함께 정해야 정의된다. |
| 기대값 expectation value | 확률로 가중한 평균. 한 번 측정한 값이나 가장 빈번한 값과 다르다. |
| 후처리 post-processing | 비트열 디코딩, 확률·비용·신뢰구간 계산 등 실행 결과를 해석하는 과정. |
| 회로 폭 circuit width | 해당 회로에 사용되는 큐비트 수. 입력 변수 수에 임시 공간이 더해질 수 있다. |
| 회로 깊이 circuit depth | 병렬 가능한 연산을 묶었을 때의 순차 단계 수. 전체 게이트 수와 다르다. |
| 2큐비트 게이트 two-qubit gate | 두 큐비트에 작용하는 게이트. 타깃에 따라 CX·CZ 등의 네이티브 구현 비용이 다르다. |
| 보조 큐비트 ancilla | 중간 계산, 조건 표시, 추정 등을 돕는 공간. 알고리즘의 출력 변수와 구별한다. |
| 가역 연산 reversible computation | 입력을 복구할 수 있는 연산. 고전 함수를 양자 회로에 넣을 때 정보 보존을 고려해야 한다. |
| 언컴퓨테이션 uncomputation | 중간 계산을 역연산으로 풀어 보조 공간을 정리하는 일. 중간 비트를 임의로 지우는 것과 다르다. |
| 오라클 oracle | 조건 검사나 함수 평가를 수행하는 계산 단위. 질의 복잡도에서는 그 내부 비용을 따로 계산한다. |
| 위상 오라클 phase oracle | 조건에 따라 입력 진폭의 위상에 부호 등을 붙이는 연산. 그것만으로 측정 확률이 바뀌는 것은 아니다. |
| 진폭 증폭 amplitude amplification | 좋은 결과가 나올 진폭을 회전으로 키우는 절차. 반복을 지나치게 하면 성공확률이 다시 줄 수 있다. |
| Grover 반복 Grover iterate | 좋은 상태 표시와 준비 상태에 대한 반사를 조합하는 증폭 연산. |
| QAE quantum amplitude estimation | 준비 회로가 만드는 성공확률 또는 그 진폭에 관한 정보를 추정하는 알고리즘 계열. |
| IQAE iterative QAE | 위상추정 레지스터 대신 반복 증폭과 측정·고전적 갱신을 사용하는 QAE 방식. 깊은 회로 비용이 사라지는 것은 아니다. |
| QPE quantum phase estimation | 유니터리의 고유위상을 추정하는 알고리즘. IQAE의 I와 구별한다. |
| Monte Carlo | 확률적 표본으로 평균 등을 근사하는 방법. 유한 분산의 독립 표본 평균은 전형적으로 표준오차가 표본 수의 제곱근에 반비례한다. |
| 표준오차 standard error | 추정량의 표준편차. 개별 데이터 값의 표준편차와 다르다. |
| 신뢰구간 confidence interval | 반복 실험에서 정해진 포괄 확률을 갖도록 구성한 구간. 한 번 얻은 구간과 정확도 목표를 혼동하지 않는다. |
| payoff | 계약 조건과 만기 가격·경로로 정해지는 지급액. 할인 전 payoff와 현재 가격을 구별한다. |
| strike 행사가 | 옵션 계약에서 정한 기준 가격. 입력 확률분포의 평균과 다르다. |
| European option | 정한 만기 시점에 행사하는 옵션. 만기 가격만으로 payoff가 정의되는 대표 예가 European call이다. |
| Asian option | 기간 중 가격 평균 등 경로에 의존하는 옵션. 만기 가격 하나를 표현하는 회로만으로 충분하지 않다. |
| 목적함수 objective | 최적화에서 줄이거나 키우려는 수학적 값. 단위·부호·계수의 정의가 필요하다. |
| 제약 constraint | 허용되는 해가 만족해야 하는 조건. 합성기의 큐비트 제약과 업무 문제의 예산 제약은 서로 다른 대상이다. |
| 벌점 penalty | 제약을 목적함수에 반영하려고 더하는 항. 계수가 작으면 위반 해가 유리해질 수 있다. |
| QUBO | quadratic unconstrained binary optimization. 이진 변수의 이차식으로 표현한 문제이며 제약은 보통 벌점 등으로 처리한다. |
| Ising 표현 | 이진 변수를 Pauli Z 연산자 등으로 옮겨 비용을 에너지로 나타내는 표현. |
| QAOA | 비용 연산과 mixer를 번갈아 적용하고 고전 최적화로 각도를 조절하는 근사 최적화 알고리즘. |
| mixer 혼합 연산자 | 탐색 상태를 바꾸는 QAOA 연산자. 단순 X mixer와 제약을 보존하는 mixer는 허용 상태가 다를 수 있다. |
| feasible 해 | 문제의 모든 제약을 만족하는 해. 목적값이 좋아도 제약을 어기면 허용 해가 아니다. |
| 최적성 간극 optimality gap | 후보 해의 비용과 기준 최적값·하한 사이의 차이. 기준값이 무엇인지 명시해야 한다. |
| 벤치마크 benchmark | 조건과 지표를 고정한 비교. 회로 합성 시간, 기대값 평가 시간, 전체 실행시간은 각각 다른 지표다. |
| Pareto trade-off | 여러 비용을 동시에 볼 때 한 비용을 더 줄이려면 다른 비용이 늘어나는 관계. 최적화 목표 한 개로 전체 우열을 정할 수 없다. |
| 양자 이점 quantum advantage | 명시한 과제·정확도·비용에서 정한 고전 기준보다 유리한 결과. GPU 시뮬레이터 가속과 구별한다. |
| 오류 완화 error mitigation | 잡음 효과를 줄이기 위한 추정·후처리 등의 기법. 오류정정 논리 큐비트를 구현한 것과 다르다. |
| 오류정정 QEC | 부호화된 정보와 syndrome 등을 이용해 오류를 제어하는 방법. 물리 큐비트와 논리 큐비트의 수는 다르다. |
| 자원 추정 resource estimation | 실행에 필요한 큐비트·게이트·주기·시간 등을 가정하에 계산하는 일. 물리 장치에서 이미 실행했다는 의미가 아니다. |
| AI skill | 에이전트가 특정 작업에 적용하는 지식과 수행 지침. 프로그램이 호출하는 실행 도구와 역할을 구별한다. |
| tool 도구 | 합성·실행·문서 조회처럼 에이전트가 호출하는 기능. 결과를 다시 검사할 책임은 남는다. |
| MCP Model Context Protocol | AI 애플리케이션과 도구·자료를 연결하는 프로토콜. 특정 양자 알고리즘이나 정확성 보증 방식의 이름은 아니다. |
| SDK software development kit | 프로그램 작성과 서비스 호출을 위한 라이브러리·인터페이스. 영상의 버전과 현재 설치 버전이 다를 수 있다. |

## 같은 단어가 다른 뜻으로 쓰일 때

금융의 risk는 수익의 분산이나 손실위험 같은 문제 정의이며, 하드웨어 오류율은 회로의 물리적 실패와 관련된다. 양자 커널을 CUDA-Q 코드 단위라는 뜻으로 쓰는 문단과, AML에서 데이터의 유사도 함수라는 뜻으로 쓰는 문단도 구분한다. “최적화”는 업무 목적함수를 푸는 QAOA, 회로 자원을 줄이는 합성, 실행 비용을 줄이는 GPU·런타임 개선을 각각 가리킬 수 있다. 무엇을 목적값으로 삼는지 문장 안에서 확인한다.
