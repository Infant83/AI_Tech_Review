# 출처 확인과 후속 대조

2026-11-24 · 편집부(AEDAUT) 기획 조사 · 원 연구의 독립 재현 전

## 제공된 링크와 원 논문

제공된 단축 링크를 일반 공개 HTTP 경로로 확인했다. 출판용 기록에는 추적 매개변수 없이 [The Matter Lab의 공개 게시물](https://www.linkedin.com/posts/the-matter-lab-uoft_aiforscience-machinelearning-computationalchemistry-activity-7530624273334407168-AV0c)을 연결한다. Article 메타데이터의 게시일은 2026-11-23 UTC다. 화면의 상대 시각과 연결 논문의 출판일은 구별했다. 게시물 전문과 댓글·수집 원문은 저장하지 않았다.

게시물이 가리킨 Perspective는 DOI **10.1088/3050-287X/aec468**이다. Crossref 공식 서지에서 Ko·Bernales·Aspuru-Guzik의 저자 순서, 제목, 학술지 *AI for Science*, 온라인 출판일 **2026-11-19**를 확인했다. 당시 권·호·쪽·논문번호는 부여되지 않았다. 링크 정보는 accepted manuscript(am)를 가리키며 CC BY 4.0 라이선스를 기록한다.

IOP 공개 HTML은 이번 HTTP 접근에서403을 반환했고 웹 도구에서도 열리지 않았다. 논문 전문·세부 표·그림을 읽은 것으로 기록하지 않는다. 공개 소개와 공식 서지로 주제를 선정하고, 과학적 사례는 공개한 별도 원 연구로 구성했다. 전문을 확보하면 Perspective가 실제로 비교한 모델·응용·불확실성 논의와 기획의 확장 부분을 대응시킨다. 새 계정이나 유료 구독·접근 보호 우회는 사용하지 않았다.

Nature의 Li–Walsh 공개 본문은 일반 HTTP로 열렸다. 응답의 쿠키 안내용 매개변수는 출처 URL에 남기지 않았다. DOI·저자·출판 정보는 Crossref와 대조했다. 검색 결과를 통해 찾은 비공식 미러와 사본은 근거로 채택하지 않았다.

### 독립 재확인 · 2026-11-25

- 제공 단축 링크는 공개 공유 URL로 이동했으며, 해당 페이지의 canonical과 `og:url`은 위에 기록한 The Matter Lab 게시물과 일치했다. 출처에는 canonical URL을 유지한다.
- Crossref에서 Perspective의 제목·세 저자·2026-11-19 출판일과 accepted manuscript 링크를 다시 확인했다. MACE-MP-0·Li–Walsh·Deng·Rensmeyer·Tahmasbi의 DOI별 정식 서지와 저자 수도 대조해 기존 목록과 일치함을 확인했다.
- Li–Walsh의 공개 본문에서 일곱 모델의 공통 기준점 표현, 전역 정렬과 국소 차이, 물리적 감독의 비교를 확인했다. 표현 정렬의 결과를 물성 정확도나 가중치의 임의 교환 가능성과 동일시하지 않는다.
- Potente v1 §2.1–2.2.1에서 LLM 기획·분기와 결정론적 수치 실행의 분리, 같은 500개 구조·모델·설정과 다섯 번 반복의 비교를 다시 읽었다. 이 비교가 확인한 것은 수동 스크립트와의 수치적 일관성이며 참조 전자계산에 대한 물성 정확도는 별도 비교다.
- RSC 공식 공개 검색 본문의 §4는 LaMnO₃에 대해 MACE-MP0 medium, PBE+U, 300→800→300 K의 150 ps 시험을 설명한다. 일부 배치가 사전학습에 포함됐어도 관심 상전이를 기술하려면 추가 검증·적응이 필요하다는 사례로 선정한다. 여기서는 결과값을 재도표하지 않았다. 집필에서는 자기질서·전자 상태·온도 경로와 기준 계산 조건을 전문 및 공개 자료에서 확인한다. 공식 코드가 가리키는 보존 판본은 [Zenodo DOI 10.5281/zenodo.18772098](https://doi.org/10.5281/zenodo.18772098)이며, 실제 실행에 앞서 파일·라이선스·판본을 다시 대조한다.

기획의 중심은 넓은 모델의 성공률을 요약하는 데서, **무엇을 재사용하고 어떤 물리적·실행적 판단을 다시 수행하는가**로 이어진다. 기존 11월 6일 리뷰가 이미 다룬 힘·MD·모델 종류·장거리 항·일반적 물성 검증은 필요한 연결만 되짚고, 모델 사이의 표현·새 계의 적응·재사용 가능한 계산 실행이라는 후속 논의를 전개한다.

## Potente의 수치와 해석 범위

본문 Table 1과 SI Table S2의 평균행이 다르다. S2에 나열된 Potente 다섯 행으로부터 단순 산술 평균을 다시 계산하면 다음과 같다.

| 항목 | S2의 다섯 행 | 행들의 산술 평균 | S2의 Avg. 행 |
|---|---|---|---|
| 토큰 비용 USD | 0.150,0.154,0.149,0.158,0.150 | 0.1522 | 0.12 |
| 총 토큰 | 26574,26851,26614,26982,26599 | 26724 | 22541 |
| 흡착열 kJ/mol | 22.40,22.56,22.30,22.94,23.77 | 22.794 | 17.21 |

비용·흡착열 평균은 본문 Table 1과 대응하지만 S2 요약행과 일치하지 않는다. 본문과 공개 출력의 판본·계산법을 대조하기 전에는 절감 배율을 새 그래프로 만들지 않는다. 두 비교군의 MLIP와 샘플링 절차가 달라 물리 정확도의 직접 비교로 해석하지 않는다는 저자의 조건도 유지한다. 토큰 비용은 전력 계측과 구별한다.

## 다음 제작에서 할 일

1. Perspective 전문의 판본과 논지를 확인해 제목·초점·인용을 대응시킨다.
2. 에너지 곡률 교육 계산을 독립 검산하고 q·k·μ·ω의 단위와 도식의 대상 대응을 확인한다.
3. 실제 모델 결과는 공개 원 데이터와 계산 조건을 확보한 뒤 선정한다. 저자 보고값의 재도표와 리뷰의 계산을 구별한다.
4. 원자·물성·워크플로의 세 설명을 각각 그림과 연결한 뒤 별도 독자 감수자가 중심 논지를 요약하게 한다.
5. 초기 학습·추가 기준 계산·검증·반복 실행·모델 호출을 포함한 비용 기준을 제안한다. 전력·탄소 절감 수치는 실제 계측이 있는 경우에만 별도로 논한다.
