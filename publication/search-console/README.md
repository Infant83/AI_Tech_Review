# Google Search Console 공개 소유권 확인 파일

이 폴더의 HTML은 Google이 사이트 공개 경로에 게시하도록 제공한 확인 파일이다. 비밀번호·API token·계정 식별정보를 넣는 폴더가 아니다.

게시기는 지정한 파일명과 원본 SHA만 허용하며 다음 빌드에서도 같은 bytes를 보존한다. 소유권 확인 뒤에도 Google이 요구하는 동안 파일을 유지한다. 임의의 `google*.html`이나 폴더 전체를 공개 복사하지 않는다.

현재 대상은 `https://infant83.io/AI_Tech_Review/` URL-prefix property다. 파일 준비·실제 HTTPS 게시·Search Console의 VERIFY 성공·사이트맵 제출·Google 색인은 각기 별도 검증 단계다. 이 확인 파일 자체는 사이트맵 URL에 넣지 않는다.
